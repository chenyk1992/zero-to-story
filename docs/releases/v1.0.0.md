# LFO 1.0.0 — breaking runtime release

LFO 1.0.0 separates creative authoring from deterministic video implementation. Creative
Skills now produce `lfo.video-execution.v1`; LFO owns asset import, backend selection,
ComfyUI execution, media normalization/QC, audio, subtitles, timeline assembly, export,
retries and recovery.

This is intentionally not compatible with the previous storyboard-driven execution entry.
Callers must adapt approved panels and assets to `VideoExecutionPackage`, validate and plan
the package, then execute it with explicit approval. Runtime commands use persistent SQLite
state, and provider output is accepted only when a durable artifact and hash are recorded.

Bundled H3 workflows support local ComfyUI T2V, I2V and R2V in horizontal and vertical
layouts. A live ComfyUI smoke test remains an environment acceptance gate for each installed
machine and workflow/model revision.
