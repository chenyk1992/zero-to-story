# LFO 1.0.0 — 单 Panel breaking runtime

LFO 1.0.0 采用极简的单 Panel 执行链。创作 Skill 交付一个已确认的
`lfo.video-execution.v1` package；每个 package 只含一个 Clip。

- 每个 Panel 作为独立的短生命周期执行单元处理，严格串行；
- `validate → execute --approved-sha256` 同步调用官方 ComfyUI/comfy-cli，`plan` 仅为可选诊断；
- 用户批准的 package 完整文件字节 SHA-256（exact file SHA-256）是唯一执行锁；
- 调用方在 `ACCEPT` 后提取真实尾帧，供需要连续首帧的下一个 Panel 使用；
- ComfyUI 或最小 QC 失败立即停止，不自动重试、不保留失败候选、不做复杂恢复；
- 所有 Panel `ACCEPT` 后只执行一次最终 `cut` assembly。

这不是旧 storyboard/shot 入口的兼容升级。旧 CLI、旧状态机、旧 production-lock/retry/recovery 语义均不属于当前公开执行协议；底层已有运行记录不由调用方读取或维护。

详细执行计划见 [`docs/plans/2026-09-05-simple-panel-execution-plan.md`](../plans/2026-09-05-simple-panel-execution-plan.md)。
