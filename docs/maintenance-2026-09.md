## 验证证据

100 个节点 / 1,000 次历史运行的隔离基准：重复解析 1,000 次降为 100 次，示例实测从 0.532 秒降为 0.074 秒。测试核对全部历史 matches_current 结果，并保留逐运行素材校验；这是合成场景，不能代替真实大型项目的全链路耗时。

当前仓库全量检查：280 通过、11 跳过（已移除源码导出专属的 2 项测试）。跳过项需要当前终端缺少的 FFmpeg/ffprobe，包含新增真实末帧集成测试；模拟测试已覆盖未接受、摘要变化、验收变化和不覆盖源文件。前端 47 项测试及 TypeScript/Vite 构建通过。Ruff、Pyright、项目配置校验、示例 dry-run 通过；Python wheel 构建成功。Vitest 升级至 4.1.11 后再次通过全部前端检查，npm audit 报告 0 个已知漏洞。

维护期间未启动真实图片/视频/语音生成，也没有重新播放所有历史成片。Comfy 提交占用只做只读检查；不会因维护重提原任务。

## 保留与后续边界

60 个一次性制作脚本已逐文件核实用途、固定项目参数和模块引用。现行代码、测试、Skills、宿主配置与前端没有调用它们；历史制作记录可能仍提到旧命令，继续制作时使用画布操作指南的通用接口。根 scripts 只保留安装、启动、配置检查、R2V 编辑、审片和接受尾帧 6 个工具。

workspace 和旧测试目录不需要作为代码资产永久保留；当前仅取消版本跟踪，不为瘦身随意破坏仍可查看的画布媒体引用。没有另建仓库、导出公共源码或重写 Git 历史。

事件驱动前端刷新、大范围模块拆分和新的蓝图同步系统不在本轮引入；现有轮询、manifest 导入与精确版本化编辑已可用，继续收集真实性能证据后再决定是否扩大改动。完整画布仍按源码方式安装；wheel 仅包含 Python 包，不能单独替代 Skills 和 Web 页面。
