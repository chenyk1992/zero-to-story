# 单 Panel 视频生产全流程复查

日期：2026-09-05。本记录说明本次实施的检查结果，不替代[当前执行计划](2026-09-05-simple-panel-execution-plan.md)。

## 范围与结论

复查覆盖创作 Skill、H3 提示词交接、适配器、公共执行包、批准 hash、素材导入、同步生成、可选放大、最小 QC、真实尾帧交接以及最终音视频组装。发现的代码与文档遗漏已补齐，自动化验收通过；真实 ComfyUI 模型生成仍受本机环境限制，不能据此宣称真机全流程已经通过。

## 本次补齐的遗漏

- **所有模型调用统一**：SeedVR2 原先仍走直接提交/轮询，现与 H3 共用官方 comfy-cli 同步执行及视频结果收集。每个已声明工作流只提交一次；放大使用原生自适应时域分块，不新增重试或恢复流程。没有本地输出根目录时可以从同一服务下载明确的结果。
- **输入与素材交接**：补齐重复 ID、引用、字幕时间、音轨参数和非有限数值检查。zero-to-story 只交付当前 Panel 使用的素材，正确映射创作侧素材标识；MG 不再静默选择生成模式。JSON Schema 与实际契约保持一致。
- **运行结果与取消**：取消后晚到的结果不能把任务重新标为完成或登记为正式产物；终态取消不篡改结果。公开报告不再暴露 attempts/recovery 等旧执行协议。
- **环境检查与 setup**：默认检查 comfy、ffmpeg、ffprobe 和真实服务可达性；无效机器配置返回明确错误。setup 只发现并保存配置，不再初始化旧数据库/环境快照；诊断不创建项目目录或写探针文件。
- **最终组装**：补齐真实 FFmpeg 回归，覆盖不同分辨率/FPS、原声保留与静音、外部音轨、字幕旁挂与烧录以及最终导出。精简后端注册表仍保留内置 passthrough 能力。
- **全部上游文档**：同步短剧、B-roll、视频拆解、MG、数字人和 zero-to-story 的交接说明；统一 validate 返回 hash → 用户批准 → execute 的顺序。补齐通用 assembly 示例、同项目相对路径和调用方尾帧提取边界。
- **跨工具使用**：Skill 和执行计划只描述独立、最小输入、串行执行的行为，不写入宿主专属模型、思考级别或子 Agent 创建参数；实际配置由宿主负责。
- **持续集成**：推送 `codex/**` 分支会触发 CI；Windows 测试环境显式安装 FFmpeg，使真实媒体测试不会仅因工具缺失而跳过。
