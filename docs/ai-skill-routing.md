# 外部 Skills 在本项目的适用边界

以当前会话实际列出的 Skills 和工具文档为准；历史审查或本文件提到某项能力，不代表它已启用。只读取正在使用的能力对应项，不安装、启用或调用与当前目标无关的能力。

- `openai-docs`：按宿主要求核验时效性官方事实；本地配置读取可并行推进。已提供充分官方材料时不重复搜索，不为 GPT-6 任务加载其他模型的迁移参考。
- `computer-use`：以当前宿主实际暴露的 API 及其文档为准，再判断可操作的应用和浏览器范围。旧 Skill 示例中的 API 名称不能代替实际能力发现；缺少某项控制能力时，说明该具体缺口并继续独立工作。
- `mmx-cli` / `mmx-h3-video`：非交互参数仅复用已有授权；用户明确授权的那一次新付费重跑无需再问。任务状态未知时不重提，下载失败只处理已有结果。发现命令示例互相冲突，先查已安装 CLI 的对应帮助，不尝试多个可能付费的命令。
- `visualize`：遵循宿主进度沟通规则；只有比较能帮助完成当前请求时才增加方案。
- 文档、PDF、演示、表格与模板 Skills 只在相应任务中启用；按输出类型及实际影响验证，不为只读提取启动创作流程。普通办公文件按用户指定路径保存；LFO 包与媒体使用根 AGENTS.md 的项目产物布局，临时文件不进入真实 workspace。
- Skill 安装、插件创建和实时 Excel 使用已明确的目标与授权；缺登录、连接或操作对象时只报告该具体缺口，不把缺少辅助能力扩展为整项任务阻塞。
