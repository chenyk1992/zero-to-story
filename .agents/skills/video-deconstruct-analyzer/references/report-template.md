# 视频拆解报告模板

只填写用户要求的维度和已取得的证据。单纯分析不生成 Prompt；需要复刻时只保留用户指定的一条路线。未选维度的章节和表格行直接删除，不留占位行。

~~~markdown
# 视频拆解报告｜【标题】

> 分析目的：【复刻 / 参考风格 / 参考剧情 / 纯分析】
> 提示词路线：【仅分析 / MiniMax-H3 / Seedance 2.0】
> 分析依据：【直接读取视频 / 语义不足后抽帧 / 用户截图 / 文字描述】
> 原视频：【实际路径或用户输入】

## 1. 元信息与证据

- 时长：【秒 / 未知】
- 画幅、方向、分辨率：【比例、横竖屏、宽×高 / 未知】
- 原视频来源推测：【可观察依据 / 未知】（不决定目标路线）
- 关键帧：【数量、覆盖时间段、拼图路径或画布来源】
- 证据限制：【截图缺少动作/声音、音轨不可用、文字描述未直接读取视频等】

## 2. 一句话定性

【30 字内概括主体、动作、风格和情绪】

## 3. 分析维度（只保留用户要求的章节）

### 【角色与主体 / 场景与环境 / 剧情与动作 / 镜头与运镜 / 光影与色彩 / 风格与美学 / 节奏与剪辑 / 音乐与音效】

- 观察证据：【带时间段或帧号】
- 复刻约束：【由证据支持的可执行保留项】
- 未知与风险：【无法观察或可能翻车的项目】

## 4. 剧情/动作时间线

| 时间段 | 主体与动作 | 镜头/转场 | 声音（有证据才写） |
|---|---|---|---|
| 0–【t】 |  |  |  |
| 【t】–【t】 |  |  |  |

## 5. H3 复刻交接（仅用户要求 H3 时保留）

本节只记录中文创作事实和交接，不在此维护第二套 H3 提示词。读取 references/h3-prompt-grammar.md，整理后交给 h3-prompt-writing；正式 H3 文本由后者按当前 Canvas 能力生成。

- Panel 与目标：{Panel、画幅、时长；按当前能力或用户后端}
- 输入模式：{T2VA / I2VA / FL2VA / Ref2VA，依据实际能力}
- 证据：{主体、场景、动作、镜头、光影、风格、声音}
- 复刻设计补全：{必要的机位/空间/动作选择，和证据分开}
- 素材映射：{实际文件、Canvas 槽位、用途；无则“无”}
- 节奏与连续性：{沿用原片转折；只在需要时写起止状态}
- 交接状态：{待 h3-prompt-writing 定稿 / 已交接}

## 6. Seedance 复刻文本（仅用户明确要求该路线时保留）

按用户指定的 Seedance 版本和实际后端规则填写时长、数量和素材；不要把该外部路线的限制写成项目 Canvas 事实。输出创作文本后仍不直接调用提供方。

- 分段依据：{沿用原片节奏；如需拆段，说明硬切/能力原因}
- 素材与衔接：{真实素材、顺序、尾帧状态}
- Prompt：{按对应 Seedance 参考生成}

## 7. 统一负向词（按需）

【只列会影响当前复刻的风格、主体、物理、场景或文字问题；准确文字交给后期】

## 8. 拆解理由与限制

【说明证据来源、分段依据、复刻设计补全和仍未知的关键事实】
~~~

交付前只确认分析依据和关键帧可追溯、选定维度已覆盖、路线分支唯一、素材/声音没有虚构、未知已保留。未执行 H3 或 Seedance 交接时不要声称已完成。
