# 视频拆解报告模板

```markdown
# 视频拆解报告 · {标题}

> 目标提示词模型：{MiniMax-H3 / Seedance 2.0}
>
> 路由依据：{用户明确 H3 / 用户明确 Seedance / 未指定，默认 MiniMax-H3}
>
> 分析目的：{复刻视频 / 参考风格 / 参考剧情 / 纯分析}  
> 重点维度：{用户选择或默认维度}  
> 分析依据：{直接读取视频 / 高密度关键帧 / 用户截图 / 文字描述}  
> 原视频：`{video_path}`

## 一、元信息

- 时长：{X 秒 / 未知}
- 画幅比例：{16:9 / 9:16 / 1:1 / 4:5 / 2.35:1 / 未知}
- 分辨率：{宽 × 高 / 未知}
- 推测帧率：{24 / 25 / 30 / 60 / 未知}
- 原视频推测来源模型：{Seedance / Sora / Veo / Runway / 可灵 / Pika / Hailuo / 未知}（仅为来源推测，不决定目标提示词模型）
- 画风类别：{真实质感 / 半写实 CG / 二次元 / 水墨 / 风格化插画 / 其他}
- 推测依据：{一句话说明}

## 二、关键帧证据

- 关键帧来源：{直接语义读取成功 / 语义读取失败后抽帧 / 用户截图}
- 抽帧数量：{N 张}
- 拼图数量：{M 张}
- 覆盖时间段：{0-Xs / 每张拼图对应的时间段}
- 画布证据：{关键帧拼图已放到画布 / 未生成，说明原因}
- 密度判断：{满足高密度要求 / 画面变化少所以降低密度 / 证据不足需补抽}

## 三、一句话定性

{30 字内总结视频在做什么、什么风格、什么情绪。}

## 四、八维度分析

### 1. {✅/⬜} 角色与主体

关键词标签：{角色数量、年龄段、外貌、服装、神态、道具}

深拆：
- 主体：{年龄、性别、体型、发型、服装、表情}
- 道具：{关键道具及其关系}
- 视觉锚点：{2-3 个复刻必须保留的特征}
- 一致性观察：{是否漂移}

### 2. {✅/⬜} 场景与环境

关键词标签：{地点、时间、天气、室内外、空间尺度}

深拆：
- 空间设定：{地点、时代、建筑/陈设}
- 时间天气：{时段、天气、季节}
- 空间深度：{前景、中景、背景}
- 氛围细节：{雾气、反光、尘埃、植物等}

### 3. {✅/⬜} 剧情与动作

关键词标签：{核心冲突、主动作、次动作、转折}

深拆：
- 剧情核心：{1-2 句话}
- 主动作弧线：{开场 → 中段 → 结尾}
- 次动作/互动：{补充动作}
- 转折点：{时间点和变化}
- 观众钩子：{吸引点}

### 4. {✅/⬜} 镜头与运镜

关键词标签：{景别、角度、运镜、焦段、构图}

深拆：
- 景别变化：{如中景到特写}
- 机位角度：{平视/仰拍/俯拍等}
- 运镜方式：{推/拉/摇/移/跟/环绕等}
- 构图法则：{中心/三分/对称/留白等}
- 焦段景深：{广角/长焦/浅景深等}

### 5. {✅/⬜} 光影与色彩

关键词标签：{光源、方向、硬软、主色、辅色、色温}

深拆：
- 光源：{自然光/人工光/屏幕光/霓虹光}
- 光质：{硬光/柔光/轮廓光}
- 色温与色调：{暖/冷/中性}
- 主色与辅色：{可附具体色名}
- LUT 推测：{如 Portra 400 / Kodak 2383 / Teal & Orange}

### 6. {✅/⬜} 风格与美学

关键词标签：{美学流派、材质、品质锚}

深拆：
- 风格类型：{写实/CG/动漫/水墨/赛博朋克等}
- 参考风格：{导演/品牌/作品气质，如适用}
- 材质质感：{胶片颗粒/UE5/水彩/Octane 等}
- 品质锚词：{电影感/杂志大片/工业光魔级等}

### 7. {✅/⬜} 节奏与剪辑

关键词标签：{镜头数、切换方式、节奏曲线}

深拆：
- 镜头数量：{约 N 个}
- 切换方式：{硬切/叠化/动作匹配/一镜到底}
- 节奏曲线：{呼吸式/心跳式/海浪式/脉冲式等}
- 拐点：{时间点}

### 8. {✅/⬜} 音乐与音效

关键词标签：{BGM、BPM、SFX、环境音、人声、情绪}

深拆：
- BGM：{流派、速度、入场/高潮/淡出}
- 音效：{关键声音及时点}
- 环境音：{风、雨、脚步、人群等}
- 人声：{对白/旁白/无}

## 五、剧情时间线

可按剧情节拍列出多个时间节点，但这些节点不等于 prompt 数量。提示词数量和时长按顶部目标提示词模型的分支规则填写。

| 时间段 | 剧情概括 | 主要画面 | 镜头/运镜 | 关键音效 |
|---|---|---|---|---|
| 0-{X}s | {阶段名} | {画面描述} | {景别 + 运镜} | {声音} |
| {X}-{Y}s | {阶段名} | {画面描述} | {景别 + 运镜} | {声音} |

## 六、目标模型中文 Prompt

只填写与顶部“目标提示词模型”一致的一个分支，删除另一分支的标题、规则和字段；不要混用 H3 与 Seedance 2.0 规则。

### A. MiniMax-H3（仅目标提示词模型为 MiniMax-H3）

#### 1. 推荐输入模式与素材映射

- 推荐输入模式：{按每个请求填写纯文本 / 首尾帧 / 多模态参考；单个请求三选一}
- 选择依据：{可见证据、动作连续性、主体一致性需求}
- 交付边界：只输出可复制 H3 提示词、推荐输入模式和素材映射；付费生成交给 `mmx-h3-video`。

| 请求 | 模式 | 素材或顺序依赖 | 映射用途 | 状态 |
|---|---|---|---|---|
| {H3-1} | {纯文本/首尾帧/多模态参考} | `{已有 asset/path 或“无”}` | {开场构图 / 主体一致性 / 动作或声音参考} | {已确认 / 未提供} |
| {H3-2} | {首尾帧等} | {上一段实际尾帧} | {承接上一段尾态} | {待 H3-1 完成后提取，不虚构路径} |

每个请求只选一种模式。首尾帧模式必须有首帧、尾帧可选，不能与多模态参考混用。参考音频必须同时有参考图或参考视频。多请求连续视频的后续段优先依赖上一段实际尾帧；生成前只写“待上段生成后提取”，不得虚构不存在的文件路径或声称素材已就绪。

- 视频证据：{直接观察或用户明确描述的内容}
- 复刻设计补全：{为可执行性补充的机位、空间左右、动作细节；不得写成原视频事实}

#### 2. H3 时长分配

- 原视频时长：{X 秒 / 未知}
- H3 目标总时长：{T=max(4, ceil(X)) / 未知}
- H3 请求数量：{N / 未知}
- 每个请求时长：{4–15 秒的整数}
- 均衡分配：{N=ceil(T/15)，用 divmod(T,N) 分配；例如 16 秒 → 8 秒 + 8 秒，31 秒 → 11 秒 + 10 秒 + 10 秒}
- 未知时长处理：写“未知”，不填写伪造的请求数量、时长或分段边界。

#### 3. H3 结构化 Prompt

```text
【MiniMax-H3｜输入模式：{纯文本/首尾帧/多模态参考}｜请求时长：{4–15}秒】
【输出目标】{画幅比例、用途、连续长镜头或剪辑式成片}
【参考输入】{按实际输入顺序逐一列出并说明用途；无素材则写“无”}
【证据与设计补全】{证据项与复刻设计补全分开列出}

【全局锁定】
{主体视觉锚点、场景、风格、光影、色彩、材质和空间连续性}

【主时间线】
镜头1｜{起止区间，时长}｜参考：{真实素材映射或无}
初态：{姿态、视线、左右手、道具归属/连接、空间关系、镜头侧}
镜头行为：{景别、机位、运动、焦点与速度}
镜头内微时间线：
- {本镜起点}-{t1}：{建立/保持}
- {t1}-{t2}：{准备动作}
- {t2}-{t3}：{核心动作}
- {t3}-{本镜终点}：{完成、稳定与保持}
尾态锁定：{下一镜必须继承的显式状态}

镜头2｜{连续区间，时长}｜参考：{下一素材映射}
初态：严格等于镜头1尾态锁定。
{继续用同样结构；所有时间段无缺口、无重叠并覆盖请求时长}

【音频】
{仅填写视频音轨或用户提供的音频证据；无证据写“无音频证据”}

【关键负向】
{角色/手部/道具/空间/镜头侧/文字水印等最可能失败的排除项}
```

#### 4. 状态账本与衔接

适用时记录每个请求的状态，不要只写“保持连续”：

| 请求 | 开始状态 | 结束状态 | 下一请求衔接 |
|---|---|---|---|
| {H3-1} | {姿态、视线、左右手、道具、空间关系、镜头侧} | {同字段} | {下一段如何承接} |
| {H3-2} | {同上} | {同上} | {下一段如何承接} |

#### 5. H3 自检

- 每个请求是否只选纯文本、首尾帧、多模态参考其中一个；首尾帧是否有首帧且未与多模态参考混用。
- 多请求连续视频是否声明上段尾帧依赖；待生成素材是否未被写成已存在文件。
- 每个请求是否为 4–15 秒整数；长视频是否均衡分段，未出现 15+1 之类的尾段。
- 素材映射是否全部指向真实素材，是否杜绝虚构素材。
- prompt 是否不超过 7000 字符；参考图是否 ≤9、参考视频是否 ≤3、参考音频是否 ≤3、混合参考是否 ≤12，编号是否与实际输入顺序一致。
- 双层时间线与状态账本是否在需要连续性时启用。
- 视频证据与复刻设计补全是否分开标注，补全项是否未冒充观察事实。
- 姿态、视线、左右手、道具归属/连接、空间关系和镜头侧是否可追溯；未知处是否明确标注。
- 声音是否只来自音频证据；截图或无音频时是否未臆测声音。
