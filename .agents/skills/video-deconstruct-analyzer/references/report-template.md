# 视频拆解报告模板

```markdown
# 视频拆解报告 · {标题}

> 分析目的：{复刻视频 / 参考风格 / 参考剧情 / 纯分析}  
> 重点维度：{用户选择或默认维度}  
> 分析依据：{直接读取视频 / 高密度关键帧 / 用户截图 / 文字描述}  
> 原视频：`{video_path}`

## 一、元信息

- 时长：{X 秒 / 未知}
- 画幅比例：{16:9 / 9:16 / 1:1 / 4:5 / 2.35:1 / 未知}
- 分辨率：{宽 × 高 / 未知}
- 推测帧率：{24 / 25 / 30 / 60 / 未知}
- 推测来源模型：{Seedance / Sora / Veo / Runway / 可灵 / Pika / Hailuo / 未知}
- 画风类别：{真实质感 / 半写实 CG / 二次元 / 水墨 / 风格化插画 / 其他}
- 推测依据：{一句话说明}

## 二、关键帧证据

- 关键帧来源：{直接语义读取成功 / 语义读取失败后抽帧 / 用户截图}
- 抽帧数量：{N 张}
- 拼图数量：{M 张}
- 覆盖时间段：{0-Xs / 每张拼图对应的时间段}
- 画布证据：{关键帧拼图已放到画布 / 未生成，说明原因}
- 密度判断：{满足高密度要求 / 画面变化少所以降低密度 / 证据不足需补抽}

## 三、一句话定性

{30 字内总结视频在做什么、什么风格、什么情绪。}

## 四、八维度分析

### 1. {✅/⬜} 角色与主体

关键词标签：{角色数量、年龄段、外貌、服装、神态、道具}

深拆：
- 主体：{年龄、性别、体型、发型、服装、表情}
- 道具：{关键道具及其关系}
- 视觉锚点：{2-3 个复刻必须保留的特征}
- 一致性观察：{是否漂移}

### 2. {✅/⬜} 场景与环境

关键词标签：{地点、时间、天气、室内外、空间尺度}

深拆：
- 空间设定：{地点、时代、建筑/陈设}
- 时间天气：{时段、天气、季节}
- 空间深度：{前景、中景、背景}
- 氛围细节：{雾气、反光、尘埃、植物等}

### 3. {✅/⬜} 剧情与动作

关键词标签：{核心冲突、主动作、次动作、转折}

深拆：
- 剧情核心：{1-2 句话}
- 主动作弧线：{开场 → 中段 → 结尾}
- 次动作/互动：{补充动作}
- 转折点：{时间点和变化}
- 观众钩子：{吸引点}

### 4. {✅/⬜} 镜头与运镜

关键词标签：{景别、角度、运镜、焦段、构图}

深拆：
- 景别变化：{如中景到特写}
- 机位角度：{平视/仰拍/俯拍等}
- 运镜方式：{推/拉/摇/移/跟/环绕等}
- 构图法则：{中心/三分/对称/留白等}
- 焦段景深：{广角/长焦/浅景深等}

### 5. {✅/⬜} 光影与色彩

关键词标签：{光源、方向、硬软、主色、辅色、色温}

深拆：
- 光源：{自然光/人工光/屏幕光/霓虹光}
- 光质：{硬光/柔光/轮廓光}
- 色温与色调：{暖/冷/中性}
- 主色与辅色：{可附具体色名}
- LUT 推测：{如 Portra 400 / Kodak 2383 / Teal & Orange}

### 6. {✅/⬜} 风格与美学

关键词标签：{美学流派、材质、品质锚}

深拆：
- 风格类型：{写实/CG/动漫/水墨/赛博朋克等}
- 参考风格：{导演/品牌/作品气质，如适用}
- 材质质感：{胶片颗粒/UE5/水彩/Octane 等}
- 品质锚词：{电影感/杂志大片/工业光魔级等}

### 7. {✅/⬜} 节奏与剪辑

关键词标签：{镜头数、切换方式、节奏曲线}

深拆：
- 镜头数量：{约 N 个}
- 切换方式：{硬切/叠化/动作匹配/一镜到底}
- 节奏曲线：{呼吸式/心跳式/海浪式/脉冲式等}
- 拐点：{时间点}

### 8. {✅/⬜} 音乐与音效

关键词标签：{BGM、BPM、SFX、环境音、人声、情绪}

深拆：
- BGM：{流派、速度、入场/高潮/淡出}
- 音效：{关键声音及时点}
- 环境音：{风、雨、脚步、人群等}
- 人声：{对白/旁白/无}

## 五、剧情时间线

可按剧情节拍列出多个时间节点，但这些节点不等于 prompt 数量。15 秒以内视频最终只输出 1 条提示词；超过 15 秒时按理论最少段数汇总输出。

| 时间段 | 剧情概括 | 主要画面 | 镜头/运镜 | 关键音效 |
|---|---|---|---|---|
| 0-{X}s | {阶段名} | {画面描述} | {景别 + 运镜} | {声音} |
| {X}-{Y}s | {阶段名} | {画面描述} | {景别 + 运镜} | {声音} |

## 六、Seedance 2.0 中文 Prompt

> 理论最少提示词数量：{ceil(视频时长 / 15)} 条  
> 实际输出提示词数量：{N} 条  
> 若实际数量大于理论最少数量，必须说明原因。

### 提示词 1（0-15s 或本段实际时长）—— {合并后的剧情动作链}

Prompt：
```text
{优先使用 13-15 秒时间戳分镜式中文提示词；同一段内可包含多个剧情节点}
```

衔接点 → 提示词 2（仅当视频超过 15 秒时出现）：
- 尾帧状态：{角色位置、动作、光影、镜头位置}

## 七、全片统一负面词

```text
禁止风格漂移，禁止角色变脸或换人，禁止突然偏色，禁止新增无关人物，禁止光线突变，禁止出现文字、字幕、LOGO、水印
```

## 八、为什么这样拆

{80-120 字说明拆段依据、风格 DNA、复刻风险。}

## 九、最终自检

- 元信息完整：{是/否}
- 高密度关键帧达标：{是/否/不适用，说明}
- 关键帧拼图已在画布：{是/否}
- 报告已连接关键帧 sourceNodeIds：{是/否}
- 提示词数量符合最少段数：{是/否，说明}
- 15 秒以内视频只输出 1 条提示词：{是/否/不适用}
- 提示词由报告结论翻译而来：{是/否}
```
