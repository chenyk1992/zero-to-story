# 视频拆解报告模板

只填写用户要求的维度和已取得的证据。单纯分析不生成 Prompt；需要复刻时只保留用户指定的一条路线。未选维度的章节和表格行直接删除，不留占位行；删节后按实际顺序重排章节编号。

~~~markdown
# 视频拆解报告｜【标题】

> 分析目的：【复刻 / 参考风格 / 参考剧情 / 纯分析】
> 当前方式：【自由改编 / 受控复刻 / 只读分析；选择依据，已有简报则引用版本】
> 提示词路线：【仅分析 / MiniMax-H3 / Seedance 2.0】
> 分析依据：【直接读取视频 / 语义不足后抽帧 / 用户截图 / 文字描述】
> 原视频：【实际路径或用户输入】

## 1. 元信息与证据

- 时长：【秒 / 未知】
- 源帧率/时间基与时序精度：【实际元信息/时间戳依据 / 未知；不由截图猜精确时间】
- 画幅、方向、分辨率：【比例、横竖屏、宽×高 / 未知】
- 原视频来源推测：【可观察依据 / 未知】（不决定目标路线）
- 关键帧：【数量、覆盖时间段、拼图路径或画布来源】
- 证据限制：【截图缺少动作/声音、音轨不可用、文字描述未直接读取视频等】

## 2. 一句话定性

【30 字内概括主体、动作、风格和情绪】

## 3. 分析维度（只保留用户要求的章节）

### 【角色与主体 / 场景与环境 / 剧情与动作 / 镜头与运镜 / 光影与色彩 / 风格与美学 / 节奏与剪辑 / 音乐与音效】

- 观察证据：【带时间段或帧号】
- 复刻约束：【由证据支持的可执行保留项】
- 未知与风险：【无法观察或可能翻车的项目】

## 4. 剧情/动作时间线

| 原片时间段（不是 Panel 时间） | 主体与动作 | 镜头/转场 | 声音（有证据才写） |
|---|---|---|---|
| 0–【t】 |  |  |  |
| 【t】–【t】 |  |  |  |

## 元素/界面替换与保留（需要时）

【按变更模板逐目标引用稳定 ID、源版本/区域/窗口、新来源、跨镜归属及共用遮挡/接触关系；背景 UI 说明载体、区域、布局/层级/密度/图标关系、已观察滚动和需要逐字保留的评论/数字，不猜未知或转录无关全 UI。非人采访替换写明保留的表演节奏、按已确立设定适配的说话结构及口型边界。分开记录源片原音、声音参考、生成声、最终混音责任和已核实的能力缺口。分析/提示词交接不冒充实际替换、精确 UI 保留、口型同步或原音保留已经完成。】

## 5. H3 复刻交接（仅用户要求 H3 时保留）

本节只记录中文创作事实和交接，不在此维护第二套 H3 提示词。读取 references/h3-prompt-grammar.md，整理后交给 h3-prompt-writing；正式 H3 文本由后者按当前 Canvas 能力生成。

- Panel 与目标：{Panel、画幅、时长；按当前能力或用户后端}
- 输入模式：{T2VA / I2VA / FL2VA / Ref2VA，依据实际能力}
- 证据：{主体、场景、动作、镜头、光影、风格、声音}
- 复刻设计补全：{必要的机位/空间/动作选择，和证据分开}
- 素材映射：{实际文件、Canvas 槽位、每项参考的用途与不沿用内容；声音参考不等于最终音轨；无则“无”}
- 关键排除：{会影响本次复刻的事项写入相应创作事实；无则删去，不另写负向词段}
- 节奏与连续性：{沿用原片转折；只在需要时写起止状态}
- 时间映射与精度：{源窗口/切点证据 → Panel零基 → 已定成片位置，另记实际音乐版本/窗口映射；授权改编/允许近似项与未知分开；源帧率、目标能力帧率及待实测输出差异按变更交接记录}
- 交接状态：{待 h3-prompt-writing 定稿 / 已交接}

## 6. Seedance 复刻文本（仅用户明确要求该路线时保留）

按用户指定的 Seedance 版本和实际后端规则填写时长、数量和素材；不要把该外部路线的限制写成项目 Canvas 事实。输出创作文本后仍不直接调用提供方。

- 分段依据：{沿用原片节奏；如需拆段，说明硬切/能力原因}
- 素材与衔接：{真实素材、顺序、尾帧状态}
- Prompt：{按对应 Seedance 参考生成}

## 7. 关键排除项（仅所选路线需要时保留；H3 删除本节）

【只列会影响当前复刻的风格、主体、物理、场景或文字问题；按实际后端能力表达，不假定有独立负向参数】

## 8. 拆解理由与限制

【说明证据来源、分段依据、复刻设计补全和仍未知的关键事实】
~~~
