# 视频元素替换的证据与交接

方法来源video-element-replacement，归纳重写对象/窗口/运动/声音边界，不复制模板、执行器或平台；源包无许可文件，不证明已接入编辑能力。

逐目标定位，而非把整组内容含混地当成一个目标。仅对本次变更、保留要求或相互关系有关的对象、人物、商品、包装或界面区域，使用单独且稳定的 ID，并记录源版本、源 Shot、载体/画面区域、可辨识证据、作用窗口、新来源/版本与允许变化；不要求穷举无关背景物。多个对象即使同镜、相似或共用遮挡/接触，也分别登记 ID；再显式记录它们共用的关系。跨 Shot 追踪同一目标的入出画、遮挡后重现和归属，不凭相似外观合并对象。区分观察事实、用户锁定项、获准变化与未知；非人主体保留相关部件数量/连接、轮廓与身体覆盖状态，商品记录相关部件/连接与使用状态。

| 当前相关事实 | 交接内容 |
| --- | --- |
| 作用窗口 | 源入点/出点、目标入出画、Panel零基窗口；精度不足保留未知 |
| 运动/机位 | 原对象轨迹/旋转/变形/尺度、摄影机方向与切点，什么不得改变 |
| 遮挡/接触 | 前后层、对象之间共用的遮挡顺序、手/支撑面、抓取/释放、反射/阴影及重现；多个 ID 分别记录各自关系，不丢失关联对象 |
| 新内容 | 身份/SKU/造型/必要视角、实际图/Key/版本，不补未知背面；人物/生物依已确立设定，不臆造解剖 |
| 跨镜映射 | 每个 ID 的源 Shot→目标 Panel/Shot、入出画/遮挡后重现、相关起止状态与连续依赖 |
| 背景界面 | 对需保留的屏幕/面板单独设 ID：记录载体（手机/显示器/仪表等）、画面区域、布局/层级/密度/图标关系与源窗口；有滚动时记录可见顺序和运动证据。关键评论、数字、标签或术语按要求逐字记录；未知不猜、不默认转录或复刻全部 UI。 |
| 声音 | 区分源片原音轨（保留/静音/替换/未知）、`reference_audio`（仅作为已选声音/演绎参考，非固定成片轨）、生成对白/配音/音乐/音效，以及后期最终混音轨和责任人；外观替换不自动替换声音。 |
| 文字 | 精确包装/Logo等依[共同文字交接](../../canvas-workspace/references/creative-handoff.md#逐项文字与时间) |
| 依赖 | 前段固定采用run/摘要/尾帧或无；修改只影响实际消费者 |

### 非人角色采访替换

将“像原采访者一样说话”拆成可观察的表演意义与节奏：采访轮次、看向采访者/镜头的方向、开始和结束时机、停顿、强调、倾听反应、点头/转头及身体重心等，只记录源证据支持且当前镜头需要的部分。新角色的口鼻、牙齿、下颌等可见说话结构应依其已确立的物种/角色设定和实际参考适配；不把真人嘴唇、鼻翼、牙列或下颌解剖轮廓直接复制给非人角色，也不对未提供的结构作事实推断。若需保留对白，另记准确文本与责任；没有音轨证据时不推定停顿或口型时点。

参考生成可把表演节拍与发声形态作为创作意图，不保证精确口型、逐字同步或源片表演逐帧重现。用户要求精确同步时，先核实实际可用的口型/后期能力和输入，再明确生成与后期责任；未核实前只报告缺口，不把近似描述写成完成保证。

### 原音、声音参考与最终音轨

源片原音、声音参考、生成声与最终混音分工不同：

- **源片原音轨**：说明是否要逐字/原样保留、静音或替换，并指明证据来源和目标窗口。要求原采访原声原样保留时，`reference_audio` 不等于该原音轨已进入最终成片。
- **声音参考**：说明 `reference_audio` 仅用于何种声音特征/表演参考；它本身不证明采样级保留，也不是最终音轨。
- **生成声音**：逐项记录由生成补充的新对白、配音、音乐或音效；与源原音和参考声音分开。
- **最终混音**：指定由谁、通过哪条已核实的后期路径保留/替换/混合源音与生成音，并在真实混音文件上验收。若没有已确认的工具/流程，写明能力缺口，不承诺原音自动提取、恢复、对齐或混音。

能力分三种：H3参考生成是按素材重建，不是精确 mask/跟踪替换，也不保证背景界面布局、关键文字/数字或滚动轨迹；已验证确定性剪辑/换轨可在授权范围处理；区域外逐像素不变、跟踪 mask、精确口型或分层编辑工程须真实工具。当前未接入精确替换/保留或最终混音时明确缺口，不静默改为 H3 近似重建。静态首尾图不能证明整段遮挡/接触/滚动成立。

只有分析时交证据/未知即止；有制作需求把记录返回当前影视、广告、音乐或原专业主责，不改策略、不新建复刻整片入口。原片、前段采用视频与真实尾帧分别使用；普通R2V不启视频前缀，音轨保留另有后期责任。变更记录用[现有模板](../assets/recreation_change_plan.template.md)，按[当前版本协调](../../canvas-workspace/references/creative-handoff.md#当前版本协调)合并新编辑，不改冻结历史。
