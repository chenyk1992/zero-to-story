# MiniMax-H3 中文复刻提示词规范

本规范仅用于输出可复制的 H3 提示词与输入计划，不发起付费生成，不调用视频生成接口。只写已有证据支持的内容；不得虚构素材、时长、动作、声音或参考映射。

## 1. 输入模式：每个请求三选一

1. **纯文本**：不带任何参考素材。
2. **首尾帧**：必须提供首帧图，可选提供一张尾帧图；不能与参考图、参考视频、参考音频等多模态参考混用。
3. **多模态参考**：使用已提供的参考图、参考视频、参考音频。参考音频至少同时配有一张参考图或一个参考视频；孤立参考音频无效。

素材缺失、未验证或无法读取时，标注“未提供/未知”，不得用占位描述冒充真实素材。

长视频可让不同请求使用不同模式，但每个请求内部仍只能选一种。首段按已有素材选择；后续段若强调连续性，优先把上一段完成视频的实际尾帧作为本段首帧，改用首尾帧模式。生成前将其标为“待上段生成后提取”的顺序依赖，不得提前编造路径或声称已经就绪。

区分两类信息：从视频、截图或用户描述得到的内容标为“证据”；为使提示词可执行而补充的机位、空间左右或动作细节标为“复刻设计补全”。设计补全可以写入 prompt，但不得冒充原视频观察结论。

## 2. H3 请求边界与长视频分段

- 每次请求时长为 **4–15 秒的整数**；每条 prompt 不超过 **7000 字符**。
- 已知原视频时长为 `S` 秒时：`T=max(4, ceil(S))`，`N=ceil(T/15)`。
- 用 `q,r=divmod(T,N)` 分配：前 `r` 段为 `q+1` 秒，其余为 `q` 秒；段差最多 1 秒，且每段均为 4–15 秒整数。按时间顺序覆盖全片。
- 原视频时长未知：不伪造 `T`、`N`、段数或时长；先标记未知，或只输出不含虚构时长的输入计划。

例：

- 原片 3 秒：`T=4，N=1`，请求 `[4秒]`；补足请求下限不等于凭空增加动作。
- 原片 16 秒：`T=16，N=2`，请求 `[8秒，8秒]`。
- 原片 31 秒：`T=31，N=3`，请求 `[11秒，10秒，10秒]`。

## 3. 参考素材编号与限制

仅在多模态参考模式使用下列上限：参考图 `≤9`、参考视频 `≤3`、参考音频 `≤3`，混合参考素材总数 `≤12`。编号必须严格按实际输入顺序分配，并在提示词中保持一致：`[参考图1]、[参考图2]、[参考视频1]、[参考音频1]`。首尾帧模式使用“首帧/尾帧”映射，不转写为多模态参考编号。

## 4. 时间线与连续性

- 单文本或单个松散参考：可用紧凑时间线。
- `≥2` 张有序分镜图、精确物理交互或高连续性要求：必须使用“**主时间线 + 镜头内微时间线**”。
- 每镜必须写：精确区间与时长、参考映射、初态、镜头行为、3–5 个有因果关系的动作微节拍、锁定尾态。
- 后一镜初态必须等于前一镜尾态；跨 H3 请求也要写明衔接点，不得重置人物、道具或镜头状态。

### 状态账本（每镜继承并更新）

持续记录：人物姿态、视线、左右手状态、道具归属/位置/连接关系、空间左右与前后景、镜头侧（拍摄轴所在侧）。发生变化时写出“由何状态因何动作变为何状态”。

## 5. H3 中文结构化模板

```text
【MiniMax-H3｜输入模式：{纯文本/首尾帧/多模态参考}｜请求时长：{4–15}秒】
【输出目标】{画幅比例、用途、连续长镜头或剪辑式成片}
【参考输入】{按实际输入顺序列出 [参考图1]/[参考视频1]/[参考音频1]；无素材则写“无”}
【证据与设计补全】{列出证据项；另列为可执行性补充的镜头/空间选择；没有补全则写“无”}
【全局锁定】{主体外观、场景、时间、光线、色彩、材质、风格、画幅；只写证据支持项}

【主时间线】
镜头1｜{起止区间，时长}｜参考：{映射}
初态：{人物、道具、空间和镜头侧的可观察状态}
镜头行为：{景别、机位、运动、焦点与速度}
镜头内微时间线：
- {本镜起点}–{t1}：{建立/保持；可见状态}
- {t1}–{t2}：{准备动作；因果变化}
- {t2}–{t3}：{核心动作；因果变化}
- {t3}–{本镜终点}：{完成、稳定与保持}
尾态锁定：{姿态、视线、左右手、道具、空间位置、镜头侧/焦点}

镜头2｜{连续的起止区间，时长}｜参考：{下一映射}
初态：严格等于镜头1的尾态锁定。
镜头行为：{景别、机位、运动、焦点与速度}
镜头内微时间线：{同样用 3–5 个无缺口、无重叠的时间段覆盖本镜}
尾态锁定：{显式状态}

【下一镜衔接】后一镜初态={上一镜尾态}；{必要的连续性说明}

【统一约束】{动作因果、连续性、光影/材质/风格、物理规律}
【负面约束】无字幕、无 Logo、无水印、无额外人物/道具、无肢体/手指/脸部/物理结构错误、无无依据的镜头跳切、无状态重置。
```

声音时点（音乐、对白、音效的进入/变化）只在存在音频证据或参考音频时写；没有证据就不写声音时点。H3 提示词不得要求生成字幕、Logo 或水印，文字与标识交给后期。

## 6. 发送前自检

- [ ] 每个请求只选一种输入模式；首尾帧模式已有首帧且未与多模态参考混用，参考音频已配图或视频。
- [ ] 多请求连续视频已声明顺序依赖；待生成尾帧未被冒充为现有素材或虚构文件路径。
- [ ] 所有素材真实存在且编号顺序等于输入顺序；未超过图 9、视频 3、音频 3、混合 12 的限制。
- [ ] 每个请求为 4–15 秒整数，prompt ≤7000 字符；已知长视频按 `T/N` 分段，未知时长未编造。
- [ ] 每镜有精确区间、时长、参考映射、初态、镜头行为、3–5 个因果微节拍和锁定尾态；下一镜初态与上一镜尾态一致。
- [ ] 状态账本完整；需要时已使用“主时间线 + 镜头内微时间线”。
- [ ] 证据与复刻设计补全已分开标注，补全项未冒充原视频事实。
- [ ] 声音时点有证据才写；未生成字幕、Logo、水印；负面约束已包含。
