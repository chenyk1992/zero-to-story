# H3 复刻创作事实与交接

本参考只把视频拆解结果整理成中文复刻输入，供 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md) 写正式 H3 提示词。它不维护第二套提示词语法，不调用生成接口。正式 H3 文本必须由 h3-prompt-writing 按当前 Canvas 能力写出并原样保存。

## 先确定可交接的事实

用户明确要求 H3 复刻时，整理：

- 原片证据：主体、空间、动作、镜头、光影、风格、节奏和有音频证据的声音；
- 复刻目的：保留哪些视觉效果，哪些只是原片偶然现象；
- 已有素材：实际文件、语义用途、序号和仍缺的输入；
- 目标 Panel：当前 Canvas 能支持的模式、时长、画幅和音频/后期责任；
- 连续性：只有实际需要时写前后 Panel 的可见状态和衔接点。

模式使用当前 Canvas 与 h3-prompt-writing 的能力说明：T2VA 无媒体输入，I2VA 用已确认的精确首帧，FL2VA 用已确认的首尾帧，Ref2VA/R2V 用普通图片、视频或音频参考。不要因素材数量推断模式；未知能力或缺素材就写明缺口，不替换路线。

## 证据与设计补全

按[变更交接](recreation-change-plan.md)附方式、保留/变更表、完整对白与逐项文字责任。受控复刻不借设计补全改变已观察关系；新文案超窗口说明冲突，不自行改词、均分时长。实际编号与参考用途分开，原片不是前段 ACCEPT。

在交接中分开写：

- **视频证据**：能从视频、关键帧、音频或用户描述直接支持的事实，并标注时间/帧；
- **复刻设计补全**：为让镜头可执行而选择的机位、空间左右、镜头速度或动作细节，不冒充原片观察。

保持原片节奏可用时，沿用原有时长和转折，不均分镜头、不把每个变化强行拆成 Panel。一个 Camera Setup 可以包含多个有因果关系的动作；只在动作或空间确实需要时拆开。

按[时间映射](recreation-change-plan.md#源panel-与成片时间映射)把源窗口/切点转为当前 Panel 的零基时点，成片位置仅在排列已定时附上；保留切点证据、改编依据与允许近似的关键目标。源帧率与所选能力帧率分别记录，不通过重解释帧率缩放秒数；实际输出帧率/时长待产出后测量。关键精确切点缺证据且未获准近似时可交草稿，不编造时点完成正式 H3 定稿；普通非帧级任务不强加精确元信息要求。

## 交接结构

将下面内容交给 h3-prompt-writing；不要在此处写完整 H3 提示词：

~~~markdown
### H3 复刻 Panel：{panel_id}
- 模式：{T2VA / I2VA / FL2VA / Ref2VA；依据当前能力}
- 时长、画幅：{已确认值；未知写未知}
- 证据：{主体、场景、镜头、动作、光影、风格、声音}
- 设计补全：{必要的可执行选择；无则“无”}
- 引用映射：{Canvas 槽位、H3 标签、实际素材用途；无则“无”}
- 时间线：{源版本/采用窗口、事件和切点证据 → 当前 Panel 零基起止/切点；保留或已授权改编依据，成片位置已定才填；未知/允许近似分开}
- 时序规格与精度：{源帧率/时间基及证据精度、目标能力帧率、已定 Panel 时长；实际输出尚未生成写待验证，不把帧率换算成变速}
- Camera Setup：{景别、角度、机位、运镜、焦点}
- 动作：{按因果写可见动作，不规定数量}
- 起始/结束状态：{仅在连续性或物理交互需要时填写；未知写未知}
- 声音与后期：{有证据才写音频时点；对白/字幕/Logo 等后期责任}
- 关键排除项：{只列会影响本 Panel 的可观察问题，交给 H3 写入相关创作事实，不单列负向词段}
~~~

## 引用与连续性

Canvas 槽位按实际输入保留其语义，H3 标签由 h3-prompt-writing 按当前模式转换；不补号、不虚构路径、不把 contact sheet 冒充方向图。普通视频参考不等于精确首帧；精确首帧只来自已接受实际输出的真实尾帧或用户已确认的首帧。

只在下一 Panel 需要接续、物理交互会出错或镜头轴线必须保持时写状态；不要为所有镜头建立全字段账本。无法观察的姿态、视线、手部、道具关系和声音写未知。

## 交接前必要确认

确认 Panel 的目标时长/画幅/模式来自当前能力或用户指定后端，素材真实且用途明确，原片节奏没有被机械均分，切点使用 Panel 零基时间且在本段范围内，源/成片时点与实际时长没有冒充生成参数，证据与设计补全分开，正式提示词将交给 h3-prompt-writing。单纯分析任务不创建 H3 交接，也不输出 Prompt。
