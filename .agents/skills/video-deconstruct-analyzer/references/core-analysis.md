# 视频拆解核心分析参考

## 八个分析维度

1. 角色与主体：角色数量、年龄段、性别、体型、发型发色、面部特征、服装材质、表情、关键道具、视觉锚点与一致性风险。
2. 场景与环境：地点、时代、室内外、时间天气、空间尺度、前中后景层次、雾气、反光、尘埃、植物摇曳等环境微动。
3. 剧情与动作：剧情核心、主动作弧线、次动作、互动关系、关键转折点、观众钩子、剧情段数。
4. 镜头与运镜：景别、机位角度、推拉摇移跟环绕升降、焦段景深、构图法、主观或客观视角。
5. 光影与色彩：光源类型、方向、硬软、三点布光、色温、主辅色、饱和度、LUT 倾向、对比度。
6. 风格与美学：写实、CG、动漫、水墨、赛博朋克、复古、极简、导演/品牌参考、材质质感、品质锚词、画幅比例。
7. 节奏与剪辑：镜头数量、平均镜头长度、切换方式、节奏曲线、节奏拐点、是否一镜到底。
8. 音乐与音效：BGM 流派、BPM 推测、入场/高潮/淡出时点、关键 SFX、环境音、人声、情绪基调。

## 深拆标准

用户选中维度要写 3-6 行，并包含：

- 关键词标签。
- 具体画面证据。
- 对复刻有用的约束。
- 可能翻车的风险。

未选维度只需一行概括，保持报告完整但不喧宾夺主。

## 目的驱动倾斜

- 复刻视频：角色、镜头、光影、风格必须写满；剧情按时间线整理。
- 参考风格：风格、光影、色彩、镜头美学写满。
- 参考剧情：角色、剧情结构、动作设计、节奏曲线写满。
- 纯分析：选中维度均衡展开。

## 镜头中文词表

景别：极特写、特写、近景、中近景、中景、中全景、全景、远景、大远景。

角度：虫视、仰拍、微仰、平视、微俯、俯拍、鸟瞰、荷兰角。

运镜：固定、推镜、拉镜、摇镜、俯仰镜、移镜、跟拍、环绕、升降、手持、一镜到底、希区柯克变焦、急摇、升格、降格。

焦段与景深：广角、标准、长焦、微距、鱼眼、浅景深、大景深。

构图：三分法、中心构图、对称构图、留白、引导线、框架构图、黄金比例、S 形构图、对角线构图。

## 风格标签速查

- 电影写实：35mm 胶片质感，写实光影，自然色彩，浅景深。
- 杂志大片：时尚杂志大片，高对比硬光，中性色调，干净构图。
- 纪录片真实：手持微抖，自然光，颗粒感，未修饰真实。
- 工业光魔级：UnrealEngine5 渲染，工业光魔级 VFX，超写实材质。
- Octane 渲染：3D 渲染，全局光照，物理材质，高清反射。
- Pixar 卡通：3D 卡通，柔和打光，圆润造型，温暖配色。
- 吉卜力手绘：柔和水彩，自然光，温暖治愈，宫崎骏式构图。
- 新海诚：高饱和天空，光斑粒子，少年系青春，城市风景。
- 中国水墨：留白构图，黑白灰阶，宣纸质感，写意。
- 赛博朋克：霓虹紫粉绿，雨夜街道，全息广告，反乌托邦。
- 废土末日：沙尘弥漫，锈蚀金属，褪色服装，荒芜空间。
- 王家卫：霓虹色斑，慢门拖影，狭窄空间，孤独情绪。
- Apple 广告片：纯白背景，柔光，极简留白，干净产品质感。

## 常见错误

- 只写“一个女孩”，没有年龄、服装、发型和视觉锚点。
- 只说“电影感”，没有具体材质、镜头、光影依据。
- 用英文镜头术语混杂中文报告。
- 单段提示词同时写极特写到大全景，造成景别冲突。
- 多段复刻时对同一角色改写称呼，导致一致性下降。
- 对截图输入强行分析音乐，未说明“基于画面推测”。
