# 视频拆解核心分析参考

## 按需分析的八个维度

1. **角色与主体**：数量、身份锚点、外貌/服装、表情、道具、漂移风险。
2. **场景与环境**：地点、时代、室内外、时段天气、空间尺度、前中后景和环境运动。
3. **剧情与动作**：目标、阻碍、主动作弧线、互动、转折、钩子。
4. **镜头与运镜**：景别、角度、机位、焦段/景深、构图、推拉摇移跟拍/环绕、剪辑点。
5. **光影与色彩**：光源与方向、硬软、色温、主辅色、对比度和材质。
6. **风格与美学**：写实/CG/动画等类别、质感、视觉参考和稳定风格锚。
7. **节奏与剪辑**：镜头数量和长度、切换方式、节奏曲线、拐点、一镜到底。
8. **音乐与音效**：仅根据实际音轨或用户音频记录 BGM、环境声、动作声、人声及进入点；无证据写未知。

用户指定的维度写具体证据和复刻约束，未指定的维度一句带过。每个结论尽量标注时间段或关键帧编号。

## 连续性状态

只有要写 H3 连续复刻时记录每段的开始/结束状态：

| 字段 | 观察内容 |
|---|---|
| 姿态 | 站/坐/蹲/躺、重心、四肢和动作进行到哪一步 |
| 视线 | 头和眼睛朝向、目标在画内还是画外 |
| 左右手 | 分别为空闲、持物、接触、交接或被遮挡 |
| 道具 | 数量、归属、位置、连接关系和交接前后 |
| 空间 | 人物/道具的左中右、前后、距离、遮挡和高度 |
| 镜头侧 | 拍摄轴、机位方向、景别、机位高度和是否切轴 |

把变化写成“状态 A —因果动作→ 状态 B”。无法观察就写未知。不要用常识填补被遮挡、过快或无音频的内容。

## 镜头词表

- 景别：极特写、特写、近景、中近景、中景、中全景、全景、远景、大远景。
- 角度：虫视、仰拍、微仰、平视、微俯、俯拍、鸟瞰、荷兰角。
- 运镜：固定、推、拉、摇、俯仰、移、跟、环绕、升降、手持、一镜到底、急摇。
- 焦段/景深：广角、标准、长焦、微距、鱼眼、浅景深、大景深。
- 构图：中心、三分、对称、留白、引导线、框架、黄金比例、S 形、对角线。

## 深拆写法

每个选中维度用“观察 → 复刻约束 → 风险”写 2–6 行。主体描述要具体到可识别特征；镜头描述要同时有景别、方向、运动和焦点；动作描述要写身体/道具如何变化。不要只写“电影感”“她很难过”或堆导演/模型名。
