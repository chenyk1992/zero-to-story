# 短剧类型指南

反转是可组合的[叙事机制](reversal-design.md)，喜剧是类型/基调，大团圆、开放或悲剧是结局走向；三者不互相替代，不要求每集反转。完整广告由[广告入口](../../advertising-creator/SKILL.md)主责，反转只是可选方法；受托编剧只返回指定稿件。

独立情景喜剧/喜剧小品按[喜剧写作](sitcom-writing.md)选择因果与回收，以下市场类型、付费和感情结构仅在适用时使用，不强加给独立短篇。

## 13 大主流类型

### 1. 都市甜宠
- **核心受众**：18–30 岁女性
- **一句话定义**：高颜值男女从误会到心动的城市爱情
- **典型爽点**：心动暴击、吃醋名场面、公开撒糖
- **常见设定**：合租/职场/假结婚/合同恋人
- **必备元素**：反差萌、双向暗恋、肢体接触升级

### 2. 霸总/豪门
- **核心受众**：25–40 岁女性
- **一句话定义**：冷酷总裁因女主失控，从占有到深爱
- **典型爽点**：霸气护妻、身份碾压、阶层逆袭
- **常见设定**：商业联姻/替嫁/秘密恋情/豪门私生女
- **必备元素**：黑卡刷不停、保镖开路、董事会暴怒

### 3. 甜蜜恋爱
- **核心受众**：16–25 岁女性
- **一句话定义**：青春校园或初入社会的纯爱故事
- **典型爽点**：初吻、告白、暗恋被发现
- **常见设定**：校园/青梅竹马/异地恋/网恋奔现
- **必备元素**：便利贴情书、共用耳机、雨天送伞

### 4. 重生/穿越
- **核心受众**：20–35 岁，男女通吃
- **一句话定义**：带着前世记忆或穿越时空，改写命运
- **典型爽点**：提前布局、打脸渣人、命运逆转
- **常见设定**：重生回高考/穿越古代/游戏穿越/末世重生
- **必备元素**：金手指、蝴蝶效应、前世今生对比

### 5. 战神归来
- **核心受众**：25–40 岁男性
- **一句话定义**：隐藏绝世身份的强者回归，碾压一切
- **典型爽点**：亮身份打脸、以一敌百、下跪道歉
- **常见设定**：退役特种兵/隐世高手/家族弃子归来
- **必备元素**：令牌/勋章亮出、跪地求饶、战力飙升

### 6. 宫斗/宅斗
- **核心受众**：22–38 岁女性
- **一句话定义**：后宫或大宅门内的权谋较量
- **典型爽点**：以牙还牙、揭穿阴谋、绝地翻盘
- **常见设定**：古代后宫/民国大院/豪门内斗
- **必备元素**：毒计、联盟、隐忍蛰伏、一击致命

### 7. 逆袭/翻身
- **核心受众**：20–35 岁，偏男性
- **一句话定义**：底层小人物一步步逆天改命
- **典型爽点**：打脸嘲讽者、阶层跨越、身份反转
- **常见设定**：赘婿/快递员逆袭/草根创业/直播翻红
- **必备元素**：前期受辱、中期崛起、后期碾压

### 8. 家庭伦理
- **核心受众**：30–50 岁，偏女性
- **一句话定义**：家庭矛盾中的人性博弈
- **典型爽点**：渣男/渣女被制裁、真相大白、善有善报
- **常见设定**：婆媳关系/出轨/遗产争夺/重组家庭
- **必备元素**：道德审判、情感共鸣、正义裁决

### 9. 萌宝/亲子
- **核心受众**：25–40 岁女性
- **一句话定义**：萌娃牵线、破镜重圆或意外相认
- **典型爽点**：萌宝金句、亲子相认、一家团圆
- **常见设定**：未婚生子/试管宝宝/私生子相认/离婚后遇见
- **必备元素**：萌宝助攻、DNA 鉴定、父爱觉醒

### 10. 悬疑/推理
- **核心受众**：22–35 岁，男女均衡
- **一句话定义**：层层反转的案件或阴谋
- **典型爽点**：真凶反转、线索串联、真相揭露
- **常见设定**：密室/连环案/复仇追凶/职场阴谋
- **必备元素**：红鲱鱼、倒计时、多重反转

### 11. 轻科幻
- **核心受众**：18–30 岁，偏男性
- **一句话定义**：近未来背景下的科技 + 情感冲突
- **典型爽点**：能力觉醒、科技碾压、末日求生
- **常见设定**：AI 觉醒/时间循环/平行世界/基因改造
- **必备元素**：硬核设定（1–2 个）、人性拷问、科技双刃剑

### 12. 末世重生
- **核心受众**：20–35 岁，偏男性
- **一句话定义**：末日浩劫中的重生求存
- **典型爽点**：囤货打脸、以弱胜强、建立据点
- **常见设定**：丧尸/极端气候/资源枯竭/异能觉醒
- **必备元素**：生存技能、团队组建、人性考验

### 13. 喜剧/搞笑
- **核心受众**：全年龄段
- **一句话定义**：以笑料推进剧情的轻松短剧
- **典型爽点**：反差幽默、误会连锁、神反转
- **常见设定**：穿越搞笑/职场整蛊/情侣日常/家庭喜剧
- **必备元素**：包袱密度、角色反差、节奏精准

## 类型叠加规则

- 最多叠加 **3 个类型**
- 必须有 1 个**主类型**，其余为辅
- 避免冲突组合（如 "甜宠 + 悬疑推理" 需要极强功力）

### 经典叠加组合

| 主类型 | 推荐搭配 | 效果 |
|--------|----------|------|
| 霸总 | + 萌宝 | 冷酷总裁遇萌娃，反差萌 |
| 重生 | + 逆袭 | 带记忆重来 + 一路碾压 |
| 战神 | + 甜宠 | 硬汉 + 反差甜 |
| 宫斗 | + 重生 | 重生复仇 + 权谋升级 |
| 悬疑 | + 重生 | 重生追凶 + 反转密集 |
| 家庭伦理 | + 逆袭 | 被欺负的人翻身做主 |

## 出海改编参考

具体对白、多语知情与地域证据由[语言适配](overseas-dialogue.md)维护。本节只提供类型设计的可能方向，不能作为某平台当前偏好或成功率的依据。

| 原剧情功能 | 可探索的目标语表达 | 需要核对 |
| --- | --- | --- |
| 财富与关系权力 | Billionaire Romance、阶层冲突 | 人物筹码与当地制度，不能只换称呼 |
| 隐藏经历与身份揭示 | Secret Past、职业或家庭秘密 | 经历与能力依据，不凭职业授予权限 |
| 第二次选择 | Second Chance、Time Loop | 是现实和解还是超自然设定 |
| 低位者争取尊重 | Underdog、家庭或职场冲突 | 谁能改变局面及其行动代价 |
| 亲子与秘密关系 | Secret Baby、Single Parent | 家庭结构、人物关系和叙事边界 |

没有来源、日期和样本范围时，不给题材排“验证梯队”或成功率。用户需要市场选择时按[参考研究](../../zero-to-story/references/reference-research.md)核对当前地区、平台与具体作品；排名、个别热剧和评论不能推导新项目成功概率。

文化元素按原场景功能重写：家庭聚会不一定要变成慈善晚宴，彩礼、婚前协议与信托不是相同制度。要保留或改变哪种关系压力由当前改编决定说明；缺少事实依据时用已确认的虚构设定或保留待核实，不编造当地法律或惯例。

观众对反击、长辈权威、开放结局和潜台词的接受因类型、地区与观看情境变化，不把“海外”当成同质观众。人物可以隐忍、直接表达或使用长句；文化梗与缩略语只在当前关系中有用时加入，不作为本地化配额。
