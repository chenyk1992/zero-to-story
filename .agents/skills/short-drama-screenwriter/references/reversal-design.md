# 反转的因果与信息揭示

有叙事需要的MV也可复用，保持已采用歌窗口与音乐主责，不要求商品或影视六Beat。创意型反转可依已建世界规则，证据型反转须让所需证据足以排除当前有意义的替代解释；不把任意意外都当反转。

用于已经需要反转的故事、广告或喜剧段落。反转是叙事机制，可与悬疑、温情、喜剧及不同结局组合；普通写作引用本方法不因此进入微短剧、分集或付费流程。

## 先明确变化

突发事件带来新情况，信息揭示带来新认识，反转则让既有局面的理解、人物目标或处境发生实质改变。根据当前表达选择误判纠正、身份/动机揭示、地位倒置、结果反用或其他有依据的变化，不固定次数、秒数或结尾位置。

写清最初预期、实际原因、此前成立的信息、揭示事件及揭示后的后果。伏笔应支持重新理解，不必在第一次出现时解释；关键原因不能只靠临时新增人物、规则、道具或能力成立。刻意超现实按已建立的世界规则判断，不与真实产品性能主张混淆。

人物改变行动时，先让他获得与代价相称的证据和动机。观众得知真相不等于人物已经知道；角色猜测也不自动成为导演事实。只要求当前作品需要的证据，不把每个反转都做成推理案件。

## 真相、知情与可见信息

在已有创作方案、场景/节拍和剪辑意图中按需记录：

| 关系 | 需要说明 |
| --- | --- |
| 导演真相 | 实际身份、原因、物件数量/归属及规则；未知保留未知 |
| 人物知识 | 谁在何时通过什么证据知道、误解或猜测什么 |
| 观众信息 | 每个节拍获得什么，何时重新理解此前信息 |
| 隐藏与揭示 | 视点、遮挡、听觉或时间省略怎样合理隐藏，哪个动作/声音完成揭示 |

例如同一人伪装身份：人物 ID 与真实关系保留，当前镜头表现伪装造型；揭示前按已定视点控制观众可见信息。完整脸部参考用于身份也不代表必须提前露脸。角色卡不写秘密长文，导演交接仍保留真相及揭示时机，H3 只描述本镜应展示的内容。

相同物件的数量、位置与归属贯穿隐藏前后。遮挡期间的变化需要已有动作、时间省略或设定支撑；“镜头没拍到”本身不能解释物件复制、消失或身份矛盾。需要听觉证据时写清说话人、准确文本及发声关系，不统一改成视觉证据。

## 与喜剧、广告和结局组合

喜剧的目标、地位、误会和反应沿用[喜剧写作](sitcom-writing.md)，笑点可以来自升级或回扣而没有反转。悲剧、大团圆和开放结局都能使用反转；结局结果与叙事机制分别记录，不能把“反转”作为互斥结局推断实际收束。

产品反转广告再由[产品因果](../../advertising-creator/references/product-causality.md)说明商品如何促成变化，普通故事无需新增商品、品牌或卖点。慢动作/冻结只改变呈现时，保留原因果；若运镜提前露出隐藏证据，则检查揭示安排是否仍成立。

## 交接与当前范围

只要剧本就交可拍稿。向导演交接时，关键铺垫、揭示动作、证据与反应进入可拍节拍，锁定对白逐字保留，知识差写入现有备注；实际结尾事件不能只放在宣传或预告里。下游将必需事件落入 coverage 和 Setup，不新增蓝图评分、知识状态 schema 或另一份 H3 草稿。

已有剧本或受控复刻只修改允许项。没有关键证据仍可交带未知的概念；正式制作依赖该证据时明确受影响单元。核对的是因果、理解与时序，不用“反转强度”分数触发生成或自动重试。来源见[编剧来源说明](source-notes.md#通用反转方法)。
