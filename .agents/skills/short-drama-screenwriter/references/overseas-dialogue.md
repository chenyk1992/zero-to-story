# 海外、多语与地域对白

仅在目标语言、地域、人物语言环境或多语互动影响当前稿件时读取。编剧、广告、Presenter 和音乐可复用所需部分，当前作品主责不变。语言是文本与表演事实，不创建 Canvas 字段或额外审批。

## 先锁场景行为，再写句子

沿用谁对谁说、此刻要促成什么、双方知道什么、哪些原句或风格不能改。已锁定台词只补表演交接；明确授权翻译/适配时保留原文对应与实际变化。新英文稿从场景目的与关系直接组织，避免逐词搬运中文语序；正式长句、类型化对白、冷面笑话与反复可以是有意风格，不一律碎句化。

按需要在现有语言/角色/交接备注中记录目标语言、地区、人物日常语言、关系与活动、保护的风格、证据/未知及版本。没有地区要求时不强行增加地区身份。姓氏、外貌、职业或所在地不能单独推出口音、能力和性格；地方名词的密度也不能证明本土化。

## 语言证据的适用范围

| 状态描述 | 依据与使用 |
| --- | --- |
| 地域用法未核实 | 可以完成清楚可演的工作稿；不宣称当地人就这样说，不强加刻板口音 |
| 有材料校准 | 引用实际阅读且接近人物关系/活动的材料，只覆盖其支持的用法 |
| 当前版本已有适当人工复核 | 记录真实复核者、版本与覆盖范围；文本换版后重新判断受影响部分 |

这些是语言证据说明，不替代媒体 ACCEPT，也不阻塞无关创作。下游不能因为句子顺畅、模型支持该语言或 TTS 成功而自行升级证据。用户明确要求当地专业复核时，缺口仅影响该项交付承诺。

## 多语切换改变谁知道什么

逐次想清楚谁在场、谁懂哪种语言、切换的目的及观众何时获得信息。双语能力不自动要求换语；字幕只让观众读懂，不会让剧中角色突然听懂。误解、排除或故意隐瞒必须在后续反应和行动中守恒。

例如甲、乙都懂中英，丙只懂英语。甲用中文提醒乙“别提钥匙”，英文字幕可以解释给观众，丙仍不知道提醒内容；乙不能在下一句默认丙已听懂。同样，人物说“我有钥匙”只是剧情中的自述，不能变成真实系统或项目授权。

## 交给声音、字幕与视频

传递逐字文本、说话人/语言、受保护称呼、必要发音线索、多语窗口及未核实用法；普通说话速度按该语言和实际音轨判断，不套中文字数阈值。配音缺少所需语言/音色时记录能力缺口，不静默换语种。TTS、H3 参考声与最终保留轨的责任按[共同声音交接](../../canvas-workspace/references/creative-handoff.md#声音身份与实际音轨)落实。

文本自然、声音可懂、字幕准确、角色口型相符分别检查；仅字幕译对不证明发音正确。歌词适配还需保护旋律、重音和可唱性；采用歌曲已冻结后只在授权范围改词，并更新受影响音频与时间轴，不能仅改字幕冒充新演唱。
