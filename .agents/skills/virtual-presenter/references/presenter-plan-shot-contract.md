# Presenter Plan 与 Shot Contract

共享授权和实际结果规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本文件只定义数字人口播计划的字段和创作标准。

## 计划用法

presenter_plan.md 是唯一创作信息源。当前阶段所需字段要补齐，或写“不适用/无”；尚未产出的结果留“待生成/待检查”，不要复制一份执行状态到别处。创作阶段可用：

待确认 → 已确认 → 进行中 → 完成

上游已确认字段被修改时，把受影响阶段和下游改为需重审。外部能力或证据不足时标记暂停，并保留原因。

计划至少记录：

| 阶段 | 关键事实 |
|---|---|
| 输入规格 | 角色、声音、语言、环境、画幅、总时长、受众 |
| 环境（需要时） | 全景比例、manifest、方向视图、区域和站位 |
| 文案 | 每段逐字口语、估计或实际时长、停顿、重音、发音；有实际音频且需要时记录采用区间 |
| Shot Plan | 每段的 Shot Contract |
| H3/Canvas | 引用槽位、提示词、provider/mode、参数、快照状态 |
| 结果 | 实际文件、实际末态、需要时的音频证据和判断 |
| 成片（需要时） | 接受的片段、顺序、音频/字幕和最终文件 |

计划记录事实即可；执行判断写在对应 Panel 行，不另建 QC 报告。

## Shot Contract 必填字段

每条 Shot/Panel 是一个可独立交接的 Clip，至少写：

- **身份**：稳定 shot_id、revision、目标画幅、4–15 秒时长。
- **空间**：环境区域、主体站位、朝向；需要 360°时写 yaw、pitch、FOV，不能只写“室内”。
- **镜头**：连续镜头编号、段界类型（首条/同镜头续接/计划切镜或换场）、景别、机位高度/朝向、人物画面位置与大小、背景布局、一个运镜及速度；无运镜写锁定机位，切镜或换场写明原因与新镜头起点。
- **表演**：起始姿态、视线、口播、一个信息意图、主动作、结束姿态；标记 L0/L1/L2（见下表）。需要语言强调时写对应词/停顿、动作进入和收束；关键表情、口型或手势的可见性按需说明。
- **声音**：逐字对白或口播、停顿/重音、环境声、起止尾音、声音生成方案及参考用途；需要保留实际音轨时另写后期责任。来源与区间按下节记录。
- **引用**：角色图、全景、方向视图、声音参考；同镜头续接必须记录上一条同画幅 ACCEPT 的采用版本、来源 run 和从该版本提取的真实尾帧，绑定 `first_frame`；完整视频参考仅按用途补充。
- **连续性**：需继承的机位、景别、构图、背景布局、身份、服装、光向、道具、站位、朝向和未完成动作；本条可见末态。默认同镜头续接，不因口播分段新增切镜。
- **验收重点**：本条必须能观察的主体、动作、空间或声音要求，注明哪些是本段采用条件、哪些由成片后期完成；同镜头续接须实际查看与前段的接缝，确认没有镜头、构图或姿态突变。

## 导演标准

先写本条的镜头目的，再写观众看到的因果动作：起始状态 → 准备 → 一个主动作/语言强调 → 稳定末态。镜头运动要服务视线或信息变化，声音进入点要与口播重音或动作相符。保持自然呼吸、眨眼、轻微视线和重心变化即可；不要在短段里堆叠手势、走位和运镜。动作不能只写“自然”“真实”，要写身体、道具、方向和停点。

## 声音与动作按需记录

这些信息写入已有的声音、表演、验收或成片字段，不另建时间轴或逐词必填表：

- **有实际音频**：听审实际采用版本，注明来源文件/版本和用途。仅作音色参考时记录所需音色事实；作本段节奏基准、需要分割或同步时，才记录原音频起止窗、已听到的对白区间、词锚点及受保护的吸气、词音和句尾余量。区分原音频时点、Panel 内时点与成片偏移；偏移在后期确定后回记。ASR/VAD 只用于定位，不能代替听审或音画同步检查。语速或采用版本改变后，重核受影响区间。
- **只有文案、由 H3 生成声音**：写逐字内容、语速意图、停顿与关键词动作，时长为估计。实际音轨返回后才确认对白起止和字幕时点；没有实际音频就省略音频参考和词级时点，不因本方法另行合成 TTS。
- **需要准确保留原录音**：记录拟采用的实际音轨、必要区间和已核实的后期保留方法及责任；声音参考可以同时用于 H3 生成，两者分别说明。原录音已进入成片也仍需实际查看嘴部同步。保留方法不可用时，保留要求并说明具体缺口，不假定 H3 会复制录音。技术边界见 [H3 控制与后期责任](../../h3-prompt-writing/references/control-boundaries.md)。

例如已听审的 12 秒原录音，若完整对白与句尾余量都能容纳，可规划一个 12 秒 Panel；时长相等仍不能证明同步。“说到‘重点’时右手轻抬、随后放回桌边”是 L1 表演意图，词出现的时间只在实际听审后填写。若只提供文字，则保留这句意图并标“实际时点待生成后核实”。

分段优先选已核实的句或短语停顿，保护完整词音和必要尾音；记录相邻区间时核对对白连续覆盖，避免漏词或重复。原录音保留和 H3 生成声音都沿用这一要求。只有计划时间时，先写停顿意图，实际段界待输出后检查。

需要看清口型或手势时，按当前景别检查脸、嘴、手是否出画或被道具/字幕遮挡；侧脸、遮挡和近景本身不判失败，只有影响本条关键表达时才调整。动作时间与音画同步属于创作和验收要求，不是 H3 的逐帧、词级强制控制。

## 动作预算

| 预算 | 可做 | 避免 |
|---|---|---|
| L0 | 呼吸、眨眼、自然口型、一个微表情；机位基本锁定 | 新手势、转身、道具交互、明显运镜 |
| L1 | L0 加一次视线/头部转移或一个小手势；一次轻微推拉/横移 | 第二个手势或信息转折、快速走位 |
| L2 | 一次拿取、指向、转身等主动作，加一项镜头变化 | 第二件道具、复杂走位、多个信息点 |

口播、动作和镜头无法在 4–15 秒自然完成时，仅在可改写范围内删次要信息；准确复述或已锁定文案靠简化动作、在此范围内调整时长或按自然停顿分段。仍无法容纳时说明具体冲突，不靠快嘴、切词或跳切掩盖超载。

动作预算中的运镜额度不是每个 Panel 都要换镜头。连续镜头默认保持机位与构图；只有已定运镜才描述连续速度和方向，不能在下一 Panel 开场重新构图。明确切镜或换场才开始新的镜头序列，不强迫新机位从旧尾帧起步。

## 环境方向

只有当空间方向会影响 Shot 才建立 Environment Pack。源图需为 2:1 equirectangular；使用脚本生成并登记 yaw 0/90/180/-90、pitch 0°、FOV 90° 的实际视图。计划要写清每个区域“主体在哪里、镜头朝哪里”。缺少可核实的空间输入时保持待确认。

## 修改与接续

文案、时长、画幅、角色锚点、环境方向、声音、引用、段界类型或连续性末态改变时，更新当前 Panel 草稿并提升 revision；已冻结快照和已接受输出保留。不同画幅另建序列。只有上一条完整 ACCEPT 片能成为普通连续性参考；同镜头续接必须从已接受实际采用版本提取真实尾帧，不用角色图、重绘图或未生成文件代替。前段采用版本改变时，重核尾帧来源与下游绑定；缺少尾帧、能力不兼容、拒绝、INCONCLUSIVE 或执行错误时暂停依赖它的下一条。
