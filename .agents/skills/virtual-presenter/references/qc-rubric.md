# Presenter 最小验收

共享验收状态和停止规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本文件只补充数字人口播的观察重点；对当前实际版本做一次必要验收，修改后的版本按共享规则复核受影响部分，不打分、不写分级 QC。

## 判断

- **ACCEPT**：文件可播放，主体身份、空间/动作意图和末态符合当前 Shot Contract 的本段采用条件；本段承担的声音/对白可懂，所需停顿和音画同步有实际证据。
- **REJECT**：能明确看到关键意图、连续性或技术条件不成立，例如身份漂移、关键动作缺失、方向/状态跳变、同镜头段界明显换机位/景别/构图或姿态重置、段内未计划的切镜、黑屏或无法播放。
- **INCONCLUSIVE**：输出存在但关键状态或声音无法观察/确认。把未知写出来，不用推测补齐。
- 技术错误记录在原 run 的状态/错误字段，不传入 `review.decision`；不把日志、轨道存在或不确定 ASR 当作内容证据。

## 只记录本条相关事实

先核对采用范围：原音轨保留或字幕若只属成片后期责任，在备注记待处理，Panel 按本阶段条件判断，不宣称最终同步已通过。若该处理是本段采用条件，先完成必要后期，再检查并绑定原 run 输出目录内的实际派生文件；尚未完成的关键要求记 INCONCLUSIVE。后期采用与版本规则见 [画布指南](../../../../guides/canvas-guide.md#实际媒体连续镜头与后期)。

根据 Shot Contract 记录一句实际末态：位置、朝向、姿态、手持物、接触关系、动作是否完成和仍未知的项目。本阶段需要声音时再记录声音、对白、停顿、同步、可懂度；没有音频写“无音频”。

本段承担准确对白或原录音保留时，听当前采用音轨，确认对白完整、发音可懂、词音和受保护句尾未被裁掉；关键词手势按对应窗口观察其进入和收束。需要口型同步时实际连看画面与声音；嘴部或关键手势不可见则保留相关未知，只处理影响用途的遮挡、出画或身份变化。原音轨存在、提示时点、时长相等和 ASR 文本均不能代替实际视听证据。

同镜头续接实际连看上一条 ACCEPT 采用版本的结尾与本条开头，检查机位、景别、人物画面位置与大小、背景布局、光线和姿态/手势的承接，以及本条镜头关系是否稳定。本阶段承担声音连续性时，检查接缝的对白覆盖、尾音与同步，区分延续前段尾音和重新说一遍前段对白。首帧参数、单张对比或文件存在不代替接缝检查；关键接缝无法查看记 INCONCLUSIVE。明确切镜/换场按计划检查。

## 处理

回填 Canvas 原节点的实际文件、实际末态/音频证据和一次判断。同镜头续接在该判断中简记实际接缝观察即可，不另建报告。ACCEPT 后，为同镜头下一条从实际采用版本提取真实尾帧，完整片仅按用途补充参考；REJECT、INCONCLUSIVE 或执行错误暂停依赖它的接力。需要重做时由调用方改草稿、确认新快照，不自动重试。

全部 Panel ACCEPT 且用户要求成片时，完成全部后期后对最终实际文件做一次完整视听检查，核对可播放性、顺序、接缝及计划要求的对白、原音轨覆盖、口型和字幕同步。

字幕跟随最终实际音轨。发生分段、剪切、变速或插入时，按需记录受影响的原音频窗与成片偏移；换轨或修改后复核改动及受影响的接缝、词音/尾音和同步窗口，旧版结论不能替代新文件检查。只有文案的 H3 口播从生成后的真实声音核实时点。疑点按共享规则只做一次局部复核，仍不清楚就记 INCONCLUSIVE。
