# Presenter 最小验收

共享验收状态和停止规则见[项目共享生产规则](../../../../docs/ai-system-prompt.md)。本文件只补充数字人口播的观察重点；每个实际 Panel 只做一次判断，不打分、不写分级 QC。

## 判断

- **ACCEPT**：文件可播放，主体身份和空间/动作意图符合当前 Shot Contract，且能确认本条需要的末态；有音频要求时声音、对白、停顿和同步可懂。
- **REJECT**：能明确看到关键意图、连续性或技术条件不成立，例如身份漂移、关键动作缺失、方向/状态跳变、黑屏或无法播放。
- **INCONCLUSIVE**：输出存在但关键状态或声音无法观察/确认。把未知写出来，不用推测补齐。
- 技术执行错误单独记录为 ERROR；不把日志、轨道存在或不确定 ASR 当作内容证据。

## 只记录本条相关事实

根据 Shot Contract 记录一句实际末态：位置、朝向、姿态、手持物、接触关系、动作是否完成和仍未知的项目。只有计划需要声音时再记录：声音、对白、停顿、同步、可懂度；没有音频写“无音频”。

有上一条 ACCEPT 片时，只观察本条开头是否接上可见末态；不为无连续性要求的项目增加检查。

## 处理

回填 Canvas 原节点的实际文件、实际末态/音频证据和一次判断。ACCEPT 后，下一条才可引用完整片或按模式提取真实尾帧；REJECT、INCONCLUSIVE 或 ERROR 暂停依赖它的接力。需要重做时由调用方改草稿、确认新快照，不自动重试。

全部 Panel ACCEPT 且用户要求成片时，对最终文件只检查可播放性、顺序、接缝及计划要求的声音/字幕同步。
