# Presenter QC Rubric

## 判定原则

QC 只依据 Shot Contract、已确认 baseline 和当前片的可观察证据。把每条片标记为 PASS、REVIEW 或 FAIL，同时记录画幅、shot_id、revision、检查器、时间和证据。缺少证据不是 PASS。

自动流程在首片双画幅确认后开始：剩余片按计划生成、QC、接受或重做，默认不逐片打断用户。任何改变已确认 baseline 的修订都回到用户确认。

## 检查项

| 类别 | PASS 条件 | REVIEW/FAIL 例子 |
|---|---|---|
| 身份与外观 | 角色图的脸、发型、服装、配饰、人数和关键道具保持；无身份漂移 | 脸或服装明显漂移、出现第二人、道具数量改变 |
| 口播与口型 | 文案完整可懂，口型与 ref_audio_0 或 ref_video_0 配对音轨同步，停顿和发音自然 | 漏词、抢拍、卡口、无声口型、声音尾音截断 |
| 表演预算 | 在 L0/L1/L2 内完成一个信息意图，动作起止清楚 | 多个手势/转折叠加、瞬移、动作未收束 |
| 空间连续性 | 区域、yaw、站位、光向、镜头方向和 ref_image_2 一致 | 方向翻转、背景穿帮、站位跳变、环境区域错误 |
| 镜头与画幅 | 景别、唯一运镜、速度和目标画幅稳定，主体不被裁切 | 抖动、突然推拉、错误画幅、脸/手出框 |
| 连续性 | 后续片正确继承上一接受片的可见末态，并用 ref_video_0；不引入未计划状态 | 手中物消失、姿态跳变、音频尾音断开 |
| 真实感与安全 | 自然光影、手指、眼睛、嘴和边缘可接受；无文字水印或生成伪影 | 多指、融脸、闪烁、文字、重影、明显合成痕迹 |
| 声音与环境 | 口播清晰，环境声不遮盖核心词，起止与片段长度匹配 | 爆音、噪声盖词、环境声突然切换 |

## 评分与动作

建议每项给 0–2 分：

- 2：满足 Shot Contract，可接受；
- 1：轻微问题，不影响理解，记为 REVIEW 并人工决定是否接受；
- 0：违反身份、口播同步、空间连续性或安全要求，记为 FAIL。

出现身份漂移、关键文案漏失、方向错误、严重口型失配或明显伪影时，即使总分高也不得 PASS。每条片的 qc_evidence 写出问题出现的时间段和对应 contract 字段。

## MiMo 路径

1. 先提取首/中/尾关键帧，分别与角色图、当前环境方向视图和同画幅上一片末态对比；再用可用的 MiMo 解析视频与证据帧。要求返回可解析的结构化对象，至少含 `shot_id`、`aspect_ratio`、`transcript`、`scores`（身份、环境、声音、动作、镜头、连续性）、`evidence`（时间段）和 `verdict`。
2. MiMo 不可用、超时或返回无法解析的结果时，保持“未判定”，只重试一次；不要把原始文本或空结果默认为通过。
3. 第二次仍不可用时，将计划状态设为 暂停，保留已生成片和输入，等待用户选择人工复核或稍后恢复。
4. MiMo 判定与人工观察冲突时，以已确认 baseline、可观察证据和用户决定为准，并记录冲突原因。

Scene D 要分别评估“只用同画幅上一片视频及其配对音轨”和“上一片视频 + `ref_audio_0`”。只有后者的声音评分不下降且连续性评分不降低，才在对应 Shot Contract 写 `include_voice_reference: true`；否则保持默认，不传独立声音参考。

## 重做上限

- FAIL 且属于语义、表演、连续性或口播问题：按原 Shot Contract 修订提示词，最多语义重做 2 次；每次提升 revision 并保留失败证据。
- 只是外部能力暂时不可用，不把重试计作语义重做；仍遵守 MiMo 只重试一次的规则。
- 第 2 次语义重做仍 FAIL，或需要更改角色/环境/方向/声音/baseline：暂停，请用户选择改计划、接受 REVIEW 或终止该片。
- PASS 后才把输出写入对应画幅的“已接受片”，并可作为同画幅下一片的 ref_video_0。REVIEW 只有用户明确接受后才可成为下一片输入；横竖画幅不得交叉引用。

## 首片基线

两种目标画幅的 S001 要分别展示和确认。确认记录必须包含画幅、输出路径、用户依据和锁定的 baseline。未确认的画幅不进入剩余自动生成；两个首片都通过后，剩余片自动按顺序运行 QC。

最终每个画幅约 29–32 秒；台词归一化相似度至少 0.90，身份、环境、声音和连续性均至少 4/5，并且不得出现身份切换、环境跳变、严重肢体错误或台词缺句。自动评分通过后仍需用户对最终双画幅成片做目视验收。
