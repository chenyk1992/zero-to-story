# Presenter 最小验收

共享验收状态和停止规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本文件只补充数字人口播的观察重点；每个实际 Panel 只做一次判断，不打分、不写分级 QC。

## 判断

- **ACCEPT**：文件可播放，主体身份和空间/动作意图符合当前 Shot Contract，且能确认本条需要的末态；有音频要求时声音、对白、停顿和同步可懂。
- **REJECT**：能明确看到关键意图、连续性或技术条件不成立，例如身份漂移、关键动作缺失、方向/状态跳变、同镜头段界明显换机位/景别/构图或姿态重置、段内未计划的切镜、黑屏或无法播放。
- **INCONCLUSIVE**：输出存在但关键状态或声音无法观察/确认。把未知写出来，不用推测补齐。
- 技术执行错误单独记录为 ERROR；不把日志、轨道存在或不确定 ASR 当作内容证据。

## 只记录本条相关事实

根据 Shot Contract 记录一句实际末态：位置、朝向、姿态、手持物、接触关系、动作是否完成和仍未知的项目。只有计划需要声音时再记录：声音、对白、停顿、同步、可懂度；没有音频写“无音频”。

同镜头续接必须实际连看上一条 ACCEPT 采用版本的结尾与本条开头，确认机位、景别、人物画面位置与大小、背景布局、光线和姿态/手势没有造成割裂感的突变，同时查看本条是否维持已定镜头关系。需要声音时检查接缝的对白、尾音和同步。首帧参数齐全、单张对比或文件存在不代替实际接缝检查；无法查看关键接缝时记 INCONCLUSIVE。明确计划的切镜/换场按计划检查，不要求同镜头无缝延续。

## 处理

回填 Canvas 原节点的实际文件、实际末态/音频证据和一次判断。同镜头续接在该判断中简记实际接缝观察即可，不另建报告。ACCEPT 后，为同镜头下一条从实际采用版本提取真实尾帧，完整片仅按用途补充参考；REJECT、INCONCLUSIVE 或 ERROR 暂停依赖它的接力。需要重做时由调用方改草稿、确认新快照，不自动重试。

全部 Panel ACCEPT 且用户要求成片时，对最终文件只检查可播放性、顺序、接缝及计划要求的声音/字幕同步。
