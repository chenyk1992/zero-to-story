# H3 Presenter Prompt

本文件把一个已确定 Shot/Panel 的创作事实整理给 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md)。它不是提供方调用说明，也不写文件路径、数据库字段或最终导出规格。

## 写作顺序

用具体、可观察的语言依次写：

1. **空间**：已确认区域、主体站位、朝向、yaw/pitch/FOV（需要时）、机位和背景关系。
2. **身份**：角色图可见的发型、服装、配饰、道具和身份锚点；不凭空添加变化。
3. **镜头**：画幅、景别、机位、人物画面位置与大小、背景布局、唯一运镜、速度和稳定性。同镜头续接默认保持这些关系，不因分段重新构图或自行切镜；无运镜时锁定机位。
4. **表演**：起始姿态 → 一个主动作或语言强调 → 结束姿态；自然呼吸、眨眼、视线和重心作为底层。需要词锚点时写在何词/停顿准备、强调和收束，并保持关键嘴部或手势可见。
5. **口播**：逐字短句、语气、停顿、重音、发音和口型同步；4–15 秒内可说完。有实际音频时采用本条需要且已听审的声音/节奏事实；没有音频时只写计划意图。
6. **连续性**：同镜头续接从独立首帧末态发展，不复演收尾。前段完整 ACCEPT 视频只补充运动/尾音承接，原片只贡献已定保留关系，各按实际标签描述。普通视频不等于精确首帧或保证声音连续，只有明确切镜/换场才按新起点写作。
7. **收束与负向**：明确可见末态；只列本条最可能发生且能观察的错误。

## 引用编号

Canvas 实际解析的每类紧凑列表从零基槽映射一基标签，用途不固定编号。身份、环境、方向图及声音只绑定需要的项，省略时其余按实际顺序编号，不留空槽或补填充素材；contact sheet 不当方向图，正文不写路径/内部 ID。

| 实际视频输入 | 新草稿绑定与用途 |
| --- | --- |
| 仅原片 | ref_video_0 / Video 1：原片保留关系，不伪造 ACCEPT |
| 仅前段 | ref_video_0 / Video 1：前段完整 ACCEPT 的运动/尾音 |
| 两者都有且有用途 | 前段 ref_video_0 / Video 1，原片 ref_video_1 / Video 2 |

已有顺序按真实快照，不强制重排；顺序改变同步当前标签。真实尾帧独立 first_frame，不占 Picture 编号，绑定上一条已接受实际版本，普通视频不能替代。普通 R2V 关闭/省略 frame_zero_video_guide，启用它的时序前缀路线须另核能力。

## 声音交接边界

提供本条 H3 声音方案、<Audio 1> 的实际用途和逐字对白。无实际音频时省略 <Audio N> 和词级时点；已听审的节奏事实按需引用。原音轨保留的版本、区间和后期责任留在计划/Canvas，按 [Shot Contract](presenter-plan-shot-contract.md#声音与动作按需记录) 记录。提示词中的复用、口型与动作时点是创作意图，当前能力见 [H3 控制与后期责任](../../h3-prompt-writing/references/control-boundaries.md)。

## 可读模板

将事实展开为自然语言，不直接把字段名堆给模型：

~~~text
在已确认的【区域】内，主体站在【站位】，朝向【方向】。
保持【角色图可见身份锚点】。使用【画幅/景别/机位】，保持【人物画面位置与大小、背景布局】，镜头【锁定或按计划连续承接的唯一运镜】。
同镜头续接时，从所提供首帧可见的【姿态、视线、手势和道具状态】直接向前发展，不重新摆姿、不改变开场构图，不复演前段收尾。
从【起始姿态】开始，以【L0/L1/L2】完成【一个主意图和可见动作】。
主体以【已确定的声音方案与参考用途】说：“【逐字口语文案】”，在【停顿/重音】处停顿并保持口型同步；需要时，在【词/停顿】处完成【一次强调动作及收束】。
保持【服装、光向、道具、视线和空间关系】，最后停在【可见末态】。
若有前段 ACCEPT 视频，按其实际 <Video N> 标签补充【运动与声音尾音】；若有原片，按其实际标签保留【已定构图/运动关系】，不混淆用途。
排除【本条相关的身份漂移、多人、肢体错误、方向翻转、未计划的切镜/变焦/构图重置、姿态跳变、口型失配等】。
~~~

自然表现要求必须通过身体、视线、道具和速度表达；不要只写“更真实”“更自然”。

本条易错项供正文避错，不输出独立 `negative prompt` 字段。

模板中的首帧承接句只用于同镜头续接；首条或明确切镜/换场时改为本镜头已确定的起始画面，不要求同时维持旧画面并切换新机位。首帧只约束开场，正文仍须维持整段已定镜头关系，不能以开场对齐代替整段镜头稳定。

## 给下游的最小事实

交给 h3-prompt-writing 时提供：Panel 时长/画幅、输入模式、各引用用途、角色和空间锚点、连续镜头编号与段界类型、镜头和主动作、逐字文案与声音方案、起止状态、连续性依赖、本条易错项。节奏、对白区间与词锚点只传本条需要且已听审的事实，计划时间注明为意图；后期处理注明责任。同镜头续接附独立首帧的可见末态、须维持的构图和接缝验收要求；素材路径留在 Canvas。
