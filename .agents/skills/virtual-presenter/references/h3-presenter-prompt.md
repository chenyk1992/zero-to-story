# H3 Presenter Prompt

本文件把一个已确定 Shot/Panel 的创作事实整理给 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md)。它不是提供方调用说明，也不写文件路径、数据库字段或最终导出规格。

## 写作顺序

用具体、可观察的语言依次写：

1. **空间**：已确认区域、主体站位、朝向、yaw/pitch/FOV（需要时）、机位和背景关系。
2. **身份**：角色图可见的发型、服装、配饰、道具和身份锚点；不凭空添加变化。
3. **镜头**：画幅、景别、机位、人物画面位置与大小、背景布局、唯一运镜、速度和稳定性。同镜头续接默认保持这些关系，不因分段重新构图或自行切镜；无运镜时锁定机位。
4. **表演**：起始姿态 → 一个主动作或语言强调 → 结束姿态；自然呼吸、眨眼、视线和重心作为底层。
5. **口播**：短句、语气、停顿、重音、发音和口型同步；4–15 秒内可说完。
6. **连续性**：同镜头续接从独立首帧输入的可见末态向前发展，承接姿态、视线、手势、道具和光线，不复演前段收尾。存在 <Video 1> 时仅用上一条完整 ACCEPT 片补充动作和声音尾音的承接要求，不把它当精确首帧或保证声音自动连续。只有明确计划的切镜或换场才按新镜头起点写作。
7. **收束与负向**：明确可见末态；只列本条最可能发生且能观察的错误。

## 引用编号

Canvas 槽位从 0 开始，提示词标签从 1 开始；缺项不顺延：

| 标签 | Canvas 槽位 | 用途 |
|---|---|---|
| <Picture 1> | ref_image_0 | 角色/身份锚点 |
| <Picture 2> | ref_image_1 | 全景或 360°环境源 |
| <Picture 3> | ref_image_2 | 当前方向视图 |
| <Audio 1> | ref_audio_0 | 声音参考 |
| <Video 1> | ref_video_0 | 同画幅上一条完整 ACCEPT 片 |

不要把 contact sheet 当方向视图；不要在提示词里写实际路径或内部 ID。首条没有 <Video 1>。同镜头续接必需的精确首帧由 Canvas 绑定上一条已接受实际采用版本的真实尾帧；它是独立输入，不凭空编号为 <Picture N>。完整视频参考按用途补充，不能代替首帧。

## 可读模板

将事实展开为自然语言，不直接把字段名堆给模型：

~~~text
在已确认的【区域】内，主体站在【站位】，朝向【方向】。
保持【角色图可见身份锚点】。使用【画幅/景别/机位】，保持【人物画面位置与大小、背景布局】，镜头【锁定或按计划连续承接的唯一运镜】。
同镜头续接时，从所提供首帧可见的【姿态、视线、手势和道具状态】直接向前发展，不重新摆姿、不改变开场构图，不复演前段收尾。
从【起始姿态】开始，以【L0/L1/L2】完成【一个主意图和可见动作】。
主体自然说：“【口语化文案】”，在【停顿/重音】处停顿并保持口型同步。
保持【服装、光向、道具、视线和空间关系】，最后停在【可见末态】。
若有 <Video 1>，只延续它的【末态和声音尾音】，不重置状态或增加无关动作。
排除【本条相关的身份漂移、多人、肢体错误、方向翻转、未计划的切镜/变焦/构图重置、姿态跳变、口型失配等】。
~~~

自然表现要求必须通过身体、视线、道具和速度表达；不要只写“更真实”“更自然”。

模板中的首帧承接句只用于同镜头续接；首条或明确切镜/换场时改为本镜头已确定的起始画面，不要求同时维持旧画面并切换新机位。首帧只约束开场，正文仍须维持整段已定镜头关系，不能以开场对齐代替整段镜头稳定。

## 给下游的最小事实

交给 h3-prompt-writing 时同时提供：Panel 时长/画幅、输入模式、每个引用的语义用途、角色和空间锚点、连续镜头编号与段界类型、镜头和主动作、文案/音频、起止状态、连续性依赖、必要负向。同镜头续接明确独立首帧的可见末态、须维持的构图和接缝验收要求；素材实际路径留在 Canvas 绑定。
