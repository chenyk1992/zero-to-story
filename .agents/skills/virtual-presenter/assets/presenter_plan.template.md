## 4. Shot Plan

每行是一个 4–15 秒的生成 Panel，分段不代表换镜头。先写镜头目的，再写可观察动作、镜头、声音和结束状态；动作预算用 L0/L1/L2。同镜头续接必须使用上一条 ACCEPT 采用版本的真实尾帧，默认锁定机位；有已定运镜时连续承接。首条或明确切镜/换场按新镜头起点准备输入，切镜须写明原因。

强调动作按需写对应词或停顿、准备与收束，并注明关键嘴部或手势的可见性；声音时点与后期责任沿用文案记录。锁定文案超出时长时按 [动作预算](../references/presenter-plan-shot-contract.md#动作预算) 调整。

| Panel | 首帧 / 采用来源 run 与版本 | 引用槽位 | H3 提示词版本 | provider / mode / 参数 | Canvas node_id | 快照状态 | 实际结果 |

| P001 | 首条：按本镜头起点准备输入 | ref_image_0/1/2、ref_audio_0 |  |  |  | 草稿 | 待生成 |

固定槽位：ref_image_0=角色，ref_image_1=全景，ref_image_2=方向视图，ref_audio_0=声音；后续按用途补充上一条同画幅完整 ACCEPT 片为 ref_video_0。H3 标签对应 Picture 1/2/3、Audio 1、Video 1。

同镜头续接另行必填 first_frame，来源为上一条同画幅完整 ACCEPT 实际采用版本的真实尾帧；登记 derived_outputs，以 source_run_id 和 require_accept 绑定来源运行，不占普通图片参考编号。本地 Comfy 可用 r2v + first_frame 保留角色/声音参考，frame_zero_video_guide 关闭或省略；能力或已确认配置冲突时暂停，不退回仅视频参考。只有真实尾帧与来源绑定齐全后才可 ready。
