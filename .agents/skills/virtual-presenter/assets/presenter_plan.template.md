## 4. Shot Plan（待确认）

每行是一个可独立重做的 Shot Contract；时长必须在 4–15 秒。动作预算只选 L0、L1、L2，并在备注中说明为什么没有超载。

| shot_id | 画幅 | 时长 | 动作预算 | 区域/yaw | 景别/唯一运镜 | 起始姿态 → 结束姿态 | 文案 | 声音尾音 | 连续性输入 → 输出 | 独立声音引用 | 重做次数 |
|---|---|---:|---|---|---|---|---|---|---|---|---:|
| S001 |  |  | L0/L1/L2 |  |  |  |  |  |  | 默认/对比通过 | 0 |

### 动作预算

- **L0 静态**：站位和镜头基本锁定；只允许呼吸、眨眼、自然口型和一个微表情。
- **L1 轻微交流**：在 L0 基础上最多一个小手势或一次头/视线转移；镜头只做一种轻微变化。
- **L2 单一复杂意图**：允许一次拿取/指向/转身等主动作和一项镜头变化；不叠加第二个道具动作或第二个信息转折。
