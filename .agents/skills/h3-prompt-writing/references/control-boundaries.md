# 创作要求与当前 H3 控制边界

遇到精确同步或外部控制方法时，用本参考核对输入与后期责任。沿用已定剧情和创作路线，提示词格式不变；执行与授权遵守[项目共享生产规则](../../../../guides/ai-system-prompt.md)。

## 从实际接口判断控制方式

本地输入以当前 [Comfy H3 能力描述](../../comfy-video-executor/capability.json)、[adapter](../../comfy-video-executor/scripts/execute.py) 和[工作流约定](../../../../guides/workflow-conventions.md)为准。提示词中的关系名称不代表执行端有同名控制接口。

- T2V 不接媒体；I2V 接一张首帧；FL2V 接首尾两帧。R2V 接普通图片、视频、音频参考，可另接首帧引导，不接尾帧；首帧引导不能替代 R2V 必需的普通参考。
- 当前 R2V 上限为图片 9 项、视频 3 项、音频 3 项。只绑定当前 Panel 需要的参考；一张多格分镜板仍是一项图片。单张首帧引导不占普通参考槽，在第 0 帧提供引导，不锁定后续动作或道具状态；使用它时关闭或省略 `frame_zero_video_guide`，否则 adapter 优先使用视频前缀引导。
- 当前本地时长参数为 0.2–15 秒，视频工作流为 24 fps。故事与连续口播沿用各自的 4–15 秒 Panel 规划，其他用途按实际能力安排。生成文件的实际时长可能因工作流帧数对齐而不同；后期源范围、接缝和歌曲窗口以实际产物为准，不按参数值截断对白或推算真实尾帧。画幅、像素预算、采样配置与步数沿用已采用规格。
- 当前接口没有姿态骨架、深度图条件、区域重绘遮罩、摄影机轨迹、Deforum 参数曲线或强制口型时间轴。动作与构图可以用文字描述，但这些外部控制通道不能登记为已绑定输入。

## 区分输入约束、生成意图与后期责任

| 创作要求 | 当前可以怎样落实 | 结果仍需确认什么 |
| --- | --- | --- |
| 人物身份、服装、场景及关键道具 | 沿用稳定文本锚点或实际参考；状态变化留在当前 Shot 描述中 | 多角度、遮挡和运动中的身份与道具关系；参考绑定不保证整段一致 |
| 首尾构图与动作承接 | 依模式提供实际首帧/尾帧，或 R2V 首帧引导；描述起止状态间的可见路径 | 实际画面及接缝是否成立；输入引导不保证逐像素一致，依赖前段时须用已 ACCEPT 的实际采用版本 |
| 特定时刻切镜、重音时的动作或字层变化 | 沿用批准切点及声音事件，用规定 Shot 语法和正文描述目标 | 分别观察实际切点、动作落点和口型；提示词时间不提供逐帧强制控制 |
| 原语音/原歌声、准确台词和音色 | 写明实际音频用途、说话人/演唱者、准确原文及已核实时序；可见演唱绑定 R2V 实际歌曲片段 | 声音参考、H3 生成声音与后期保留原音轨可组合使用；写 `audio reuse` 或接入音频不能证明输出逐样本相同或口型精确 |
| 精确歌词、字幕、空间文字及遮挡 | 保留上游已选的生成式文字事实和准确原文，准备其实际字图/首帧/参考；独立字幕按已选后期责任处理 | 字形、可读窗口、透视/遮挡和音画同步须看实际视频；普通字幕器不能冒充空间跟踪 |
| 局部修订构图、表演或道具状态 | 修改草稿并核对素材、依赖；已有授权覆盖修改后的输入时沿用授权，经 Canvas 确认新快照 | 检查实际变化及受影响关系；局部改稿不保证只改变指定像素区域，历史快照与媒体仍保留 |

后期责任应注明作用于当前 Panel 的采用版本还是最终成片，验收相应实际文件。仅在成片执行的音轨或字幕处理留待成片检查；若当前片段的关键用途依赖该处理，须处理后再判断能否采用。现有基础剪辑与字幕接口不包含空间跟踪、区域修复或任意音量/视觉曲线；缺少能力时说明受影响要求，保留用户原目标。

## 把外部方法改写成可观察的镜头设计

把变化写清起点、触发、过程和结果。调整拍法时说明具体差异，保留锁定对白、关键动作与文字；严格要求无法执行时报告缺口，不自行降低目标。

- **音乐脉冲：** “每 0.12 秒精确改变 zoom”需要当前没有的逐帧曲线接口。可提供自然动作的候选方案，并说明它与原精度要求的差异；生成式字层仍按已定责任交给 H3。
- **词语强调：** “说到‘这里’时抬手指向桌面，强调后放松”可以作为表演意图。只有实际音频证据支持时才给具体时点，写入时间也须检查实际口型和手势落点。
- **人物转身：** 关键动作露出背部道具时，核对参考是否覆盖所需状态；有缺口就补必要视角或提出局部调度建议，只暂停依赖该状态或参考的镜头。
