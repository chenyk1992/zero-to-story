# 单 Panel H3 提示词

遵守[项目共享生产规则](../../../guides/ai-system-prompt.md)。输入齐全后直接写作，输出只含一份提示词；不再要求用户确认已有创作决定。

## 输入与模式

需要当前 Panel 的：模式、精确时长、镜头及切点、动作与起止状态、画风/视觉锚点、逐字对白和声音要求，以及模式要求的实际素材与引用槽位。采用上游已确定的机位、节奏和字幕/后期责任。缺少会改变生成结果的必要输入，或输入相互冲突时，简短说明具体缺口；不编造素材或静默改模式。非必需细节可按创作意图写清，不把它们变成新的审批。

| 模式 | 输入与写法 | 只读取对应参考 |
| --- | --- | --- |
| T2VA / `video.text_to_video` | 无媒体输入；用已确定的文本锚点建立画面与声音 | [基础格式](references/base-en.txt) |
| I2VA / `video.image_to_video` | 一张精确首帧；从已完成的可见状态向前发展 | [基础格式](references/base-en.txt) |
| FL2VA / `video.first_last_frame` | 精确首帧和尾帧；写清两帧之间的连续路径 | [基础格式](references/base-en.txt) |
| Ref2VA / R2V / `video.reference_to_video` | 已提供的图片、视频或音频参考；不把普通参考当精确首帧 | [全参考格式](references/ref-en.txt) |

当前 Canvas 不支持仅尾帧 L2VA。选定模式还须符合当前能力说明，不因 H3 文本格式存在就假定执行端支持。

遇到精确同步、姿态/轨迹/曲线控制、原音轨保留或局部画面修复要求时，读[创作控制边界](references/control-boundaries.md)，核对实际输入和后期责任。

本地 Comfy R2V 可另带 `first_frame`，形成第 0 帧视觉引导；交接必须区分它与普通参考槽。沿用全参考六字段，开场从该帧可见末态推进，人物/音频标签保持原槽位；不要把引导帧凭空编号为 `<Picture N>`，只有它确实也占用图片参考槽时才使用对应编号。若需改变构图，先承接开场再执行已定的运镜或切点，不同时要求第 0 帧保持旧画面并换新机位。不能宣称像素级锁定或音频自动连续。

上游使用实际采用歌曲且人物可见演唱或说唱时（包括独立MV、广告及影视歌曲表演），当前 Panel 必须是带对应实际歌曲片段 `reference_audio` 的 R2V。按真实槽位写 `<Audio N>`，说明它对应哪位演唱者及本段唱词、起口和停顿；成片音频由当前主责后期按实际主歌曲处理。若输入只有歌词或首帧、没有该段音频绑定，指出具体缺口，不写成已经由原曲驱动的口型。无可见张口的镜头不强加音频参考；普通对白/口播仍沿各自上游声音方案，不机械套演唱规则。

多人歌曲沿用上游已经冻结的角色图片与实际声源映射；`reference_audio` 使用最终采用混剪的同窗口裁片，逐句写明演唱者、轮唱交接、齐唱和其他成员非演唱时段。混合音频不能自动证明逐人声源归属或多人同步，不能用未对齐干声替代主音轨。未提供角色轮唱表时报告具体身份/时序缺口，不凭女团描述自行分配声音。

上游为 `virtual-presenter` 同镜头连续口播时，真实尾帧首帧输入是必需事实，完整视频参考不能替代。写清从首帧末态直接继续口播，保持机位、景别、人物画面位置与大小、背景布局和光线；无已定运镜时锁定机位，有运镜时连续承接，不因 Panel 分段重新构图、摆姿或新增切镜。缺少首帧或模式冲突时报告具体缺口；只有上游明确计划的切镜或换场才按新镜头起点写作。具体事实按 [Presenter 提示词交接](../virtual-presenter/references/h3-presenter-prompt.md)读取，不把此要求扩展到独立镜头或其他创作类型。

## 写作步骤

上游提供产品利益证据、反转信息窗口或[时间效果事实](../zero-to-story/references/time-effects-direction.md)时，将本段实际可见可听的动作、冻结/可动对象、环绕、恢复和声音关系写入既有描述字段，沿用 Panel 内时点。身份参考不表示提前揭密；冻结可见嘴部与正常同步对白冲突时指出缺口，不自动改 VO。不得添加速度曲线、冻结遮罩或 provider 参数。

1. 核对当前 Panel 的模式、素材和时长能否相互满足。连续接力从前段已完成状态开始；硬切或换场从本段批准的新机位开始，不复演前段收尾。
2. 按所选参考的字段顺序组织提示词。T2VA/I2VA/FL2VA 使用三个核心字段；Ref2VA 使用六个字段。I2VA/FL2VA 的首行对齐指令照基础格式填写。
3. 按实际 Camera Setup（摄影镜头）写 `[Shot N]`。每镜写清构图与主体、动作如何发生和完成、摄影机如何运动、声音如何对应；只包含当前可见可听且有用途的信息。
4. 返回前随写作核对一次：字段顺序、引用标签、镜头切点、逐字对白。不要另写检查报告。

调用方将这份提示词保存到 Canvas 草稿后，可按[定稿提示词检查](references/prompt-validation.md)读取当前版本的结构结果。H3 写作者仍只返回完整提示词，不需要拥有 Canvas 工具，也不把检查 JSON 追加到提示词。

上游若提供故事板的六个 Beat 映射，Beat 是语义时刻，不等于六个镜头；一个 Setup 内的发展放在同一 Shot，P002 以后的边界 Beat 是零时长上下文，不添加动作、对白或时长。广告、音乐MV等没有该映射的输入，直接按已确定的 Shot 与歌曲切点写作，不补造 Beat。所有输入的切点与对白窗口均沿用已确定事实，不拉伸、压缩、重排或补造。

上游已指定由生成承担的动态文字、拼贴或空间字层，须在对应 Shot 的描述正文保留准确原文、字形/材质、层级与遮挡、Panel 内进入/可读/变化/退出时刻及动作关系；基础模式写入 `integrated_multimodal_description`，全参考模式写入 `detailed_description`。不要将这些要求改成“后期添加字幕”，也不在规定字段之外追加新顶层字段。只有上游明确交后期的事件才不要求在画面中生成；该分工不改变歌词原文保留规则。

有参考界面、非人替换或服装动态时，把上游已定的背景UI组织/滚动关系、新主体结构与表演适配、面料对动作的响应写入同一描述正文；关键文字仍逐字，背景小字不自行编成新剧情。只消费当前已定事实与生成责任，不新增控制字段或声称精确编辑；严格声线/原音策略按[共同声音交接](../canvas-workspace/references/creative-handoff.md#声音身份与实际音轨)与[控制边界](references/control-boundaries.md)核实。

## 引用与严格格式

- 全参考模式按 `subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music` 排列；基础模式按 `integrated_multimodal_description → overall_soundscape → non_diegetic_music` 排列。
- Canvas 槽位 `ref_image_0`、`ref_video_0`、`ref_audio_0` 分别映射 `<Picture 1>`、`<Video 1>`、`<Audio 1>`，后续槽位同样从零基转为一基编号；保留槽位身份，不补号、不重复、不虚构参考。
- 编号依据实际解析后的紧凑列表，不把身份/原片/前段等用途永久绑定某槽，不预留空槽。顺序改变同步当前标签，历史快照不改；尾帧独立 first_frame，普通 R2V 不启用视频前缀选项。
- 受控复刻只改明确项，其余相关观察关系保留，未知不补成事实，时序不平均化。混合文字按[逐项文字与时间](../canvas-workspace/references/creative-handoff.md#逐项文字与时间)读取源表：post 摘要仍写生成项，只把已分配项留给后期，不新增格式。表演发展在同一 Shot 内，不擅改机位/对白或增加独立动作。
- `<Subject N>` 只用于需要跨镜复用或单独说明参考保留关系的内容；普通布景和一次性道具直接写进镜头正文，不为每个名词创建标签。相同人物或道具的状态变化沿用同一身份。
- 先区分规划故事板和最终展示网格：最终网格同时存在，格内局部动作不是时间Shot；主格全屏开场须匹配实际首帧，目标海报R2V参考不保证精确结束。所需事实读[布局动效](../visual-design-creator/references/layout-motion-handoff.md)，保留已定画幅适配与实际关键状态，写清归位后的格位/间距/边界及允许运动窗口，不套故事板阅读时刻语义或把所有过程锁死。
- 一张分镜板只占一个 `<Picture N>`。保留已确定的 2–6 格 `rowsxcolumns` 布局与从左到右、从上到下顺序；板内格子不成为独立素材或额外 Shot。
- 第一镜写 `[Shot 1] 描述正文`，后面不带 `At`、`From` 或时间范围。后续写 `[Shot 2] At 00:04.000, ...`，时间取自批准切点并严格递增。
- 描述字段用英文；对白、歌词和场景可见文字保留原语言、原文和标点。对白标记、说话人和发声时机按对应参考格式填写。
- 只返回完整提示词，不加标题、解释、代码围栏、negative prompt 或元数据。调用方将其原样保存到目标 Canvas 视频节点。
