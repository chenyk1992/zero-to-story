# 实拍世界与动态图形的标题序列

当真实摄影空间和图形共同建立作品身份时读取；它可以克制，也可以复杂鲜明，不预设城市、卡司或效果密度。字体机制按需取[共演方法](../../mg-voiceover-animation-generator/references/type-subject-direction.md)，片头持有作品与准确文字，专业方法返回原计划。

## 从作品里找到运动母题

先找已经属于这部作品的线索：修复工作的手势、交通的方向、建筑的轴线、人物之间的距离或一道反光。让文字、窗口和图形继承这条线索，随后在新信息中变化，最后回收到片名。不是先挑一串特效再给每个镜头找理由。

例如原创维修题材片头“夜班轨迹”：车间传送带的横向运动引出姓名；窗框切成不同工作位置，镜头稍慢时名字完整可读；下一镜通过轨道方向匹配，前段的细线成为片名基线。高能版本可在班次交接中加快尺度与窗口交换，安静版本保留长一点的工作观察。姓名和身份只能来自当前真实资料或明确原创提案。

## 把摄影与字层放在同一关系中

在所选Shot说明：真实主体/空间与机位，文字依附的表面或独立深度，谁从前面经过，焦点和受光怎样对应，何时能读完整。相机移动时有相符透视与视差；需要阅读时允许相机或图形停住。不要把每种摄影属性都变成必填检查；只展开本镜会被看见、会影响用途的关系。

多窗口能表现同时发生的工作或关系，反射可把未见空间带进画面，字的轮廓可以成为转场；选择要由作品身份支持。若只是普通姓名叠字，按该目标完成，不自动扩成复杂空间合成。若已经选了空间共演，普通字幕不能代替。

## 源素材与实现责任

原创写实生成与保留真实原片分开。前者把完整摄影、字层、遮挡和发展交H3；后者核实原片、遮罩/跟踪、字形与真实合成能力，不承诺视频参考可保存原像素或精确人物表演。原片有用的摄影关系和允许变化写清，普通参考不变成首帧锁定。

准确片名/姓名按文字事件关联当前主体或署名职责，区分人物名、演员名和职务，标明语言、大小写、换行/读序及来源；不从人物照片猜姓名，不为形成卡司结构发明署名。字形用可见骨架/材料描述，独立排字另核实真实字体及字符覆盖。

## 落回模板、提示词和验收

在title_plan现有镜头/文字/边界中记录本次母题、具体空间过程及最终回收；持续事件交实际显露状态，不在后段从头构建。H3接收本Panel的完整过程与准确生成项，Canvas接真实端口，后期项保持单独责任。

实际连续观看时看作品气质、摄影与字层是否共同成立、姓名是否对上当前人物/职责，以及片名是否由此前线索收束。刻意的平面包装按平面设计看，不强求接触影；已选空间关系则核对该关系，不用“有字、可读”替代。
