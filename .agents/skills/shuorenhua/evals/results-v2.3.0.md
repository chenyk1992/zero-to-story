# v2.3.0 合并版跨模型验收归档

> 日期：2026-08-07（第一阶段）/ 2026-08-12（合并阶段）
> 状态：**本地 release-ready**。原规划的 v2.3.0 与 v2.4.0 已合并为一个对外版本 v2.3.0；规则、用例、跨模型盲测、交叉判分、硬判与静态检查均已完成。
> 最终评测集：103 条（57 SF + 46 SNF）；本轮采用 targeted + 影响面回归，不是 103 条全量新基线。

## 1. 本版范围

第一阶段完成两块规则工作：

1. 篇章级病灶补齐：名词化、同义词躲避、连词过密、装饰性细节、借喻场混用（`structures.md` 第 21–25 条），以及翻案腔的跨句 / 换字变体。
2. 原 v2.1.1 欠账：标点腔长文与 `bounded` 删除清单的交互。破折号是句内动作，不进删除清单；同段整句空话仍照常进清单。

合并阶段再补四块：

3. 用户当前要求与项目 style guide / 术语表优先于通用词表，项目正式术语不能因为命中代表词就被替换。
4. 中文词表补 `洞察 / 赛道 / 协同 / 卡点 / 联动` 及各自误杀边界；Tier 2 增加按对象和场景判断的抒情词层。
5. 量化歧义不由改写侧代选关系：`docs / status` 默认 audit-only，非关键信息才允许压掉含糊倍数；正常的百分点、单位、基数和测量结果逐字保护。
6. residual 统计增加 `「」/『』` 高亮短语候选计数；盲测编号跨 100 后仍保持 `B-01…B-99, B-100…` 的兼容格式。

最终评测集从 84 条扩到 103 条（57 SF + 46 SNF），场景样本从 19 条扩到 20 条。

### 3.3 SF-52：跨模型对比给出了新结论

这是本轮最有价值的一条。

- **Claude 改写：通过。** Codex judge 判 6/6，`赛道 / 护城河 / 坍塌 / 浪潮 / 点燃` 五套借喻全部还原本义。
- **Codex 改写：⚠️。** Claude judge 与 SDK judge 独立给出同一结论——五套降到一套，事实与强度没有漂移，但 `技术壁垒` 未还原、`点燃斗志` 只换成 `重振士气`，属「动作不完整」。
- **SDK 改写：⚠️。** 与 Codex 同型残留（还多留了 `抹平`、`找到自己的位置`）。

上一轮只有 Codex 和 SDK 两条同模型路径时，无法区分「规则要求过严」和「某个模型执行不彻底」。Claude 路径补上后结论清楚了：**第 25 条的默认动作是可达成的，SF-52 的 ⚠️ 是模型执行差异，不是规则缺陷。**

因此不改 benchmark 预期、不加单用例例外、不为一条继续加规则。这条留作跨模型执行差异的观察项。

## 5. residual 标定

`python3 automation/eval/hard_metrics.py --calibrate` 在 95 条语料（53 SF / 42 SNF）上实测：

| 指标 | SF | SNF | 结论 |
|------|----|-----|------|
| 句长 CV | 够 12 句的样本 2 条 | 0 条 | 对照组不足，不设阈值 |
| 连词密度 | 中位 0.00，max 80.00/千字 | 中位 5.26，max 81.08/千字 | 全局阈值被否掉，改为按场景判 |
| 名词化 | max 4 | max 0 | SNF 侧零误报，只报警不判死 |
| 借喻场 | max 5 | max 1 | SNF 侧未达 3 套报警线，只报警不判死 |

最重要的是负结论：外部常见的「每千字 7 个连词」不能照抄。SNF 的最高密度反而高于 SF，技术文档靠显性连词承担条件和因果。这个结论已写进 `structures.md` 第 23 条与 `automation/eval/README.md`。

## 6. 本轮修掉的一个脚本缺陷

Claude judge 在判分时指出：硬判报告把 B-14（SNF-38，no-op 用例）标成「bounded 长文不适用留存率判据」。

核实后确认是**措辞缺陷而非判定缺陷**——脚本对所有 `is_long` 且非 `in-place` 的用例统一打印「bounded 长文」，实际这一支同时包含 bounded 用例和 no-op 判定用例。判定行为正确（`retention` 为 `None`，未参与判分），但措辞会误导 judge 以为用例被判成了 bounded。

已改为按实际场景标签直述：`不适用（场景标签 X 不含 in-place，run-eval.md 口径只对 in-place 长文判留存率）`。改动只涉及报告文案，不影响任何判定逻辑与本轮结论。
