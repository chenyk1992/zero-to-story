# Seedance 2.0 全能参考提示词规则

本文件用于把已确认的静态分镜图、15 秒音频区间和逐句时间映射表转化为 Seedance 2.0 兼容提示词。它只产生创作文本；实际生成仍须由 `canvas-workspace` 核对当前宿主是否存在用户选择的对应能力，缺失时报告而不换提供方。

## 1. 使用时机

每个 15 秒左右的音频区间生成视频前，必须先加载本文件。

适用输入：

- 一个 15 秒左右的音频区间。
- 该区间内按时间顺序出现的所有分镜图。
- 已完成的分镜计划。
- 已加载的 MG 动效/转场知识库。

输出：

- 该区间的时间映射表。
- Seedance 2.0 全能参考提示词。

## 2. 音频区间切分

- 每约 15 秒音频生成 1 个视频片段。
- 最后不足 15 秒也生成独立片段。
- 区间边界优先贴近自然停顿、句号、转折词、并列项或语义完整点。
- 不要为了机械满 15 秒切断一句完整表达。
- 每个区间都必须有明确的 `audio_range`。

## 3. 分镜图收集

对每个音频区间，收集该时间范围内涉及的所有分镜图：

- 必须按分镜出现顺序排列。
- 不要漏掉区间内的过渡分镜。
- 如果一句话跨越多张分镜图，要保留所有相关分镜图。
- 如果多句话共用一张分镜图，要在映射表中为每句话设置不同视觉动作。

## 4. 时间映射表模板

每个视频片段生成前，必须先生成以下结构：

```json
{
  "clip_id": "CLIP_01",
  "audio_range": "00:00-00:15",
  "reference_storyboards": ["SH01", "SH02", "SH03"],
  "mapping": [
    {
      "sentence": "逐句口播文本",
      "sentence_time": "00:00-00:03",
      "storyboard_images": ["SH01"],
      "target_switch_time": "00:03",
      "visual_action": "这一句对应的画面动作、元素强调或转场"
    }
  ]
}
```

字段规则：

- `clip_id`：当前视频片段编号。
- `audio_range`：该视频片段对应的音频起止时间。
- `reference_storyboards`：该区间全部参考分镜图，按出现顺序排列。
- `sentence`：该区间内的逐句口播或语义短句。
- `sentence_time`：该句在区间内或全局音频中的时间。
- `storyboard_images`：该句对应的一张或多张分镜图编号。
- `target_switch_time`：画面切换、重点元素出现或转场发生的目标秒点。
- `visual_action`：具体视觉动作，不写空泛描述。

## 5. Seedance 2.0 全能参考提示词结构

提示词必须包含以下信息：

1. **任务声明**：生成一个 MG 动画视频片段。
2. **音频区间**：说明该片段对应的音频范围。
3. **参考素材顺序**：列出该区间内所有分镜图，并说明必须按顺序推进。
4. **时间映射表摘要**：把每句口播对应的分镜图和目标切换秒点写清楚。
5. **画面推进**：说明每张分镜图如何进入、停留、强调、过渡到下一张。
6. **动效设计**：根据内容调用对应动效知识库。
7. **同步要求**：口播重音、关键词和视觉强调必须对应。
8. **禁止事项**：不要停留在第一张图，不要乱序，不要生成无关画面，不要让文字漂移或重写。

## 6. 提示词写法模板

```text
使用 Seedance 2.0 全能参考方式生成一个 MG 动画视频片段。

音频区间：{audio_range}。
参考分镜图顺序：{SH01} → {SH02} → {SH03}。必须严格按照这个顺序推进画面，不要跳过、乱序或只停留在第一张图。

时间映射：
- {sentence_time}：口播“{sentence}”对应 {storyboard_images}，在 {target_switch_time} 触发 {visual_action}。
- {sentence_time}：口播“{sentence}”对应 {storyboard_images}，在 {target_switch_time} 触发 {visual_action}。

画面从第一张分镜的构图开始，保持已确认的 MG 视觉系统、文字内容、配色、图标、卡片和布局。根据时间映射表推进画面：关键词出现时做文字强调，数据出现时做图表生长，因果或流程内容用箭头/线条/卡片转场，抽象概念用对应 MG 图形隐喻。每一次画面切换都服务于口播语义。

动效和转场：{根据已加载知识库提取的具体动效规则}。

同步要求：视觉强调点必须贴合口播重音和目标切换秒点。最终效果应像一段连续 MG 动画，而不是几张静态图简单切换。

禁止：不要改变屏幕文字含义，不要生成普通字幕条，不要引入无关角色或背景，不要让画面停在第一张分镜，不要忽略后续分镜，不要打乱参考图顺序。
```

## 7. 动效知识库调用规则

根据内容类型选择对应知识库：

- 图形动效、卡片动效、线条运动、镜头联动、场景转场：参考 `element-motion-transition-library.md`。
- 抽象 MG 概念动效、高级图形隐喻：参考 `mg-motion-pattern-library.md`。
- 数据、百分比、增长、排名、图表：参考 `data-visualization-motion-library.md`。
- 标题、关键词、金句、搜索输入、代码、文字节奏：参考 `kinetic-typography-motion-library.md`。

提示词中不要只写“参考知识库”。必须把知识库里的动效方法转写成具体可执行动作，例如：

- “卡片从右侧滑入并轻微回弹”。
- “折线图随口播数字从左到右生长”。
- “关键词以打字机方式出现，随后轻微放大强调”。
- “箭头沿流程方向绘制，带动下一张分镜入场”。

## 8. 常见失败与修正

### 只停留在第一张图

修正：在提示词开头明确“参考分镜图顺序”，并逐句写出每张图的进入秒点。

### 分镜顺序错乱

修正：用 `SH01 → SH02 → SH03` 形式列出顺序，并写“必须严格按照这个顺序推进”。

### 口播和画面不同步

修正：强化时间映射表，给每个句子设置 `target_switch_time`，后期按同一映射表校准。

### 文字漂移或被改写

修正：提示词里写“保持分镜图中的屏幕文字含义和布局，不要重写文字，不要生成普通字幕条”。

### 动效太弱，不像 MG

修正：补充具体图形动作、卡片运动、线条绘制、数据生长、关键词强调和转场动作。

## 9. 后期校准

只有对应 Canvas 能力实际回填媒体后，剪辑阶段才把实际视频节拍与时间映射表对照：

- 画面切换是否接近 `target_switch_time`。
- 每句口播是否落到对应分镜图或视觉动作上。
- 如果偏差小，用裁剪、变速、冻结帧修正。
- 如果偏差大，先记录具体差异；是否修改提示词并确认新的 Canvas 快照由当前授权决定，不自动重生成。
