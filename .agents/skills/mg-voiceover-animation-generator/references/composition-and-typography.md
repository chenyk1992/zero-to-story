# 构图状态、字体与主体共演

用于动态图形、文字包装或主体与图形互动需要具体设计时。MG 独立任务按本 Skill，广告、MV、Presenter 复用限定视觉方法后返回原主计划。本文为原创创作参考，不提供渲染器、追踪接口或固定效果数量。

## 先看整幅画面怎样改变

构图状态是一段可辨认的画面关系：主体、主要信息、辅助图形与留白如何共同组织注意。变化可以发生在同一摄影镜头中，不把每次换字或变形都算成新 Shot。先选择当前解释需要的关系，再从已有[元素库](element-motion-transition-library.md)或[文字库](kinetic-typography-motion-library.md)取具体手段。

| 表达需要 | 可以采用的构图与运动 |
| --- | --- |
| 从分散到协作 | 多张卡片带着原有线索靠近，共享一条路径，最终形成能读懂的整体 |
| 让观众发现重点 | 主体或遮挡物让开，显露完整词组；读完后局部笔画成为下一状态入口 |
| 两个机制不同 | 同一对象分成两种路径，差异通过运动与结果呈现，最后回到共同对照基准 |
| 真实口播中的证据 | 原片主体与实际截图/录屏交换注意，关键词和来源卡各有停留，不把证据画面虚构成新 UI |

## 字体角色是一种配合，不是固定套餐

需要丰富层级时，可让 Hero 承担主标题、Secondary 承担补充观点、Utility 承担清楚的说明。角色通过骨架、宽窄、字重、材质和对齐建立区别，不必全都出现。中文重心和偏旁、拉丁字腔和字距分别设计；原文、语言及品牌标准字沿用来源。

例如工艺方向可用带纸面压痕的厚衬线主字配克制的小字；轻快方向可用圆厚字块配清楚的窄辅字；精密方向可用开放字腔和贴合主体边线的标注。颜色和字形跟随本作品，不靠字体名称要求 H3 调用本机字体文件；只有独立排字时才核实实际字体。

需要从内容选具体骨架、读序和排字关系时，读[字形选型与排字机制](../../visual-design-creator/references/type-and-layout-choices.md)；需要把材料、字形和运动发展成包装身份时，读[包装风格](../../visual-design-creator/references/packaging-style-directions.md)。两者返回当前系统与Shot，已有字体角色、空间共演和主源不另建定义；数值只在真实工具可执行的范围内作为参数。

文字可以完整存在、显露、重排或被穿过。先决定观众何时能读清，再发展与主体、空间、材质或声音的关系；有意的遮挡保留恢复点。准确 Logo 的结构不随创意变形，图形可以借其轮廓发展并回到原标识。

需要展开具体过程时读[共演方法](type-subject-direction.md)：深度与注意交换、材料经过、字形成为结构、多窗口/尺度和建筑轴线继承。只取已经选择的关系；原有动效库中的保活、弹性、配色比例和时长是情境建议，稳定画面不因此判为不足。

## 示例：从分散工作到一个结果

假设锁定口播讲“分散的记录汇成一个结果”，规划一条 10 秒 Clip：前段不同来源的纸卡沿各自路径进入；中段卡片边线延伸成连接，内容仍保持各自归属，镜头或画面重心随连接靠近；后段连接收进同一个清楚的结果区域，已有标题稳定出现，留下阅读。卡片上的具体文字、数字只用已有来源；没有资料时用抽象标记，不编造软件操作。

这条设计可以有纸张触感，也可以是极简线性图形。风格改变时同步改材料、运动惯性与声音，保留“来源汇合产生结果”的解释作用。镜头与元素不必同时运动；稳定构图本身也能有表现力。

## 示例：真人与手绘的接触

若创意已允许实拍与二维融合，可以让手绘线沿桌面绕过实际杯子，人物用手指挡住它，线条在接触处停住、绕行，再成为标题下划线。杯子遮挡、手指接触和纸笔质感使两种媒介发生关系，摄影机只跟随本次发现。无需强加手机抖动、曝光漂移、固定道具数或连续变形；用户要稳定摄影或无字时沿用原意。

如果要保留真实人物原片，区分重建式生成与独立叠加；生成参考不保证原像素或嘴部保持。拟用的遮罩、追踪或分层工程须有实际能力，缺口只影响这条实现方案，不取消创意目标。

## 从方案交给实际制作

将选定构图、准确文字、字形/材料、主导层、动作触发、可读停留与下一状态写入现有 MG 时间线或调用方 Shot。H3 只消费分配给生成的内容，独立图层交实际后期工具；不要把内部字体角色或构图编号原样当成模型指令。

原片声音、外部口播和生成声音依[共同交接](../../canvas-workspace/references/creative-handoff.md)明确保留项。包装变化不自动授权切断锁定口播、改变原轨或改拍 Presenter 的连续镜头。观察实际画面时，关注图形是否帮助理解、字是否读清、主体与视觉发展是否符合所选方向，合并到原有一次验收，不按效果数量打分。

需要进一步设计先声后形、材料回答、延迟回响或留白时，按需读[声音互动](../../music-video-creator/references/sound-image-interaction.md)，只把本段选中的关系并入原时间线。
