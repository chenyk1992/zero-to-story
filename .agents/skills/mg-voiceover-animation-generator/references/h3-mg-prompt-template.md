# H3 MG 提示词模板

这份模板用于生成可审阅的 H3 提示词文档，也支持在已授权任务中直接作为执行包的创作输入。按项目删减字段，不要把模板当成固定镜头表。

## 审阅文档结构

```markdown
# {产品/主题}｜MG 口播动画提示词

## 制作摘要
- 目标：{讲解 / 发布 / 功能演示 / 抽象主题}
- 真实或虚构：{真实对象保真 / 原创概念}
- 时长与画幅：{duration}s，{aspect_ratio}，{output_width}x{output_height}
- 像素比：{pixel_ratio}（执行包映射到 GenerationRequirements.megapixels）
- Clip：单个连续 Clip
- 口播：{外部音频 / H3 原生音频 / 无口播}
- 普通字幕：none；画面文字仅为 MG/UI 设计元素

## 输入素材与保真约束
- 素材文件：{asset path/key、类型、用途}
- 必须保真：{外观、材质、颜色、结构、Logo、界面等}
- 可原创范围：{仅概念对象可原创的部分}
- 素材状态：每个素材具备 review、provenance，并通过参考位或音轨绑定到 Clip

## 整体视觉与叙事
- 主风格：{从输入和参考资料推导}
- 辅助模块：{0-2 个}
- 核心结构：{信息流 / 对比 / 流程 / 中心对象 / 聚合收束等}
- 视觉锚点与桥接：{上一段如何变为下一段}

## H3 提示词
{可直接执行的完整提示词}

## 授权与执行记录
- 创作方案授权：{当前指令、已有计划或明确确认的原文/摘要}
```

## H3 提示词正文顺序

1. **生成规格**：时长、9:16/横竖屏、单连续 MG Clip、是否口播、音频来源、普通字幕关闭。
2. **产品/主题设定**：真实或虚构属性、产品外观、功能和不得改写的元素。
3. **参考素材使用**：说明每个参考文件的语义用途、保真重点和连续性要求；不要把文件名当成故事板语义。
4. **整体视觉**：背景、构图、层级、材质、信息密度、UI/图形载体和节奏；由用户输入与参考资料推导，不强加无关品牌模板。
5. **核心结构与时间线**：按秒或时间段写画面、屏幕短字、对应 Voiceover、元素动效、镜头运动和桥接动作。
6. **文字规则**：只出现短关键词、标题、标签、按钮或数据；不得把整段口播逐字铺成底部字幕。
7. **音频提示**：外部口播时让音乐和音效避让；H3 原生音频时写清语气、节奏和混音禁项；无口播时仅用音乐/轻音效承担节奏。
8. **连续性与负面约束**：主体、配色、字体层级、几何语言和视觉锚点保持连续；不要做静态图轮播、PPT 硬切、无关角色、真实品牌冒充或文字改写。

## 参数与执行包对照

| 提示词信息 | 执行包位置 | 规则 |
|---|---|---|
| `pixel_ratio` | `GenerationRequirements.megapixels` | 例如 `0.4 -> 0.4`；缺省时不写入，generation 不写 width/height |
| 交付画幅 | `OutputPolicy` | 可独立保持 `1080x1920` |
| 视觉参考 | `assets` + `references` | 按已确定的 operation 和参考用途绑定，不按数量猜测：无参考可选 T2V；精确首帧用 I2V、精确首尾帧用 FL2V；普通图像/视频参考用 R2V，即使只有一个 |
| 外部口播 | audio asset + Clip audio track | 以外部音频为准，避免重复原生口播 |
| 普通字幕 | `OutputPolicy.subtitles_mode` | 默认 `none` |
| 创作方案授权 | package approval metadata | 记录当前指令或已有计划；不重复询问已确定事项 |
| 执行包文件 hash | package approval metadata | `validate` 后必须明确批准完整文件字节 SHA-256；笼统生成请求不代替该批准 |

提示词方案确定后，保留此文档作为创作侧记录；用 `lfo.skill_adapter.mg_voiceover.build_package` 将它和素材文件转换为 `lfo.video-execution.v1`，再交给 LFO CLI/runtime。用户要求审阅时先交付文档；已授权任务可直接进入包构建，但 execute 仍受精确 hash 批准约束。
