# H3 MG 提示词模板

这份模板用于生成“先审阅、后执行”的 H3 提示词文档。按项目删减字段，不要把模板当成固定镜头表。

## 审阅文档结构

```markdown
# {产品/主题}｜MG 口播动画提示词

## 制作摘要
- 目标：{讲解 / 发布 / 功能演示 / 抽象主题}
- 真实或虚构：{真实对象保真 / 原创概念}
- 时长与画幅：{duration}s，{aspect_ratio}，{output_width}x{output_height}
- 像素比：{pixel_ratio}（执行包映射到 GenerationRequirements.megapixels）
- Clip：单个连续 Clip
- 口播：{外部音频 / H3 原生音频 / 无口播}
- 普通字幕：none；画面文字仅为 MG/UI 设计元素

## 输入素材与保真约束
- 素材文件：{asset path/key、类型、用途}
- 必须保真：{外观、材质、颜色、结构、Logo、界面等}
- 可原创范围：{仅概念对象可原创的部分}
- 素材状态：每个素材具备 review、provenance，并通过参考位或音轨绑定到 Clip

## 整体视觉与叙事
- 主风格：{从输入和参考资料推导}
- 辅助模块：{0-2 个}
- 核心结构：{信息流 / 对比 / 流程 / 中心对象 / 聚合收束等}
- 视觉锚点与桥接：{上一段如何变为下一段}

## H3 提示词
{可直接执行的完整提示词}

## 审批记录
- 用户确认：{明确确认原文或摘要}
- 确认者/时间：{approval metadata}
```

## H3 提示词正文顺序

1. **生成规格**：时长、9:16/横竖屏、单连续 MG Clip、是否口播、音频来源、普通字幕关闭。
2. **产品/主题设定**：真实或虚构属性、产品外观、功能和不得改写的元素。
3. **参考素材使用**：说明每个参考文件的语义用途、保真重点和连续性要求；不要把文件名当成故事板语义。
4. **整体视觉**：背景、构图、层级、材质、信息密度、UI/图形载体和节奏；由用户输入与参考资料推导，不强加无关品牌模板。
5. **核心结构与时间线**：按秒或时间段写画面、屏幕短字、对应 Voiceover、元素动效、镜头运动和桥接动作。
6. **文字规则**：只出现短关键词、标题、标签、按钮或数据；不得把整段口播逐字铺成底部字幕。
7. **音频提示**：外部口播时让音乐和音效避让；H3 原生音频时写清语气、节奏和混音禁项；无口播时仅用音乐/轻音效承担节奏。
8. **连续性与负面约束**：主体、配色、字体层级、几何语言和视觉锚点保持连续；不要做静态图轮播、PPT 硬切、无关角色、真实品牌冒充或文字改写。

## 参数与执行包对照

| 提示词信息 | 执行包位置 | 规则 |
|---|---|---|
| `pixel_ratio` | `GenerationRequirements.megapixels` | 例如 `0.4 -> 0.4`；与 generation width/height 互斥 |
| 交付画幅 | `OutputPolicy` | 可独立保持 `1080x1920` |
| 视觉参考 | `assets` + `references` | 0/1/多参考分别路由 T2V/I2V/R2V |
| 外部口播 | audio asset + Clip audio track | 以外部音频为准，避免重复原生口播 |
| 普通字幕 | `OutputPolicy.subtitles_mode` | 默认 `none` |
| 用户确认 | package approval metadata | 未明确确认不得执行 |

提示词审阅通过后，保留此文档作为创作侧记录；用 `lfo.skill_adapter.mg_voiceover.build_package` 将它和素材文件转换为 `lfo.video-execution.v1`，再交给 LFO CLI/runtime。
