## H3 正文顺序

给 h3-prompt-writing 的事实按这个顺序组织：

1. 生成规格：时长、画幅、单连续 Clip、口播和音频来源；
2. 产品/主题：真实或虚构、外观、功能、不得改写的元素；
3. 参考素材：每项语义用途和保真重点；
4. 视觉系统：背景、构图、层级、材质、UI/图形载体、信息密度；
5. 时间线：每段画面、短文字、Voiceover、元素动作、镜头和桥接；
6. 文字规则：只写标题、关键词、标签、按钮或准确数据，不把口播全文铺成字幕；
7. 音频：外部音频/原生音频/无口播和避让关系；
8. 连续性与负向：视觉锚点、主体和本条最可能的可观察错误。

导演标准是“语义有对应画面，动作有因果，焦点有层级，段落有桥接，文字能读清”。不要只写“高级、丝滑、自然”，要写元素从哪里来、做什么、停在哪里。

## Canvas 参数对照

| 信息 | Canvas 位置 | 规则 |
|---|---|---|
| 旧输入中的 pixel_ratio | parameters.megapixels | 只有明确同一 MP 像素预算才映射；不要把画幅或像素宽高比当作 MP，未指定不猜 |
| 画幅 | parameters.aspect_ratio | 与 Panel 一致 |
| 视觉参考 | inputs | 按已确认的 T2V/I2V/FL2V/R2V 用途绑定 |
| 外部口播 | 音频输入或后期责任 | 以实际音频为准，避免重复生成口播 |
| 普通字幕 | 后期责任 | 默认关闭，用户明确要求才准备 |
| 正式 H3 文本 | 当前节点 prompt | 逐字保存，不在 Canvas 端另写一版 |

用户只要审阅时交付文档；方案和授权齐全时再保存 Canvas 草稿。模式或素材缺口要明确报告，不用默认值掩盖。
