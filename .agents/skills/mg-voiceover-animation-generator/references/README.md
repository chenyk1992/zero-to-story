# MG Skill 参考资料索引

当前 canonical 路径是：创作与审阅 → `h3-prompt-writing` → `canvas-workspace` 固定快照 → 已选 Canvas 能力 → 实际媒体回填与审片。用户选择 `comfy` 时由 Canvas 服务调用 `comfy-video-executor`。参考资料只服务创作侧的风格、语义、动效和 H3 提示词，不负责视频运行时。

- `reference-routing.md`：参考资料选择、0/1/多参考路由和 Canvas 交接；先读。
- `h3-mg-prompt-template.md`：H3 提示词审阅文档结构、提示词正文顺序和 Canvas 参数对照；所有任务必读。
- `visual-style-layout-library.md`：视觉系统、配色、版式、层级、背景、图标与行业映射。
- `element-motion-transition-library.md`：元素生命周期、卡片/线条/图标动效、镜头联动和连续桥接。
- `kinetic-typography-motion-library.md`：标题、关键词、UI 文本和动态字形。
- `data-visualization-motion-library.md`：数字、百分比、增长、排名、图表和进度动效。
- `mg-motion-pattern-library.md`：对比、分流、聚焦、聚合、平衡和波形等抽象 MG 模式。
- `seedance-omni-reference-prompt.md`：legacy optional，仅用于明确的 Seedance 兼容创作；不属于当前 H3 → Canvas canonical flow，也不构成可执行提供方入口。

不要引用不存在的语义映射、桥接或 UI 专用资料；相应判断由现有视觉、元素动效、文字和 MG 模式资料覆盖。
