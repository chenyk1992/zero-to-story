# 广告后期与验收

实际文件返回或进入成片阶段时，按[共享规则](../../../../guides/ai-system-prompt.md#产出后一次必要验收)检查当前版本。对照 ad_plan 的目标连续观看有关画面与声音，确认商品、人物、文字和声音共同传达广告主张；克制陈列和强烈表达都按选定方向判断。

## 用途相关的接受

按 ad_plan 选择的表达，连续观看实际画面与声音，核对：

| 观察方面 | 检查内容 |
| --- | --- |
| 产品与主张 | SKU/结构、使用或接触动作、数量/归属、容器及结束状态；产品性能依据已核实资料，生成演示呈现主张但不算实测。 |
| 品牌与文字 | 产品身份、完整文案与 Logo、信息顺序和阅读窗口；选用字体共演时检查承载面、深度、材料与运动轴是否实际呈现。 |
| 事件与节奏 | 人物选择与动作因果、产品如何改变局面、揭示与反应；高能表达检查身份及完整阅读，克制表达检查细节和停留，重复或回返是否发展关系。 |
| 声音与剪辑 | 声音是否按选定目的支撑主张；声音本身是卖点时检查实际音轨。按创作方案保留无人/无声选择，不把静音可懂设为所有广告的门槛。 |

关键项无法从实际素材确认时保留待核，再按共享规则记录接受结论。

## 采用路径与后期

后期前按[共同采用版本与后期](../../canvas-workspace/references/creative-handoff.md#采用版本与后期)选取当前可用素材。生成素材核对 review 的采用路径、摘要与实际文件；导入或拍摄素材沿用实际来源、版本和用途依据。后期写入新文件，并使编辑清单、采用版本与依赖末态保持对应。

源生成声、参考声、最终音轨分别登记。保留主歌/原声不等于口型已同步；替换音轨检查实际新文件及接缝。现有工具支持硬切/选段/尺寸fps归一、有限ASS、混音增益/渐变；对白窗压低、定时透明Logo、静态图片段及显式片尾沿[共用后期字段](../../music-video-creator/references/postproduction-manifest.md)执行。默认旧background策略仍为整轨-12dB，显式窗口会替代它；跟踪文字、人物mask、透视、任意转场与分层工程另核工具。

保护完整文案/句尾、反转揭示、视觉反应、产品证据和品牌阅读窗；静音不等于可删。只换CTA则检查其新阅读窗、声音和结尾/接缝，保留未影响片段。未知影响尾帧依赖则只停相关续接，不通过普通资产边绕过固定源run。

借用共用后期字段时还要核对实际入口的前置条件，尤其[无音乐任务与图片叠加](../../music-video-creator/references/postproduction-manifest.md#定时-logo-与图片叠加)。普通品牌文字与必须保留原图的 Logo 分开；本来只需静态屏幕文字时可走通用 ASS，不能因此把真实 Logo 改成字体或给无音乐广告强加主歌。

## 实际画面问题的最小修正

本节用于已返回且可观察的成功媒体，并在当前授权范围内提出内容修正。执行状态依[共享规则](../../../../guides/ai-system-prompt.md#唯一执行入口)处理；按实际画面判断偏差来自执行还是创意因果，并针对已观察的问题提出修正。

- 商品拿取、涂抹或装配变形：把易失败的接触动作单独成镜或简化为可观察的一步，并锁定开始/结束状态。
- 物件重复、佩戴与收纳冲突或支撑错误：核对数量、归属、容器占用及支撑关系；用已计划的硬切说明省略后的新状态。
- 卖点效果被次要特效或竞争手势遮住：只移除/简化干扰项，让已确认的商品动作与证据重新可读。
- 翻转目标或证据不清：判断需补充可见/可听证据还是说明；新增解说或产品主张时回广告主责核实资料与文案。

修订只触及受影响Shot，保留已确认的时长、商品入场策略、逐字对白、CTA与其他锁定事实；若这些项确需改变，或修正无法放入当前时长预算，先把取舍交回主责。新媒体版本仍按现有Canvas采用/派生路径核对授权与精确输入，不自动重试、换提供方或覆盖已采用文件。无法由现有生成/后期工具完成的修正明确报告能力缺口。

## 最终交付

用编辑清单引用实际采用文件、摘要、窗口和成片位置，区分生成、旧素材与后期段，并记录精确文字与实际发声时间。全部后期完成后连续检查最终文件，核对时长、顺序、品牌信息、声音、字幕、安全区和用途。返回成片、规格、完成范围及待核项；需要可编辑工程时，先按实际导出能力确认格式。
