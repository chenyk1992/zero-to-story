# 剧情反转广告的创意搜索与自筛

当广告要让**卖点自己造成一次可见的状态倒置**，而不是给产品配一段剧情时读取。通用反转机制（真相、知情、隐藏与揭示）统一在[通用反转](../../short-drama-screenwriter/references/reversal-design.md)维护；商品如何促成变化、证据与人物行动在[产品因果](product-causality.md)维护。本文只补两件事：**怎么找到这类创意**，以及**怎么判断一个创意站得住**。不新增广告入口，不改变产品事实，也不把任何自筛变成交付门禁。

## 先确认这条路线适不适合

品牌感受、静态宣传、口播说明、纯使用演示都不必用本方法；用户只要求产品露出时沿用露出目标。已有脚本或受控复刻只修改允许项。已按[开放式构思](ad-direction.md#开放式构思)给出方向时，本页只用于深化选中的那条，不重开发散。

## 四类创意原型

不是固定菜单，是四个可组合的搜索方向。同一卖点可以落在不同原型上，效果完全不同；用户已指定路线时直接沿用。

| 原型 | 做法 | 观众一眼看到的变化 |
| --- | --- | --- |
| **重新解释** | 卖点的可见结果改变一个既有动作的意义或地位 | 同一件事，因为卖点而变成了另一件事 |
| **限制倒置** | 先建立一个真实限制，再让卖点清楚解除或反转它 | 原本做不到的事，现在做得到 |
| **规则倒置** | 先建立一条简单世界规则，让卖点改变谁受这条规则约束 | 规则还在，但被管的人换了 |
| **目标替换** | 卖点前后复用一个清楚构图或动作，只替换被重视的目标 | 同一镜头里，被争的东西变了 |

原型提供的是"往哪找"，不是"必须写成这样"。已有的故事世界、人物关系和场景压力比原型优先；原型只用来打开没找到的方向。

## 一个创意怎样写出来

用自然语言写，不用编号菜单。每项按这个顺序展开：

> 世界压力与开场状态 → 商品入场并执行已确认的卖点 → 同一事件产生大尺度可见倒置

观众不需要一段解释就能看懂每项创意。**需要解释才成立的创意还没成型**——那说明翻转没有真正发生在大纲里，只发生在文字里。

数量随请求决定，不固定；给少量有实质差别的候选，并说清各自靠什么成立，不为凑选项增加确认轮次。

## 自筛：把弱创意淘汰掉

下面任一条成立，这个创意大概率只是"故事里放了一个商品"：

- 商品起作用了，但对手只是沉默、让开或尴尬；
- 卖点只是被测试、测量、陈述，或被人物私下欣赏，没有产生新的可见状态；
- 记忆点来自无关的惩罚、意外或另一个高潮，而不是卖点事件本身；
- 承担揭晓的是微小视觉差异、文案、谐音梗或结尾一句台词；
- 一个普通物件能完全替换产品，而因果链不变。

这些是判断创意时的自查项，**不是验收条款**。没通过的创意不进入下一阶段，通过的也不因此免去后续的实际检查。

## 静音自问

把对白拿掉，这个翻转还成立吗？开场目标、商品入场、卖点动作和改变后的状态仍然读得懂，就说明翻转发生在画面里；对白只是让它更快被理解，而不是负责凭空制造翻转。

这是**筛选时问自己的一个问题**，不是交付要求。广告不以静音可懂为门槛——投放明确要求静音优先时，才按[产品因果](product-causality.md#隐藏、证据与连续性)检查画面是否足以传达；声音本身是卖点的一部分时，标明需要声音的事实或交付版本。

## 人物动机怎样被翻转改变

翻转要改变人的选择，得有一条看得见的路径：

> **原有判断 → 亲自感受到卖点 → 明确的态度变化 → 有动机的新行动**

态度变化要有与代价相称的证据。极轻微微笑、敲一下手指或结尾一句口号，撑不起高代价或大幅度的选择——这种幅度要么降低，要么补上能看见的受益证据。门槛与证据要求见[产品因果](product-causality.md#选择情境与人物行动)。

## 商品结尾与落版

结尾是**剧情结束之后**的状态，不是参考图里的包装状态。写清商品此刻是组装、佩戴、收纳、打开、关闭、占槽、支撑还是连接；容器里还有什么、盒盖开着还是合着、容器外是否仍有物件。参考图里的播放器界面、载体痕迹、悬浮展示或不可能的支撑关系默认不继承，除非用户明确要。

文案、落版与字幕各自登记用途，按[逐项文字与时间](../../canvas-workspace/references/creative-handoff.md#逐项文字与时间)写回 ad_plan 的生成与后期责任。不统一去标点，也不机械裁到商品镜头之前。

## 交接

选定创意后按[广告导演](ad-direction.md)深化为脚本与分镜，按[生产交接](production-handoff.md)交 H3 与 Canvas。已确认的创意、锁定对白、产品事实和投放规格直接进入 ad_plan，不另建一份反转计划或第二套全片事实。
