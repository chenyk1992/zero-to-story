# 广告与宣传片的分阶段协作

按[共享职责与交接规则](../../../../guides/ai-system-prompt.md#职责与最小交接)安排工作。商品、服务或卖点主导的视频广告使用 `ad`，品牌形象、企业/机构、活动或独立影视宣发片按传播主体主导时使用 `promo`。混合形式按 `ad_plan` 的主要传播目的选一次。带歌曲的广告仍由广告主责。概念、文案、静态物料、单 Panel 和仅做局部后期按指定范围结束。

| 阶段 | 谁处理与实际交接 |
| --- | --- |
| 简报与脚本 | 主会话持有来源、传播目的和采用的 `ad_plan`。主做接当前阶段目标、采用版本、锁定事实及必要素材，交连续可读稿。若理解有疑点，可另用无制作历史的审核者读观众能听到或读到的稿件，只问看懂了什么以及依据。 |
| 分镜与素材 | 主做按当前场面交清观众先注意什么，以及产品行动、场所、人物或声音如何改变印象。监督在重要交接或用户要求变化时，核对已落实的要求、来源和遗漏，保留有意留白。 |
| Panel 生成前 | 审核者拿当前 Panel 分镜、完整提示词、实际参考图/音频、模式和必要锁定事实。产品广告看 SKU、结构、使用条件及文字；宣传片看标识、地点/人物、旁白与素材证据及声音分工；用往期画面时，核对本次与回顾的日期、归属提示。给出材料位置、影响和最小修正，主做修正关键冲突后再按[生产交接](production-handoff.md)使用已有授权。 |
| 后期与成片 | 主做完成观众版；独立审核者仅看成片并回答该类型的固定问题。先保存首次观察，再由监督或主会话对照 `ad_plan` 和真实依据处理问题。按[最终交付](finishing-and-review.md#最终交付)完成视听检查。 |

代理仅在实际局部分歧时收到争议、证据和可选改法，作一次既有授权内的裁决；改变已定宣传目的、产品主张或锁定文案时交回主会话。审核、监督和代理只返回结果，由调用方保存或决定修订。复用当前主源与已有交接页，仅交当前版本、受托范围、材料与待核项。

## 独立成片观察

完整交付使用实际最终观众版，保留观众可见的 Logo、字幕和实际声音。导出时去掉制作注释、内部附轨和答题信息。盲审只接收实际媒体与固定问题：广告用[产品与主张观察](../assets/ad_blind_review_prompt.txt)，宣传片用[主体与印象观察](../assets/promo_blind_review_prompt.txt)。使用无制作历史、可实际观察音视频的新实例时，只交这两项，不加载本参考、需求、来源表、原标题文件名或历史评价。审核者若已知本片目标或看过旧版，可做定向复查；首次观察另开干净入口。

可复用[独立媒体观察脚本](../../zero-to-story/scripts/blind_review.py)。正式调用向 MiMo 发送一份媒体快照和所选固定问题，按当前实际外部媒体分析授权执行。仅验证请求准备或用户限定离线时，不发送远端请求。无适用的独立观察能力时，记录该项未核实，继续能够完成的视听和需求核对。

~~~powershell
./.venv/Scripts/python.exe .agents/skills/zero-to-story/scripts/blind_review.py --profile ad --video "<广告成片.mp4>" --output "<项目目录>/reviews/<版本>-ad-prepare.json" --prepare-only
./.venv/Scripts/python.exe .agents/skills/zero-to-story/scripts/blind_review.py --profile promo --video "<宣传成片.mp4>" --output "<项目目录>/reviews/<版本>-promo-prepare.json" --prepare-only
~~~

正式执行时选用对应命令，去掉 `--prepare-only` 并使用新的报告路径。观察绑定实际文件和摘要。人工或独立子任务观察可按[现有审片模板](../../zero-to-story/assets/story_review.template.md)记录实际输入、范围和未知项。先保存原始观察，再在同一交付记录或 `ad_plan` 引用它并核对创作意图。用时间点定位误读，优先调整受影响的台词、阅读窗口或镜头。仅局部替换时复核改动和相邻接缝；新版若要记录首次观察，使用新实例和新报告。采样或声音覆盖不足时保留未知，采用判断沿用现有验收。
