# 创作事实与画布交接

适用于影视、音乐/MV、广告和限定专业任务。本文解释现有接口，不统筹作品；授权、单次执行、失败与必要验收以[共享生产规则](../../../../guides/ai-system-prompt.md)为唯一来源。字段查[操作接口](operations.md)，不新增业务 schema。

## 当前版本协调

每项交付只有一个当前主源：影视故事板及其编译蓝图、音乐稿/MV计划、广告 `ad_plan.md`。专业成果可独立保存，调用方引用实际版本，不复制可独立漂移的全片事实。

独立片头用title_plan维护限定成果；受托片头、拼贴表演或游戏镜头回原主计划的指定范围，不成为第四个完整作品主入口。专业方法/交接模板可引用，不能另维护一份可独立改全片的时间轴。

广告已有制作画布时，主文件在配置解析的 `media_root/projects/<canvas_id>/ad_plan.md`，不在代码写死 workspace。纯文本阶段无需画布；用户要求保存则在指定位置保存一份。进入生产采用当前稿为项目主源，旧位置指向新来源并停止双写；不可移动的指定文件继续作为唯一主源，画布引用其实际绝对路径。

`document.content` 是展示/交接投影，`data.source_path` 指向实际主文件；媒体 `content/description` 只保存本Panel事实、来源位置及版本。它们不会自动反写或进入模型。计划版本与Panel事实版本分开，实际摘要辅助一致性核对；不按时间戳猜意图。计划换版先比对差异，只更新受影响Panel。

写提示词/执行前比较主源、最新草稿与有关冻结输入。明确用户对话/Canvas编辑先合并回主源，再同步受影响投影与草稿；旧文件不覆盖新决定，定稿提示词不自动优化。未知冲突只停受影响单元。版本冲突重读合并，不用新版本号提交旧图。历史运行、快照、采用媒体维持原状；输入改变核对已有授权覆盖，不默认全项目失效。

## 当前任务的最小上下文

主会话从当前主源提取本轮目标、采用版本、锁定事实与待处理差异，按现有[最小交接](../../../../guides/ai-system-prompt.md#职责与最小交接)给下游；它们是已有记录的选取方式，不新增表单。只读当前阶段涉及的参考。已有模板满足需要时沿用，不复制全片历史或重新填写未变化的全套规格。

局部反馈先定位到有关 Shot、时间窗或文字/声音事件；能由现有事实判断时直接修订受影响单元。H3 收到的交接仍须包含生成所需的具体描述、准确原文与真实输入，不能用一个主源链接代替模型必须收到的事实；执行者仍使用完整冻结快照。面向用户的呈现按[每轮交付](../../../../guides/ai-system-prompt.md#每轮交付)。

## 整体风格的继承与分镜方法

故事、MV和广告主责按[风格推荐与继承](../../zero-to-story/references/style-selection.md)在各自主源确定整体方向；已有风格及局部例外直接继承，不因专业委托、换Panel或写H3重新选择。整体媒介/美术/气质与局部反转、微表情、时间效果或运镜分别记录，局部方法说明其剧情/音乐/品牌用途。

准备当前Panel时，从主源采用版本取本段必要的媒介、人物/环境轮廓与材质、色光、表演/运动语言及声音关系，连同本段具体动作和拍法交H3；只传有关特征，不复制全片风格库。反查这些特征是否进入完整`prompt`相应描述，所需实际参考是否通过正确端口绑定；只在文档节点、`content/description`、`related`或方法链接中出现不代表进入生成。参考与已选风格冲突先由主责修正草稿，不让执行端自行换媒介。

Canvas文档引用整体方向的当前主源与版本，视频节点保留当前Panel的具体事实、最终prompt与真实输入，不新增风格schema/运行字段。明确的风格修改按上面的版本协调，仅同步受影响脚本表达、资产/参考、Shot、提示词、后期与验收重点；沿用未变的剧情、歌词、品牌事实及历史快照。单纯调整机位或局部手法不自动重开全片风格。

实际验收对照当前采用方向与已声明的段落变化，连续观看美术、人物气质、节奏和声音是否共同成立；克制与高能按各自意图判断。离线投影一致或关键词齐全只说明交接可追溯，不能作实际风格采用结论。

## 表现方法的传递与局部更新

主责在现有风格、Shot、文字或声音记录中保存已选方法的具体过程及其用途，例如“拆封声后展开盒面，借反光显出压纹”，而不只写“高级产品展示”。交给 H3 时保留动作因果、构图/材质变化和声音落点，交给后期时保留对应事件与实际工具。资料节点或方法链接只供阅读；由生成承担的事实必须进入当前 `prompt`，参考素材必须通过真实端口进入模型。示例时长、字体角色名和图层方案不成为新参数、配额或能力声明。

| 当前改动 | 同步受影响的现有内容 |
| --- | --- |
| 风格、构图、人物或产品状态 | 主源的相关 Shot/资产用途、媒体事实、H3 草稿及确实变化的参考输入 |
| 文字、旁白、对白或歌曲窗口 | 精确原文、相应时间映射、生成/后期责任、有关提示词与编辑清单 |
| 生成与后期分工、切点或采用素材 | 事件所属环节、实际工具与文件/窗口、受影响接缝及验收重点 |

这些是现有信息的同步位置，不要求另建表或重写全片；范围、授权与历史快照处理沿用上面的当前版本协调。沿用未受影响的已确认决定，实际采用仍以本文件的采用版本规则为准。某次成片偏离意图时，先比对当时主源、冻结输入、实际参考、生成结果与后期版本，再判断应补方法、修交接还是处理执行偏差；历史视频问题本身不证明当前 Skill 有缺陷。

准备当前Panel时，从本次已选表达反查：观众要发现什么，画面通过什么具体过程实现，关键身份/文字/声音或状态怎样保留；分别定位到完整prompt段落、实际素材用途或后期责任。现有记录已说明就直接引用，不另建创意账本，不逐个风格形容词设FAIL。若只剩“电影感/拼贴/继续”等标签，回原Shot补可见关系；结构检查和提示词字符串一致不替代这项语义对照。未选择的技法不补作业，实际效果仍等真实视听。

### 字形包装与声音互动的具体交接

主源的字体角色、排字机制或包装名是设计索引。交H3时展开本Panel的准确原文、可见骨架、主次/读序、对齐/空位、材料与完整阅读状态，保留静止、重复或高能变化的具体作用；不只传编号、字重数值或“参考母版”。规则仍引用原主源，必要具体事实仍进入当前完整prompt。真实文字/风格图按现有首帧或普通R2V端口与用途传递，不需要新素材类型；资料边和样式卡不自动覆盖其他原文。

声音互动在既有Shot/声音记录中保存依据与核对状态、先后/延迟或保持、响应落点、结束/跨段与生成/后期责任。只有设计时写估计；有实际音轨时沿既有版本、窗口和时钟映射。后期原轨不再要求H3重复生成，原轨中的材料声不自动变成独立音效；确定性压低/恢复或分层处理仍核实真实素材与工具。冻结输入、运行、采用规则不变；上述记录不增加schema、审批或声音事件配额。

方法按需读[字形与排字](../../visual-design-creator/references/type-and-layout-choices.md)、[包装方向](../../visual-design-creator/references/packaging-style-directions.md)、[声音互动](../../music-video-creator/references/sound-image-interaction.md)。验收只看当前已选关系是否在实际版本成立，数值/角色/效果名称齐全不构成通过。

## 固定人物文字与实际输入

人物连续性沿用当前主源的[固定人物描述](../../zero-to-story/references/creative-assets.md#人物与场景文本锚点)：交接本 Panel 出场 ID、当前造型和适用固定子句，含跨镜配角。调用方在保存/确认前核对这些内容已进入实际 `prompt`，并与实际帧/参考相符；角色节点、`related` 连线、节点 `content` 或文件路径本身不会把描述传给模型。只用文字的人物不虚构资产/槽位、不判为缺角色图。图文冲突回主责修订，执行方不改冻结提示词。

## 逐项文字与时间

相关时记录文字ID、载体、精确字符串、Panel/Shot、出现/变化窗口、生成或后期责任与可执行工具。H3只消费生成项，后期只消费分配项；字幕、包装字、品牌落版不混为一项。有限字幕不等于任意Logo、透视字层或跟踪合成。无文字需求不强制表格。

必须精确呈现真实界面操作、消息、数字或文字时，使用实际录屏、截图或可核实的界面素材，在现有编辑清单记录来源、窗口与后期责任；操作过程用实际录屏，截图只证明静态界面状态，不让 H3 重绘后冒充操作证据。说明性且允许近似的界面才作为生成内容。现有工具不能完成所需遮挡、跟踪或合成时，指出该镜头的具体缺口，不虚构已接通；导入素材沿用来源与用途核对，不伪造生成 run。

源视频、Panel零基、成片位置与实际音乐时间分开。原速窗口用偏移；删减/重排/多来源逐段映射，未定位置保留未定。源20～33秒映射13秒Panel，源25秒为Panel5秒；帧率改变不改变秒数，不平均补切点。改窗口/音轨/CTA阅读时间只重算有关映射与接缝。

## 声音身份与实际音轨

仅在用户要求跨Panel同角色音色连续、或声音身份影响当前用途时，在现有主计划/角色声音记录中建立角色ID与已听审参考的对应，引用实际文件、来源run/版本或摘要、适用授权及用途。沿用同一有效参考，不逐镜重做声线；没有该要求不强制voice profile或额外试听。新声音及试听仍经Canvas，角色声音设计与复用按[Qwen TTS](../../qwen3-tts/SKILL.md#角色复用与验收)的真实音频与转写要求处理。

分别交接参考声、生成声与最终音轨：H3音频参考提供声线/节奏线索，不是自动保留原轨或保证逐样本相同。精确保留采访原声、采用TTS对白或其他指定音轨，须注明实际文件/窗口、生成声保留或丢弃项、后期责任及已验证工具；普通视频生成不自动接入MV音频编辑。音色、原声和可见口型各按实际用途检查。声音参考与所选模式冲突时报告缺口，不静默改模式；已有歌唱同窗口绑定规则仍保留，不用一般声线样本代替主歌曲片段。

混合叙事的每句原文仍保留在主源及对白账本，用现有声音/后期责任记录关联句 ID，区分 H3 生成与后期发声。后期旁白的原文交后期，H3 仅接收该窗口的画面、嘴部任务及需保留的环境声，不再次生成同句。使用蓝图核对 H3 文本时，按[提示词检查](../../h3-prompt-writing/references/prompt-validation.md#混合叙事与后期对白范围)显式提供这些后期句 ID；这只是检查上下文，不是蓝图或 provider 新字段，不证明实际音轨已存在或后期已完成。

## 采用版本与后期

后期前将当前 Cue/声音意图对应到实际声源、源范围、成片位置、保留/丢弃层及真实工具。源轨已混有对白和音乐时，提取整轨不等于分离；图像尾帧不带声音。对白窗口可在原混音/正式 MV 清单使用[动态压低与图片后期字段](../../music-video-creator/references/postproduction-manifest.md)，不更换生产入口。旧整轨压低与显式窗口处理分开，具体声层边界见[声音能力](../../music-video-creator/references/finishing-and-review.md#声音方案与实际能力)。影视、MV、广告保持原主责。

正式后期对 Canvas 生成素材读取当前 `run.review`，核对ACCEPT、`output_path`、`output_sha256` 与实际字节；run_id和技术成功不证明采用。导入/拍摄素材按共享规则保存实际版本、来源与用途证据，不要求伪造 run。后期写新文件，检查改动及接缝；采用文件、摘要、末态、尾帧同版。

| 当前条件 | 合法处理 |
| --- | --- |
| 首次待审 | 完成影响本段采用的已授权必要后期，原review绑定原run输出目录内实际版本 |
| 完整INCONCLUSIVE | 原因＋最新expected_updated_at调用canvas_reopen_review，CAS重开取得新token后审实际版 |
| succeeded且完整REJECT视频 | canvas_review_derived登记原run目录内不同路径且不同字节的实际派生版；最终ACCEPT/REJECT，不重新claim |
| ACCEPT后成片处理 | 保留源review，另写项目final文件并检查最终版 |
| ACCEPT后改绑Panel/尾帧 | 当前不支持终态替换；说明缺口停相关续接，不伪造状态 |
| 改提示词重生成 | 当前草稿＋授权范围＋新request_id/快照；不是派生审片 |

未完成审查不抢占；技术failed/unknown核实原请求，不走内容修复或自动重提。内容证据不足与提交未知分开。

精确同镜续演固定已采用source_run_id、require_accept:true，使用该实际采用视频完整解码提取的derived_outputs，output:<id>→first_frame；文件与摘要均核对。普通output选择最近成功结果，不用于固定接力。硬切/换场不机械要求尾帧。已确认请求继续用冻结引用，不原地覆盖输入/采用媒体。

## 跨Panel文字声音与状态

仅在边界确有这些关系时，在现有主计划的边界/Shot/文字/声音记录中说明下表事实。它们仍是创作数据，不新增Canvas字段、独立账本或审批；同一事实已有记录就引用。设计后段可以用计划末态，实际依赖的执行与采用按共享规则核实真实前段。

| 边界关系 | 保留什么 | 分配与实际核对 |
| --- | --- | --- |
| 持续文字/同一HUD项 | 同一事件ID、准确原文、字形/载体/位置、已完成的显露与可读状态 | 后期跨段是一个成片窗口，不在每Panel重做入场；生成式跨段传实际可见状态，不能仅凭同一ID宣称像素或字形稳定 |
| 新文字/姓名或新状态 | 新事件或原事件的明确更新、原文与开始依据 | 前段退出、后段进入各有归属；无意重复、旧字变成新字或先报任务完成都不是自然承接；有意反复仍按所选表达保留 |
| 主歌/原轨/配乐/环境尾音 | 源文件与采用版本、源范围→成片→Panel局部映射、保留/丢弃层及完成条件 | 音轨不随Panel从头播放；混音覆盖连续窗口，图像尾帧不携声。未知真实时点仍为估计，song_window声明不等于已裁出音频 |
| 跨段对白或画外声 | 完整原文及各段承担部分、发声者、实际声源或生成责任 | 不重复已完成句子、不裁掉词音/句尾；分段生成不保证音色/语流连续，指定原轨口型核实真实音频与模式。scenetrans仅是同一提示词内跨Shot写法，不是跨请求音频续接接口 |
| 人物/道具/空间/材料 | 固定身份与当前造型，必要地标、朝向、持物/接触、动作进度、媒介与受光 | 硬切可换机位但不重置世界状态；同镜精确续演等前段实际ACCEPT及真实尾帧，不能用一份计划末态代替 |

参考Picture/Audio编号和S编号按当前Panel实际输入/发声顺序重映射，主源人物、文字事件与声源身份不变，不预留前段槽位。生成式字图/参考、精确帧与仅供后期的文字或HUD分别走真实端口与清单；最终后期才叠的文字不能伪装成前段原生视频或已接受尾帧的一部分。

显露未完成的生成式文字交接已可见的部分、遮挡物和待完成过程，不能在后段从空白再演；新机位中的空间匹配另写承载面与视角，不声称同一ID保证像素连续。原文相同但有意再次出现时记录该次出现的范围与作用，避免把重现误判为持续或无意重复。

跨句声与J/L声音桥分别记录完整句ID及已发/待发范围、画面切点、声音切点和所选真实声源。片段局部时间到源轨/成片可逐段映射，裁切、重排或变速时不再只用一个偏移；已定原轨/口型和句尾保护继续保留。环境声与最终音乐并用先核对可取得的声层；混合生成轨没有可靠分离就保留缺口，不宣称只静音音乐便保留拟音。

遮挡期间的持物者、接触和位置区分最后已观察、计划继续与未知。接物者伸手不等于转移完成，车内/外和世界方向不由屏幕左右推断；HUD因果以可见完成或已定信息来源更新。后段可按计划准备，真实依赖的执行仍等实际采用证据。

前段实际结果偏离计划时，先更新主源的已观察末态与受影响后段草稿，再核对文字/声音窗口及当前授权；历史快照保留。转场由前段、后段或已验证后期中的一个环节承担，不把同一次动作/显露在两端各演一遍。纯视觉呼应或普通切镜不机械建立尾帧依赖，真正依赖未就绪也不靠改名取消。
