# 静态资产生产交接

按[共同交接](../../canvas-workspace/references/creative-handoff.md)协调源/草稿/历史。独立任务保存asset_plan，受托引用主源/单元版本，不建视频计划。

创作侧按用途选模板：单角色用[唯一角色卡](../../zero-to-story/assets/character_card_prompt.template.md)，产品/服装/布局用本Skill模板。准备data.prompt、尺寸/透明度与真实参考。Qwen见[图片指南](../../../../guides/qwen-image.md)：create零图，reference/edit 1～10图，edit首图目标；图号不沿用H3标签。

Canvas最新版本保存image节点和参数，reference_image实际绑定，document/related不参与生成。保存不是授权；queued由worker，pending_agent由真实工具会话按冻结输入一次执行。无授权交方案，缺能力报告具体缺口，不静默替代。

返回实际文件/key/版本、来源、用途证据/未知。视频用途需要动态信息时，另交当前镜头所需的可见状态、动态响应证据、裁切/保留边界与未知项；将它们交回既有作品主计划，不复制镜头表或建立第二套生产状态。广告镜头安排仍由广告主Skill负责。资产通过不证明视频动作/口型/功效。局部修订更新当前消费者，不覆盖采用文件/冻结历史。独立请求到所需资产结束。
