# 可复用角色身份设计

新身份、身份/服装冲突及独立角色资产使用本方法。已有身份先匹配来源、cast ID、年龄/造型阶段，不重新选脸。影视别名与阶段映射按[故事适配](../../zero-to-story/references/creative-assets.md#角色身份与造型复用)。

## 身份与造型分开

换衣时服装参考只贡献结构/材质/批准造型，不换脸、年龄、体型；同身份适用侧背参考可补信息，不限定一张正脸。别名依据出处/关系/时间线，不按相似姓名直接合并；双胞胎、伪装、同名角色保留区别。

从零设计选少量可见指纹：完整头部轮廓、脸/五官关系、发型结构、比例、辨识细节；职业/标志物/动作习惯有用才加，不强制持物。童年/成年同cast ID，但适龄比例和资产独立，不能成年脸贴儿童身体。换装、年龄或非人形变是阶段版本，不新增误身份。

新设计多个角色时，在所需景别下检查少量特征能否区分彼此，不只换衣服或发色。例如同为短发的两位新角色，可在允许范围分别用头部剪影与发际结构建立区别；服装变化后仍应可辨。已有角色、双胞胎或有意相似的设计先保留来源设定，只采用已授权的区别，不为“辨识度”改脸或强加职业、配件。

非人主体锁輪廓、部件数量/连接、材质、主色、标志物、运动方式和身体覆盖状态。无衣动物不自动加袖口/鞋帽/裤装，已穿衣玩偶不丢服装；不为拟人表演加手指/关节。形变按已确认阶段，不混两种身体。

记录cast ID、阶段、主身份/造型来源、可见指纹、asset key/版本、消费者；未知不升级采用。

## 最小有用资产

每个新建角色单独生成 1 张完整设定图，沿用[现有模板](../../zero-to-story/assets/character_card_prompt.template.md)：横版 16:9、正/侧/背视图、1–2 张小尺寸半身表情/动作变化、标志性动作与关键道具；默认无文字标签。人物完整描述从当前主源逐字复制，不改写。三视图和半身变化不因本镜只拍正面而删减；不额外强制独立头肩近景。已有采用的完整设定图复用，明确的局部返修保留其余视图。

必要全身视图保留完整头部与关键肢体，非人沿用自身结构和覆盖状态。设定图画幅不改变成片画幅。多视图卡不是单帧开场，I2V/FL2V另选场景帧；可作明确用途R2V参考。

检查身份、结构、覆盖状态、服装归属、必要视角与用途。只修背面保留正面/身份，只更新相关消费者，冻结历史不改。未知背面保留未知或明确新设计，不因360旋转补事实。指定提供方未接入则报告，不自动换、去水印、复制外部资产库。
