# 按用途规划资产

独立任务用[模板](../assets/asset_plan.template.md)，受托仅记录调用方所需资产。说明asset key/版本、来源、确认事实、未知、用途、消费者、普通参考/实际帧、允许文字、文件与检查依据。空路径表示未生成，不伪造采用。

先区分新增角色事实与新增图片需求，不因角色条目存在就安排生图。确需新建完整[角色设定图](character-identity-design.md#最小有用资产)时采用完整 16:9 三视图与半身变化，不按消费者删减；已有采用的适用角色图可复用。其他资产只补消费者需要的视角、细节或状态。展示卡、海报、规划板不自动成为精确开场；同一图不能称为不同构图的第0帧。角色设定图以外的资产遵守用户媒介/画幅/颜色，不默认3D/横屏/粉彩；角色图 16:9 不反向修改成片画幅。

局部返修核对直接引用及旧图派生的关键帧/整板，只变受影响部分/草稿；保留有效视角、其他SKU、身份和历史运行。新版本实际可用后同步，不声称派生图自动更新。并行限无依赖资产，不固定候选数/全套套餐/自动重试。

## 让图片分别回答设计问题

身份图解决“它是谁、哪些特征稳定”；场景设计解决“空间、光色与材料是什么”；关键状态解决“当前机位能看见什么、动作从哪里开始”。一张图可承担多项用途，也可以分开准备。清楚原图与已有设计足够时直接复用，模糊来源中的未知细节不能靠生成资料卡认证。

例如纸包装广告可按需要研究受光的纤维细节、产品与环境的尺度关系及完整识别构图；人物故事可研究角色轮廓、行动空间与某次接触的起点。每张带来不同发现或解决实际缺口即可，不机械补远中近三图。服装、物件和场景颜色可以形成呼应，但不改真实产品颜色或既有人物身份。

将设计特征、适用视角/状态与未覆盖部分交回原主计划。动画的方向、速度感、接触或读字过程由当前视频主责设计；资产检查能确认静态用途，不能证明连续运动或跨镜效果已经成立。

按需探索不删减已定交付；确需新建完整角色设定图时，仍执行上文的既有规格，不用本节的互补用途方法替代它。
