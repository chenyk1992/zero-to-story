# 布局动效交接

当前影视、广告、MV主责或独立MG图形动效按需使用；静态资产Skill只准备[版式和关键状态](poster-grid-layout.md)，不安排整片。方法选择随目的，不默认每种都用。

## 八类海报方法

每项写起始、动态过程、目标锁版、保留窗口、关键不变量与声音责任，动态不等于把几个静态图当整段运动证据。

| 方法 | 起始→过程→目标 | 关键边界 |
| --- | --- | --- |
| 渐进成版 | 空白或稀疏→主体/信息依次进入→完整海报 | 阅读层级与准确文字，纯白开场须实际白图 |
| 纸卷展开 | 已定卷曲/折叠→连续展开→平整版式 | 纸张连接与信息位置不漂移，背面无依据不补事实 |
| 破框立体 | 平面主体→局部越框/伸出→回到或保留突破状态 | 框/主体接触与遮挡，媒介由用户选，不自动3D化 |
| 多层视差 | 已定层次→前后层相对位移→锁定构图 | 深度、遮挡和字层归属，不承诺分层工程 |
| 粒子/线框重组 | 分散结构→有方向汇合→实体/版式成立 | 数量/结构重建，生成式过程非精确逐粒控制 |
| 光影材质 | 完整版式→扫光/反射/表面变化→目标受光 | 文字与产品不变形，反射随真实关系变化 |
| 动态排版 | 已定文字/图形→出现/位移/组合→最终信息 | 精确字符串与阅读窗；任意逐字轨迹须真实工具 |
| 环境循环 | 完整版式→背景/风/水等局部运动→可重复状态 | 主体/文字的保留区域，首尾近似不保证无缝循环 |

## 视觉锚点与画幅适配

先从海报实际内容中找承载运动的信息锚点：人物海报可由人物或其明确动作承载；产品/食品由产品轮廓、使用状态或可见材质承载；建筑由关键结构、空间层次或光影承载；纯文字由主标题/字形承载；抽象或无明确主体时可选辨识度最高的图形、纹理、色块、光线或色彩关系。只让有表达作用的元素运动，不为填时间虚构主体、商品属性或画面文字。锚点与动效方向按用途决定，不固定方向排序。

若来源海报比例与目标画幅不同，先按[海报/网格版式](poster-grid-layout.md#来源画幅与目标画幅)确定适配策略，再将其落实到起始和目标状态；不要在动效提示词里默认为最近比例、全画幅铺满、无黑边或拉伸变形。

## 最终网格/六格与全屏主格

最终网格为同步构图时，格子同时存在而不是时间Shot；按实际设计记录行列或不等分区域、各区主体/局部动作，以及同步/错峰窗口。对已锁定的Bento/不规则版式，沿用静态参考中的区域相对位置与比例、间距、圆角/边缘、对齐关系、裁切边界和阅读顺序，不将其简化成均分网格。旋转只表现已定结构，未知背面需证据或明确新设计。无衣IP保持覆盖状态，局部动作不新增肢体。摄影机看整板时格内动不等于全片切镜。

按设计允许网格进入、展开或重组；进入目标构图并稳定后，验收区域不再意外漂移、并格、互相遮盖或丢失分隔，区域内容不越出各自裁切边界/串入邻格。若当前方案明确包含跨格或持续变形，将其按该段已定目标状态检查，而不误判为偶发越界；不套用固定9:16、黑底、六格或任何统一模板。目标状态的几何与内容是否清楚，以当前用途和实际参考为准。

主格全屏开场→拉回完整网格：第0秒须真实全屏构图，整板另作目标/普通参考，不能又称整板是精确开场。只局部放大某格时也记录实际起止布局和内容，不从规划板推最终网格。

## 模式与可实现边界

I2V从实际开场图出发；FL2V有实际首图/目标尾图，可设计目标尾图，不用目标代替真实续接尾帧。R2V目标海报只提供参考，不能承诺精确末帧；可另带开场first_frame但无last_frame。t2v不声称图像已传入。最终锁版留足阅读窗，字形/布局实际验收，不靠“完全不变”保证。

精确逐帧像素锁定、任意层缓动、mask/跟踪、分层工程超出现有生成/硬切/有限字幕能力时，明确工具缺口及受影响交付，不静默换成近似生成。静态关键状态负责图，运动事实进入当前Panel并交H3；没有新的speed_curve、freeze_mask或动效提供方参数。采用/后期按[共同交接](../../canvas-workspace/references/creative-handoff.md#采用版本与后期)处理。
