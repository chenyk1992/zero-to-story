# 字形选型与排字机制

当整体方向已有、但“用什么字、怎样排才属于这部作品”仍不具体时读取。供资产、片头、MG、MV和广告主责复用；本文补选型方法，不重建[字体角色与主体构图](../../mg-voiceover-animation-generator/references/composition-and-typography.md)或[空间共演](../../mg-voiceover-animation-generator/references/type-subject-direction.md)。不要求用完字族、增加辅助字或制作额外卡片。

## 从内容选字，而不是从效果名选字

先看准确原文、语言、字数与阅读用途，再联系作品气质：是需要亲近、紧张、庄重、粗粝、灵巧，还是清楚解释？沿用真实品牌标准字和已有视觉身份；需要区别主次时，再从骨架、宽窄、笔画对比、边缘、间距或材料中选择有作用的差异。主标题和说明可以同族，不规定对比项目数。

| 字形方向 | 画面中可描述的选择 | 表达机会与阅读取舍 |
| --- | --- | --- |
| 方整厚黑 | 较重的等粗笔画、清楚偏旁/字腔、平直端部、紧而不粘的字距 | 坚决、直接、压迫或欢快都能成立；大字可形成图形，复杂汉字仍保留内部空隙 |
| 窄体无衬线 | 纵向挺拔、收窄字面、明确基线；拉丁字可凝缩，汉字按偏旁重新组织 | 长标题、紧迫感或高挑空间；不把英文横向压缩比例直接套给汉字 |
| 开放的人文黑体 | 开放字腔、自然重心、可辨标点和适度字距 | 亲近、陈述或安静主标题；字号大也可以有力量，不只作为小字 |
| 圆厚几何字 | 圆端点、饱满重心、开放内部空间，保留各字差异 | 轻快、触感、怪趣；克制版用稳定圆字，高能版可让整词和载体共同回弹，不把字形揉成不可读团块 |
| 宋体或高对比衬线 | 横细竖粗/粗细对照、清楚收笔、疏密有节奏；中文重心与拉丁字腔分别处理 | 编辑感、工艺、历史或疏离；细笔画需要足够对比与停留，不以“高级”默认细到看不见 |
| 板状衬线与模块块字 | 厚实端部、矩形支撑、像构件一样稳定的字面 | 工业、手作或强节奏；可与材料结构呼应，不让装配隐喻改掉准确文字或真实产品结构 |
| 笔刷或记号笔字 | 起收笔、轻重与方向可见，偏旁、字母和读序仍完整 | 亲密、愤怒、自由或身体能量；笔势可延成线，但不自动加入签名、外语或涂鸦词 |
| 等宽、模板与线框辅助字 | 等距节奏、可辨切口或空心轮廓，选与内容相符的一种 | 精密、档案或机械语气；只呈现有依据的标签，空心/重复字的主要阅读另有清楚状态，不生成伪数据 |

这些是可组合的方向，不是封闭编号。比如同一句告别可用疏朗宋体形成距离，也可用厚笔刷保留不肯放手的力度；选择应联系歌词或人物关系。已有字形足够时，只调行距、空白或读序就可以形成新表达。

## 排字怎样组织注意

以下补平面排字的具体关系。前后景、材料经过、字腔通道和建筑轴线沿用已有空间共演，不在此另设一套机制。

| 排字机制 | 克制的用法 | 高能的用法与恢复 |
| --- | --- | --- |
| 语义折行与错位基线 | 在一句有转折的词组处换行，让空白成为迟疑；准确原文和读序不变 | 两行沿不同方向到达同一对齐边，完成词组后停稳；不逐字随机换字体 |
| 主块与旁注的距离 | 主标题与必要署名共享一条边，较远的空白使两者有呼吸 | 主字接管大面积，旁注仍留在可追踪位置，最后回到共同基线；不为填版编造说明 |
| 实心与轮廓的主次交替 | 完整实心词旁保留同源细轮廓，形成回声而非新语义 | 同一准确词的实心/轮廓交换重心，回到清楚主态；轮廓副本不冒充下一句歌词 |
| 字阵中的空位 | 已定短词的重复阵列留出主体或有意义的缺口 | 阵列错列后聚回可辨主词，变化来自队形与空位；不用随机文字做纹理 |
| 跨边大字与完整读字 | 字面靠近画幅边界，先以完整词建立身份 | 已读清的主词可短暂越界形成冲击，再回到完整可读状态；新姓名和首次歌词不只留下残片 |
| 反白与色场换位 | 同一布局的明暗缓慢交换，使观点或乐句得到强调 | 色场快速接管，主词借对比保持连续识别，随后留下阅读；不把产品本色或肤色一同改掉 |
| 横竖读向对位 | 中文竖题与必要横排署名相互定位，明确先后读序 | 横向词组与纵向主字交替接管空白，结尾建立完整读序；不把两种方向揉成字团 |
| 沿弧线或真实边缘排字 | 短词沿已知圆沿或轮廓排列，字面朝向可连续阅读 | 载体绕行或弧线展开为直行，完整短词有稳定阅读窗；文字透视/运动另按所选工具核实 |

没有必要的文字就不补字；只选当前内容需要的机制。字距、尺度、颜色和位置按实际画幅、原文与人物保护区判断，不设统一占屏比例。重复、静止或单一字族也能构成设计。

## 同一原文的两种设计

片名“借一场晴”可用疏朗宋体，在纸白空处对齐一条细雨线，文字稳定、雨声渐远；也可用厚黑字和横竖留白，在风掀纸面的时刻以反白展开。前者通过距离和停留，后者通过对比和材料能量建立身份。两者都保留准确四字，不必更换剧情或增加卡司；具体空间过程仍写入原Shot。

## 怎样交给模板、图片和H3

在现有字形/版式记录中写选择依据、可见骨架、主次与对齐关系、阅读状态及必要的变化，模板已有字段能容纳就不另建字族台账。下游正文展开这些特征，不只写“厚黑路线/机制编号”。

H3中的字重、宽窄、尺度或色值是意图描述，不是可精确调用的字体/排版参数。生成式字图使用准确原文与所选骨架并查看实际结果；图片沿现有首帧或普通R2V路径传递，规则见[文字资产](../../music-video-creator/references/visual-assets.md#文字样式卡与逐事件文字图片)。确定性排字才核实真实字体、字形覆盖和布局工具。无论路径如何，都看实际字形、读序和观看效果，不以参数写得细代替验收。
