# 品牌IP按需模块

已有IP优先复用，先锁身份轮廓、配色、可变范围，不强制黑白草图或3D化。参考来源不自动等于商用授权。

| 模块 | 交付与用途检查 |
| --- | --- |
| 配色 | 主辅色/材质与背景可辨性；精确品牌色看实际文件 |
| 动作 | 符合身体连接和运动方式，不添加人体部件 |
| 表情 | 身份/情绪极性/覆盖状态不漂移，不改变头部结构凑表情 |
| 服装 | 独立造型版本，无衣IP不自动穿衣 |
| 主题海报 | 用途来自主责，按版式方法落实精确文字 |
| 周边 | 尺寸/材质/用途概念；展示稿不等于刀模/工艺/生产文件 |

可单模块交，不强制套餐/候选数。只改帽子/手势/背面保留有效模块，变化影响剪影/接触则更新消费者。分层/印刷/工厂文件须实际工具交付，PNG不能冒充工程。

## 系列配色与角色区分（按需）

用户需要多个角色或同一IP系列时，可先标出系列共同锚点（例如线条/材质语言、共用底色或装饰规则），再为各角色选择少量可辨差异（主/辅色、标志性局部、配件或轮廓特征）；只改用户允许变化的部分。若品牌已有精确色值或角色规范，以实际规范为准；没有规范时，可用相近明度/饱和度或重复的共用色维持家族感，但这不是必须规则。仅靠换色仍难分辨时，先核对可否用其他已授权特征区分，不擅改身份剪影、核心符号或固定配件。

按需并列检查系列成员在目标背景和常用尺寸下的区分度与一致性。无需为单角色建立色彩系统，也不规定固定颜色数、角色数、候选数或变体套餐。
