# 海报与网格静态版式

五层分析：主体与身份/产品；信息层级与精确字；空间/留白/格位；光色/材质；装饰/环境。锁定与可变分开，参考无关文字不带入。用[版式模板](../assets/layout_prompt.template.md)。

## 来源画幅与目标画幅

海报参考图的实际尺寸/比例与交付画幅是两项事实，分别记录；来源图不自动决定成片画幅。用户已锁定目标画幅时按该目标设计，未锁定时沿用当前主计划或发布用途的已知规格；只有画幅会改变主体、文字可读性或交付用途且无法从上下文判断时才澄清。

来源与目标比例不同时，依据文字/Logo安全区、主体边界及用户偏好选择扩展背景、重新编排、保留边框/留白，或在已授权且不会损伤关键信息时裁切。不得拉伸变形、擅裁锁定内容、默认取最近的模型比例，也不预设必须铺满、无黑边或必须加黑边；方案须符合当前图片/视频能力，不能仅凭提示词承诺像素级适配。

用途必须明确：
- 规划故事板：格子代表时刻，只供规划或按故事板契约作为参考。
- 最终展示网格：格子同时存在；若为六宫格，写行列、主格/其他格内容；不称六Shot，不清除格线。
- 静态海报：完整最终信息版式。
- 实际单帧：当前模式第0帧/目标尾图，构图与该瞬间一致。

最终网格不套故事单帧禁止网格默认。文字逐项允许，精确Logo/字形看实际图；后期项仅留位。运动过程不塞静态图，准备起始/目标锁版后交[动效方法](layout-motion-handoff.md)。主格全屏开场须另备全屏图，整板不是该第0帧。

用户要求不等分/Bento/错落网格时，静态版式应足以区分各区域：按需要记录区域内容与相对大小/位置、对齐和顺序、间距、圆角、预期裁切边界及必须完整可见的文字/主体。参考图已有明确几何时沿用；否则仅为当前用途确定必要约束，不默认六格、纯黑间隔、固定圆角或某一种行列布局。

锁版注明元素位置/内容与保留窗口；像素不变、任意层级缓动、跟踪字或工程格式须核实工具，不靠提示词保证。
