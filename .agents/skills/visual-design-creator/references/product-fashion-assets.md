# 产品与服装资料

产品、人物身份、服装、场景四类来源分别注明贡献；服装图不换主脸，商品场景不自动锁定环境。静物图能显示结构，不证明功效、价格或活动。

产品记录SKU/型号/色号、包装比例/开闭、标签原文、盖体/涂抹器连接、材质/质地、数量和未知背面。唇妆区分瓶/盖/刷头、膏体/液体与使用状态；光色差异不补造色号名称。按用途选整体/细节/使用/开场图，不固定九格。用[产品模板](../assets/product_reference_prompt.template.md)。

服装记录廓形、长度、面料、垂坠、透明度、纹样/接缝、穿法；人物身份独立。正侧背/刀版/空场景按需要，不推未知背面。runway/lifestyle由作品目的而非衣服类别决定。用[服装模板](../assets/fashion_reference_prompt.template.md)。

### 视频用途的动态响应证据

资产将用于视频时，仅按实际参考记录与当前动作相关的动态事实：服装的摆动惯性、垂坠、褶皱/回弹、反光及与人物或道具的接触；产品的开合状态、部件连接、涂抹器/膏体位置、质地变化或使用前后状态。没有参考支持的背面、内部结构、功效或动态行为仍标为未知，不把静态图说成已证明运动连续性。只提取下游镜头需要的事实，不要求为每件资产生成完整动态套件。

把可用状态、动态响应依据与不确定项交回现有作品主计划，由视频主责编排镜头。完整商业广告的服装场景、镜头顺序和动作节奏由 [`advertising-creator` 的时装方向](../../advertising-creator/references/fashion-direction.md)维护；本Skill提供身份/服装/产品资产事实，不另建广告镜头计划或替代其决策。

只改SKU色号/服装背面保留身份/有效图，检查旧图派生板/帧。参考与帧用途按[生产交接](production-handoff.md)，商业主张交广告，资产不补功效。
