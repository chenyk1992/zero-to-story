# 服装参考提示词

```text
生成一张[服装展示/细节/开场帧]。
主身份/年龄阶段：[已有来源；无人则无]
服装来源：[只贡献造型不換脸]
服装锁定：[廓形/长度/材质/透明度/垂坠/纹样/接缝/覆盖状态]
场景/构图：[独立选择]
视角：[必要用途；背面未知或明确新设计]
允许文字：[原文/载体/责任或无]
媒介/光色/画幅/可变范围：[用户要求]
此图仅表现所需静态姿态、衣料形态与接触状态，不绘完整运动过程。
不合并冲突造型，不自动添加模特/刀版/多视图。
```

交接给视频时，另在资产计划/主计划中记录参考支持的动态响应依据及未知，如摆动惯性、回落或反光变化；静态图不证明这些运动已成立，镜头顺序由视频主责编排。
