# 版式静态图提示词

```text
生成一张[规划故事板/最终同时展示网格/静态海报/实际单帧]。
输入参考原尺寸/比例：[可测得时记录；未知则标未知]
交付媒介/目标画幅：[用户已锁定的规格；未锁定时沿用已知主计划/用途，不从参考图擅自推断]
比例适配方式：[无需适配/扩展背景/重新编排/保留边框或留白/已授权裁切；保护范围与安全区]
五层：[主体；信息；空间；光色材质；装饰环境]
布局：[行列/主格/其他格；若为不等分网格，按需写区域大小与位置、间距、圆角、对齐、阅读顺序和裁切边界；最终网格同时存在，不是时间顺序]
各区静态内容：[当前状态与身份/产品来源]
允许文字：[ID/精确字符串/载体/状态；后期项只留位]
锁定/可变：[位置/比例/颜色/结构]
用途：[普通参考/实际第0帧/目标尾图/规划]
不画完整运动过程；只有用途为“实际第0帧”时，画面才须与视频第0秒构图一致，其他资产只表达指定静态状态。不得拉伸变形；不要预设铺满、无黑边或统一黑底；不得超出授权裁切已锁定的文字/主体。
```
