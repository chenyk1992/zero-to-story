# 口播视频 B-roll 规划器

遵守[项目共享生产规则](../../../guides/ai-system-prompt.md)。本 Skill 负责逐字稿的语义拆分、镜头选择、素材缺口和 Panel 创作输入；不直接生成视频，不改口播事实，不另建执行或 QC 流程。

## 输入与边界

必需：一份可按语义拆分的逐字稿、配音稿或讲稿。可选：配音音频、Logo、产品图、截图、文档、地图、图表、数据表和风格/画幅/时长/连续性要求。

若用户没有脚本，先说明缺口；不要用自编事实替代。纯字幕导出、普通剪切/压缩、单张图片提示词、长篇剧本创作和与口播无关的剪辑不触发本 Skill。

## 工作流程

### 1. 拆语义

按“一个核心意思”划分语义单元，记录其在 A-roll 与 B-roll 中的关系：

- 保留 A-roll；
- 使用证据或确定性素材；
- 复用已有素材；
- 动态文字/包装；
- 生成纯视觉 B-roll。

一句包含多个互相独立的意思时拆成多个节拍；用户要求连续一镜到底时，仍保留语义节拍，但把它们安排在同一条有因果的运镜中。

精确数字、品牌名、引用、法律文字、声明和不能出错的事实，标记为证据或确定性处理。不要让生成模型猜，也不要改写逐字稿。

### 2. 选视觉方法

为每个单元选择最简单且足够清楚的方法：

| 语义 | 方法 |
|---|---|
| 结论、金句、反转 | kinetic statement |
| 概念、主张、单一隐喻 | concept hero |
| 已核实数字、比例、排名 | number impact |
| 论文、报告、引用 | evidence excerpt/desk |
| 流程、因果、步骤 | relation flow/chapter sequence |
| 对比、前后变化 | split system comparison |
| 机制、分类、系统 | diorama/taxonomy/mechanism explainer |
| 产品、零件、装配 | 3D product assembly |
| 地点、地图、分布 | geospatial intelligence map |

如果证据画面或干净叠字更合适，就不用隐喻；不要为了套模板添加复杂运动。

### 3. 检查素材与文字

在计划中列出每个镜头需要的素材、实际来源、用途和状态。指出缺少的 Logo、产品图、截图、原始数据、地图或角色参考。需要精确出现的文字必须有用户提供的原文或可信来源；屏幕文字语言遵守用户指令。缺少关键信息时暂停相关镜头并说明，其他不依赖镜头可继续规划。

### 4. 写可审阅计划

每个镜头/节拍写：

- 编号与对应逐字稿；
- 视觉目的和模板方法；
- A-roll/证据/复用/文字/B-roll 归类；
- 主体、动作、景别/运镜、屏幕短文字；
- 所需素材和精确文字责任；
- 与上一段的连续性或形变桥接；
- 应使用生成、证据工具还是确定性处理。

导演标准：镜头目的明确，动作可拍且有起止状态，视觉变化对应口播意思，焦点和层级清楚，声音/口播有节拍位置。每个节拍只承载一个核心意思；连续一镜到底写清上一个元素如何变成下一个元素，避免“自然转场”这类空话。

### 5. 授权与交接

用户只要计划或审阅时，交付计划并保留可选方向。当前指令或已有计划已明确生成范围、素材、语言、风格和连续性要求时，直接准备已选 Panel 输入，不为同一内容重复确认；缺少会改变成品的事实才提问。

先把语义节拍组合成用户要求的 Clip，再按 Clip 交接：一个 Clip 对应一个 Panel。用户要求连续一镜到底时，保持为一个连续 Panel；使用 H3 时该 Panel 遵守当前能力的 4–15 秒。若时长超过能力上限且无法无缝兑现，报告限制并等待用户选择，不静默切镜。提示词事实交给 [h3-prompt-writing](../h3-prompt-writing/SKILL.md)，再把最终提示词、素材、模式、参数、音频/后期责任和验收重点交给 [canvas-workspace](../canvas-workspace/SKILL.md)。保存是草稿，确认由画布按项目规则执行；本 Skill 不直接操作 ComfyUI 或提供方。独立 Panel 可先准备；有连续性依赖才等待上一条实际 ACCEPT。

### 6. 实际结果

执行后只对实际输出做一次任务相关验收：记录可观察的末态；有音频要求时记录声音、对白、停顿、同步和可懂度。判断为 ACCEPT、REJECT 或证据不足时 INCONCLUSIVE；失败或拒绝时停止依赖它的接力，不自动重试、换模型或保留候选。需要精确首帧时只使用已接受实际输出提取的真实尾帧，不能虚构路径。

全部需要的 Panel 接受且用户要求完整视频时，只对已接受输出做确定性排序、连接、外部口播/字幕处理，并检查实际文件的可播放性、顺序、接缝和计划要求的同步。

## 交付

交付 B-roll 计划、素材缺口、每个已接受 Panel 的实际路径、必要的真实尾帧、未解决问题以及用户要求的最终文件。画布请求状态留在画布服务，不复制成另一份状态或复杂 QC。
