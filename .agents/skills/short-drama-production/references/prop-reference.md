# 道具参考

剧情关键道具需要跨镜头复用、出现特写，或在剧中发生状态变化时，为其建立可复用的外观依据。已有参考足够就复用；只作背景陈设或一闪而过的物件，直接在镜头或场景描述中写明，不必单独做道具图。

- 从剧本中挑出推动剧情或承载信息的物件，如信物、凶器、合同、鉴定报告、戒指、手机屏幕内容。已在定妆图中清楚呈现的角色随身饰物沿用角色参考；固定在场景里的家具陈设沿用场景参考，避免同一物件出现两套外观。
- 用户未明确指定道具参考图画幅时，默认 16:9 横版；用户明确指定时按其要求。参考图画幅独立于成片比例，提示词与生成设置保持一致。
- 默认干净背景、均匀照明，呈现道具全貌及关键细节特写；造型不对称或剧情会从多面拍到时，只补实际需要的侧面、背面或顶视。写清形状、材质、颜色、磨损和标记，并用手掌等常见参照说明尺寸，保证进入镜头后与人物和家具比例合理。
- 道具上的文字、图案、印章需要观众读清时，在参考中写明确切内容和位置，后续镜头保持一致；不需要读清时避免生成可读的假文字。不使用真实商标。
- 同款多件或成对出现（如两半玉佩、两份不同的合同）时，在参考中写明数量与区分特征。
- 碎裂、染血、撕开、打开前后等剧情状态，以基础外观为准另作状态参考并注明对应场次；一张参考只表达一种状态。
- 下游引用时说明采用的道具、当前状态、由谁持有或放在何处；参考只提供道具外观，不把参考图的背景与排版带入镜头。

新建道具参考时，在提示词中写明约定视图和需要一致的外观要点；用户反馈细节不一致时，只补或改对应视图或状态。
