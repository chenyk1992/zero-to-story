# 抖音发布

把「已经做好的本地成片」变成「创作者中心里一条已定时或已发布的作品」，并交出可复核的证据。

平台操作细节（选择器、坐标、URL、状态判据）见[操作图谱](references/dom-map.md)；账号默认值与文案模板见[文案与账号](references/copywriting.md)。本 Skill 只做平台操作与核实，不做内容创作，也不改项目里的成片。

项目协作先遵守[共享生产规则](../../../guides/ai-system-prompt.md)；对外可见的发布动作按当次请求与用户确认执行。

## 先确认的输入

缺哪一项就问哪一项，其余按账号默认值走；不要用猜的文案发出去。

- **视频文件来源**：工作区内的绝对路径，或用户当轮贴上来的附件。`upload_files` 只接受落在当前工作区内的路径或当轮附件；工作区外的路径（如桌面、下载目录）要用户先拷进来。
- **账号与合集**：默认抖音号 65082605655（Aigc老陈）。合集必须**事先存在**于「内容管理 → 作品合集」；发布页下拉只能选、不能建。
- **标题与简介**：用户给了就照用；没给就套[文案与账号](references/copywriting.md)的模板，并把拟好的文案连同发布参数一起放进确认卡。
- **发布时间**：立即发布，或定时（平台只支持 2 小时后～14 天内；**以页面提示为准**——表单会显示「支持2小时后及14天内」，别照抄外部说法或自己推算）。**下限从点发布那一刻起算，不是从开工起算**——上传加转码可能吃掉几十分钟，目标时间要按「准备完成时刻 + 2 小时」往后再留。超窗要停下来让用户在「改期」和「立即发布」之间拍板，不要填了再说。
- **封面**：横 4:3 与竖 3:4 各一帧。平台只给 10 个推荐帧且自定义上传在本机内嵌浏览器不可用，帧内带烧录字幕时在确认卡里写明。
- **保存权限**：默认「不允许他人保存视频」。

## 执行顺序

1. **先载入浏览器能力**（`browser-use:control-in-app-browser`）。未加载就调浏览器会被拒。
2. **查重并核对表单现状**：去「内容管理 → 作品列表」搜标题，确认没有同名作品已存在（避免重复发布）。同时确认当前发布页是不是空表单——发布表单可能被平台重置（标题、简介、合集、声明、封面、权限、定时全回默认，视频回到未上传）。**以页面上实际读到的字段为准，不要凭上一轮记忆直接点发布**；表单是空的就整套重做。
3. **上传**：作品发布 → 上传页 → `query(kind="semantic", text="选择文件")` 拿 `input[type=file]` 的 ref → `upload_files` → 等转码完成（百兆级文件要等，页面出现「预览视频 / 重新上传」即转码完成）。上传页会提示「超过 40 秒的视频建议上传横版视频」并列出建议画幅——16:9 的横版成片合规，不要为此改画幅。**不要为了重新上传而另开标签页**：新开的创作者中心页可能一直停在「加载中…」，元素拿不到可交互 ref，报 `stale_element_ref` / `BROWSER_OPERATION_TIMEOUT`，得靠人工在 FilePanel 点回原标签页。
4. **标题与简介**：标题用 `fill` 填 `input[placeholder*="填写作品标题"]`；简介是 slate 的 `div[contenteditable="true"]`，`fill` 会返回 `ACTION_EFFECT_MISMATCH`——那是编辑器插入零宽换行符造成的正常现象，用 `query(kind="dom", selector='div[contenteditable="true"]')` 复核文本是否逐段正确即可，不要因此重填。
   - **话题标签**：编辑器会把 `#AI短剧` 这类词自动补全成别的词条（例如 `#ai短剧超市`）。两种走法：把话题作为纯文本写进简介（我们既往 EP1–EP4 就是这样，回读文本一致，但**是否算真话题卡未经验证**），或逐个键入触发下拉、逐字点选精确话题卡（流量更好，步骤更多）。无论走哪条，发布后都要回读话题文本有没有被换成别的词，并在发布记录里写明走的是哪种。
5. **合集**：点「请选择合集」→ 选中合集（`div.semi-select-option.collection-option`）→ 序号会自动变成「第N集」，读一遍确认序号对。
6. **双封面**：点封面槽（`div.coverControl-CjlzqC`，第一个是横 4:3）→ 帧条选帧 → 切「设置竖封面」再选一帧 → 点「完成」。三个高频坑见[操作图谱](references/dom-map.md)的封面章节：帧条滚动容器不是 `.preview-frames-*`、点缩略图会让帧条重绘导致坐标失效、竖模式下「完成」按钮在视口外但仍可用 ref 点击。**封面只能在平台的 10 个推荐帧里选**（自定义上传不可用），本地 ffmpeg 抽帧只用来判断某帧带没带烧录字幕，不要为选封面去渲染新素材。
7. **自主声明**：点「请选择自主声明」→ 选「内容由AI生成」→ 「确定」。这些 radio 没有 semantic ref，只能按坐标点，坐标每次重取。
8. **谁可以看 / 保存权限**：分别选「公开」和「不允许」。平台的保存权限默认是「允许」，不手动改就会错。
9. **发布时间**：选「定时发布」→ 填时间（格式 `YYYY-MM-DD HH:MM`，填完按 Tab 让值落定）→ 核对输入框显示值与预期一致，并确认页面提示的时间窗口没有把它判为非法。若目标时间距「此刻」不足 2 小时，按「准备完成时刻 + 2 小时」重算后放进确认卡，别等平台夹取。
10. **等检测通过**：右侧「发文助手」显示**作品未见异常**才允许发布，否则平台会静默失败（页面重置回上传页、作品不进后台）。封面检测同样要过。
11. **发布前出确认卡**：用 `ask_user` 写清页面、账号、合集与序号、视频文件、标题、简介全文、封面两版描述、AI 声明、可见性、保存权限、发布时间，等用户确认后再点发布。发布是外部可见动作，确认不能省。发布可能触发**短信本人验证**：由用户在 FilePanel 弹层里自行输入验证码，Agent 只代点「获取验证码」。
12. **点发布**：`query(kind="semantic", text="发布")` 拿按钮 ref（class 名是构建哈希，别硬编码 CSS）。判据：跳到 `/content/manage?enter_from=publish` 即成功；**停在原地或回上传页就是没发出去**，此时作品不在后台，别当成功汇报。
13. **三处核实**（都要做，缺一处不算发布完成）：
    - 作品列表：搜标题，确认条目在、时长对、**发布时间列显示定时目标时间**、状态符合预期（定时作品会显示「定时发布中」并带「修改定时」入口，未到点也可能显示「审核中」）。
    - 作品合集：合集显示的作品数 +1。
    - 设置权限弹窗：回读「谁可以看」和「允许他人保存视频」的落库值。**回读前先 reload 页面**——该弹窗是复用组件，会沿用上一次打开时的 radio 状态，「改完立刻重开看到新值」属于自证成功。
14. **落发布记录**：写到 `workspace/projects/<项目目录>/publish_record.md`（该目录已有同名文件就续写，不要另起一套）。内容照既有格式：发布前实测发现（影响决策的事实）/ 实际填入的内容（逐字段）/ 过程中的关键处置 / 最终发布结果（落库值 + 核验方式）。话题是纯文本还是真话题卡、封面帧有没有烧录字幕，都要如实写。

## 输出

交付一条发布记录，写清：作品标题、发布时间（定时则写目标时间）、合集与序号、可见性、保存权限、AI 声明、横竖封面各是什么画面、话题是纯文本还是真话题卡、后台三处核实的结果（作品列表条目与状态、合集作品数、权限回读值）。另外说明任何与用户预期的偏差：封面带字幕、定时时间被平台调整、合集序号与预期不符、平台检测提示。

同一份记录按既有格式落到 `workspace/projects/<项目目录>/publish_record.md`（见执行顺序第 14 步），并在对话里给出一份摘要。

若用户还问了数据（播放、完播、封面点击率），回「内容管理 → 作品列表」读同一口径的数字，不要和外部榜单口径混用。

## 失败处理

- **页面跳回上传页 / 作品没进后台**：静默失败，不是成功。重新走上传与填表，发布前再看一次「作品未见异常」。
- **导航报错**（`CURRENT_TAB_OCCUPIED`、`Browser action failed in Electron main`）：改用页面左侧导航栏按钮做站内跳转，不要反复试 `navigate`。
- **新标签页卡在「加载中…」**（`stale_element_ref`、`BROWSER_OPERATION_TIMEOUT`）：新开的创作者中心标签页的 JS 可能没跑起来。不要在坏标签页里反复操作，让用户在 FilePanel 点回原来那个能用的标签页继续。
- **封面自定义上传失败**：走帧选择器；选不到无字幕帧时接受带字幕帧，并在确认卡与最终报告里写明。
- **定时时间超窗**：提示平台限制，改成立即发布或另选时间，由用户决定。
- **合集不存在**：先去「内容管理 → 作品合集 → 创建合集」建好，再回到发布页选择。
- **登录态失效或出现验证码**：停下来交给用户处理，不自动重试或绕过；验证码由用户在 FilePanel 弹层里自己输入。
