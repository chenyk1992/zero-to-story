# 剧本与改编层

只在从小说、故事梗概或既有剧本改编、分集拆分、写场景剧本或确定叙事声音时读取。它负责把材料发展为可拍的戏，再交[故事板与导演工作台](storyboard-production.md)；原文歧义的静态登记仍用蓝图 `source.conflicts`。剧本保存在当前主源，不另建平行剧情文档。

## 从故事到场景剧本

事件摘要说明发生了什么，场景剧本让观众经历人物如何走到这个结果。从小说或梗概开始的叙事创作，先在本次范围完成下面的工作，再拆 Panel；只要大纲时止于大纲，不自动写全剧。已有可拍剧本只检查当前交接需要，局部改拍不触发全剧重写。微短剧与独立情景喜剧的独立编剧产物仍归[编剧入口](../../short-drama-screenwriter/SKILL.md)，可复用本节方法，不因此套用同一种类型节奏。

### 识别原作的观看价值

先从实际读到的材料提取：跟随谁、他想得到什么、什么力量阻止他、失败或选择会失去什么，以及哪段关系、秘密、奇观或情感值得观众继续看。用本故事的具体事实表达，不只贴“悬疑、爽、感人”标签。对手可以是另一个有目标的人，也可以是制度、环境或人物自身的矛盾，不必增设反派。

长篇先梳理已提供范围内的主线、人物关系与关键兑现，再细写当前改编集/段；只读过片段时说明覆盖范围，不声称已掌握全书伏笔。小说吸引力若依赖叙述口吻、心理判断或读者的信息优势，应保留相应叙事作用，不能只抽取外部事件后丢掉原作的魅力。

把这条主线写进现有“故事梗概”，原作保护项与删改理由写进“改编决策”。尚无依据的动机、秘密或结局不当成原作事实；需要增补时遵循下文授权边界。

### 让场景由人物推动

先顺着人物选择建立因果，再写每场的动作与对话。对冲突驱动的戏，说明人物当场要办成什么、阻力怎样回应、人物改变了什么办法，以及结果怎样迫使下一步行动。升级可以是旧办法失效、代价变大、关系改变或新证据改变理解；重复争吵、追加同类羞辱或再说一遍危险不等于推进。

这些关系落进现有“场景状态链”的场景目的、转折和下一场义务，并由“场景剧本”实际演出，不能只在表里写“冲突升级”。转场能说清“因为本场结果，人物接下来必须……”，通常比按原文章节轮流介绍地点更连贯。必要的平行叙事、时间省略与观察段按其用途保留，不强求每场都由上一场直接触发。

人物性格通过压力下的选择和交流方式体现。对白既可以试探、隐瞒、交换、拒绝，也可以安慰、修复关系；对方的回应要改变交流走向。避免双方轮流替作者介绍彼此早已知道的背景。旁白承担的心理与前史仍按声音原则处理，不为“画面化”一律删掉；同一信息在旁白、对白、画面反复出现时，检查是否有反差、情感或其他明确用途。

### 设计观众获得信息的顺序

从本次范围决定开场让观众关心谁、理解什么处境，以及期待什么；可以用正在发生的选择、关系异常、感官发现或有后果的动作切入。背景在理解当下所必需的位置交代，避免先用大段世界观挤走人物行动。安静开场也要有观察或情感的进入点，不统一改成追杀、吼叫或提前曝光高潮。

中段让人物的尝试改变局势，再给观众消化与预期下一步的空间。涉及悬念时区分人物知道什么、观众知道什么、何时提供证据与答案；信息差不能靠人物无故不说话或观众看不见必要事实维持。转折须有前因、线索或性格依据，并产生后果，不为频繁刺激临时增设秘密。

结尾回应本段开场建立的期待，让人物选择、发现或关系变化落地。连载可在本集已有进展上打开下一问；独立短片和完结集完成既定收束。不要只切在动作完成前，或用下集预告替代本集应有的兑现。结论写入现有“情绪弧线”和“全章节奏图”，不采用固定秒数、反转次数或每 Panel 一个钩子的配额。

### 写成能直接读的场景剧本

小说/梗概改编的当前源在“场景剧本”中按场次连续写：场景与时间、当场动作、准确对白/旁白、必要反应、结果和转场。读者不查 Panel、资产或机位表也能理解人物为何行动、局势如何改变。此时先不填生成参数或六 Beat；摄影安排稍后承接剧本，不用运镜术语替代行为。无对白的戏直接写可见过程，不为格式补台词。

zero-to-story 统筹时该段放入 `storyboard_brief.md`；纯剧本任务直接交付所需文本，不强制建完整故事板或蓝图。已有独立剧本（如 `episodes/epNNN.md`）则引用其当前版本与场次，不再复制一份可独立修改的正文。小说原文是改编依据，当前采用剧本是分镜与对白账本的直接依据；逐字来源、允许增补和调整顺序仍在改编决策中可追溯。锁定的原文顺序和对白不能因这一区分而被擅改。

### 在拆镜前修一次具体问题

主责连读本次场景稿，按观看顺序找最影响表达的缺口并在授权范围修订：读不懂选择的因果，场景换了却重复相同信息，人物说话互不回应，只有危机介绍没有尝试与后果，或承诺的情感/剧情落点被省略。可以用“去掉这一段，观众会损失哪条因果、人物理解或情绪体验”识别空转；答案不能只剩“凑时长”。

这是写作阶段的一次修订，不是新增审批或独立审计。已有锁定剧情的问题只说明具体位置与影响，不借分镜授权改剧情；无需改稿的交接不重开。静观、抒情、喜剧停顿与持续压迫按其观看意图判断，不能仅因冲突少、节奏慢就删去。写作检查不证明实际视频成立，后续仍按实际视听验收。

修订后按正常对白、可见行动和理解时间估算各场长度，再进入节奏图。若规格装不下，先处理授权范围内的重复和支线，保护选择、因果与兑现；确有不可兼得时说明具体取舍，不让下游赶台词、删结果或拉长空镜。只简述关键修订及未解决冲突，不追加评分表或反复自审。

### 同一素材的两种写法

假设素材已定：“姐姐要拿回母亲的信；弟弟因她又要离开而不肯交还；姐姐决定留下，弟弟交信。”下面仅为自由改编练习，具体台词与动作均属原创增补，不是任何实际项目的已采用稿。

- 摘要式写法：“她回家。两人争吵。她决定留下。弟弟把信给她。”事件齐全，但选择是被告知的，观众没有经历阻力和改变。
- 场景写法：姐姐伸手要信。弟弟把信收回：“拿到了，就又走？”她的手停住，先问：“妈还说什么了？”他不答。她收回手，坐下：“那你从头说。我不走了。”弟弟看她片刻，把信放到她面前。这段用索取、拒绝、换一种接近方式和交付体现关系变化；实际所需停顿与长度再按作品规格安排。

示例展示事件怎样成为人物交流，不要求每场沿用这套动作，也不把“加反转、加台词、加时长”当成提升质量的通法。

## 先继承整体风格

新改编方案的整体风格未定时，按[风格推荐](style-selection.md)结合原文、人物关系与观看目标先提出适合方向；已有剧本不是跳过风格推荐的理由。当前风格、来源与局部例外已定则直接继承，再安排场景、人物交流和叙事声音的表达。风格选择不改变原文保护与改编权限，不为“更适合该风格”擅改结局、人物关系或锁定对白。具体反转保留剧本因果、伏笔与知情窗口，再交分镜设计揭示方式；慢动作、微表情或运镜按对应场面使用，不作为整体风格选项。

## 先定叙事声音

改编前先决定本片的叙事声音，写入故事板"声音原则"：

| 选择 | 适用 | 风险 |
| --- | --- | --- |
| 纯画面叙事（第三人称） | 动作与关系驱动的类型 | 内心动机说不清时只能靠表演和调度补 |
| 第一人称旁白 / 内心独白 | 原著为内心独白体、主角信息优势大 | 旁白与画面重复信息＝冗余；剥离原著旁白＝丢掉叙事主干 |
| 混合（旁白扛主线 + 对话保人物） | 都市悬疑、成长、回忆体 | 旁白与对白分工不清会互相抢戏 |

原则：旁白只承担画面表达不了的信息（前史、动机、时间跨度），不复述画面已表达的内容；原文为内心独白体时，默认保留第一人称声音，改为纯画面叙事须明示理由。叙事声音一旦确定，全章一致，不逐 Panel 切换。

## 改编决策登记

已选混合叙事且需要安排旁白、对白与画面时，读[混合叙事示例](mixed-narration-direction.md)。它补充表达分工与估计/实际窗口的用法，结论仍回本故事板；不改变本文的改编授权和原文边界。

已有参考作品研究时按[研究交接](reference-research.md)继承实际观察、推断与采用决定，不由热度反推剧情有效性。外来标准剧本只有对白/结果动作时，可以在当前导演任务范围补充机位、视线、动作过程与停顿，写回对应 Setup；这不授权改对白、事件、人物动机或结局。发现事实冲突交回主责，仅阻塞受影响镜头，不先强制润色整部剧。多语对白与证据范围按[语言适配](../../short-drama-screenwriter/references/overseas-dialogue.md)继承。

从原文到故事板之间的每个改变都在"改编决策"中登记，不静默发生：

| 决策 | 登记内容 |
| --- | --- |
| 删改 | 删去的事件 / 人物 / 线索及理由；删除的伏笔须同步检查其回收事件 |
| 合并 | 合并的人物或场景，及合并后归属的身份与文本锚点 |
| 增补 | 原文没有的新增事件、台词或旁白；标注"原创"，与逐字来源区分 |
| 旁白化 / 画面化 | 原文心理描写改为旁白，或改为可见动作的选择及理由 |
| 时间线 | 倒叙、插叙、平行重组，及观众的辨识手段（角标、声音桥、色调变化等） |

忠实度边界沿用用户明确选择：自由改编在锁定项外允许影像化重组，实质变更登记；受控复刻只改变明确项，其余相关可观察顺序、构图、运动、停顿与声音关系保留，不能套用自由改编默认。只读分析不进入制作。方式在对话/Skill 入口选择并写入现有改编决策，不是提供方 mode 或生成授权。参考片按[变更交接](../../video-deconstruct-analyzer/references/recreation-change-plan.md)接收证据与未知。逐字对白与原创增补在对白账本备注中区分来源，不新增账本格式。

## 分集拆分与集际状态链

- 尚需分集时按因果与冲突单元拆分，不机械照搬原文章节边界：一章可以拆多集，多章也可并一集。已有确认的场景数、事件顺序和结局按原范围保留；节奏按[类型节奏模式](storyboard-production.md#类型节奏模式)选择，独立单集和完结集允许完整收束。
- 多集生产建立集际状态链：每集结束时登记人物伤势、关系变化、道具归属、时间线与未回收伏笔，作为下一集的入场状态；跨集伏笔在覆盖矩阵的回收跟踪中登记到具体集。
- 钩子链：连载需要悬念时保留已定钩子，兑现位置沿用已确认大纲并登记到具体集；尚未确定时可优先考虑下一集开场，不提前兑现已批准的跨集伏笔。上集回顾（recap）只有观众隔集观看确有信息缺口时才加，且 recap 不进生成内容。

## 写入故事板

影视中的产品道具保留已确认结构/作用/状态，不补真实性能。完整剧情广告由[广告入口](../../advertising-creator/SKILL.md)统筹，不迁入影视六Beat蓝图。影视反转按[通用方法](../../short-drama-screenwriter/references/reversal-design.md)保留真相与获知；改伏笔联查揭示，受控复刻不擅加反转/时间效果。

叙事声音写入"声音原则"；改编决策汇总进故事板的"改编决策"区（模板已含）；集际状态链接入场景状态链——下一集的入场状态引用上一集的离场登记。其余字段沿用故事板模板。
