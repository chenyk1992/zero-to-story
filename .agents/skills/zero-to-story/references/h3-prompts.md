# H3 Panel 视频提示词规范（v0.9.0 双档版）

> 本规范基于 MiniMax H3 官方使用手册对齐升级。Skill 之前 0.8.1 版本的"单段紧凑 300–900 字符"作为**紧凑档**保留，并新增**成片档**（1.5–3KB，3 段公式）作为对节奏从容、动作/对白复杂的成片的标准做法。

## 目标

一个 2×3 黑白分镜板对应一条 MiniMax H3 Clip。故事板负责严谨的六镜设计与连续性账本；H3 提示词只保留模型生成成片真正需要的信息，不复述制作推理。

默认按每 Panel 10 秒、6 镜节奏准备提示词；自定义单段时长仍保持 4–15 秒。

## 硬限制

- 单段时长 4–15 秒，默认 10 秒；单条提示词不超过 7000 字符。
- 最多 9 张参考图；图 + 视频 + 音频混合上限 **12 个文件**（≤9 张图 + ≤3 段视频 + ≤3 段音频）。
- 图片编号必须与 LFO 的 `ref_image_0`–`ref_image_8` 顺序一致。
- H3 生成原生音频。写明需要的对白、环境声、动作声；默认结尾写 `非叙事性音乐：N/A`（或 `"non_diegetic_music": N/A`）。
- 每张 2×3 分镜板按左上→上中→右上→左下→下中→右下阅读。
- 成片不得输出六宫格、分割线、黑白线稿、镜号、文字或漫画页面。
- 分辨率 768p / 1440p，**官方推荐 1440p**；24 FPS；原生双声道。

## 3 段公式（默认骨架）

H3 提示词按以下三段组织，是成片档的核心结构；紧凑档可压缩成 1 段但**内部仍按这个顺序**。

```
【参考素材说明】+【核心创意】+【画面过程说明】
```

| 段 | 必含 | 作用 |
|---|---|---|
| 参考素材说明 | 每张参考图/视频/音频的 `@图片N` 编号 + 用途 | 告诉 H3 怎么用每个素材 |
| 核心创意 | 主体 + 地点 + 事件 + 题材/风格 + 运镜/切镜风格 | 一句话锁全片 |
| 画面过程说明 | 按 6 格 shot 顺序，每格 5 要素（景别/运镜/动作/台词/声音） | 生成成片的过程展开 |

## 两档长度决策

| 档位 | 字数 | 段落结构 | 适用场景 |
|---|---|---|---|
| **紧凑档**（默认） | 300–900 中文字符 | 1 段自然段，3 段公式顺序压成 3 个长句 | 节奏快、6 镜 ≤ 6 个动作、少对白或画外音对白、纯文生 |
| **成片档** | 1.5–3KB | 3 个清晰自然段，每 shot 5 要素可全展开 | 节奏从容、动作链复杂、含对白同步、需精确运镜/声音控制 |

**判定规则**（任一满足选成片档）：

- 6 镜中 ≥ 3 镜含精确对白落点（>5 字台词）
- 6 镜中 ≥ 2 镜需要跨 shot 台词（J-cut / L-cut）
- 涉及至少 1 个有具体动作语义的运镜（`truck left`、`dolly in`、`crane up` 等词汇表词）
- 多模态参考 ≥ 4 个文件（图 + 视频 + 音频合计）
- 涉及 TTS 多语种场景（11 主语言：中文/英/日/韩/法/德/西/阿/泰/印尼/印地等）
- 复杂声音设计（需要 R 声场、多层音效、节奏卡点）

否则用紧凑档。

## 运镜词汇

H3 对**运镜词汇**有明确响应；用模糊词（"手持微晃""跟拍"）效果差。统一用以下词汇（来源：官方使用手册）：

| 词汇 | 含义 | 典型用途 |
|---|---|---|
| `truck left` / `truck right` | 摄影机水平平移 | 跟主体侧向移动、扫视环境 |
| `pan left` / `pan right` | 摄影机水平摇（原地转） | 揭示空间、展示全景 |
| `dolly in` / `dolly out` | 推/拉 | 逼近主体或拉远建立空间 |
| `push-in` / `pull-out` | 跟推/跟拉 | 跟主体运动中同步推近 |
| `tilt up` / `tilt down` | 俯仰 | 揭示高度、强调细节 |
| `pedestal up` / `pedestal down` | 整体升降 | 改变视平线 |
| `zoom in` / `zoom out` | 变焦 | 不移动机位，靠镜头焦距 |
| `crane up` / `crane down` | 摇臂 | 大范围上升下降 |
| `handheld shake` | 手持微晃 | 真实感、纪实、紧迫 |

**环绕运镜必须写明**（官方明确）：用 `truck left + pan right` 或 `truck right + pan left` 组合，**不要直接说"环绕运镜"**，模型不知道旋转方向。

**景别词汇**：`extreme close-up`（极特写）/`close-up`（特写）/`medium close-up`（中近景）/`medium shot`（中景）/`full shot`（全景）/`wide shot`（远景）/`establishing shot`（建立镜头）。

**切镜风格**：`cut`（普通切镜）/`fade`（叠化切镜）/`rhythmic cut`（随节奏卡点切镜）/`jump cut`（快切）。

## 跨 shot 台词（J-cut / L-cut）

H3 **支持跨 shot 台词**，但必须明确写出来。常用表达：

- 一句台词跨两个相邻 shot：`S1 人物开始说：…，S2 同一句继续，…`
- 画外音从 S1 切到 S2 才看见人：`S1 画外音起：…，S2 切镜到说话人，…`
- 同理 L-cut 写法。

**台词长度要对齐 shot 时长**——3 秒 shot 不要塞 20 字台词，会口型错位。规则：每 shot 内台词字数 ≤ shot 秒数 × 4（按中文每字约 0.25s 朗读）。

## 不要 BGM 的官方写法

H3 默认会生成背景音乐。要明确"无 BGM"必须用以下任一写法（H3 内部识别的关键词）：

- 中文：`非叙事性音乐：N/A`
- 英文：`"non_diegetic_music": N/A`
- 短句：`不要任何背景音乐`

**不要只写"不要背景音乐"**——H3 在不同上下文里可能识别不到。"非叙事性音乐：N/A"是官方示例里反复出现的固定用法。

## 三种生成模式分模板

H3 提供三种入口，提示词写法不同。

### 模式 A：多模态参考（混合输入）

适用：上传人物图 + 动作视频 + 场景图 + 音乐等组合。**每个素材必须写清它的"角色"**。

```
【参考素材说明】
@图片1 = 主角身份参考（锁脸/锁形象/锁服装）
@图片2 = 场景参考（锁环境与色调）
@视频1 = 动作参考（锁动作轨迹）
@音频1 = 情绪/音色参考（锁配乐/音色）
[如有更多素材同理编号]
```

`mixed` 输入上限：≤9 张图 + ≤3 段视频（每段 2-15s，总 ≤15s）+ ≤3 段音频 = ≤12 文件。

### 模式 B：图生视频

- **1 张图**：明确写是**首帧**（视频开头画面）还是**尾帧**（视频结尾画面）。
- **2 张图（首 + 尾帧）**：H3 **不会自动加切镜**，只在两帧之间补动作/光影/声音过渡。

```
【参考素材说明】
@图片1 = 首帧参考图：[描述首帧画面]
@图片2 = 尾帧参考图：[描述尾帧画面]
```

### 模式 C：纯文生视频

不依赖任何参考素材。文字描述要**更具体**：

- 主体外观（脸/发型/体型/服饰/年龄/气质）
- 场景细节（空间结构/光线/色调/天气/时间）
- 动作描述（具体动作 + 节奏）
- 风格（写实/动画/电影感/广告片/纪录片 + 特殊风格如赛博朋克、霓虹灯美学、涂鸦风）

**官方推荐分层写法**：「大全景交代空间 + 中景承载动作 + 特写强调细节」。

## 紧凑档模板

> 10 秒、16:9、3D 渲染悬疑短剧。@图片 1 = 角色 A 角色卡（身份/发型/服装/道具不变）；@图片 2 = 当前 Panel 黑白分镜（仅参考构图/空间/动作链/节奏，不采用线稿画风）。开场 [景别+运镜]，[核心事件一句概括]；中段 [按 6 格顺序压缩的连续动作链]；结尾 [末态一句]。运镜 [一句话概括景别变化与镜头运动]；[对白（画外音 / 角色 N）]；环境声 [列出]；动作声 [列出]；非叙事性音乐：N/A，不要可读文字。负面：[当前段最可能失败 3-6 项]。

**字数**：300–900 中文字符。

**使用规则**：

- 把三段公式压成 3 个长句
- 6 镜动作链用单一因果叙述串起来，不写"shot 1... shot 2..."
- 运镜用一句话概括（不展开成 shot 级别词汇）
- 声音只列总类，不展开具体音效

## 成片档模板

```
【参考素材说明】
@图片 1 = [角色 A 角色卡：身份、发型、体型、服装、关键道具保持不变]
@图片 2 = [角色 B 角色卡：身份、发型、服装、关键道具保持不变]
@图片 3 = [Panel N 黑白分镜：仅参考构图、空间关系、动作链与节奏，不采用线稿画风]
[如有末帧、视频参考、音频参考，顺延编号]

【核心创意】
[主体] 在 [地点]，做 [事件]；[题材/风格，如：3D 渲染都市悬疑、电影感、克制超自然]。
[画幅]、[光线]、[整体气质]。[运镜风格总述，如：开场 wide → medium close-up → extreme close-up + 慢动作；切镜以 cut 为主，结尾叠化]。
[P002 起：承接上一段最小可见末态：主体位置/朝向/关键道具/仍在变化的动作。]

【画面过程说明】
S1（0–1.7s）— [景别]，[运镜]：[主体位置/朝向/空间关系]，[具体动作]。[台词（如有）]。[声音：环境声/动作声/音效]。
S2（1.7–3.3s）— [景别]，[运镜]：[...]。
S3（3.3–5.0s）— [景别]，[运镜]：[...]。
S4（5.0–6.7s）— [景别]，[运镜]：[...]。
S5（6.7–8.3s）— [景别]，[运镜]：[...]。
S6（8.3–10s）— [景别]，[运镜]：[末态锁定：下一段依赖时写清可见末态]。

【声音与禁项】
对白：[列出，含角色名 + 完整台词；跨 shot 台词写明"接着上镜继续"或"画外音起"]。
环境声：[列出]。
动作声：[列出]。
非叙事性音乐：N/A，不要可读文字，不要 [当前段最可能失败 3-6 项负面约束]。
```

**字数**：1.5–3KB。

**使用规则**：

- 三段分明、自然段分隔
- 每个 shot 5 要素（景别/运镜/动作/台词/声音）尽量齐全
- 时间戳是按 24 FPS 切分的近似分段（10s/6 镜 ≈ 1.67s/镜），不是毫秒级精确
- 运镜从词汇表选词，不用"手持微晃""跟拍"等泛词

## TTS 与多语种

H3 TTS 精准覆盖 11 种主语言：**中文、英语、日语、韩语、法语、德语、西班牙语**等；可衍生探索阿拉伯语、泰语、印尼语、印地语等 40+ 种。

- 多语种对白场景：用 `@音频1` 锁音色参考，提示词中明确"对白使用 [语言]，[音色参考音频 1]"
- 跨语种场景：每个角色分别传音色参考
- 提示词中如需写出对白原文，按目标语言写

## 连续性压缩规则

- P001 直接建立开场。
- P002 起只写一句最小承接锚点：上一段末态中的主体位置、朝向、关键道具和仍在变化的动作。
- 当前分镜板左上格已经复用上一板右下格，不再逐项复述全部连续性账本。
- 本段结尾只在下一段依赖它时写清可见末态。
- 角色、服饰、道具和光线只写最容易漂移的 2–4 项；其余由角色卡和分镜板承担。

## 参考图写法

只传当前 Panel 真正需要的身份角色卡，再传当前分镜板。写法：

> 图片1是角色A角色卡：身份、发型、体型、服装和关键道具保持不变；图片2是角色B角色卡：身份与外观保持不变；图片3是当前Panel黑白分镜：仅参考构图、空间关系、动作链与节奏，不采用线稿画风。

背景路人和不需要身份锁定的轮廓不占角色卡槽位。提示词确认后不得改变图片顺序。

只有上一 Clip 已生成并提取实际末帧时，才能把末帧加入下一 Clip。加入后将其放在图片1并重新编号所有引用；首轮批量包不引用尚不存在的末帧。

## 合格示例

### 紧凑档示例

> 3D渲染悬疑短剧，真实人类比例，都市烧烤街，克制超自然。图片1是林野角色卡：深蓝跑腿工作服、发型、体型和外卖箱保持不变；图片2是赵启明角色卡：身份、发型、服装和手机保持不变；图片3是Panel1黑白分镜，仅参考构图、空间关系、动作链与节奏，不采用线稿画风。开场特写翻倒旧外卖箱和溅在林野衣服上的汤汁，镜头迅速切到压迫性的双人构图：林野在左前景弯腰捡餐盒，赵启明在右侧贴近他的脸直播羞辱，提出把空餐盒送到雾巷17号并承诺五千元，订单只显示抽象光块。后景同伴望向高架桥下黑暗入口并变色劝阻。林野看手机、擦脸、提起箱子，被推搡后重新站稳，冷声说"5千，记得到账"。镜头从动作特写平稳转为中近景并收住。烧烤街人声、油锅、车辆、外卖箱撞地、直播提示音、肩膀碰撞、提手摩擦；只要环境声和动作声；非叙事性音乐：N/A，不要可读文字。电影感体积雾、现实灯光、干净轮廓，避免肢体变形、身份漂移、背景闪烁。

### 成片档示例

```
【参考素材说明】
@图片 1 = 林野角色卡：深蓝跑腿工作服、反光条马甲、短黑发、窄脸、疲惫眼神、磨损外卖箱、欠款短信手机保持不变。
@图片 2 = 赵启明角色卡：昂贵休闲夹克、名表、白色球鞋、直播手机、短发、偏壮体型保持不变。
@图片 3 = Panel 1 黑白分镜：仅参考构图、空间关系、动作链与节奏，不采用线稿画风。

【核心创意】
临海市烧烤街，27 岁的外卖跑腿员林野被 28 岁的富二代赵启明当众羞辱与金钱诱惑。3D 渲染都市悬疑，写实人类比例，脏暖橙色街灯与湿冷蓝色阴影，克制超自然。16:9 横屏，10 秒，1 Panel 6 镜。运镜以 cut 为主：从动作特写急推到双人压迫构图，再用 push-in 把赵启明的手机贴到林野脸上，最后回拉形成中近景收住；除急推处使用 handheld shake 外，整体保持固定机位。

【画面过程说明】
S1（0–1.7s）— extreme close-up，handheld shake：旧外卖箱位于画面前景左下，被赵启明从右侧一脚踢翻，汤汁溅过箱盖和林野深蓝工作服下摆。环境：烧烤摊喧闹；动作：箱体撞地、汤汁泼洒。
S2（1.7–3.3s）— medium shot，固定：林野在画面中央偏左弯腰捡餐盒，赵启明在右侧俯视他，手机举在两人之间直播，围观人群背景虚焦。赵启明：都说跑腿员最能吃苦，怎么一份空餐盒都送不明白？手机直播提示音短促响起。
S3（3.3–5.0s）— close-up，dolly in：林野抬头，脸上沾着汤汁，眼神压住怒意；赵启明的手机和手指从右前景侵入，遮住林野部分脸。林野：地址是你发的，东西也是你点的。林野呼吸清晰。
S4（5.0–6.7s）— medium close-up，handheld shake：赵启明从右侧逼近镜头，手机贴到林野脸前，昂贵手表和夹克袖口清晰可见，林野退到左侧摊车边缘。赵启明：少废话。送到雾巷，今晚这单给你五千。敢不敢？赵启明笑声；环境声形成压迫性混响。
S5（6.7–8.3s）— extreme close-up，固定：手机屏幕位于画面中央，订单地址快速刷新为"雾巷17号"，尾号"4444"停留在屏幕底部；林野的手从左侧接近屏幕。订单提示音单独突出，市井声第一次明显降低。
S6（8.3–10s）— medium close-up，pull-out：赵启明从右向左推林野肩膀，林野踉跄一步停在翻倒的外卖箱旁；同伴向后退，围观者保持距离。肩膀碰撞声；直播评论音效变尖。林野双手握紧外卖箱提手，重新站稳，目光盯住赵启明。

【声音与禁项】
对白：赵启明（"都说跑腿员最能吃苦，怎么一份空餐盒都送不明白？""少废话。送到雾巷，今晚这单给你五千。敢不敢？"）；林野（"地址是你发的，东西也是你点的。"）。林野最后一句作为末钩子，不在本镜说完，留给 P002 起手承接。
环境声：烧烤摊喧闹、远处油锅、车辆、人群。
动作声：外卖箱撞地、汤汁泼洒、手机直播提示音、肩膀碰撞、提手摩擦。

```

## 生成前检查

### 通用

- [ ] 模型是 MiniMax H3，时长与画幅明确。
- [ ] 图片编号与执行槽位一致，分镜板用途写清。
- [ ] 六格核心动作按阅读顺序完整出现，没有新增剧情。
- [ ] P002 起用一句话承接上一段末态。
- [ ] 提示词不超过 7000 字符，紧凑档 ≤ 900 中文字符。
- [ ] 声音结尾明确 `非叙事性音乐：N/A`（或 `non_diegetic_music: N/A`）。
- [ ] 成片媒介明确，不继承黑白线稿和分镜边框。

### 紧凑档额外

- [ ] 单段 3 段公式顺序，3 个长句。
- [ ] 6 镜动作链用单一因果叙述，不写"shot 1…"。
- [ ] 运镜/声音只用总括，不展开成 shot 级别。

### 成片档额外

- [ ] 3 段分明，【参考素材说明】【核心创意】【画面过程说明】结构清晰。
- [ ] 每个 shot 5 要素（景别/运镜/动作/台词/声音）尽量齐全。
- [ ] 运镜从词汇表选词，不用"手持微晃"等泛词。
- [ ] 跨 shot 台词写明"接着上镜继续"或"画外音起"。
- [ ] 台词字数对齐 shot 时长（≤ shot 秒数 × 4 中文字）。
- [ ] 末态锁定写清（下一段依赖时）。

## 常见失败与修正

| 失败 | 修正 |
|---|---|
| 提示词冗长，模型忽略核心动作 | 紧凑档删除逐镜时间戳、重复初末态和通用负面词，只保留六格动作链；或切换到成片档并按 shot 分段 |
| 视频输出六宫格或黑白线稿 | 明确"分镜仅参考构图、空间、动作链与节奏，不采用线稿画风" |
| 跨 Clip 跳变 | 在新段开头补一句上一段末态，不重复整个连续性账本 |
| 动作换序 | 按分镜阅读顺序改写成单一因果叙述，或成片档按 shot 严格编号 |
| 身份或道具漂移 | 在对应角色卡后只补最关键的身份、服装和道具不变项 |
| 对白或声音混乱 | 删除无关声音，只保留指定对白、环境声、动作声和"非叙事性音乐：N/A" |
| 环绕运镜执行方向错 | 不写"环绕运镜"，改写 `truck left + pan right` 或反之 |
| 跨 shot 台词断在镜中 | 一句台词跨多 shot 时，写明"接着上个 shot 继续说"或"画外音起" |
| 台词对不上嘴型 | shot 内台词字数 ≤ shot 秒数 × 4；过长时拆镜或改画外音 |
| 模型生成了背景音乐 | 末尾加 `非叙事性音乐：N/A` 而不只是"不要背景音乐" |
| 多模态参考没锁脸/动作 | 每张图/视频/音频都写明 `@X = YY 参考`（人物参考/动作参考/场景参考/...）|
| TTS 语种不对 | 提示词对白原文用目标语言写 + 传 `@音频 N` 锁音色参考 |
| 1 Panel 默认 10s 太短 | 调整 Panel 时长到 4–15s 区间，或拆为多 Panel |

## 不写的内容（两档都遵守）

- Shot 1–6 表格或逐镜标题（紧凑档不写；成片档用 S1–S6 短编号，不写表格）。
- 重复出现的 Medium Lock、Style Brief 或角色全量描述。
- 同一动作的自然语言、箭头清单和时间表三次复述。
- 与当前 Panel 无关的通用负面词。
- 真实品牌、可识别 Logo、原参考图标题（成片合规要求）。
- 模糊运镜词（"手持微晃""跟拍""推进"单独出现时）——必须配合具体方向词或与词汇表词共现。
