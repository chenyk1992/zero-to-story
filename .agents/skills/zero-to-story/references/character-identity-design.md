# 影视角色身份设计适配

通用身份、非人结构/身体覆盖状态统一维护于[视觉身份设计](../../visual-design-creator/references/character-identity-design.md)。已有故事角色先按[身份与造型复用](creative-assets.md#角色身份与造型复用)匹配cast ID、别名、年龄/造型，再委托必要资产，不重新选脸。

沿用故事板角色事实及asset key，专业成果返回本Panel所需版本。单角色卡使用[唯一模板](../assets/character_card_prompt.template.md)，不复制身份状态或模板。独立资产交visual-design-creator，影视整片仍由zero-to-story统筹。局部返修只更新消费者，冻结历史保留。
