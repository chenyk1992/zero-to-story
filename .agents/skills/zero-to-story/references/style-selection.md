# 从内容推荐与继承整体风格

供故事、MV、广告主责及受托编剧共用。先看用户现在有什么、希望观众感受到什么，再决定整体方向；用户不必点名 Skill 或先列完整制作规格。本文是创作方法，授权与执行沿用[共享规则](../../../../guides/ai-system-prompt.md)，不新增审批、生成任务或控制字段。

## 整体方向与局部方法

“影视风格”在交流中可以包含题材、画风和气质；主责将它们整理成相容的作品方向，而不要求用户学习分类。

| 层次 | 决定什么 | 例子与使用方式 |
| --- | --- | --- |
| 题材、类型与世界 | 人物在什么世界、面对怎样的冲突与规则 | 末日、科幻、仙侠、现实都市；已有设定直接保留，末日与科幻可以组合 |
| 媒介与整体美术 | 人物、环境和运动以什么视觉语言成立 | 真人摄影、二维国漫、赛璐璐、风格化3D、手绘、水墨、拼贴或混合媒介；“国漫”仍需在当前方向内具体化 |
| 整体气质与节奏 | 观众与人物/世界保持怎样的情绪距离、注意如何发展 | 克制悬疑、温暖观察、荒诞喜剧、热烈冒险；允许同一作品内安静与高能段落有发展 |
| 叙事与拍摄方法 | 某段信息、动作或情绪怎样被表达 | 反转、微表情、慢动作、子弹时间、运镜、遮挡揭示；按剧本和分镜需要选择，不与末日/国漫并列成互斥风格 |

整体风格也可由持续的摄影、调度或拼贴关系构成。方法成为全片视觉语言时，在整体方向中说明其作用，再在各段落实；不禁止它参与整体设计，也不要求每镜重复同一种动作或拍法。反转的因果、伏笔和知情安排在剧本层建立，分镜再安排可见证据与揭示窗口，不能到拍镜头时才凭空补真相。

## 何时推荐，何时直接继承

- **尚未选整体风格：** 在新剧本、改编方案或详细分镜成形前，主动结合已有内容推荐。已有剧情、脚本或歌曲不代表视觉风格已经确定；保留原内容，补其表达方向即可。用户要求风格方案时直接交方案，不先要求用户选 Skill。
- **已经有风格：** 沿用用户指定、同作品已采用的方向及适用范围，不重新给菜单或再索批准。“国漫”等宽泛方向在其内部具体化；有现成参考和设计先继承。只有具体化会带来现有依据无法判断的实质分歧时才集中问清，不能借细化换成另一媒介。
- **用户希望比较后选择：** 先交推荐与理由，让用户选定、融合或修订一次，再深化依赖该方向的剧本、分镜和资产；候选不写成已采用，明确尚待选择的范围，无关分析可继续。
- **要求直接完成或已授权自主设计：** 主责选择合适方向并说明依据，按该方向继续；不新增风格审批。用户明确要求先选再做时仍尊重该要求。
- **只做局部改稿、已定 Panel/H3 或修复：** 继承当前作品风格，仅处理请求范围，不重开全片风格探索。只写歌词、歌曲/器乐、纯小说文本或只读分析时按当前交付讨论需要的类型、语气与节奏，不强加视觉媒介、分镜或视频参数。

## 怎样给出有用的推荐

从现有输入提取创作依据，而不先发制作问卷：故事核心、人物关系/选择、世界设定、情绪发展、用户希望保留/避免的内容、目标观看感受，以及已有参考与交付条件。已有信息直接用；仅补问会改变方向的真实缺口。

故事看冲突与人物处境，MV看歌曲主题、情绪和编曲发展，广告看品牌目的、产品特征与资料能支持的主张。没有实际歌曲也可先推荐暂定视觉方向，但精确段落、歌词、口型与卡点等实际音频核对后再定；实际歌曲到来或换版后按[内部复核](../../music-video-creator/references/music-timeline.md#实际歌曲到来后的内部复核)核对原推荐依据，不因视觉推荐改动已采用词曲，也不重新审批已有风格。广告的世界想象与产品事实分开，风格不证明性能。

给少量有实质差别的候选，数量随请求决定，并明确主推及理由。每项用自然语言说明：

- **整体组合：** 题材/世界中已有的部分，选用的媒介与主要气质；不为填满维度增添题材。
- **为什么适合这份内容：** 联系具体人物、矛盾、歌词情绪或品牌目的；同时说明相对其他方向的表达取舍，不能只写“高级、电影感”。
- **会怎样被看见和听见：** 一个来自当前内容的场景/乐句/产品事件，说明人物与环境怎样呈现、节奏与声音如何配合。克制表达、强烈动作或大胆视觉均可被推荐，不以低运动作为共同默认。
- **后续如何发展：** 这一方向会怎样影响场景设计、剧本的可见表达、表演、分镜、文字和声音；相关实际能力尚未核实的部分保持候选，不承诺可精确实现。

不是按题材查唯一预设：科幻不自动等于霓虹，国漫不自动等于夸张演出，慢歌不自动等于慢镜头，广告不自动等于快切。可复用[视觉风格分支](visual-style-profiles.md)、[对称童话](symmetric-storybook-style.md)及 MV 的[视觉方法](../../music-video-creator/references/style-library.md)，这些是深化资源，不是封闭菜单；不为展示风格库把所有分支都读一遍。

选中标题/图形包装主导方向后，可按需用[字形与排字选型](../../visual-design-creator/references/type-and-layout-choices.md)、[包装材料与能量](../../visual-design-creator/references/packaging-style-directions.md)深化；声音与动作、文字或情绪的关系可用[声音互动](../../music-video-creator/references/sound-image-interaction.md)。它们是整体方向内的具体设计资源，不让未选包装覆盖故事美术，也不为风格自动指定配乐或镜头变化。

例如同一“末日中两人寻找亲人”的剧情，可比较写实末日公路片（行程与环境压力）、二维国漫冒险（清楚轮廓、尺度与动作）、手绘废土寓言（日常物件与荒芜环境的情感反差）。推荐依据应回到两人的关系和用户希望的感受，而非末日题材固定选灰色、慢动作或爆炸。

同一告别歌曲可比较都市赛璐璐的空间距离与有限动画、手绘记忆的材料与痕迹、拼贴表演的人物/字层关系；都可有留白或释放，不由音乐曲风直接套视觉路线。同一金属产品展示可比较真实材料的连续发现、图形化结构的清楚组织、超现实尺度的品牌想象；不可让后两者冒充真实功能证据。

## 同一内容、不同目标的对照

比较方案时，先固定剧情/歌词与声音依据/产品事实，只改变观看或传播目标，看看推荐依据、优先方向和具体表现是否有合理响应。这是创作推敲方法，不是每个任务必做的测试或菜单；候选可以重叠、数量可以不同，不能为证明灵活而强迫改画风。已有风格时直接在该方向内比较表达，不重新选风格。

| 固定内容 | 目标A下的推荐与表现 | 目标B下的推荐与表现 |
| --- | --- | --- |
| 兄妹在末日车站折好地图、转移避风，仍未找到母亲 | 强调彼此照料时，可优先柔和手绘或清楚人物关系的二维国漫；让压住纸边与共享避风空间成为注意中心 | 强调环境压力时，可优先写实观察或冷峻国漫；让风、通行空间和停步的重量承担压力，不新增敌人或改变亲情关系 |
| 同一首告别歌曲，同样的歌词、人声、留白与展开 | 强调私人记忆时，可优先手绘痕迹或安静实景，让旋律延续到物件与空间 | 强调演唱者视觉身份时，可优先明确轮廓、平面图形或拼贴表演，让少量姿态与字形建立识别；仍保留歌曲留白，不因身份展示改为全程快切 |
| 同一无标签金属圆罐，闭盖，结构/功能/价格证据边界不变 | 品牌记忆目标可借材料光感或图形轮廓形成印象；品牌感受不当成功能证据 | 商品理解目标优先形体、盖缝与比例关系的清楚呈现；若目标转为促购，只基于已有事实组织信息，缺尺寸/用途/价格等资料就说明缺口，不能用更强特效补造理由 |

对照不只换候选名字或理由里的名词：应能指出本段观众主要看见什么、哪些动作/空间/文字/声音因此被强调，以及选定后怎样进入主计划、Shot和H3。相同风格下改变视点与主导关系也可满足不同目标；风格更换不是对照成功的条件。独立的歌词、音频或文学交付仍保持原范围。

## 采用方向怎样进入后续工作

主源中只保存当前方向及其依据；需要保留候选供比较时明确其候选状态，后续生产不混用未采用方案。依据区分用户指定、沿用本作品、主责自主选择与待用户选择，不把建议写成用户已确认。风格采用与生成授权分别记录。

| 环节 | 传递位置与内容 |
| --- | --- |
| 剧本/改编 | 当前创作方案或剧本简报引用采用方向与来源；让世界、动作、人物交流、场景与声音的表达相容。保留锁定事件、人物关系、结局、对白/歌词与广告事实，风格选择本身不授权重写这些内容 |
| 故事主源 | `storyboard_brief` 的 Medium Lock / Style Brief 记录媒介、具体美术/气质、选择依据与稳定特征；局部手法进入相应 Setup、信息安排和声音，不另建可漂移的风格主档 |
| MV主源 | `mv_plan` 的视觉媒介/风格锚点记录整体方向；剧情/表演/意象/文字是表达组织，分别记录与风格的组合关系。音乐母题和暂定视觉可早期互相启发，详细分镜与卡点绑定实际采用歌 |
| 广告主源 | `ad_plan` 的整体风格与表达记录媒介/气质、品牌联系和依据；剧情/展示/口播等表达与具体手法分别落实，不把已有脚本视为风格已定 |
| 资产与分镜 | 人物、场景、服装/产品与关键帧共享已定视觉语言；逐镜说明剧情作用、主体/空间关系和运动。稳定特征按需继承，段落变化说明用途，不让换镜头或专能委托暗中换媒介 |
| H3与Canvas | 依[共同风格交接](../../canvas-workspace/references/creative-handoff.md#整体风格的继承与分镜方法)取当前镜头具体特征进入完整提示词，实际参考通过真实端口绑定；文档/节点说明本身不会进入模型。执行端沿用冻结事实，不重新推荐 |
| 验收 | 正常观看实际片段与跨段关系，看选定的美术、人物气质、节奏发展与作品意图是否成立；选择克制或高能都按其目标判断，不以效果数量、风格关键词计分。静态图、离线方案和结构检查不证明真实视频风格成立 |

全片统一是共同视觉与表达依据，不是全片使用同一景别、同一速度或每镜加同一技巧。梦境、回忆或媒介混合可按已定范围变化，保留观众辨认与返回主风格的关系；已有局部例外一起继承。

用户改变风格时，先明确改变的是题材、媒介还是气质，沿[当前版本协调](../../canvas-workspace/references/creative-handoff.md#当前版本协调)更新受影响剧本表达、资产用途、Shot、提示词、后期与验收重点；无关剧情和未受影响媒体保持原采用依据，历史快照保留。不能只换总标题而让下游沿旧风格，也不能因换风格自动重做全片。
