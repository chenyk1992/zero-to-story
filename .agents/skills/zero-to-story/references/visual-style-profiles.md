# 按需视觉风格参考

对称、舞台化调度、韦斯·安德森启发的复古童话短片，按需读[对称童话风格](symmetric-storybook-style.md)。该分支与以下手绘/科幻同为可选方法，不覆盖用户画幅、颜色、媒介、无人或无音乐决定。

用户提出宫崎骏／吉卜力启发的动画、温暖手绘，或写实未来科幻时，读取对应分支。前者将风格名称落实为线条、色块、环境绘制与生活化设计，后者落实为空间、材质、光源与物理介质；不能只把名称写进提示词。沿用已确认的故事、主体和媒介；这些方法是创作选项，不是每镜验收清单。只要人物、环境或道具参考图时，完成该图片范围，不扩成完整视频。

把相关决定写回故事板已有 Medium Lock、Style Brief、角色/场景锚点和 Camera Setup；局部图片任务直接使用当前图片简报，无需建立完整故事板。歌曲驱动 MV 沿用其自身视觉参考和制作流程。资产数量、视频模式、时长与生成流程仍由各自的生产计划决定，不因选择风格而增加一套资产或审批。

## 用实际参考图确认风格

人物、环境或必要道具的实际参考图是美术方向验证的主要依据，不要求先生成短片。按当前制作需要复用已有图，或在已有生成授权范围内制作所需资产；不另建固定数量的试图、全套视图或风格测试视频。图片生产与修正仍使用 Canvas。

1. **把风格写成可见要求。** 记录当前主体、媒介、形状/轮廓、色彩组织、线条或材质、光照关系，以及确有必要的排除项。区分全片稳定特征与当前图的天气、灯光、姿态和剧情状态。
2. **查看真正生成的图片。** 在现有资产用途检查中判断：目标媒介是否成立，主体与环境是否属于同一美术体系，必要结构和身份是否保持，关键区域是否可辨。角色中性背景卡可验证人物画法，不能单凭它认定场景纵深与环境绘制也通过；无人物作品可只用环境图验证。
3. **按已有证据判断稳定范围。** 需要跨人物、视角或场景复用时，对照制作中实际需要的相关图，看轮廓、线条/材料、色彩和受光是否保持同一规则。已有有效结果直接复用，不要求额外抽样数量。只有一张符合要求时，记为该图可用，不宣称全部对象或任意条件下都稳定。
4. **记录采用版本与具体保留项。** 在现有 Style Brief 或资产记录中引用实际图片及版本、用途和观察结论；只写了提示词就保持待生成。偏差影响风格用途时，保留已成立的身份、构图和结构，修正有证据的线条、材料或光色问题。新生成沿用共享授权与失败规则，不自动重试到满意。

参考图提供可复用的美术依据并帮助校正 H3 偏差；它不证明动作、对白或镜头接缝已通过。视频生成后在原有一次验收中检查风格延续，不增加独立的风格试片关卡。具体传递见下文[参考图进入视频](#参考图进入视频)。

## 温暖手绘动画

用清楚的线稿和平涂色块保持主体轮廓，阴影层次克制；背景可用水彩或水粉的软边、干笔触和局部纸张颗粒。线条颜色、笔触和服装设计服从现有视觉锚点，材质变化不能盖住人物关系或关键物件。

选择与本镜动作有关的环境运动：近处悬挂物轻摆，中景衣角或树叶响应风，远处云或烟缓慢变化。不同物体按距离、柔软程度和受力产生不同节奏，不让所有元素同步摆动。摄影机移动时再描述有依据的层间视差；固定镜头中的云、叶或水面运动不等于摄影机视差。

人物停下后，衣料或携带物可以稍晚收稳；接触、放下和转身保留重量、重心变化及适度回弹。先让主要动作清楚，再用微运动补充环境，不为表现“自然”添加无关动作。

日常照料、自然观察、旅途或轻奇幻都可承载这种媒介。只有故事需要时才加入魔法、生物或飞行，不强制角色缺陷、成长弧线或固定节拍。比如窗边修补风筝的镜头，手部接触和纸面状态是主要信息，窗帘的轻摆只补充空气流动。

### 方向与情绪设计

用户已有方向就直接深化；以下用于缺少具体表达时选择，不要求逐项提问或全部出现。按当前原创简报设计主体和场景，不因风格名称自动补入某部作品的角色、载具或标志性构图。

| 方向 | 参考图应帮助确定什么 | 转成镜头时的重点 |
| --- | --- | --- |
| 日常治愈 | 居家/邻里空间、实用衣着、被照料的物件、柔和但有方向的光 | 用做饭、修补、递物等可见行为表达关系，不用统一笑脸代替情绪 |
| 自然观察 | 植物形态、水面、天气、季节色彩与前中后景；可无人 | 环境变化承担注意力，风、雨、云、水各按自身节奏运动 |
| 成长旅途 | 目的地与路径、随身物件、出发/归来时可复用的视觉锚点 | 选择与行动体现变化；成长只在已定故事需要时采用 |
| 原创轻奇幻 | 生物或现象与日常尺度的关系、可见世界规则、光色来源 | 奇观与情绪相连，不因画风给每件东西加魔法光 |
| 诗意机械 | 工坊、风力装置、机械部件、接触面与使用痕迹 | 照料、启动、停机表现情感；转动与接触按已定结构完成 |
| 画面主导 | 主次轮廓、色彩关系、天气和首尾意象 | 极简剧情也可完整收束，不为完整短片补反派或任务 |

### 人物、环境与道具的图片写法

人物图把身份和画法分开写：轮廓与身体比例、简洁可辨的五官、块面头发、实用服装和关键配件属于设计；深灰/深褐线稿、平涂与少量阴影属于画法。颜色服从已定人物，不把所有皮肤、服装和阴影染成同一暖黄色。参考图侧面或背面沿用同一服装结构与身体比例；非人主体沿用已定身体类型。

环境图先写可行走的空间、地标和前中后景，再写水彩/水粉叠色、远处软边和局部纸纹。主体或关键接触区保持清晰，不能用满屏颗粒和模糊掩盖空间。只承担场景身份时用空环境，避免把临时路人固定进场景；当前任务明确需要人物与环境合图时按构图保留。

道具图突出用途、尺寸参照、手工接缝、连接和接触部位；机械必须能解释开口、铰链、把手或转动部分在哪里。图片只画指定状态，动作先后和重心转移写入镜头，不能用单图证明机关已经可动。

例如雨后工坊环境图可写：木窗与工作台分出近中远层，桌面保留修补空间；深褐结构线配灰绿和赭色块，窗外水粉叶簇边缘较软，侧窗亮面与室内阴影清楚，纸纹只在大面积背景轻微可见。把“治愈”落实为可见设计，而不只追加风格名。

### 从图片转为动画

将图中可动层和受力写回对应镜头：窗帘先响应风、较重衣摆稍晚收稳；近景叶片幅度与远处树冠不同，主角的接触动作优先。机位移动才产生对应视差，不将分层背景机械等速滑动。对白、视线、动作归属按既有表演与接力规则；自然声、静默与音乐沿用当前声音方案，不因手绘风格强配 BGM。

## 写实未来科幻

先确定空间尺度、主光来源、材质和环境介质。灯光使关键接口与动作可辨，表面反射随灯位和机位变化；磨损、湿润、尘土或锈蚀需要环境或使用依据。完整的新设备同样可以成立，不靠脏旧或深黑暗部替代设计。

区分舱内空气、室外大气、水下和真空：悬浮物、烟尘、衣物与声源按已定环境处理。虚构世界可有自己的规则，但前后要一致；概念参考不能证明真实工程结构或性能。角色需要进出、抓握或操作时，按已确认结构安排接触与路径。

需要选择具体方向时，可从以下方法取相关部分，不强制套用整套题材：

| 方向 | 人物/道具参考重点 | 环境参考与镜头重点 |
| --- | --- | --- |
| 深空探索 | 宇航服层次、设备连接与维护接口，金属/织物/密封件各有不同受光 | 舱内实用灯、明确通道和尺度，舱外真空与舱内空气分开；失重动作保留惯性，不在真空默认添加飘尘和传播声 |
| 史诗空间 | 厚重衣料、装甲或仪式物件服从人物身份与世界设定 | 巨构、负空间与人物尺度对照，有来源的侧光或顶光揭示体积；远景交代规模，近景仍保留叙事信息 |
| 废土遗迹 | 修补、磨损、锈蚀与长期使用位置对应，不把所有表面统一做旧 | 遗迹结构、风向、侵蚀面、日照和沙尘相互对应，保留可通行路径和关键轮廓 |
| 异星生态 | 生物身体类型、附肢数量/连接、角质或半透明组织；运动方式与结构相容 | 植物/真菌和有机建筑具有重复的生长规律，湿润/透光/局部生物发光有依据，尺度与环境介质自洽 |

未来感也可以来自结构、尺度和使用方式。用户选择赛博朋克、霓虹或全息界面时，沿用该方向并说明具体光源与视觉作用；没有这种选择时，不自动把它们加到每个场景。画面文字和配乐仍按用户要求及既有制作责任处理。

### 人物、场景与物件的共同美术规则

写实方向从角色参考到场景、关键帧和分镜板都保持真人摄影般的尺度与材质响应，不在中间资产默认换成铅笔草稿、游戏 CG 或塑料模型。用户选择手绘科幻或其他媒介时保留其媒介，再借用结构、尺度与介质方法，不能用科幻题材覆盖用户画风。

人物/物种图先锁定人类、仿生、机器人或生物的身体类型、整体轮廓、部件数量、连接及识别特征；皮肤、金属、织物和透明罩各按自身材料呈现。角色身份图保持独立、主体完整，不把不同物种混成一张角色卡；已有参考直接保留核心设计。视角由身份与后续动作需要决定，不为每个主体补固定四视图。

场景图先写空间拓扑：入口、通道、平台、设备、地标与关键动作区域，再写主光方向、明暗层次、材料和介质。用门、扶手、设备或已知物体提供尺寸参照；空环境图不必为尺度硬塞人物。必要时补能回答具体空间疑问的角度，不强制每个场景四面齐全。深黑位不能吞掉必须看清的接口，也不把浅景深当成所有场景的固定要求。

关键道具写清整体尺寸关系、支撑/连接、开口与可操作部件，区分稳定结构和当前开合/损坏状态。进入舱口、抓握、装配等动作沿用[动作接口与接触要求](action-direction.md)，不让后续模型补出参考中没有依据的踏板、门或手柄。设计图可表达虚构机制，但不冒充真实工程性能证据。

例如舱内环境图可写：单人可通行的检修走廊，两侧设备柜与连续扶手给出尺度，顶灯照亮通道和检修接口；钛色金属、暗色橡胶密封件和织物束带反光不同，磨损只集中在把手与接触边缘，远端气密门位置清楚。这个例子不要求全部深空场景都采用旧舱或同一色调。

## 参考图进入视频

先根据本镜的风格、身份和构图控制需要选模式，再落实实际输入。需要图片约束时，在创作阶段安排可用的图片输入模式；不能一边选无图片的 T2V，一边声称模型已经受到该图纠偏。

| 生产方式 | 风格依据怎样进入实际输入 |
| --- | --- |
| I2V | 用采用的人物/环境/必要道具图制作或复用一张当前构图的首帧，检查其已继承美术规则；H3 只收到该首帧，不能把多视图角色卡当成完整开场 |
| FL2V | 实际首尾帧都符合相同媒介与关键设计，状态与运动路径相容；真实接力仍使用已接受视频的实际尾帧 |
| 普通 R2V | 把当前镜头不可替代的风格/身份/空间图绑定实际参考槽，说明各图保留项、不沿用的临时状态与冲突取舍，不盲目叠加相似图 |
| 分镜板 R2V | 将必要参考落实到一张符合已定布局和画风的整板并查看实际图；H3 默认收到整板，制板时用过的角色卡不会自动成为额外视频输入 |
| T2V | 只使用具体文本美术规则；图片可供创作者判断，但不算视频模型的输入，不宣称与有图控制具有相同依据 |

图片后端的参考数量、图号与编辑方式按当前能力核实。只挂 `related` 资料边、仅把路径写在文本里或只生成了上游卡，都不足以证明视觉要求已进入当前视频输入。具体素材、版本与用途写入现有资产记录和[单 Panel 交接](panel-execution.md)，不新建状态系统。

发现 H3 明显偏离时，先核对实际冻结输入、参考用途和首帧/整板本身；参考已经偏离则修图，参考正确而视频偏离则在原采用图基础上修正当前镜头的提示词或控制方案。先保留正确设计，相关修改只影响有关镜头及依赖；参考图能帮助纠偏，不承诺像素级复刻或自动消除全部视频偏差。
