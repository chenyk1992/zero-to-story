# 故事板与导演工作台

只在设计故事板、镜头与资产计划时读取。字段解释见[故事板结构](storyboard-brief.md)，流程与生产边界见 [SKILL.md](../SKILL.md)。

## 先做导演决定

先写观众要理解和感受的变化，再选择拍法。把决定写入已有的场景目的、表演、机位、运镜、声音与节奏字段，无需单独的导演报告或评分。

| 决定 | 落到镜头上的要求 |
| --- | --- |
| 信息与视点 | 写清观众和人物各自知道什么；本镜新增什么，关键结果如何被看懂 |
| 表演动机 | 人物想做什么，受到什么刺激，怎样回应；动作、视线和停顿服务这次变化 |
| 空间与动作 | 先安排人物、障碍和道具位置；关键过程写清起点、路径、接触与完成状态 |
| 视觉注意力 | 确定此刻应看说话者、听者反应、人物关系还是道具，再选景别和构图 |
| 摄影与声音 | 运镜写明对象、方向、触发点和结束构图；光色、环境声和音乐服务叙事 |
| 节奏与剪辑 | 用正常对白和表演判断时长，给理解与反应留空间；信息、视点或时间变化才切镜 |

这些是创作依据，不是每镜必填六项。固定镜头、静默、长镜头和切镜都可成立；专业程度取决于表达是否准确。不要堆“电影感”、微表情或复杂运镜来替代具体设计。

例如“她发现戒指不见了”：先让手指触到空出的戒痕，再让视线落向桌面，停顿后看向门口。若观众需要看清戒痕，就安排特写；若一镜已能看懂，就保留同一机位。时长给触摸、发现和反应，不为六个 Beat 凑六次切镜。

## 把设计变成 Panel

1. 从原文提取必需事件、逐字对白和人物/场景稳定锚点，先解决会改变剧情的冲突。
2. 按故事因果建立场景、节奏与 Camera Setup，再拆成 4–15 秒 Panel。一个 Setup 对应一个实际摄影镜头；计划内连续运镜不自动产生新 Setup。
3. 完整故事的 v2 蓝图保留每 Panel 六个语义 Beat。同一动作可以有准备、发展、理解和反应，勿补无意义动作。P002 起 Beat 1 为前段已完成状态的零时长上下文；新段从当前计划的有效动作推进。
4. 边界动作指定一次归属（`transition ownership`），防止相邻片段复演。硬切、换场或时间省略写明桥接，不为了尾帧接力牺牲叙事。
5. 最后选择生成控制方式和最少素材。字段与静态检查查[蓝图](creative-blueprint.md)，实际生成资产时才读[视觉资产](creative-assets.md)。

## 选择控制方式

| 当前镜头需要 | operation | 注意 |
| --- | --- | --- |
| 从文字建立画面，无媒体约束 | T2VA | 使用必要的稳定文本锚点 |
| 精确开场构图 | I2VA | 只用一个首帧；连续接力可用前段接受后的真实尾帧 |
| 精确首尾构图与连续路径 | FL2VA | 提供两帧，动作须能从首帧自然到达尾帧 |
| 多参考或按参考设计新机位 | R2V | 普通参考或分镜板均可，不承诺像素级首帧锁 |

首镜要反打或换机位时，不能同时要求它严格复用另一构图的旧尾帧。可以用匹配新机位的关键帧或明确的参考方式；保留旧尾帧时，先承接旧构图，再在批准的切点换镜。

分镜板采用与目标成片一致的电影画面风格，视觉与资产检查按[分镜板视觉标准](creative-assets.md#分镜板视觉标准)执行。R2V 采用 `storyboard_board` 时，在计划中锁定 `rowsxcolumns` 的 2–6 格布局，一次生成整板，按从左到右、从上到下表达有新增信息的时刻。格子不是独立输入或 Shot。普通参考采用 `reference_assets` 时不强制生板。

专业参考：[NFTS 导演、摄影与剪辑](https://nfts.co.uk/sites/default/files/Course_Outline_Filmmaking_2022.pdf)、[ASC 机位与场面调度](https://theasc.com/article/shot-craft-where-do-you-put-the-camera/)、[BFI 反应镜头](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)。用于理解选择依据，不规定统一风格，也不要求每次创作打开。
