# 故事板与导演工作台

只在设计故事板、镜头与资产计划时读取。字段解释见[故事板结构](storyboard-brief.md)，流程与生产边界见 [SKILL.md](../SKILL.md)。

## 先做导演决定

完整产品剧情广告由[广告入口](../../advertising-creator/SKILL.md)统筹，可按需复用本目录拍法，不使用影视全片契约。影视产品道具保留真实结构/状态，不因露出要求广告功效证明。反转读[通用方法](../../short-drama-screenwriter/references/reversal-design.md)，慢动作/冻结读[时间效果](time-effects-direction.md)，原影视主责不变。

先写观众要理解和感受的变化，再选择拍法。把决定写入已有的场景目的、表演、机位、运镜、声音与节奏字段，无需单独的导演报告或评分。

| 决定 | 落到镜头上的要求 |
| --- | --- |
| 信息与视点 | 写清观众和人物各自知道什么；本镜新增什么，关键结果如何被看懂 |
| 表演动机 | 人物想做什么，受到什么刺激，怎样回应；动作、视线和停顿服务这次变化 |
| 空间与动作 | 先安排人物、障碍和道具位置；关键过程写清起点、路径、接触与完成状态 |
| 视觉注意力 | 确定此刻应看说话者、听者反应、人物关系还是道具，再选景别和构图 |
| 摄影与声音 | 运镜写明对象、方向、触发点和结束构图；光色、环境声和音乐服务叙事 |
| 节奏与剪辑 | 用正常对白和表演判断时长，给理解与反应留空间；信息、视点或时间变化才切镜 |

这些是创作依据，不是每镜必填六项。固定镜头、静默、长镜头和切镜都可成立；专业程度取决于表达是否准确。不要堆“电影感”、微表情或复杂运镜来替代具体设计。

需要细化镜头画面时，先确定观众必须看清的动作，再选能解释空间关系的机位。光照意图说明光源照到哪里、关键人物或道具如何被看见；材质反光随光源变化，湿润和磨损要有剧情或环境依据。次要区域可自然退入暗部，但不能遮住关键证据。人物或摄影机移动后，受光、遮挡和焦点按已定动作发展，不要求每帧保持同一构图。角色卡、产品展示及非写实媒介按各自用途保持必要的清晰度和画面语言。

例如"她发现戒指不见了"：先让手指触到空出的戒痕，再让视线落向桌面，停顿后看向门口。若观众需要看清戒痕，就安排特写；若一镜已能看懂，就保留同一机位。时长给触摸、发现和反应，不为六个 Beat 凑六次切镜。

## 局部改拍

用户只改景别、视点、表演强调或运镜时，先读当前创作源，取目标 Panel 的源版本、关键可见证据、逐字对白及前后状态。已有 coverage 时取对应条目；只有单 Panel 分镜或提示词时沿用其已定事实，不要求补全章。将“更紧张”“换成她的视点”写成具体拍法：观众从谁的视点获得什么信息，注意力落在哪个动作，再据此调整机位、视线、表演、运镜与 reason。人物小传中的秘密若本镜尚未揭示，不因换视点提前拍成事实。

在现有创作源中修订目标内容；已有蓝图时同步受影响的 coverage、`panels`、`generation.shots` 与 `generation.panel_plans`，单 Panel 交付不新建全章蓝图。只换拍法时保留原事件、场景、Panel、Setup ID 与 `source_refs`；确实新增或拆出摄影镜头时才新增 Setup，并调整已有 Beat、对白归属和覆盖落点。交付用一小段话说明“改哪里、为什么、保留什么、影响哪些输入”。

| 改动 | 需要同步的范围 |
| --- | --- |
| 只换取景、景别或注意力 | 当前 Setup 的构图、轴线/视线和关键可见证据；核对原参考是否仍能承担新构图 |
| 改动作、对白呈现、切点或起止状态 | 当前 Beat/Setup、对白归属、边界与声音责任；只追查使用这些状态的相邻镜头和真实依赖 |
| 改事件、角色关系或信息揭示 | 回到当前授权范围内的改编决定与 coverage，更新对应场景及落点，再决定拍法 |

例如 S001/P003/C003 原为甲桌左、乙桌右的双人中景。甲说“这封信，你昨天看过吗？”，乙看见桌上信封已开口，收住伸向信封的手再抬眼；P004 才回答“没有。”。用户只要 P003 贴近乙的视点：可以改成乙侧后方的中近景，把开口与收住的手留在前景、甲留在乙的视线方向，让观众看懂乙的发现与停顿。保持原 8 秒、事件与 Setup ID、逐字对白和信封已放妥的状态；只拍脸会裁掉关键证据。这是贴近人物的叙事视点；用户明确要求眼睛所见的严格主观镜头时，按该要求设计。P002 不重演放信封，P004 的回答不提前。

新机位的参考在当前资产计划中按用途选择；R2V 普通参考不承诺精确构图，I2V/FL2V 的精确首帧须与新开场构图一致。摄影描述表达创作意图，预演工具的姿态、轨迹或精确机位参数不属于 [H3 控制能力](../../h3-prompt-writing/references/control-boundaries.md)。

修订交给[单 Panel 交接](panel-execution.md)，保存仍是草稿。生成修订版时，按共享规则核对已有授权是否覆盖新输入，并确认新的 Canvas 快照。替换实际片段后，按[替换片段后的接缝](video-qc.md#替换片段后的接缝)检查新版末态、前后关系和尾帧来源；只在真实依赖失效时修正受影响的后段，保留其他片段。

## 类型节奏模式

拆 Panel 前先按项目意图声明节奏策略（写入故事板项目信息与[全章节奏图](storyboard-brief.md#节奏图与-camera-setup)）。以下模式提供常规参考；自然观察、环境空镜或已确认的持续压迫段按其表达安排注意力与时长，不强加冲突、高潮或释放。不同段落采用不同节奏时写明用途与衔接，连续性、对白和验收契约不变。

### 连贯叙事模式（默认）

适用影视剧情短片与叙事预告片，独立宣发广告走advertising-creator；歌曲驱动的 MV 由 [music-video-creator](../../music-video-creator/SKILL.md) 规划。时长由正常对白和表演决定；只有新信息、空间、视点、时间或人物反应出现时才切镜；长镜头与静默可以成立。

### 情景喜剧模式

明确的情景喜剧、喜剧小品或以误会/人物关系推动的喜剧段落，先按[情景喜剧导演](sitcom-direction.md)组织铺垫、升级、落点与反应空间，不因分集交付套用下面的冲突短剧模式。保留剧本已定的笑点因果、潜台词和必要停顿；按信息安排主镜、双人镜、反打与反应，不强制每句切镜、付费钩子或“直白扎心”。画幅沿用用户规格，横屏可保留双人关系和空间地理，竖屏再按其安全区适配。不同段落可采用不同策略，写明依据，不按“喜剧”标签覆盖用户已确定的拍法。

### 短剧 / 漫剧模式

适用已选冲突驱动节奏的短剧或漫剧；分集交付本身不决定竖屏、付费钩子或该节奏模式，情景喜剧优先走上面的分支，其他章节按项目意图选择。沿用已确认剧本的场景数、事件顺序和结局；尚未确定的节奏可参考以下方法，不借分镜阶段改写已定内容：

- **核心冲突与场景**：围绕本集核心冲突安排建立、升级、转折与余波；场景转换服务因果，不把已确认的多场戏压成一场，也不把整章预告式压进一集。
- **开场吸引力**：需要快节奏入口时，可在开头数秒以动作、关键台词或既成冲突切入；已确认的安静建立或其他开场按原意执行。
- **结尾与集际关系**：连载需要钩子时，在拆 Panel 前确定未解问题或下一步冲突。独立单集、完结集或已确认的完整结局按本集收束，不强行延期解决或添加下集预告。
- **时长服从内容与规格**：按已确认片长容纳必要冲突、表演与结尾，不以平台均值或固定钩子决定时长。装不下时在创作阶段说明取舍，不让分镜或生成阶段静默删场、赶台词或改结局。
- **松弛有度**：常规冲突短剧可用压力升降帮助理解，高压拍后按表演需要留反应或余韵。2–4 秒反应、15–25 秒压力变化只是未定节奏时的参考，不是定额；已确认的持续压迫、静默或观察段按原意保留，必要信息和正常对白仍须装得下。
- **竖屏构图（仅已选竖屏规格）**：主体与关键动作保持在画面中央安全区，避开上下平台 UI 遮挡带；常规冲突镜头可偏中近景和近景，空间建立、走位与群体关系按实际信息选全景，不因分集交付缩掉必要证据。横屏按其构图与人物空间关系设计。
- **改编与集际结构**：多集改编的拆分原则、集际状态链与钩子链见[剧本与改编层](script-adaptation.md)。

节奏图沿用相同字段；“压力曲线”可记录上升、保持、释放、停顿或注意力变化，并说明表达目的，不为填表添加转折或停顿。

## 把设计变成 Panel

1. 从原文提取必需事件、逐字对白和人物/场景稳定锚点，先解决会改变剧情的冲突。钩子区内本集实际发生的结尾动作和揭示也进入覆盖矩阵；宣传文案、付费提示和下一集尚未发生的预告不自动进入本集镜头。
2. 按故事因果建立场景、节奏与 Camera Setup，再拆成 4–15 秒 Panel。一个 Setup 对应一个实际摄影镜头；计划内连续运镜不自动产生新 Setup。
3. 完整故事的 v2 蓝图保留每 Panel 六个语义 Beat。同一动作可以有准备、发展、理解和反应，勿补无意义动作。P002 起 Beat 1 为前段已完成状态的零时长上下文；新段从当前计划的有效动作推进。
4. 边界动作指定一次归属（`transition ownership`），防止相邻片段复演。硬切、换场或时间省略写明桥接，不为了尾帧接力牺牲叙事。
5. 最后选择生成控制方式和最少素材。字段与静态检查查[蓝图](creative-blueprint.md)，实际生成资产时才读[视觉资产](creative-assets.md)。

## 连续场景的分段

先设计整场动作、对白与声音，再拆 4–15 秒 Panel；可完整容纳的动作优先在一段，不为用满上限赶台词或牺牲句尾。超限在动作完成、反应成立或自然停顿处划分。必要的短暂完成姿态计入已定 Panel 时长，不增加生成余量后裁切，不强制定格或静音。目标总时长等于 Panel 合计，Canvas 与 Panel 一致，不自动变速凑时长。

| 边界关系 | 分段与承接方式 |
| --- | --- |
| 同机位、同一动作链续演 | 在可辨认的完成状态结束；下段从实际采用末态推进，不重新演已完成动作。需要精确开场时依当前能力绑定真实尾帧 |
| 同场换机位或反打 | 新构图仍继承实际人物位置、朝向/视线、动作进度、道具归属与光线；按新机位准备参考，不强锁不同构图的旧尾帧 |
| 换场或时间省略 | 交代对剧情重要的离开、物品转移或时间变化；用有依据的画面/声音桥接，不要求不同场景像素连续 |

三个常见边界可以这样写入已有的转场、声音策略和连续性说明：

- **同机位续演：** P014 已拍到甲把信封放到桌上，手离开信封后停住；P015 从“信封留在桌上、甲的手已空闲”继续甲抬头说话。只有当前段确实需要精确开场时，才按能力把 P014 已 `ACCEPT` 的真实尾帧绑定为输入；P015 不重演放下动作。
- **同场反打：** P014 结束时甲在画面左侧面对乙，信封仍在桌上。P015 切到乙的反应近景，保留两人的相对位置、乙的视线方向、桌上信封和光线事实，但为新构图准备合适的参考。旧构图的尾帧不能同时被说成这个反打镜头的精确首帧。
- **换场声音先入：** 办公室内的交谈结束后，门外脚步声可以先进入，再切到走廊门口。交接要写清脚步声来自仍在使用的源片，或由已确认的后期时间线添加；只写了声音桥并不表示生成素材已经含有连续脚步声。

每个边界的画面与声音切点分别决定，二者不必同时结束：

- **对白与表演**：尽量让完整语句、反应和必要停顿由一段承担；连续语句跨画面切点时，明确声音由哪个源片持有，并由已具备的后期链路连续保留。不能让相邻生成各补半句来碰运气，也不能重复台词、截断词音或让下段重置说话者和情绪。
- **环境声与音效**：决定同场持续、换场切换或延续到下一镜；一次动作音效只归属一次。图片尾帧不携带声音，不能据此假定底噪、混响和音效尾声会自动连续。
- **BGM**：按场景或情绪段规划起点、延续、退出和对白避让，不随 Panel 从头播放。需要跨段连续的配乐优先由已启用的后期在整场时间线上处理；若由生成提供，须检查实际音乐能否衔接。音乐乐句/节拍可辅助选切点，不能凌驾于有效对白和关键动作；有意硬切或静默要写明。

音乐由生成还是后期承担须在交接时确定；后期加配乐前核实源音轨是否已有音乐，避免未经设计的双层配乐。源音乐与有效对白混在一起且无法可靠分离时，保留声音并说明限制，不能直接静音整条源轨。关键物品转移或动作结果也承载剧情信息：省略过程后，观众仍须能理解发生了什么，而不只是看见外观相近的下一镜。

需要新配乐时，只复用[音乐方向的锁定画面分支](../../music-video-creator/references/music-direction.md#锁定画面配乐)，由本故事流程保留画面、对白与动作时点。选择性保留原声或对白窗口避让的能力边界见[声音方案与实际能力](../../music-video-creator/references/finishing-and-review.md#声音方案与实际能力)；只有整轨 mix/replace 不能证明这些要求已完成。

将边界理由、动作归属、声音归属及续接/淡出/硬切方式写入已有的“转场 / 承接说明”“声音策略”和连续性账本，不新增必填数据格式。比如“物品放入抽屉→手离把手→抬头说话”：可在手离开后分段；下段保持物品已放妥，环境声继续，配乐按同一乐句推进，而不是重新摆回物品并重起音乐。

真实依赖前段的镜头可以先准备文本和独立资产，生成须等待前段实际采用状态；不能把依赖改写成“普通场景参考、无尾帧”来提前生产。角色参考负责身份，末态参考负责此刻状态，按当前模式能力安排两者；所需身份或精确开场约束无法同时满足时，调整分段/机位或说明能力缺口，不静默丢约束。

## 选择控制方式

| 当前镜头需要 | operation | 注意 |
| --- | --- | --- |
| 从文字建立画面，无媒体约束 | T2VA | 使用必要的稳定文本锚点 |
| 精确开场构图 | I2VA | 只用一个首帧；连续接力可用前段接受后的真实尾帧 |
| 精确首尾构图与连续路径 | FL2VA | 提供两帧，动作须能从首帧自然到达尾帧 |
| 多参考或按参考设计新机位 | R2V | 普通参考或分镜板均可，不承诺像素级首帧锁 |

连续接力按所需约束选最少输入：仍需人物身份或声音参考时，优先考虑当前本地 Comfy 已支持的 R2V 加可选首帧引导；将前段已接受的真实尾帧接入 `first_frame`，人物与声音保留各自参考槽。只需延续画面、首帧已足以交代主体且不需额外人物或声音参考时，可选 I2VA；简单场景不必为了接续强用多参考。需要同时指定起点和终点时保留 FL2VA，不把 R2V 当作所有模式的替代。

R2V 的普通图片参考只提供状态/外观依据，不能代替首帧引导。首帧引导也不承诺像素硬复制；按实际接缝验收，不因一次成功就将所有后续镜头批量换模式。要从旧构图接续，就先保留开场，再按设计运镜或切换景别；不要同时要求第 0 帧保持旧画面和立即换新构图。具体素材绑定见[单 Panel 交接](panel-execution.md)。

选择简单 I2VA 前还要核对后续取景：若运镜将露出首帧未包含、但连续性重要的人物或道具，首帧未必足够。应补充已核实的状态参考并考虑 R2V 首帧引导，或调整构图；不能让模型自行补出关键区域后默认采用。

首镜要反打或换机位时，不能同时要求它严格复用另一构图的旧尾帧。可以用匹配新机位的关键帧或明确的参考方式；保留旧尾帧时，先承接旧构图，再在批准的切点换镜。

分镜板沿用已定的目标成片媒介和画风，视觉与资产检查按[分镜板视觉标准](creative-assets.md#分镜板视觉标准)执行。R2V 采用 `storyboard_board` 时，在计划中锁定 `rowsxcolumns` 的 2–6 格布局，一次生成整板，按从左到右、从上到下表达有新增信息的时刻。格子不是独立输入或 Shot。普通参考采用 `reference_assets` 时不强制生板。

专业参考：[NFTS 导演、摄影与剪辑](https://nfts.co.uk/sites/default/files/Course_Outline_Filmmaking_2022.pdf)、[ASC 机位与场面调度](https://theasc.com/article/shot-craft-where-do-you-put-the-camera/)、[BFI 反应镜头](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)。用于理解选择依据，不规定统一风格，也不要求每次创作打开。
