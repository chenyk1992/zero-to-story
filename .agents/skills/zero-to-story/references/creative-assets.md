## 角色设定图

### 目标

为每个需要视频身份一致性的主要角色制作独立角色卡。角色卡负责身份、体型、发型、服饰和关键道具，不承担剧情构图。

从已批准的 `storyboard_brief.md` 逐字提取角色身份锚点。不要混入人物小传、剧情秘密或镜头安排。

### 提示词模板

使用 [单角色设定图 Prompt 模板](../assets/character_card_prompt.template.md)。只替换占位字段，不在 reference 和项目文档中复制维护另一版模板。

### 角色卡检查

- 只有一个角色身份，没有混入另一个角色或不同年龄版本。
- 头肩近景与三视图的脸型、发型、体型、服饰和道具一致。
- 全身完整，双脚未裁切；正、侧、背方向清楚。
- 没有文字、标签、编号、UI、水印或额外道具。
- 媒介与 Medium Lock 一致，不是照片、海报或无关画风。

任何一项失败就重做该角色卡，不要把错误身份资产带入下游视频生成。

## 人物与场景文本锚点

`storyboard_brief.md` 中的文本锚点是跨模式复用的最小视觉描述，不是每个镜头重新发挥的提示词。人物文本锚点只包含稳定的年龄段、脸型、发型、体型、服装主色和标志性道具；场景文本锚点只包含稳定的空间结构、材质、主色、光源、时间天气和辨识物。雨湿、尘土、伤势、手持物等随剧情变化的状态放在连续性账本。

- T2V 没有视觉首帧时，必须把当前镜头真正可见的人物/场景文本锚点写入提示词；一次性空镜只需要场景锚点。
- I2V 以已确认首帧为主要身份和环境参照，只补充首帧无法表达的稳定约束，不引入与首帧冲突的第二套描述。
- 反复出现且空间布局重要的场景，按需生成并确认一张彩色场景关键帧，供新场景 I2V 或必要的 R2V 使用；一次性空镜不强制创建场景卡。
- 不要把完整角色卡、完整分镜板和场景关键帧无条件同时塞给每个视频模式；每份参考必须有明确的身份、环境、构图或运动用途。

## 2×3 六格分镜板工作法

### 一板一次生成

每个 Panel 只调用一次图片生成，直接得到一张完整的黑白分镜板。不要默认拆成六张图片，不要裁格或调用拼板脚本。

每张分镜板恰好包含 2 行 × 3 列共 6 个完全等大的画格，阅读顺序为：

```text
┌────────┬────────┬────────┐
│ Beat 1 │ Beat 2 │ Beat 3 │
├────────┼────────┼────────┤
│ Beat 4 │ Beat 5 │ Beat 6 │
└────────┴────────┴────────┘
```

P001 对应 Beat 01–06。P002 起左上格复用上一板右下格的已完成状态，作为新 Clip 的零时长边界锚点；其余五格是当前 Panel 的新 Beat。每个 Beat 必须标注所属 Camera Setup；同一 Setup 的相邻 Beat 是同一长镜头内的不同可见时刻，不是额外的剪辑镜头。只有 Setup 改变且带来新的观看信息时才产生 cut。

### 生成前输入

一次整板生成只需要：

1. 已确认的 `Medium Lock` 和 `Style Brief`。
2. 当前 Panel 映射的 6 个 Beat、所属 Camera Setup、画面关系及其初态、动作和锁定末态；若为 P002 起，左上格只提供已完成状态，不提供动作、节拍、台词或时长。
3. 本 Panel 出场角色的已确认角色设定图。
4. 需要严格锁定场景布局时的已确认彩色场景关键帧（按需）。
5. 从 P002 起，上一张已确认分镜板，用于让左上格承接上一板右下格。

角色设定图只提供身份和最小轮廓参考，不应把分镜板画成精致角色概念图。场景关键帧只提供已批准的布局、光线和材质锚点。上一板只提供连续性参考，不应被整体复制到新板。

### 画布选择

选择图片模型原生支持且下游视频工作流可接收的整板画幅，宽高比保持在 0.4–2.5。优先使用 16:9、3:2、4:3、1:1 或 4:5 等常见画幅，不为了让每个格子获得精确像素画幅而增加后处理。

每格按目标成片画幅的构图意识安排主体和安全区即可；整板的任务是传达 Beat 顺序、空间、动作、Setup 关系与切镜理由，不是六张成片关键帧的机械拼接。相邻格若属于同一 Setup，保持摄影机位置、观看方向、轴线侧和人物相对画面位置稳定，只推进动作或可见状态。

## 整板直出图片提示词

使用 [2×3 六格黑白分镜板 Prompt 模板](../assets/storyboard_board_prompt.template.md)，只保留当前 Panel 实际出现的角色和场景。不要把音频说明、完整台词、视频时间戳或动态过程指令塞进图片提示词；分镜图只负责六个静态 Beat/可见时刻，并用 Setup 标记表达哪些格属于同一长镜头。

## 跨镜头与跨板连续性

为每个 Beat 的初态和末态维护状态账本；为每个 Camera Setup 另维护机位关系：

| 项目 | 必须记录 |
|---|---|
| 人物 | 左/中/右，前/中/远景，朝向，姿势，视线 |
| 双手 | 左右手分别空闲、持物、接触或遮挡什么 |
| 道具 | 数量、所有者、位置、连接状态、是否可见 |
| 场景 | 门窗开合、灯光状态、天气、背景人物数量 |
| 镜头 / Setup | 轴线哪一侧、景别、机位高度、摄影机所在位置与朝向、下镜是否切轴 |
| 画面关系 | 人物在画面中的位置与朝向、面对的目标、视线落点、屏幕运动方向、与前格是同镜继续还是 cut |

让相邻 Beat 的锁定末态成为下一 Beat 的初始状态；同一 Setup 内的相邻 Beat 不改变机位、轴线或人物面对关系，只推进动作或状态。发生交接时按“接近 → 接触 → 双方共同持有 → 原持有者释放 → 新持有者收稳”分配到相邻 Beat，避免道具瞬移。跨 Panel 时先登记 `transition ownership`：共享边界动作只能归前段或后段，后一段的边界锚点只保留完成后的状态，首个有效新 Beat 必须立即推进，不能倒带、重置或重演。

从 P002 开始，把上一张已确认分镜板作为图片参考，并在文字中明确指定“上一板右下格 → 新板左上格”。直接生成整板时不要求像素级复制，但景别、构图、人物站位、朝向、手部、道具与已完成末态必须目视一致；不要把边界动作画成正在发生。

跨 Panel 生成方式按镜头关系选择：同场连续接力优先 I2VA，以上一段真实尾帧锁定当前段首帧；只有同时需要精确首帧和尾帧才用 FL2VA；多参考或明确硬切才用 R2V。R2V 只使用 `placement: "fixed"` 与明确的 `ref_image_N`、`ref_video_N` 或 `ref_audio_N` 槽位；参考图只约束身份/构图/风格，不是精确首帧锁。

## 视觉质量检查与重做

每张整板生成后检查：

- 恰好 2 行 × 3 列、6 个等大格；没有标题区、额外格、并格、跨格或错行。
- 六格与 Panel Beat 映射一致，没有漏 Beat、换序或错误重复；每格的 Camera Setup 标注完整。
- 每格只表达一个可见变化或表演时刻，人物与场景空间关系可读；P002 起左上格仅为静态边界锚点。
- 同一 Setup 的相邻格保持摄影机位置、观看方向、轴线侧、景别和人物相对画面位置连续，只推进动作或状态；发生 cut 的格间必须有新的信息或视点理由。
- 每个有空间叙事作用的 Beat 都能回答：摄影机在哪里、朝哪里看；人物位于何处、面向谁；视线目标和落点是什么；人物或摄影机沿哪个屏幕方向运动；没有把追赶、对视或接触拍成相反关系。
- 相邻格的人物位置、朝向、轴线、手部和道具状态连续。
- P002 起左上格承接上一板右下格的已完成状态，后五格立即继续新 Beat，不复演边界动作。
- R2V 的参考素材均为 typed fixed slot，且不把普通参考图描述成精确首帧锁。
- 黑白灰粗略线稿成立；没有彩色、写实渲染、精致角色卡或完成漫画风格。
- 角色最小轮廓提示一致，没有年龄、体型、发型、身份或人物数量漂移。
- 无可读文字、伪文字、数字、标签、UI、水印、对白气泡或箭头。

任一关键项失败，就修正当前 Panel 的整板提示词并重新生成这一张完整分镜板。不要自动拆成六次生成，也不要引入裁切或拼板脚本。当前板通过并经用户确认后，再生成下一板。

## 运镜词汇与摄影动作词典

> 黑白分镜的每格只是关键帧。本词典用于故事板阶段统一景别、机位和运动方向，让后续制作可以无歧义读取导演意图。

### 运镜

| 词汇 | 含义 | 适用场景 |
|---|---|---|
| `固定` / `fixed` | 摄影机不动 | 静态人物对话、关键帧建立空间 |
| `handheld shake` | 手持微晃 | 真实感、纪实、紧迫、跟拍人物 |
| `dolly in` / `dolly out` | 推/拉（移动机位） | 逼近主体或拉远建立空间，景别变化 |
| `push-in` / `pull-out` | 跟推/跟拉 | 跟主体运动中同步推近/拉远 |
| `truck left` / `truck right` | 水平平移 | 跟主体侧向移动、扫视环境 |
| `pan left` / `pan right` | 水平摇（原地转） | 揭示空间、展示全景、不动人物 |
| `tilt up` / `tilt down` | 俯仰 | 揭示高度、强调细节 |
| `pedestal up` / `pedestal down` | 整体升降 | 改变视平线 |
| `zoom in` / `zoom out` | 变焦 | 不移动机位，靠镜头焦距拉近/拉远（廉价感慎用） |
| `crane up` / `crane down` | 摇臂 | 大范围上升下降（开场/收尾常用） |
| `环绕` | 围绕主体旋转 | **必须写明**：`truck left + pan right` 或反之；不要直接写"环绕" |
| `tracking shot` | 跟拍 | 必须补方向：`truck right + handheld shake` |

### 景别

| 词汇 | 范围 | 用途 |
|---|---|---|
| `extreme close-up`（极特写） | 眼睛、手、道具细节 | 强调情绪或关键物件 |
| `close-up`（特写） | 脸、头部 | 情绪反应、对话 |
| `medium close-up`（中近景） | 头肩到胸 | 人物对话、反应 |
| `medium shot`（中景） | 膝盖以上 | 动作 + 表情 |
| `full shot`（全景） | 全身 | 人物与场景关系 |
| `wide shot`（远景） | 全身 + 大场景 | 建立空间、群戏 |
| `establishing shot`（建立镜头） | 远景+标志物 | 项目开场、场景切换 |

### 切镜风格

| 词汇 | 含义 |
|---|---|
| `cut` | 普通硬切（默认） |
| `fade` / `dissolve` | 叠化视觉意图（仅由单个 Clip 或已批准派生素材实现） |
| `rhythmic cut` | 随节奏卡点切镜（与 BGM/MV 场景） |
| `jump cut` | 快切（同主体不同时间） |
| `match cut` | 动作/构图匹配切镜（连续性高级用法） |

### 用法约定

- 故事板 Camera Setup 行的"运镜"列：必须用本表词汇，**不要用"跟拍""推进"等泛词作为唯一描述**。
- 黑白分镜图本身不需要写出运镜词，但分镜构图要符合运镜逻辑（如 `dolly in` 对应人物占据画面越来越大）。
- 跨 Panel 末态承接时，写清运镜方向（"上镜结束在 `tilt up` 末态"），下 Panel 第一镜的运镜要能合理接续。
- 当前 LFO final assembly 只执行 `cut`；`match cut` 仍是剪辑关系并以一次 cut 落地，不在 `output.transitions` 写 `fade`、`dissolve` 或音频桥接。若需要淡化、黑场或声音桥接，必须由单个 Clip 完整持有，或先制作并确认派生素材。
