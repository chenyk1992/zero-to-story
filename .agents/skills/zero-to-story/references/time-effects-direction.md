# 时间效果导演

广告与叙事MV同样只复用方法，主责不转移。先区分正常速度基准、慢动作对象、冻结对象和可动对象，记录触发/环绕/恢复窗口及声音；参考背面未知不自动补结构。

用于当前故事或已确定 Panel 的慢动作、时间冻结、环绕与恢复。项目方法涵盖 bullet-time-slow-motion-video；其他 MG、Presenter、B-roll、MV 主流程可按需读取本方法，但不因此改变制作主责。只改提示词时由 H3 消费已有导演事实，已有视频的确定性变速另核实真实工具。

## 先区分效果

| 意图 | 必须明确的事实 |
| --- | --- |
| 主体慢动作 | 哪个动作变慢、其他对象怎样运动、观众要看清什么 |
| 世界冻结、摄影机移动 | 哪些对象保持世界空间中的姿态，摄影机如何绕行及恢复点 |
| 选择性冻结 | 允许运动的对象与已建立的世界规则；不能同时要求同一液滴固定又落下 |
| 生成中的速度变化 | 作为画面意图描述起止与动作阶段，不承诺精确速度曲线 |
| 已有媒体确定性重定时 | 先核实变速、音频和字幕同步工具；当前 timeline / speech edit 不是通用 retime 引擎 |

H3 当前没有任意速度曲线、精确摄影轨迹、骨骼控制或逐帧冻结通道。能够写进提示词不表示能保证执行；无法满足的精确控制要报告缺口，不新增虚构参数。

## 写进现有导演字段

在当前 Setup 的时间窗、目的、运镜、主动作和起止状态，以及相关 Beat/声音备注中记录必要事实：触发时刻；Panel 内画面窗口；冻结与可动对象；姿态、支撑、接触、道具归属及相关粒子；环绕主体、方向、范围和起止构图；该移动新增什么信息；恢复动作从何状态继续；声音由生成或后期负责什么。不建立另一套状态表。

连续环绕仍是同一 Setup，实际切镜才新增 Setup。对象冻结在世界空间不等于锁定屏幕坐标：摄影机移动可改变透视、遮挡、反射和受光观感，不能要求画面投影也完全不变。恢复沿冻结前动作接续，不瞬移、换手、复制物件或重演已完成动作。

例如已规划的12秒Panel用0–3秒动作、3–7秒冻结环绕、7–12秒恢复，三段仍合计12秒，不推导世界时间或另加倍速时长。影视1秒Setup放在自身4～15秒Panel内；广告短Panel按实际0.2～15秒能力与可读性设计，不把影视下限当全局限制。

## 素材和信息边界

按当前控制需要选 T2VA、I2VA、FL2VA 或 Ref2VA，并复用现有身份/动作/空间参考。新建角色遵守[完整设定图](../assets/character_card_prompt.template.md)规格，不因时间效果删减三视图/半身变化，也不为每次环绕重做角色图。环绕要显露参考不可见的细节或产品结构时，只补必要证据或说明未知，不强制产品三视图或四格板。参考组合仍遵守实际紧凑槽位与所选模式，普通 R2V 的前缀引导默认关闭。

冻结姿态继承触发瞬间的动作、相关支撑与接触；腾空或液滴悬停可按已定时间规则成立，不强加落地或支撑面，也不凭冻结改写持物关系。静态板只表达选定时刻，不能证明实际冻结或环绕。隐藏身份、产品机关或伏笔按[通用反转](../../short-drama-screenwriter/references/reversal-design.md)维护导演真相与观众获知时间：模型可用身份参考不等于观众提前看见，环绕也不能无意揭露尚未到时的证据。

受控复刻沿用[变更边界](../../video-deconstruct-analyzer/references/recreation-change-plan.md)，保持锁定时点；未允许加入冻结时不擅自改写原节奏。

## 声音与预算

可见嘴部冻结与正常同步说话冲突。已定画外音可以继续，但不能自动把锁定口型对白改成 VO；按当前故事决定可动嘴部、停顿或调整窗口，锁定项冲突则说明。没有声音需求不附加音色、配乐或字幕。Music 3 不承担拟音，整轨混音也不意味着已具备任意局部 ducking。

MV 保持已采用主音轨与同窗口声源；可见演唱仍按实际 R2V 音频槽位绑定。冻结嘴部与持续演唱冲突必须在提示词前解决，不能借冻结重排锁定音乐时间轴。

效果、反应、恢复及必要停顿都在 Panel 原预算内；时长不足回到当前计划处理，不额外生成后裁切或自动变速凑时长。喜剧反应和冻结读图窗口在现有后期备注中声明保护用途，不能按“没说话”删除；当前 speech edit 不会自动识别所有视觉保护窗口，工具无法保留时不对该区间执行删除。

## 提示词与实际采用

交 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md)把已定事实写入已有英文描述字段，不新增 speed_curve、freeze_mask、negative 或提供方参数。关键验收依据是实际对象运动、接触与数量、环绕所揭示的信息、恢复接缝及有关声音，不凭静帧或模型描述通过。
