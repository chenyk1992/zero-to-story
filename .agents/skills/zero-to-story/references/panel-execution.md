# 单 Panel 交接

只在当前 Panel 已确定、要写提示词或进入 Canvas 时读取。授权、串行执行和失败处理统一遵守[共享规则](../../../../guides/ai-system-prompt.md)。

## 交给 H3

给 [h3-prompt-writing](../../h3-prompt-writing/SKILL.md) 当前 Panel 的必要事实，不预写另一份 H3 草稿：

- Panel ID、源版本、精确时长、画幅、画风与节奏意图。
- operation、Camera Setup 及切点；各镜头的构图、动作起止、必要空间关系和声音。沿用故事板信息，不复制整章。
- 逐字对白、说话人、语言、画外音状态与时机；字幕和场景文字由谁制作。
- 实际素材、用途、`runtime_input_keys` 及槽位；使用分镜板时附布局、格子顺序映射及需要保持的人物与场景外观。
- 需要接力时附已完成边界状态与动作归属；明确硬切时附新场景/机位关系。

H3 Skill 负责格式、标签、时间和英文描述。缺必要事实时回到当前计划修正；不让提示词作者静默换模式、丢素材或改对白。提示词需改写时仍交 H3 Skill，不维护两份定稿。

## 保存 Canvas 输入

每个 Panel 一个 `video` 节点，保存完整提示词、素材、模式、参数及内容要求。节点内容来自上述交接；采样参数放配置，不塞入提示词。

`megapixels`、`sampler_profile`、`steps` 从故事板/蓝图 `user_constraints` 继承，后续 Panel 不重问。用户变更时只改项目规格和受影响节点草稿，冻结请求保留原值。

| 模式 | 绑定 |
| --- | --- |
| T2VA | 无媒体 |
| I2VA | `first_frame` |
| FL2VA | `first_frame` 与 `last_frame` |
| R2V | 整张分镜板或已列出的 typed references，保留槽位 |

交给 [canvas-workspace](../../canvas-workspace/SKILL.md) 保存和确认。已有授权覆盖时直接推进；用户只要草稿或要求先审阅时停在保存。创作文件不写 ComfyUI 内部节点、素材 ID 或模型路径。

## 实际结果与下一步

~~~text
节点草稿 → 授权确认并冻结 → 服务按能力执行一次
→ 实际媒体回填 → 一次内容验收
→ 已接受且下游需要时提取真实尾帧 → 下一项 ready 工作
~~~

只有真实依赖前段时才等待其 `ACCEPT`；独立素材和提示词可先准备。服务处理 Comfy 视频，Agent 不重复启动 adapter。收到结果后才读取[视频验收](video-qc.md)；检查实际采用版本，片段后期纳入该版本结论。

拒绝、关键证据不足、执行失败或未知时，说明具体问题并暂停相关依赖。可逆草稿错误按报错修正；无新依据不反复修改。状态未知先核对原请求，新的生成必须按授权确认新快照。生产状态保存在 Canvas，不另建恢复文件或下游失效表。

用户要求完整视频时，用已接受输出做确定性后期并检查[最终成片](video-qc.md#最终成片)。更换片段只处理受影响的相邻接缝，不默认重做整章。
