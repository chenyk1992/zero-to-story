# 最小视频接受检查

通用判断和失败规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本文件仅在实际视频已返回、片段被替换或成片待交付时读取。每个实际版本一次必要验收，不给提示词形容词逐项打分。

## Panel 接受

读取当前 Panel 的关键要求、必要参考和实际采用版本，先正常观看连续运动，再核对有关声音。只检查会影响用途的项目：

| 内容 | 何时检查 |
| --- | --- |
| 可播放性、时长、规格、严重空帧/伪影 | 所有视频；已有可靠技术检查可复用 |
| 人物身份、关键动作的因果与完成状态、道具归属 | 叙事依赖这些事实时 |
| 对白原文与说话人、可懂度、句尾、明显音画错位 | 有对白、口播或关键声音要求时；无声视频记明无音频 |
| 实际末态 | 写清与本镜目的或下一镜有关的位置、姿态、接触/持物等；其余不逐项填表 |
| 相邻接缝 | 有连续性要求时看前段结尾到本段开头；硬切、换场和时间省略按创作意图判断 |
| 字幕和片段后期 | 当前采用版本包含这些处理时 |

涉及穿越、交接或书写等关键过程，必须看清变化如何发生，不能只靠单帧姿势判定成功。关键接触、遮挡或身份重现有疑点时，只加密查看该窗口，最多做一次局部复核。按动画、超现实或写实项目的既定规则判断；不把正常遮挡或剪辑误当物理错误。

满足关键用途记 `ACCEPT`；已确认错误妨碍用途记 `REJECT`；关键证据仍不足记 `INCONCLUSIVE`。分镜板用于核对关键外观、构图关系与动作状态，不要求视频逐格复刻或在每格对应时刻停顿。轻微五官细节、衣纹、光影、材质或构图差异不影响身份辨识、叙事和目标成片风格时，不触发返工。无需默认调用视频理解；需要时只取短观察，由调用方结合实际文件判断，不多模型投票。

## 尾帧接力

仅当下一 Panel 需要精确首帧，才在 `ACCEPT` 后从实际采用视频提取真实末帧并导入画布。抽样截图、文字描述或未采用片段不能代替尾帧。提取与绑定使用[画布操作接口](../../canvas-workspace/references/operations.md)。

### 替换片段后的接缝

只核对新版与前、后片段的关系，以及后段是否仍引用旧版末帧。硬切或时间省略足以解释差异时保留后段；连续关系确实失效时才修正受影响输入。更新采用路径和必要尾帧引用，不默认整章返工、不删除历史媒体。生成新版本仍通过 Canvas 确认新快照。

## 字幕与后期画面

字幕采用锁定对白和实际发声时间，需要烧录时在最终时间线统一处理，避免双层字幕。ASR/VAD 只定位待复核窗口，不替代听审。检查当前画幅中的可读性、时机与遮挡。

场景文字有透视、遮挡或形成过程要求时，检查这些关系；整字跳出不能冒充正在书写。清理意外字幕不能遮住关键人物、手部或道具。不要以“后期可修”提前接受不可用版本。

后期生成新文件，保留已接受源片。调速或改音轨时核对受影响的时长、字幕和同步；涉及剪音时遵守共享规则的对白保护要求。

## 最终成片

全部所需 Panel 已接受后，完成计划中的确定性后期，对实际交付文件做一次正常速度的完整视听检查。确认顺序与故事可理解、接缝成立、声音没有截断或意外静音、字幕可读且无残留，以及所需交付文件齐全。无声项目不强制加音轨。

复用片段结论，不重写逐 Panel 报告；只针对成片新增问题定位最小修正范围。无法观看或听审的关键项目如实记为未验证，不能用轨道存在或模型描述宣称通过。

## 最小记录

直接使用 Canvas 当前 review 接口，路径和摘要绑定实际采用文件；字段格式查操作接口，不另建旁路状态或重复 QC 报告。

| review 字段 | 填写内容 |
| --- | --- |
| `decision` | `ACCEPT` / `REJECT` / `INCONCLUSIVE` |
| `output_path`、`output_sha256` | 实际采用文件的路径与 SHA-256 摘要 |
| `evidence` | 非空数组，简述实际观察、有关音频与结论依据；无声视频说明无音频 |
| `end_state` | 对象，仅记录与任务/下游有关的实际末态 |
| `unverified` | 未验证关键项数组；`ACCEPT` 时须为空 |

`run_id` 是请求标识，不写入 review 对象。尾帧由画布派生输出接口绑定，不向 review 添加 `tail_frame_path`、`actual_endstate` 或 `actual_audio_evidence` 等未定义字段。技术错误写入运行状态，不把 `ERROR` 当成内容决策。缺失的关键证据不得以“不适用”绕过；不相关项目无需展开。
