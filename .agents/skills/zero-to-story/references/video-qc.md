# 生成视频分级 QC 与重试止损规则

## 目标与边界

技术 QC 和语义 QC 分开判定：

- **技术 QC**检查视频可解码、时长、帧率、编码和必需音轨。失败时直接阻断，不降低标准。
- **语义 QC**检查剧情、角色、文字、画面和连续性，使用 `PASS`、`PASS_WITH_REPAIR`、`FAIL` 三级结论。

提示词描述的是目标画面，不等于每个细节都是二元验收合同。只有在故事板的 Panel QC 约束中事先登记为硬约束，或者符合本文的通用硬失败条件，才能因为偏差拒绝整段。不要把提示词中的每个形容词、背景物或排除项自动升级为硬失败。

## 三级结论

### `FAIL`：硬失败

出现下列任一问题时拒绝当前片段，不把其尾帧接入下一段：

- 技术 QC 失败，视频无法可靠解码或不满足执行合同。
- 主要角色身份明显错误、关键角色互换、出现重复/替身，或人物数量改变导致剧情关系错误。
- 非创作要求的可读字幕、角色名、对白、地址、号码、乱码、气泡或清晰 UI 进入画面。
- 核心剧情动作缺失、反转或由错误角色完成；剧情关键道具的数量、归属或状态错误。
- 严重肢体错误、重影、溶解或画面破坏持续影响主体表演和故事理解。
- 开场无法承接上一段已确认末态，或者最后一秒的角色、位置、朝向、道具和构图无法作为下一段真实参考。
- 用户明确标为不可妥协的合规、品牌、安全或叙事限制被违反。

远景路人、非主体装饰或短暂低显著性异常，只有在改变剧情关系、被误认成关键角色或持续占据注意中心时，才升级为硬失败。

### `PASS_WITH_REPAIR`：通过但需修复

主体故事和尾帧成立，而且问题能够在不重做整段的前提下确定性修复时使用：

- 原生对白内容、音色或音量不正确，但可用已确认音轨替换，且人物表演不与台词明显冲突。
- 短暂白场、云团、闪帧、接缝或局部异常可以裁切、定帧、遮盖、重定时或硬切修复。
- 中段出现非关键背景物、无可读内容的小型屏幕状物体、额外装饰或非剧情道具。
- 非关键服装色差、轻微身份特征波动、局部手部或背景瑕疵不影响主体辨认和剧情。
- 问题只出现在中段，修复不会改变已经通过的真实尾帧。

记录明确的修复动作。最终组装只能使用完成修复并重新检查过的版本，不能使用未修复原片。

如果修复会改变最后一秒，必须先完成修复、检查新的真实尾帧，再继续接力。如果修复只影响中段或音频，可以保留已通过的原始尾帧作为连续性锚点。

### `PASS`：通过并记录轻微偏差

以下问题通常只记录，不重生成：

- 背景杂物、无意义小道具或装饰与设想略有不同。
- 非主体区域短暂手部瑕疵、边缘噪点或轻微画风波动。
- 不影响身份辨认的服装纹理、色温、光线和表情细微差异。
- 不影响对白理解的轻微口型误差。
- 不可读、低显著性且不承担剧情信息的背景图形。

## 判定顺序

每段只按以下顺序检查：

1. 运行技术 QC。
2. 核对当前 Panel 事先登记的硬约束。
3. 检查角色身份与人数、非预期可读文字、核心剧情动作和关键道具。
4. 检查开场承接与最后一秒的真实尾帧状态。
5. 将其余问题分类为可修复项或接受备注，不继续扩大检查范围。

检查使用完整视频、切点附近、首尾一秒和约 1–2 fps 接触表。只有多人镜头、文字/UI 风险、身份判断不清或抽帧证据冲突时，才增加密集逐帧检查或视频理解复核；不要求每个普通单人镜头都做最高强度复核。

精确对白以最终锁定音轨和必要的 ASR 结果为准。视频模型原生音频将被替换时，不因原生对白逐字不准而拒绝画面；只检查可见说话人、表演节奏和口型是否存在明显矛盾。

## 重试止损

- 第一次 `FAIL`：定位单一主要根因，修正 Panel 输入、素材或通过 `$h3-prompt-writing` 重新生成提示词，再重试。
- 同一根因连续第二次 `FAIL`：停止继续只换 seed 或堆叠约束。必须选择模式/后端调整、拆分 Panel、替换参考素材或确定性修复。
- 只有发生实质策略变化时才允许再做一次生成；仍复现同一根因时，不再继续采样，转修复、接受已记录偏差，或请求用户决定。
- `PASS_WITH_REPAIR` 不触发整段重生成，除非没有可行的确定性修复，或修复会实质改变用户已确认的表演与剧情。

失败 run、修复源和最终采用片段全部保留，不覆盖历史产物。

## 日志最小字段

每个生成或修复结果至少记录：

```text
Panel / package revision / run id
QC result: PASS | PASS_WITH_REPAIR | FAIL
hard blockers: 无或具体原因
repair items: 无或具体动作
accepted notes: 可接受偏差
tail impact: unchanged | repaired-and-rechecked | unusable
approved clip and tail path
```

最终成片 QC 再检查整体时长、音画、字幕轨、Panel 接缝和所有修复项是否真正落地；不要在最终阶段重新把已记录的轻微偏差升级为整段失败，除非它在连续观看时暴露出新的剧情、身份、文字或合规问题。
