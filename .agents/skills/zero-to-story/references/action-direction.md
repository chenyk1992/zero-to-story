# 动作导演参考

只在当前故事板或 Panel 已确定、需要把关键动作写得可拍可见时读取。它帮助补足当前 Setup 的动作事实，不要求增加镜头、Beat、动作数量或审批。

## 先说明动作如何改变局面

用少量可观察事实交代：人物要达成什么、什么造成阻力、从何处开始、怎样移动、何时接触、对方或物件怎样反馈，以及最后是谁处于什么状态。只展开会影响观众理解、接续或安全的部分。

不要只写“激烈争夺”或“迅速交手”。也不要为了显得丰富，把一次主动作拆成一串无关的击打和切镜。

| 过于抽象 | 可拍的写法 |
| --- | --- |
| 两人激烈争夺信封 | 甲伸手夺信封；乙先把信封收向胸前，甲扣住乙的手腕。两人短暂僵住，信封仍在乙手里。 |
| 两人展开写实打斗 | 走廊狭窄，甲被逼到墙边后侧身避开，借墙稳住自己；乙扑空，重心前倾，甲趁空当拉开距离。 |
| 两名术士爆发对决 | 蓝色符光从甲掌心沿地面逼近，乙抬伞挡住光线，伞沿震开一圈雨水；光芒熄灭后，两人仍隔着半步对视。 |

## 三种常见写法

### 近身交锋

先写空间和优势如何变化。比如狭窄厨房里，甲的退路被餐桌挡住，乙伸手抓向围裙口袋；甲转身让开，同时用手压住口袋。此时观众应看懂“乙没拿到东西、甲仍在防守”，不必把每次推拉都写成独立动作。

### 道具争夺

交接和归属最重要。可按“接近 → 接触 → 双方共同控制 → 一方释放或夺回 → 新的稳定状态”写，但这些阶段可在同一镜头中连续发生。若最终仍由原持有者保留，必须写明，不让下一个 Panel 猜测物品去向。

### 风格化交锋

特效也要服务因果。先交代谁发动、效果走向哪里、另一方怎样抵挡或被迫改变位置、残留效果如何影响结尾。不要把光效、腾空和爆炸连续堆叠到遮住人物关系；高速多人动作看不清时，减少同时发生的无关动作，或改用能看清主关系的机位。

## 进出空间与操作界面

当前动作需要攀爬、踩踏、倚靠、进出或操作机械时，先核对已确认设计中的开口、接触面和承重位置，再写手、脚、身体与部件的运动先后、重心转移及完成状态。机位应让关键接触或开合过程能被看懂，只展开本次动作实际使用的结构。

参考未显示某个踏板、把手或通道时，不能为完成动作自行补造，也不能仅凭未显示就断言它不存在。依据已有结构资料或已确认的虚构设计补足说明；仍有关键缺口时，调整机位或简化动作并记录取舍，需要改变已定设计时先更新受影响的资产计划。比如登舱前先确定脚踩的承重面和手扶的位置，再安排身体移入；不让模型用临时长出的平台接住人物。

## 打戏动作库索引（按需选用，不设固定招式数）

需要武打、追逐、对抗或法武动作时，按**当次风格与写实程度**选用下列写法要点；同一场只选一种主基调，不把三套混叠。这里提供的是可观察因果与接触约束，不是招式套餐、固定连招长度或强制换机位。

### 通用近身对抗

- 一次有效交锋写清：谁先动 → 接触点/抓握点 → 优势如何转移 → 本拍结束姿态。
- 连续对抗至少有一处**可见实体接触**（格挡、抓握、撞击、着地）；只有挥空和位移会让观众看不懂输赢。
- 群戏减少同帧无关动作：先定 1–2 对主对抗关系，其余写位置变化即可。

### 风格化 / 玄幻向

- 特效跟因果：谁发动、能量/效果走向、另一方如何挡或躲、残留物是否改变下拍站位。
- 大招前后各保留一拍可读姿态（蓄力结束 / 收势），避免连续光效遮住人物关系。
- 法宝、飞剑、护盾等道具写明**从谁到谁**、是否可被夺走；与[道具单实例](creative-assets.md)一致。

### 写实克制向

- 优先真实格挡、重心、脚步和疲劳：推不开就写推不开，打不穿护具就写护具。
- 伤害后果可观察（捂住、跛行、武器脱手），不在单镜内无限复原。
- 不用慢动作掩盖看不清的接触；需要看清就换景别或减动作，而不是加词。

### 与已有字段的衔接

打戏仍写入 Camera Setup、动作起止、道具归属与转场；跨 Panel 一次击打/一次夺取只归一段。动能、位移和末态服务剧情转折，不为“燃”堆镜头。

## 场面调度与站位（散文可拍性）

目标是让观众**一眼看懂谁在哪、能碰到什么、在对谁说话**。以下是写法习惯，不是新 schema，也不做机检；结论仍写入已有 Setup、动作起止、道具归属与转场。

### 一行站位（建议写法）

关键人物首次进入新空间或关系突变时，用一行交代四件事（可合并进动作句，不必单独成段）：

> 甲（站位）桌内侧，手撑桌面，面向门口的乙；乙在门框内，侧身，右手仍搭在门把上。

| 要素 | 写什么 | 不写成 |
| --- | --- | --- |
| 位置 | 相对空间锚点：桌内侧 / 门框内 / 楼梯口 | “左边一点”“附近” |
| 依托 | 身体靠着/扶着/坐在什么上 | 无接触却写“倚着” |
| 朝向 | 面向谁 / 背对谁 / 侧身 | “看着镜头”（除非破墙设计） |
| 姿态 | 站/坐/蹲/俯身及重心 | 与后续动作矛盾的静止词 |

同场后续镜若关系未变，可只写**变化**（“乙进到桌旁”），不重复四要素。变化要能接上一镜末态；跨 Panel 时，上一段已接受的末态就是下一段的起点事实。

### 空间锚与人物账

- **背景锚：** 站位尽量绑一个可见背景物（“背对书架”“在窗下”），便于跨镜对齐；换场硬切则换锚，不假装还在原位。
- **谁能看见谁：** 对话或冲突戏先定视线关系；转头、被遮挡、入画/出画写清触发原因，不让人物凭空“已经在对视”。
- **人数与归属：** 在场谁有动作、谁只是旁观，写进该 Setup 的 `critical_characters` / 动作句；说话却未入账的按[人物账](creative-blueprint.md)补 ID，不另造称呼。

### 位移链

一次有意义的移动写清 **起点 → 路径/障碍 → 终点姿态**，而不是“走来走去”。例：

> 乙从门口沿桌沿走到甲侧后方（绕开地上的纸箱），停在甲右肩外半步，伸手按住账本。

路径上的障碍、承重和接触面须与已有设计一致（见上文「进出空间」）；一次移动只归一个 Setup/Panel，跨段不重演。

### 轴线与机位（可选自觉，非硬规则）

- 同一场对话尽量保持稳定的“左—右”人物关系，避免无动机跳轴让观众误判位置；**有意**反轴、环绕或换边时，在 Setup 写明目的（揭示、压迫、混乱）。
- 全景交代位置与关系，中近景才承担手势、持物和面部变化；站位句服务于可见关系，不为凑词堆空间术语。
- 不强制每镜写满四要素，也不规定镜头数或切镜频率。

### 与验收的关系

静态分镜和提示词写清站位，**不等于**画面已成立。仍以实际采用视频核对：人在画面中的位置/朝向是否与计划一致、关键接触是否可见、入离场是否可读。对不齐时改 Setup 或下一段承接，不靠再加形容词补救。

## 写入现有导演字段

把动作结论放回已有的 Camera Setup、Beat、动作起止状态、道具归属和转场说明。跨 Panel 的边界动作只能归一段承担：前段已经完成“放下”，后段就从“物已放妥、手已离开”继续，不能再演一次。

动作要与景别匹配。全景优先交代位置、路径和关系；近景才承担手部接触或关键物件变化。只有动作、空间或信息发生变化时才切镜；固定镜头和完整长动作都可以成立。
