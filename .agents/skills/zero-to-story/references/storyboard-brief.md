## 固定契约

`storyboard_brief.md` 是故事、视觉资产和 H3 提示词的唯一信息中枢。保持：

- `1 Panel = 1 张 2×3 六镜板 = 1 条 H3 Clip`。
- 每个 Panel 的六格按左上、上中、右上、左下、下中、右下阅读，保留六个 Shot ID。
- P001 使用 S001–S006；P002 使用 S006–S011；每个后续 Panel 复用上一 Panel 最后一 Shot，再新增五个唯一镜头。
- 唯一镜头数为 `6 + (Panel 数 - 1) × 5`，Panel、分镜板、Clip 数相等。
- 六格是视觉节拍，不强行等价为六次剪切。H3 阶段可以把相邻连续节拍合并成 3–6 个执行节拍，但不得删除、换序或重编号 Shot。

## 项目模板

从 [storyboard_brief.template.md](../assets/storyboard_brief.template.md) 创建项目文件。模板是可复制的成品骨架；本 reference 只解释字段语义、合并、时序和检查规则，不再维护第二份模板正文。

## 唯一镜头表

每行只表达一个视觉节拍或信息转折。`画面描述与空间关系` 同时写清景别可见范围、人物位置、朝向、距离、场景锚点、双手和道具归属；`锁定末态` 只写动作完成后的可见状态，不写无法拍摄的抽象情绪。

`运镜` 使用 [creative-assets.md 的运镜词典](creative-assets.md#运镜词汇与摄影动作词典)。静态机位可写 `固定`；方向、平移、推拉和环绕必须使用词典中的明确词汇。

“与前镜关系”至少使用一种可判断关系：`新场景`、`连续承接`、`动作延续`、`反应`、`匹配切`、`J/L 声音延续`、`必须硬切`。`时长权重` 是相对数值，不是秒数；`必须独立` 只在场景/说话人/视点/硬切/同步等要求阻止合并时标记 `是`。

## Panel 映射与合并

六格是否合并由以下规则判断：

可合并：相邻格处于同一场景、同一轴线和连续动作轨迹，没有新说话人或必须切换的视点；后格只是动作推进、反应或同一声音延续。

不可合并：场景改变、说话人改变且需要看口型、视点/轴线改变、故事板明确要求硬切或匹配切、J/L 对白落点必须独立、首尾帧/素材约束必须独立，或合并会丢失信息转折。

合并只减少 H3 的“执行节拍”数量，不改变六个 Shot 的创作账本。每个执行节拍必须仍能追溯到一个或多个连续 Shot；无法追溯就退回故事板复核。

## 动态时序前置标注

故事板先标记时长权重和动作类型，H3 阶段再计算具体秒数。基础最短时长：

| 类型 | 基础最短时长 |
|---|---:|
| 插入 / 反应 | 0.6s |
| 简单动作 | 0.9s |
| 建立 | 1.1s |
| 复杂动作 | 1.5s |
| 情绪停留 | 1.2s |

中文台词的最低时间为 `字符数 / 4 + 0.3s`。若所有执行节拍的最低时间总和超过目标时长，按顺序：简化动作 → 缩短台词或改旁白 → 合并相邻节拍 → 延长到 4–15 秒 → 拆分 Panel。不得把超载留给模型猜测。

最低时间满足后，把剩余时间按 `时长权重` 分配，最后按 0.1 秒取整并回收舍入误差。单段仍须在 4–15 秒，时间段不能倒序或越界。

## 连续性与确认检查

- [ ] Panel = 分镜板 = Clip；每 Panel 恰好六格，唯一镜头公式正确。
- [ ] 每个 Shot 有空间、动作、声音、末态、前镜关系、时长权重和合并判定。
- [ ] 场景/轴线/人物/道具/双手/灯光连续；跨 Panel 只携带最小状态差。
- [ ] 需要独立的切镜、对白、素材或首尾帧没有被合并。
- [ ] 时长合计等于目标总时长，单段 4–15 秒，台词按 `chars/4+0.3` 可容纳。
- [ ] 所有可读文字、号码、地址、聊天内容和复杂 UI 已登记为确定性后期资产。
- [ ] Medium Lock、Style Brief、角色锚点和场景锚点无冲突。

向用户展示故事板时指出为适配目标时长所做的删减、合并或旁白取舍。只有用户明确确认，才将“故事板概要”状态改为 `已确认`。
