# 单角色设定图 Prompt

共同的可观察要求和资产验收规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本模板只生成一张单角色视觉参考卡。

```text
为单个角色创建一张视觉参考卡，不是海报、剧照或剧情场景，不把多个角色合并到同一张图。

角色：[姓名与身份]
完整描述：[从已确认 storyboard_brief.md 逐字复制外貌、服饰和标志性特征]
关键道具：[名称、数量、携带方式；没有则写“无道具”]
标志动作：[最能识别角色的站姿、手势或动作习惯]

展示内容：一张清晰头肩近景；同一角色的正面、侧面、背面全身视图，头到脚完整、双脚可见；1–2 张小尺寸半身表情或动作变化。关键道具只允许被手持、佩戴或背挂，不在背景中复制。

所有视图必须是同一个人；发型、脸型、体型、服饰、道具数量和画风一致；统一中性背景和柔和工作室光；默认无文字。

避免：第二个角色、剧情背景、文字、标签、编号、字幕、标志、水印、UI、道具复制、服饰变化、年龄漂移、脸型漂移、肢体畸形。

[Style Brief]
[Medium Lock]
```
