# 单角色设定图 Prompt

影视与广告的角色设定图使用本模板；MV 的[人物参考模板](../../music-video-creator/assets/character_reference.template.md)保持相同展示规格，只适配人物描述来源。通用身份方法见[身份设计](../../visual-design-creator/references/character-identity-design.md)。

为每个新建角色单独生成 1 张横版 16:9 角色设定图，记录完整外观。后续采用黑白分镜时，可从中提取最小轮廓符号；设定图本身遵守已定的 Style Brief 与 Medium Lock，不因此改成黑白。图片能力（image agent）仍通过 Canvas 已确认请求执行，见[共享生产规则](../../../../guides/ai-system-prompt.md)。

## Prompt 模板

```text
为单个角色创建一张角色设定图，画面为横版 16:9 构图，默认不包含任何文字。不要把多个角色合并到同一张图中。

角色：[角色姓名]
角色完整描述：[从故事板概要文档的该角色条目逐字复制外貌、服饰、标志性特征]

展示内容：
- 正面视图：[角色外貌+服饰+标志性特征完整描述]
- 侧面视图：[同一角色侧面外观描述]
- 背面视图：[同一角色背面外观描述]
- 1-2 张小尺寸半身变化：展示该角色的表情变化 / 动作变化，用于辅助理解角色性格和动作习惯
- 标志性动作：[该角色最典型的身体姿态、手势、站姿或动作习惯]
- 关键道具：[该角色的关键道具；如果没有则写“无道具”]

要求：
- 三个视图保持完全一致的服装、发型、体型和标志性特征
- 半身变化和动作变化必须保持同一角色身份，不改变发型、服装、体型或关键特征
- 关键道具必须与角色保持同一风格和比例
- 默认不要添加任何文字标签、编号、说明或 UI 标记

[Style Brief] + [Medium Lock]
```

## 填充与交接

- 每个角色单独 1 张，禁止合并多个角色；正/侧/背视图与 1–2 张半身变化都是完整设定图的必备内容，不按镜头朝向自行删减，也不额外强制独立头肩近景。
- 影视从 `storyboard_brief.md` 的角色列表逐字复制描述，不改写；广告把同一来源占位替换为当前 `ad_plan` 的角色条目，独立资产使用当前已确认角色条目。角色姓名、标志动作、关键道具与主源一致，缺少的角色事实先在主源确定，不在填模板时编造。
- 正/侧/背展示完整身体轮廓，人形角色全身头到脚完整。非人角色沿用已定部件、连接与覆盖状态，不为套模板添加人类肢体或服装。半身变化按其实际结构表现，仍保留 1–2 个表情/动作变化。
- 必须展示已定标志性动作和关键道具；没有道具时写“无道具”，不同视角不得增加道具数量或改变携带关系。
- 默认不加文字标签。角色/道具已有必要徽记或品牌时，保留主源明确要求的内容，不将“无标签”理解为删除身份特征；不新增未声明文字或去除参考水印。
- 有童年/成年、换装或变形阶段时，按[身份与造型复用](../references/creative-assets.md#角色身份与造型复用)用同 cast ID 的不同 asset key 表达，不混合阶段。已有采用的完整设定图可复用；局部修正保留其余已采用视图，不重新选脸或覆盖冻结历史。
- 设定图的 16:9 是资产规格，不改变成片画幅；Canvas 图片节点与提示词保持该规格。多视图卡用于身份参考或制作分镜/单镜首帧，不直接冒充 I2V/FL2V 的场景帧。
