# 可变网格电影画面分镜板 Prompt

共同的 Panel ready、可观察要求和实际验收规则见[项目共享生产规则](../../../../docs/ai-system-prompt.md)。本模板只生成选择了 `storyboard_board` 的 R2V 分镜板。

> 只用于 `visual_asset_policy: "storyboard_board"` 的 R2V Panel。STEP 1 必须先为该 Panel 锁定一个 `rowsxcolumns` 布局，且行数 × 列数为 2–6（例如 `1x2`、`2x2`、`2x3`）。STEP 3 只调用一次图片生成，直接输出一张自包含分镜板；不先生成独立分镜帧，也不在后期拼接。资产 key 为 `storyboard_board.<panel>`，H3 将它作为一张参考图接收。

```text
生成一张自包含的电影画面分镜板：使用图片模型支持的一张标准尺寸画布 [BOARD_W:BOARD_H]，整张板的像素预算不随格数成倍增加；目标成片画幅 [VIDEO_W:VIDEO_H] 只用于指导各格的镜头构图。严格采用 [rowsxcolumns] 网格（[rows] 行 × [columns] 列），共 [cell_count] 个等大画格。画格之间清晰分隔。阅读顺序必须严格为从左到右、从上到下。

这是一次图片生成的单张板，不是独立帧集合：只输出这一张完整分镜板，不输出单张画格，不做后期拼接，不添加标题区、页边栏、额外小格、跨格、并格或不等大画格。必须准确锁定 [rowsxcolumns]、[cell_count] 个画格和上述阅读顺序，不能漏格、增格或改变顺序。

项目与媒介：
- 分镜板画布：[BOARD_W:BOARD_H；图片模型支持的一张标准尺寸]
- 成片画幅：[VIDEO_W:VIDEO_H；仅指导各格构图]
- Medium Lock：[与目标成片一致的已确认媒介要求]
- Style Brief：[目标成片的色彩、光线与材质风格]

角色与场景锚点：
- 角色 A：[仅凭文字即可区分的身份、发型或帽形、体型、服装外轮廓/明暗块、关键道具和表演锚点]
- 角色 B：[如有；按同样原则填写；没有则删除]
- 场景：[空间结构、材质、光线、时间天气和连续性辨识物]
- 可选图片参考：[仅在当前图片模型支持时列出每张图及用途；不支持时删除本行。图片参考不能替代上述文字锚点]

可检查约束（只写当前 Panel 必须观察到的事实）：
- 数量：[人物、物件和重复元素的数量]
- 相对大小：[与谁相比更大/更小，或画面占比]
- 身份锚点：[发型/帽形、体型、服装轮廓、关键道具等]
- 物体形状：[必须保持的轮廓和结构]
- 必须可见部分：[身体、道具、结果状态或空间部位]
- 接触关系：[谁与谁如何接触、持有或保持距离]
- 精确文字：[逐字内容或无；分镜板默认不可读，说明由生成还是后期负责]
- 生成/后期责任：[生成 / 确定性后期 / 无]

板内格位内容（只填写 1 到 [cell_count] 格，严格按从左到右、从上到下排列；每格只表达一个静态关键瞬间）：
- 第 1 格：[对应 Beat；Setup ID；景别、摄影机位置与朝向、轴线侧、人物/场景位置、人物朝向、目标/视线、屏幕运动方向、当前状态；本格唯一新增控制信息]
- 第 2 格：[对应 Beat；Setup ID；上述画面关系与静态状态；本格唯一新增控制信息]
- 第 3 格：[对应 Beat；Setup ID；上述画面关系与静态状态；本格唯一新增控制信息；若 [cell_count] < 3 删除]
- 第 4 格：[对应 Beat；Setup ID；上述画面关系与静态状态；本格唯一新增控制信息；若 [cell_count] < 4 删除]
- 第 5 格：[对应 Beat；Setup ID；上述画面关系与静态状态；本格唯一新增控制信息；若 [cell_count] < 5 删除]
- 第 6 格：[对应 Beat；Setup ID；上述画面关系与静态状态；本格唯一新增控制信息；若 [cell_count] < 6 删除]

按信息增量选择恰好 [cell_count] 个格位，形成当前 Panel 最有参考价值的动作、构图或状态链。需要连续承接上一 Panel 时，才把已确认的零时长边界状态放入第 1 格；硬切、新场景或该状态不能增加控制价值时，第 1 格直接表达当前 Panel 的第一个有效关键瞬间。六个 Beat 仍是故事语义映射，不要求每个 Beat 都成为一个画格。每格必须写清其所属 Setup 和唯一新增控制信息，但这些字段只用于组织输入，不得绘制在画面中。

同一 Setup 的相邻格按已计划的运镜和人物走位推进，保持空间与动作连续；Setup 改变时表达新的观看信息。用人物构图、姿态和相对位置表达屏幕运动与视线关系，不要画箭头、速度线、运动轨迹或动作残影。保持人物左右、前后景、朝向、手部、道具归属、门窗和灯光状态连续。

分镜板统一采用与目标成片一致的电影画面风格，保留必要的人物形象、五官和衣着等。各格明确必要的构图、人物关系和关键动作状态，保持角色与场景外观一致；中间运动、自然表演和声音由视频生成完成。

禁止任何可读或伪造文字：标题、镜号、编号、格位标签、Beat、Setup、对白、字幕、地址、门牌、UI、logo、水印、签名、字母和数字；所有组织字段只作为输入，不能渲染为画面文字，屏幕与门面文字画成空白。

避免：错误网格、不等大画格、并格、漏格、增格、改变阅读顺序、角色设定板、会遮蔽关键关系的过度细节、箭头、速度线、运动轨迹、动作残影、额外人物、额外肢体、道具复制、动作换序、身份漂移、裸露或明确性行为。
```
