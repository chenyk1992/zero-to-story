# 单帧视觉控制图 Prompt 模板

共同的 Panel ready、可观察要求和实际验收规则见[项目共享生产规则](../../../../guides/ai-system-prompt.md)。本模板只生成一张单帧视觉控制图。

## 使用方式

只用于 `visual_asset_policy: "scene_keyframe"` 或 `"last_frame"`。替换方括号占位内容，删除不适用的备注。输出是一张与目标成片画幅和已定媒介一致的独立画面，不是分镜板、角色卡或前后对比图。

```text
创作一张单帧视觉控制图。

资产类型：[场景/首帧关键帧 scene_keyframe / 目标尾帧 last_frame]
对应 Panel：[Panel ID 与标题]
目标画幅：[例如 9:16]
Medium Lock：[逐字复制已确认内容]
Style Brief：[只复制当前单帧可见的风格要点]
可选图片参考：[仅在当前图片后端支持时，按实际图号写每张图的用途与不沿用内容；无则删除]

画面必须精确表达的已完成可见状态：
- 时间、地点、天气与主光：[主光来源、方向及关键主体受光；与本帧用途无关的细节省略]
- 摄影机位置、景别、高度、朝向和轴线侧：[内容]
- 主体在画面中的左/中/右、前/中/后景、朝向、姿势和视线落点：[内容]
- 肢体或部件状态：[人形按需写左右手；非人沿用已定部件及连接，无相关结构则删除]
- 关键道具的数量、归属、位置、连接状态和可见性：[内容]
- 可检查要求：数量 [内容]；相对大小 [与谁相比/画面占比]；身份锚点 [内容]；物体形状 [内容]；必须可见部分 [内容]；接触关系 [内容]
- 需要出现的精确文字：[逐字内容、载体、可见状态或无；仅绘制由生成负责且本帧应可见的文字，后期专属项只预留载体]
- 文字、UI 或复杂图形的制作责任：[生成 / 确定性后期 / 无]
- 背景中必须保留或排除的辨识物：[内容]
- 此帧与前后状态的连续关系：[内容]

[若为 scene_keyframe]
这是动作开始前的精确起点。所有人物和道具已就位，但不提前发生当前 Panel 的主动作。

[若为 last_frame]
这是当前 Panel 所有动作完成后的精确尾帧。只画已完成末态，不画运动轨迹、前后对比、中间动作或下一 Panel 的新动作。

硬性输出要求：
- 恰好一张独立画面；无网格、无多格、无拼贴、无插图边框、无多视图。
- 默认不写标题、台词、标签、编号、字幕、对白气泡、箭头或水印；用户明确要求的画内文字或 UI 按上文的原文与制作责任处理，不能一边要求可读一边要求无字。
- 不用抽象符号代替可见的人物、空间、道具或光线状态。
- 不额外增加角色、道具、灯光、文字或剧情事件。
```
