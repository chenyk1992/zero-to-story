# 从零开始创作短片

> 从零开始，引导用户完成故事设计 → 生成故事板文档 → 生成角色设定图 → 生成黑白分镜图 → 确认提示词后生成视频。
> 适用：没有现成剧本、想从一个灵感开始逐步构建完整分镜并继续生成视频的创作者。
> 已有完整剧本想直接生成分镜，可使用 `storyboard` 或 `character-scene-storyboard`；需要角色 / 场景 / 道具设定图可使用 `film-assets`。

---

## 可用工具

本 Skill 可调用以下工具：

| 工具类型 | 可用工具 | 用途 |
|---|---|---|
| **文件操作** | `hub_read`, `hub_write`, `hub_edit` | 创建、读取和编辑故事板概要文档 |
| **媒体分析** | `hub_analyse_media` | 按需分析用户上传的参考图 / 视频 / 音频 |
| **画布操作** | `hub_canvas_get_node`, `hub_canvas_search_nodes`, `hub_canvas_write_text_node`, `hub_canvas_write_table_node`, `hub_canvas_write_media_node` | 在画布上读取、展示和更新文本 / 表格 / 外部生成资产 |
| **图片搜索** | `hub_image_search` | 搜索参考图 |
| **子 Agent** | `image` agent, `video` agent | 生成角色设定图、黑白分镜图，以及基于黑白分镜和提示词生成视频 |

> **画布规则**：image agent 生成的图片通常会自动注册到 session 并出现在画布上，不要再手动调用 `hub_canvas_write_media_node` 造成重复节点。只有本地脚本、外部下载、裁切或非生成管线产出的媒体文件，才需要用 `hub_canvas_write_media_node` 放到画布。

---

## STEP 0 — 分析输入

读取用户提供的剧本 / 分镜脚本，提取：

1. **角色列表**：姓名、外貌、服饰、标志性动作
2. **场景列表**：场景名、视觉描述、色调氛围
3. **镜头数**：N 个镜头的视觉描述
4. **一句话故事**：用户用一句话描述的故事核心内容
5. **风格关键词**：用户指定或推断（赛博朋克 / 古风 / 写实 等）

用户未提供剧本时，使用一次对话选项合并询问以下 6 个维度，协助用户逐步完成故事设计；不要调用 GUI 或脚本入口。

### 剧本设计引导（用户无脚本时触发）

| 步骤 | 标题 | 问题 | 选项 |
|---|---|---|---|
| Step 1 | 故事类型 | 你想做什么类型的作品？ | 剧情短片 / 预告片 / MV / 广告创意 / 竖屏短剧 |
| Step 2 | 角色设定 | 有哪些主要角色？ | 提供角色描述 / 上传角色参考 / 帮我想一个 |
| Step 3 | 场景设定 | 故事发生在哪些场景？ | 列举场景 / 上传场景参考 / 帮我想一个 |
| Step 4 | 故事描述 | 用一句话描述你的故事 | 上传剧情文档 |
| Step 5 | 视频时长 | 最终视频想做多长？ | 15 秒（8 个分镜）/ 30 秒（15 个分镜）/ 45 秒（22 个分镜）/ 60 秒（29 个分镜） |
| Step 6 | 视觉风格 | 想要什么视觉风格？ | 写实 / 2D动画 / 3D渲染 / 水彩 / 3渲2 |

**引导要求**：
- 使用一次对话选项合并询问全部维度，不逐个开放式追问。
- 剧情部分优先让用户上传剧情文档，也可用一句话补充故事核心。
- 视频时长选项只标注对应分镜数量，不标注 2x4 黑白分镜图数量。
- 用户提交后输出结构化剧本摘要（含一句话故事 / 剧情文档摘要 + 角色表 + 场景表 + 视频时长 + 镜头数 + 风格），供 STEP 1 使用。

## STEP 1 — 生成故事板 MD 文档

### 1.1 建立 Medium Lock + Style Brief

根据用户选择的风格，建立：

**Medium Lock**（一句陈述句，放生成 prompt 末尾）：

示例（3D 渲染）：
> "Medium: 3D rendered scene with cinematic 2D animation composition, clean geometry, stylized realism. NOT 2D anime cel-shading, NOT live-action, NOT sketch."

示例（2D 动画）：
> "Medium: 2D hand-drawn animation with watercolor backgrounds. NOT 3D render, NOT photoreal, NOT live-action."

**Style Brief**（以下字段逐字传递后续步骤）：
- **Style keywords**：cinematic, neon-lit, rain-soaked 等
- **Color palette**：2-3 个主色 + 各自动态角色
- **Lighting**：方向 / 质感 / 色温
- **Mood**：情绪关键词

### 1.2 生成故事板 MD 文档

根据用户输入和已确认的视觉风格，创建故事板概要文档，并将完整内容同步到画布作为 markdown 文本节点。

推荐做法：以画布 markdown 节点作为主文档；如需要本地文件，再用 `hub_write` 写入 `storyboard_brief.md`。如果文件和画布节点同时存在，更新时必须保持两者内容一致。

> **画布同步规则**：
> - 新建文档：调用 `hub_canvas_write_text_node`，`name: "storyboard_brief"`
> - 更新文档：先通过 `hub_canvas_search_nodes` / `hub_canvas_get_node` 找到对应文本节点，再调用 `hub_canvas_write_text_node` Patch 模式更新完整 markdown
> - 如果同时维护本地文件：新建 / 覆盖用 `hub_write`，局部修改用 `hub_edit`
> - 禁止只更新文件不更新画布节点

**`storyboard_brief.md` 模板**：

```markdown
# 故事板概要 — [项目标题]

## 项目信息
- **类型**：[剧情短片 / 预告片 / MV / 广告创意 / 竖屏短剧]
- **风格**：[视觉风格]
- **视频时长**：[15 秒 / 30 秒 / 45 秒 / 60 秒]
- **目标镜头数**：[8 / 15 / 22 / 29]
- **比例**：[默认 16:9；如用户明确修改则写用户确认比例]

## 故事梗概
[2-3 句话概括整个故事的核心情节和情感走向]

## 角色列表

### 角色 1：[姓名]
- **外貌**：[详细外貌描述——发型、肤色、体型]
- **服饰**：[服装描述]
- **标志性特征**：[独特特征、道具、纹身等]

### 角色 2：[姓名]
- **外貌**：[详细外貌描述]
- **服饰**：[服装描述]
- **标志性特征**：[独特特征]

## 场景列表

### 场景 A：[场景名]
- **视觉描述**：[空间布局、关键道具、环境细节]
- **色调氛围**：[该场景的特有光影和情绪]

### 场景 B：[场景名]
- **视觉描述**：[空间布局、关键道具、环境细节]
- **色调氛围**：[该场景的特有光影和情绪]

## 分镜列表

| 镜头 | 景别 | 场景 | 画面描述 | 角色台词 | 音效设计 |
|---|---|---|---|---|---|
| 01 | [全景/中景/近景/特写] | [场景名] | [该镜头的详细视觉描述；必须写清人物在场景中的位置关系，例如角色位于空间的前景/中景/远景、左侧/右侧/中央、站在/坐在/靠近/远离哪个场景元素，以及角色与门窗、桌椅、道路、建筑、光源等关键环境物的相对位置] | [角色名：台词；无台词则写“无”] | [环境声 / 动作声 / 空间声效；默认无 BGM] |
| 02 | [景别] | [场景名] | [画面描述；必须包含人物与场景的位置关系] | [角色台词或“无”] | [音效设计；默认无 BGM] |
| 03 | [景别] | [场景名] | [画面描述；必须包含人物与场景的位置关系] | [角色台词或“无”] | [音效设计；默认无 BGM] |
| ... | ... | ... | ... | ... | ... |

## 视觉规范

### Medium Lock
> [完整的 Medium Lock 陈述句]

### Style Brief
- **Style keywords**：[关键词列表]
- **Color palette**：[主色 + 辅色]
- **Lighting**：[光照方向/质感/色温]
- **Mood**：[情绪关键词]
```

**填充规则**：
- 从 STEP 0 的分析结果中提取所有内容
- 角色描述在故事板概要文档中保持详尽；生成黑白分镜图时只提取少量轮廓特征，统一表现为线框人偶 / 火柴人动作模型
- 分镜列表按最终视频时长确定镜头数量：最短 15 秒写 8 个镜头；此后时长每增加 15 秒，增加 7 个镜头（例如 30 秒 15 个、45 秒 22 个、60 秒 29 个）
- 每个镜头的「画面描述」必须明确人物与场景的位置关系：说明角色在空间中的前景 / 中景 / 远景、左 / 右 / 中央位置，与关键场景元素（门窗、桌椅、道路、建筑、光源、道具等）的相对位置，以及角色之间的距离、朝向和遮挡关系（如适用）
- 每个镜头必须填写「角色台词」和「音效设计」；没有台词时写“无”，音效设计默认只使用环境声、动作声和空间声效，不添加 BGM

**生成后**：将故事板概要文档展示给用户，明确告知用户：

> “这是你的故事板概要文档，请审阅并编辑。你可以修改角色描述、调整镜头顺序、增删镜头、修改场景设定。确认无误后告诉我，我将基于这个文档生成视觉资产。”

**用户确认后才进入 STEP 2。**

## STEP 2 — 生成角色设定图

用户确认故事板概要文档后（如果用户编辑了文档，先重新读取最新内容），生成：

1. **角色设定图**（每个角色单独生成 1 张；逻辑名称：角色三视图 / 角色设定图）

- **比例**：默认 16:9；如用户明确修改比例，则以用户确认比例为准
- **模型**：推荐 `g-image-2`；如用户另有指定，以用户指定为准；如模型不可用，按模型路由规则请求用户确认替代模型
- **文件路径**：以 image agent 返回的 `image_path` 为准，不要重命名、移动或强制保存为固定文件名
- **图片内文字**：默认不在图片内生成任何文字、编号、时间戳、视角标签。镜头编号和说明放在 markdown 文档 / 表格 / 资产清单中。只有用户明确要求时，才在图片内加入文字。

### 2.1 生成角色设定图

用 **image agent** 为每个角色单独生成 1 张角色设定图，不要把多个角色合并到同一张设定图中。角色设定图用于记录完整角色外观，并供后续黑白分镜提取最小轮廓符号参考。

**Prompt 模板**：

```text
为单个角色创建一张角色设定图，画面为横版 16:9 构图，默认不包含任何文字。不要把多个角色合并到同一张图中。

角色：[角色姓名]
角色完整描述：[从故事板概要文档的该角色条目逐字复制外貌、服饰、标志性特征]

展示内容：
- 正面视图：[角色外貌+服饰+标志性特征完整描述]
- 侧面视图：[同一角色侧面外观描述]
- 背面视图：[同一角色背面外观描述]
- 1-2 张小尺寸半身变化：展示该角色的表情变化 / 动作变化，用于辅助理解角色性格和动作习惯
- 标志性动作：[该角色最典型的身体姿态、手势、站姿或动作习惯]
- 关键道具：[该角色的关键道具；如果没有则写“无道具”]

要求：
- 三个视图保持完全一致的服装、发型、体型和标志性特征
- 半身变化和动作变化必须保持同一角色身份，不改变发型、服装、体型或关键特征
- 关键道具必须与角色保持同一风格和比例
- 默认不要添加任何文字标签、编号、说明或 UI 标记

[Style Brief] + [Medium Lock]
```

**填充规则**：
- 每个角色必须单独生成 1 张角色设定图，禁止把多个角色合并到同一张设定图中
- 角色描述从故事板概要文档的「角色列表」逐字复制，**不可改写**
- 三个视图必须保持一致的服装、发型、体型
- 必须包含 1-2 张小尺寸半身表情变化 / 动作变化
- 必须展示角色标志性动作和关键道具；没有道具时写“无道具”
- 默认不要添加任何文字标签

### 2.2 展示结果

image agent 生成的图片通常会自动出现在画布上，不要重复调用 `hub_canvas_write_media_node`。

向用户说明：

> “这是角色设定图。角色设定图用于后续黑白分镜中提取最小轮廓符号参考。确认后我将生成完整的黑白分镜图。”

**用户确认后才进入 STEP 3。**

## STEP 3 — 生成黑白分镜图

### 3.1 确认宫格布局

默认每张黑白分镜图使用 **2x4 布局（8 格）**。如果用户没有明确要求其他布局，始终使用 2x4。

**默认连续分组规则**：

| 黑白分镜图 | 使用的 storyboard_brief 分镜范围 | 说明 |
|---|---|---|
| 第 1 张 | Shot 01-08 | 完整使用前 8 个分镜 |
| 第 2 张 | Shot 08-15 | 第 1 格复用上一张最后一格 Shot 08，再推进 7 个新镜头 |
| 第 3 张 | Shot 15-22 | 第 1 格复用上一张最后一格 Shot 15，再推进 7 个新镜头 |
| 第 4 张 | Shot 22-29 | 第 1 格复用上一张最后一格 Shot 22，再推进 7 个新镜头 |
| 后续 | 依此类推 | 每张从上一张最后一格开始承接 |

**关键连续性规则**：
- 从第 2 张黑白分镜图开始，每张图的第 1 格必须复用上一张黑白分镜图的最后一格。
- 复用格用于动作连续性承接，不算新镜头。
- 因此第 1 张黑白分镜图包含 8 个新镜头；之后每新增 1 张 2x4 黑白分镜图，只新增 7 个镜头。
- 这条规则必须和分镜数量规则一致：15 秒 8 个镜头，30 秒 15 个镜头，45 秒 22 个镜头，60 秒 29 个镜头。

### 3.2 自动扩展镜头数量

> **关键规则**：如果故事板概要文档中的分镜数量不足目标时长所需数量，必须先扩展分镜，再生成黑白分镜图。

**目标镜头数**：

| 最终视频时长 | 目标镜头数 | 黑白分镜图数量 |
|---|---:|---:|
| 15 秒 | 8 | 1 张 2x4 |
| 30 秒 | 15 | 2 张 2x4（1-8、8-15） |
| 45 秒 | 22 | 3 张 2x4（1-8、8-15、15-22） |
| 60 秒 | 29 | 4 张 2x4（1-8、8-15、15-22、22-29） |

**扩展流程**：

1. **确定目标镜头数**：根据最终视频时长确定目标分镜数量。
2. **计算缺口**：目标镜头数 - 现有镜头数 = 需要新增的镜头数。
3. **分析故事节奏**：读取现有镜头，理解画面推进和情绪变化。
4. **在合适位置插入新镜头**：
   - 故事开头 → 可插入开场氛围镜头
   - 场景转换处 → 可插入过渡镜头
   - 高潮前后 → 可插入情绪特写或环境镜头
   - 故事结尾 → 可插入收尾镜头或尾声画面
5. **设计新镜头描述**：风格与现有镜头保持一致，景别分布合理（避免全是同一景别）。每个新增镜头的「画面描述」都必须补足人物与场景的位置关系，明确角色位于场景中的哪个区域、靠近或远离哪些环境元素、与其他角色和关键道具的相对距离与朝向。
6. **更新文档**：将新镜头插入「分镜列表」表格，重新编号（01, 02, 03...）。
7. **同步画布**：调用 `hub_canvas_write_text_node` Patch 模式更新画布上的 markdown 节点。

### 3.3 生成黑白分镜图

用 **image agent** 按 2x4 分组生成一张或多张黑白分镜图。

**Prompt 结构**：

```text
风格参考：
仅使用【具体的黑白分镜图】作为整体动作关系、空间关系以及场景蒙太奇氛围的松散参考。【具体的角色设定板】仅作为最小的轮廓符号参考，不用于角色设计细节参考。

生成内容：
创建一张 16:9 横版简约黑白灰预览分镜图纸，排列为干净的 2x4 网格，共 8 个面板，使用细黑色分割线，自左向右阅读上排，再自左向右阅读下排。绝不显示任何可读文本：无标题、编号、标签、说明、对白、标志、水印、签名、UI 标记、字母或数字。

所有角色必须为简单的火柴人 / 线框动作模型，无面部特征，无服装细节。仅使用黑色线条、白色背景和浅灰色块用于深度和光感。环境保持极度简化。使用动作线和身体轨迹展示连续动作，避免箭头符号。每个面板必须清楚显示姿势、朝向以及与前一面板的连续性，像一个不中断的动作链，而非独立的姿势样本。

角色外观（所有面板统一）：线框人偶 / 火柴人动作模型 + 少量角色特征。
```

## STEP 4 — 确认提示词后生成视频

### 4.1 整理 Panel 级视频提示词主文档

生成视频前，只创建 / 更新一个 `video_prompt_list.md`。每张黑白分镜图对应一个 Panel。每个 Panel 用自然段描述整段动作链、台词和音效。用户确认该文档后再生成视频。

**`video_prompt_list.md` 模板**：

```markdown
# [项目标题] — Video Generation Prompts

## 项目信息
- **类型**：[剧情短片 / 预告片 / MV / 广告创意 / 竖屏短剧]
- **时长**：[总时长]
- **风格**：[视觉风格]
- **画面比例**：[默认 16:9；如用户明确修改则写用户确认比例]

## 视觉参考
- **角色设定图**：`[角色设定图路径，可多张]`
- **黑白分镜参考**：`[storyboard_bw_01.png]`，`[storyboard_bw_02.png]`...
- **Medium Lock**：[完整 Medium Lock]

## 声音原则
- **NO background music**：只使用环境声、动作音效、拟音、空间回响、必要静默和声画节奏；不写配乐、BGM、音乐氛围或歌曲。

---

## Panel x

视频参考角色的画风和形象：[只列出本 Panel 出现的角色。角色A【角色名称】的形象是……；角色B【角色名称】的形象是……；角色C【角色名称】的形象是……。描述参考 `storyboard_brief` 的角色列表进行简要提炼，用于统一视频画风，并确保角色名称与故事剧情中的角色名称一致。不出现在本 Panel 中的角色不要硬塞。]

画面的分镜参考黑白的简约故事板：`[对应黑白分镜图路径]`

故事剧情：
[从上一 Panel 的动作末态继续，将本 Panel 覆盖的所有镜头整合成一个连续自然段。必须写清动作链、情绪推进和关键事件，不要写成表格，不要逐镜头机械罗列。如果有角色台词，必须以「角色名：台词」的形式自然穿插在剧情段落中，不单独列出台词。]

声音设计：NO background music；[按环境声、动作声、空间声效、必要静默整合本 Panel 的声音设计。]

---

## 生成前确认
- 每张黑白分镜图 = 1 个 Panel = 1 段视频。
- 默认模型参数：`seedance2.0 / 1080P / [默认 16:9；如用户明确修改则写用户确认比例]`。
- 默认不添加 BGM，只使用环境声、动作声和空间声效。
- 后续生成视频时，每段都引用所有角色设定图，并分别引用对应黑白分镜图。
```

**Panel 分组规则**：
- `Panel x` 是通用模板；生成 `video_prompt_list.md` 时，必须按黑白分镜图顺序实例化为 `Panel 1`、`Panel 2`、`Panel 3`……
- 第 1 张黑白分镜图覆盖 Shot 01-08 → `Panel 1`
- 第 2 张黑白分镜图覆盖 Shot 08-15 → `Panel 2`，开头必须承接 `Panel 1` 的动作末态
- 第 3 张黑白分镜图覆盖 Shot 15-22 → `Panel 3`，开头必须承接 `Panel 2` 的动作末态
- 第 4 张黑白分镜图覆盖 Shot 22-29 → `Panel 4`，开头必须承接 `Panel 3` 的动作末态

**关键规则**：
- 视频生成前必须先让用户确认 `video_prompt_list.md` 主文档。
- 只创建 / 更新一个 `video_prompt_list.md`，不生成其他重复确认文档。
- 每个 Panel 都必须按以下顺序组织：`视频参考角色的画风和形象` → `画面的分镜参考黑白的简约故事板` → `故事剧情` → `声音设计`。
- 每个 Panel 的“视频参考角色的画风和形象”必须从 `storyboard_brief` 的角色列表中提取简要角色形象，并用角色A、角色B、角色C的格式继续罗列；该段用于统一视频画风，并让角色名称与故事剧情中的角色名称对应。

- 用户可以在确认前修改模型参数，包括模型、分辨率、比例、每段时长、是否生成声音等。

## 关键约束

- **故事板概要文档是信息中枢。** 所有生成步骤都从这个文档提取内容，不从对话历史中推断。
- **画布文档优先。** 用户可见、可编辑的画布 markdown 节点是主文档；如同时维护本地 markdown 文件，必须与画布节点保持一致。
- **角色设定图必须先于黑白分镜图生成。** 角色设定图是黑白分镜的最小轮廓符号参考，后续所有生成必须引用它。
- **黑白分镜目标镜头数大于文档镜头数时，必须先扩展文档再生成黑白分镜图。** 禁止跳过 STEP 3.2 直接生成镜头不够的黑白分镜图。
- **Medium Lock 是硬约束。** 每个生成 prompt 必须包含 Medium Lock 作为最后一句。
- **分镜画面描述必须包含空间位置关系。** `storyboard_brief.md` 的每个分镜都必须写清人物与场景的位置关系，包括角色在画面前/中/远景和左/右/中央的位置、角色靠近或远离的场景元素、角色之间的距离与朝向；后续黑白分镜和视频提示词必须继承这些空间关系。
- **黑白分镜角色表达。** 黑白分镜图中的角色统一使用线框人偶 / 火柴人动作模型，只保留少量角色特征用于区分角色，不复制完整外貌、服装、材质或颜色。
- **用户编辑优先。** 如果用户编辑了故事板概要文档，在生成前必须重新读取最新内容。
- **默认不在图片内生成文字。** 镜头编号、视角标签、时间戳和说明文字放在 markdown / 表格 / 资产清单中；只有用户明确要求时才写进图里。
- **推荐使用 `g-image-2`。** 用户指定模型优先；模型不可用时询问用户确认替代模型，不静默替换。
- **使用 image agent 生成图片。** 不要直接调用生图工具，通过 agent 统一管理。
- **不要重命名或移动生成文件。** 输出路径以 image agent 返回的 `image_path` 为准。
- **不要重复添加生成图到画布。** image agent 生成输出通常已自动上画布；`hub_canvas_write_media_node` 只用于外部导入、本地脚本或非生成管线产物。
- **视频生成必须等待用户确认提示词。** `video_prompt_list.md` 中的 Panel 级自然段提示词和模型参数确认前，不生成视频。
- **视频提示词主文档唯一。** 只生成 / 更新一个 `video_prompt_list.md`，不生成其他重复确认文档。
- **视频默认参数。** 用户未修改时，默认使用 `seedance2.0`、`1080P`、`16:9`；如用户明确修改比例则使用用户确认比例；每段时长按总时长 ÷ 黑白分镜图数量估算，并允许用户确认前修改。
- **视频引用规则。** 每张黑白分镜图对应生成一段视频；每段自动引用所有角色设定图，并引用对应黑白分镜图和对应 Panel 自然段提示词。
- **用户可改模型参数。** 用户可以在生成前修改模型、分辨率、比例、每段时长和声音设置；修改后以用户确认版本为准。
- **默认不添加 BGM。** 除非用户明确要求，否则不额外生成或添加背景音乐。
