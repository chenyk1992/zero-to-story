# 选题卡模板

> `scout.py card "<关键词>"` 会生成证据部分（表格 + 供给信息），下面这些**由你（Agent）填写**。

## 必须填的字段

### 切入角度（按请求数量，标注适配账号类型）

同一个热点可有多种讲法；比较时给有实质差异的角度，用户只要一条则选最适合的一条。下面是可选示例位置，不要求凑满。

- 角度 1（类型：____）：____
- 角度 2（类型：____）：____
- 角度 3（类型：____）：____

「适配账号类型」指这个角度适合哪种号：测评 / 教程 / 观点 / 跟做实测 / 案例拆解。
**只给这个号真正能做的类型**，不要凑数。

### 内容形式 + 开头 3 秒钩子

- 形式：录屏实测 / 屏幕演示 / 口播讲解 / 对比评测 / 跟做复刻
- 钩子（第一句话）：____

钩子的要求：**第一句就给出反常识或具体到能截图的东西**。
「今天聊聊 AI」不是钩子；「这个功能藏在一个二级菜单里，我找了 20 分钟」是钩子。

### 竞争度与难度

- 同题最新一条作品距今：____ 天（`card` 已给）
- 同题最强一条的播放量：____
- 素材是否需要真拍 / 能否用录屏替代：____
- **我的差异化在哪**（已有的都在讲什么，我多讲哪一层）：____

### tag 建议 / BGM 方向

- tag：____
- BGM（当前确有音乐需求时）：____

### 借势风险提示

- 该话题的**负面/争议**面：____
- 平台的**合规风险**（违禁词、敏感）：____
- **时效风险**：这个话题多久会过期：____

### 违禁词自检

用 `douyin-prohibited-word` 替代方案（自建词库）或人工逐句检查。
**脚本定稿前必须过这一关**，并在卡上写明检查结论。

---

## 交付格式

一张卡 = 一个选题。数量服从当前请求，开放比较时给少量不同方向；已有选题不重开候选菜单。
每张卡都要有：
1. 证据（脚本算的，不许改）
2. 本次选用的切入角度
3. 钩子
4. 差异化说明
5. 风险

最后给一条**推荐**：先做哪张，为什么。
