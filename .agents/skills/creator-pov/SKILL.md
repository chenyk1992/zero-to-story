# 真人记录创作

遵守[项目共享生产规则](../../../guides/ai-system-prompt.md)。

根据内容简述或参考素材，为vlog、口播、街访、对谈、教程、测评、日常记录等由真人自己或身边的人用手机拍的内容确定拍摄关系、人物真实感和视频提示词，包括真实记录风格的UGC推广。这类内容里的真人图片仅适用人物真实感部分。剧情短片、广告大片、纯产品、纯空镜和动画不使用本技能。交付所需拍摄说明或提示词，本技能本身不直接制作成片。

## 在项目中的定位与协作交接

- **独立调用**：用户需要 vlog、日常记录、探店测评、教程、街访、手持/支架手机口播或真人 UGC 种草的拍摄关系设计、人物真实感把控和手机实拍感提示词时，直接使用本 Skill；仅要求拍摄方案或提示词时止于文本交付。
- **与项目主责 Skill 的协同**：
  - 虚拟实拍/数字人连续口播需要“手机自拍、朋友跟拍、桌面支架日常记录感”而非棚拍演讲感时，[virtual-presenter](../virtual-presenter/SKILL.md) 可复用本 Skill 的拍摄关系与人物真实感规则；
  - 品牌与电商广告中的真人 UGC 测评/种草段落，由 [advertising-creator](../advertising-creator/SKILL.md) 统筹产品事实与合规边界，复用本 Skill 的手机实拍语法；
  - 叙事短片中的伪纪录片或手机第一视角片段，由 [zero-to-story](../zero-to-story/SKILL.md) 统筹故事板并复用本 Skill 写法。
- **生成与画布交接**：当用户明确授权进入视频生产时，遵守项目三项关键硬门（生成模式选择 T2VA/I2VA/FL2VA/Ref2VA、跨片段同镜续演的 `ACCEPT` 真实尾帧绑定、同期口播/后配旁白的声音方案），将单 Panel 创作事实与本 Skill 编写的手机实拍提示词交接给 [h3-prompt-writing](../h3-prompt-writing/SKILL.md) 与唯一生产入口 [canvas-workspace](../canvas-workspace/SKILL.md) 保存并执行。

## 拍摄关系
- 按内容在做什么、观众要看清什么，定下谁拿或支撑手机：自拍、镜前、朋友跟拍、固定机位、桌面第一人称、街访等。拿着手机不等于对镜自拍；镜子只在照镜子这个动作本身有意义时出现。确保动作所需的手可用；需要双手时使用支架或由他人拍摄。
- 镜头运动由拍摄关系推出：随手记录有轻微晃动和取景修正，跟拍有跟随感，固定机位画面不动；不把同一套效果复制到每段。
- 镜头变化要让观众看清动作、关系或信息。同一机位或连续跟拍写成连续描述；真正切换才写“切到……”并说明理由。需要分镜表时，镜头列写明是连续跟拍、同一机位继续还是切到近景。

## 人物真实感
- 真实感来自具体身份、正在做的事和生活逻辑，不靠降低画质或硬加瑕疵。人物要有与当前内容相关的持续状态、小动作和反应，用具体动作代替“自然”“松弛”这类形容词。
- 台词像人说话：短句、停顿、自我纠正、语气词；台词量给动作和反应留出时间，不写成广告口号。
- 不写美颜、磨皮、完美皮肤、模特感。面部是主体时保留自然差异，但不作为固定尾缀。有参考图时沿用同一身份和稳定外观，描述相关变化；没有参考图时建立简短人物设定。每个独立片段携带同一身份参考或必要稳定特征，保持服饰、声音、持续状态和说话人身份一致，变化须显式说明。

## 写进视频提示词
- 视觉描述用英文；台词和画面文字保持原语言、逐字写出，并注明说话人，区分画内同期口播、画外同期说话和后配旁白。
- 开头一句定手机记录基调和拍摄关系。画幅服从用户要求，仅在未指定时默认竖屏；竖屏可写“raw vertical smartphone footage”，横屏可写“raw horizontal smartphone footage”。说明谁拿手机、前置或后置、距离与高度或手机架在哪，以及视线看哪。避免与当前日常记录需求冲突的cinematic、studio lighting、shallow depth of field等广告片写法。
- 每个画面写清机位与构图、人物动作和状态变化、环境与实际光源、同步声音，以及台词落在哪个动作上。动作按先后和相对节奏推进，不写具体秒数或时间码；内容量匹配片段时长，过长顺序拆成独立片段，不压成步骤清单，也不为凑长度重复。
- 最多一两处与拍摄关系相符的可见不完美，例如转向窗户时曝光变化、凑近时对焦慢半拍。声音写环境声、动作声及同期说话实际的手机麦克风听感；后配旁白单独描述。配乐与字幕分别处理：未要求配乐时不加背景音乐，未要求字幕时不加字幕；各自服从明确要求。“不加字幕”不能删除用户要求的场景文字。
- 保持本技能的领域写法，不强套机械模板或无动机镜头编号。生成前核验可用能力支持的参考素材、时长和声音需求；不支持时调整方案，不擅自改变已确认意图。
