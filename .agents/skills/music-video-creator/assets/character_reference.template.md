## 完整人物卡生成提示词

以下提示词按用户角色设定图实例，与[通用模板](../../zero-to-story/assets/character_card_prompt.template.md)保持相同展示规格，只将来源改为 MV 创作计划。每个新建角色都使用完整模板，不以只拍正面为由删视图或半身变化；已有采用的完整设定图可复用。人物描述从本片计划逐字复制，不读取影视故事板。填写后只发送提示词正文，制作记录不送入图片模型；图片经 Canvas 确认执行，不另开提交入口。设定图 16:9 不改变 MV 成片画幅。

```text
为单个角色创建一张角色设定图，画面为横版 16:9 构图，默认不包含任何文字。不要把多个角色合并到同一张图中。

角色：[角色姓名]
角色完整描述：[从已确认 MV 创作计划的该角色条目逐字复制外貌、服饰、标志性特征]

展示内容：
- 正面视图：[角色外貌+服饰+标志性特征完整描述]
- 侧面视图：[同一角色侧面外观描述]
- 背面视图：[同一角色背面外观描述]
- 1-2 张小尺寸半身变化：展示该角色的表情变化 / 动作变化，用于辅助理解角色性格和动作习惯
- 标志性动作：[该角色最典型的身体姿态、手势、站姿或动作习惯]
- 关键道具：[该角色的关键道具；如果没有则写“无道具”]

要求：
- 三个视图保持完全一致的服装、发型、体型和标志性特征
- 半身变化和动作变化必须保持同一角色身份，不改变发型、服装、体型或关键特征
- 关键道具必须与角色保持同一风格和比例
- 默认不要添加任何文字标签、编号、说明或 UI 标记

[Style Brief] + [Medium Lock]
```
