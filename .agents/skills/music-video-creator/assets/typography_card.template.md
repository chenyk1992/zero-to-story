# MV 文字包装卡图片提示词

对应 MV / 文字系统版本 / 使用段落：
图片用途：[全片样式卡 / 具体文字事件图；样式卡不自动覆盖未展示的歌词]
覆盖的事件 ID、Shot/Panel 与逐项准确原文：[事件图必填；同原文同布局可复用]
目标画幅与视觉路线：
要展示的准确样例文字及类别：[选定歌词短句或视觉关键词，保留原语言；样例不是整首歌词时间轴]
主字族的可见骨架、字重、字宽、字距与读序：
主色、辅色、字面材料与边缘质感：
主字、印刷层、动作/前景层的视觉区别：[按路线使用，不重复复制同一字幕]
排版比例、负空间、前后层级与必要透视：
运动关键状态：[按需展示清晰主态与少量变化态，静态卡只说明视觉状态，不证明动画或同步]
引用的真实文字样式参考及保留范围：
与歌曲及全片美术的关系：[字体重量、材质、颜色为何适合当前音乐；不能用片名海报效果代替空间歌词系统]
对应镜头的构图依据：[事件图填写人物路径、承载区域和透视要求；卡片本身不画人物与场景，组合画面另用首帧模板]

生成一张独立文字包装参考图，只呈现已指定文字及其图形、材料和排版关系。不要画人物、实际场景、Logo、随机小字或无关词语。主态准确可读，装饰不破坏字形。若采用状态分区，分区用于展示同一文字系统，不代表实际镜头或额外视频输入槽。

制作记录（不发送为图片提示词）：
所选图片后端 / Canvas 节点与 run / 实际采用图片路径与版本：
检查：[指定字是否正确、主态是否可读、材质/层级是否符合文字方案]
后续用途：[供首帧图片生成引用 / 普通 R2V 的文字样式参考；明确不控制人物身份和场景]
实际输入核对：[最终 I2V 首帧是否清楚呈现本事件原文，或普通 R2V 的实际图片槽位；尚未绑定则标待完成]
