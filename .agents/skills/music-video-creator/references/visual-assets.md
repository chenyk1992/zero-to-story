# MV 视觉资产

按单镜控制需要制作资产。现有素材可用时直接复用；新图由用户选择已接入的本地 Qwen、当前宿主 imagegen 或现有文件。Qwen 由 Canvas worker 生成；imagegen 需要当前宿主真实工具。每张参考明确身份、服装、空间、构图、光色或媒介等用途，避免相互冲突的要求。

## 先做独立参考卡，再做单镜首帧

原 Skill 的“歌词卡”在本项目明确为文字包装卡，“空间卡”为场景参考卡。它们是实际图片资产，不能用文字计划、提示词草稿或生成中的节点代替。歌词原文与时间仍由文字方案和歌曲时间轴管理。

| 资产 | 生成模板 | 独立职责 |
| --- | --- | --- |
| 人物卡 | [人物参考模板](../assets/character_reference.template.md) | 身份、服装/结构与形态；无人物或无需身份连续时可省略 |
| 文字包装卡 | [文字卡模板](../assets/typography_card.template.md) | 样例原文、字形、材料、排版与图层；不混入人物和场景 |
| 场景空间卡 | [空间卡模板](../assets/scene_reference.template.md) | 空间、光色、材料、背景层次与行动路径；不混入主角和歌词包装 |
| 单镜首帧 | [首帧模板](../assets/scene_keyframe.template.md) | 把当前镜头需要的身份、环境和第 0 秒文字状态合为精确开场 |

采用原 Skill 的完整歌词贴字/拼贴路线时，在图片生产阶段落实文字卡和必要空间卡；已有符合用途的实际图片直接登记复用。纯无字作品不建文字卡，纯文字画面不建无用途的场景卡，用户明确跳过时记录替代依据。不要把“一张 I2V 输入”理解为不制作独立参考卡。

制作顺序：实际歌曲与上屏事件 → 全片文字系统和人物/空间美术 → 独立参考卡 → 具体歌词图与镜头共同设计 → 代表镜头首帧或普通 R2V 绑定 → 核实代表片段后扩展。样式探索可早于精确时序，但不能据此锁定歌词入出或批量生成通用镜头。具体歌词图的尺度、透视和布局取决于人物路径与摄影机，不先脱离镜头批量制作歌词海报。

使用所选图片后端经 Canvas 生成后，查看真实图片是否符合窄用途并记录采用版本。只有提示词时记为待生成；未接受卡的依赖按共享规则处理。相同空间可复用；相同原文且排版仍适用的文字图片可跨镜复用，不按每次重复演唱重做。采用图片支撑的生成式文字路线时，不同上屏原文必须有对应可读图片依据，不能因为字族相同就只用一张样式卡覆盖全曲。

## 人物视角与空间覆盖

两份音乐原 Skill 不强制三视图。按已经规划的景别、人物朝向和转动检查身份参考：正面/近景可建立脸与造型，但不证明侧脸、后脑发型、背面服装、鞋或包带左右关系已明确。需要侧拍、背拍、绕拍或转身且现有图无法支持关键特征时，基于已采用身份补必要侧面、背面或细节；跨多角度表演可制作正/侧/背视图，必要时保留脸部近景。只做正面短镜或现有图片已足够时不强制补卡；无人作品不造人物卡。

多视图中的脸、比例、服装和左右特征须一致；镜像图不能冒充另一侧身份事实。一张多视图板只占一个参考槽，板内人物是同一身份的不同视角，不是多人，也不是镜头顺序。它供身份参考或制作单镜首帧，不直接作为常规 I2V 开场，否则分栏/重复人物可能进入视频。补视角后只重新核对受影响镜头，不自动推翻已有有效素材。

环境卡确定空间与光色，不锁定所有机位或物件状态。岸上看桥的参考不能证明桥面机位已经存在，半开的门也不能直接作为关门状态起始的镜头。制作首帧时核实实际可见的行动路径、支点、光源和开场状态；保留同一空间的锚点，在构图需要时补机位，不机械地每镜新建空间卡。

## 文字样式卡与逐事件文字图片

区分三个用途：全片样式卡固定字形、颜色、材料和层级；独立文字事件图呈现当前镜头实际要显示的准确原文、行序和布局，两者不含人物与实际场景；带字镜头首帧则将文字与人物、环境、机位合成第 0 秒的真实画面。样式卡只有在原文和布局确实覆盖该事件时才能兼作事件图；含几个样例不代表其余歌词已经准备。采用 H3 生成式歌词路线时，先按[文字事件清单](../assets/typography_plan.template.md)逐项落实真实图片，核对字形后再供视频参考；已经满足原文与布局的首帧可直接作为该事件的图片依据，不重复造无用途的卡。保持已选重点句密度，不因此把全曲每句歌词都上屏。

每项记录“准确原文 → 已采用文字图片及版本 → Shot/Panel → 实际输入方式”。I2V 将该事件原文落实到最终首帧并检查可读性，原始文字卡只有真正用于制作该帧才算传递依据。若从无字首帧开始、稍后才出现新词，I2V 无额外参考槽，不能凭提示词宣称模型已参考该词图片；改用带对应文字图片的普通 R2V，或拆成以可读字态开场的独立 I2V 镜头，按真实能力选择。保留精确干净开场又需独立字层时可明确选择已落实的后期方案，不能静默替换创意。

普通 R2V 把该段需要的文字事件图接到实际 reference_image 槽，并说明准确文字、布局和材料保留范围。一张图若包含多个词，只在字形都足够清楚且当前镜头关系明确时复用；不塞整首歌词的密集缩略图。样式图和文字事件图均不证明模型会稳定保持文字，生成后仍须检查逐字正确、可读窗口、遮挡与同步。

I2V 路线：在图片后端实际支持的参考数量内，用人物卡、空间卡和文字卡制作一张首帧；原文、各卡保留范围和开场文字状态同时写清。当前已接入 Qwen 支持多图参考；其他后端以当前能力为准。视频阶段只上传最终首帧，其余卡保留来源关系，不伪称三卡直接输入 I2V。普通 R2V 路线：按真实参考槽位分别绑定需要的卡，并在 H3 提示词注明身份、环境、字形各自作用；不额外启用首帧引导。

普通 R2V 确需一张多机位参考时用[分镜板模板](../assets/storyboard_board.template.md)。板是单张参考图，不是多个输入槽；布局按镜头信息量选择，不按每个节拍画格。

I2V 首帧中直接放入实际主体、环境、机位和光线；人形保留外貌与服装，非人保留已定轮廓、部件数量/连接、材质与运动方式，无人物空镜不补角色。姿态、运动方向、画外余量、遮挡与摄影机路径须支持后续动作。首帧只直接约束开场，视频实际身份和空间延续需要回看。硬切换景可以用新的精确首帧；仅真实连续动作才依据已接受片段制作尾帧依赖。

歌词贴字或拼贴路线先完成[文字方案](../assets/typography_plan.template.md)，再定首帧。默认按生成式视觉设计文字区域、人物路径、前后景和遮挡过程，H3 连同人物与场景一同生成；首帧只显示第 0 秒应有的字。只有独立后期合成路线才要求干净底片或遮罩/跟踪素材。两种路线都须检查实际运动中的可读性与面部保护。

## 卡片采用与下游使用

卡片检查针对用途：人物检查身份和必要视角，空间检查光色与动作条件，文字检查准确字形及与歌曲视觉方向的适配。标题卡漂亮或单字可读不等于适合全片空间歌词；在代表镜头检查字体重量、材质、尺度和人物关系，必要时修订系统再扩展。静态变化态不证明实际动效成立。

记录采用资产版本、保留范围、不继承的内容及对应 Shot。资料关系、提示词里提及路径、实际媒体输入分别核对：`related` 边只表达资料关系，不能代替视频输入绑定。参考卡被用于制作首帧属于间接传递，视频模型直接收到的仍只有最终首帧。参考图是生成约束，不是训练模型或稳定文字的保证。生成式歌词与后期叠字分别登记，不重复覆盖同一事件。
