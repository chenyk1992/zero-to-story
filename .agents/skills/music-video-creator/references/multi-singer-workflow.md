# 多人轮唱与 MV 交接

用于女团、男团、混合组合等需要可辨演唱者的歌曲。单人歌曲、器乐、只写歌词和锁定画面配乐沿用各自入口，不自动增加翻唱。当前采用路线是：**采用原曲 → YuE2 完整翻唱候选 → MelBandRoFormer 分离 → 整句对齐与轮唱混音 → 完整版听审 → 角色绑定 → 最终主音轨驱动 H3 R2V → MV 后期**。

这是当前工具链已通过一首作品听审的方法，不是所有歌曲或男声组合的质量保证。Music 3 没有固定歌手或参考音色参数；YuE2 提取参考旋律后重新生成演唱和伴奏，风格描述与种子不能保证指定性别、人数、音色或跨歌曲身份。N 人项目可先规划原声加 N−1 次完整翻唱；只有实际可辨、自然且可用的候选才计入人数。候选不足时报告缺口，在已有授权范围内补候选，不把多次生成自动说成多人成功。当前 YuE2 权重为 CC BY-NC 4.0，按实际用途核实许可。

## 歌曲与角色规划

沿用已有采用原曲，或先经 Music 3 生成并听审主歌曲。记录主曲路径、哈希、实际时长、真实唱词及听审依据。已有歌曲不因需要多人而重写歌词、重做伴奏或更改旋律。

新歌在音乐创作稿记录人数、组合构成、每位成员的音色意图和独立乐句，安排清楚的轮唱与换气空间。给每位成员足以形成音色印象的完整乐句，避免只分一个词或把乐句切在元音中。独唱、轮唱、齐唱、回应与和声分别规划，均衡分配是创作目标，最终按实际可用演唱调整。不得为追求区分度强行拉开基频或整体移调。

角色名、A/B 标签、括号舞台/编曲说明保存在分工表，提交 Music 3 与 YuE2 的 `lyrics` 只保留拟唱的逐字正文，不能把这些标记唱进歌里。风格、人声与编曲要求写入 `prompt`。锁定原文不改写；如果原曲把拟分配的句子连唱，先找可用完整换气窗口。确需改歌词并重生成时，按新的创作范围与授权处理。

## 完整翻唱与筛选

1. 在画布为每份候选建立独立 `audio` 节点，选择 `comfy-yue2-music` / `yue2-3b` / `cover`；每份都引用同一采用原曲，使用匹配的完整歌词。分别记录声音风格、种子、原 run 和输出哈希。风格只作软条件，不指定不存在的 voice_id。
2. 每份候选是一次原生完整生成。上限需容纳歌曲；提前结束、缺句或未覆盖目标段落的结果按实际范围登记，不循环补长、不拼短片冒充完整翻唱。超出当前能力上限的长曲保留具体缺口。
3. 保留完整原版与独立完整翻唱供比较。听选音色差异、自然度、唱词、旋律/调性、节奏和句尾；只采用无明显嘶哑、刺耳、拐调或唱错的完整乐句。失败或未知核实原任务，不能自动重提。
4. 经画布 `comfy-singing` / `melband-seedvc-44k` / `separate` 分离原曲及候选，保存人声/伴奏的真实输出和源对应关系。分离模型共用，不从对话直接运行生成器。

ASR、旋律分析和模型音频理解只帮助定位，不能证明歌词准确、歌手可辨或口型同步；外部音频理解按其授权边界处理。采用混音中的几句不等于整份翻唱都通过听审。

## 保持原曲身份的确定性混音

优先保留**原曲的伴奏、节奏、结构、标志性 Hook、副歌和时间轴**，只替换已听选的独立乐句人声，不交替拼接不同翻唱的整段混合伴奏。分离残差可按 `原曲 - 原曲分离人声` 保留原始编曲细节；替换窗口内按下式处理：

`混音 = 原曲 + 窗口淡化包络 ×（对齐后的候选人声 - 原曲分离人声）`

这是确定性后期配方，不是新生成能力；不创建虚构 run。调用方使用可用的本地音频编辑工具或临时后期脚本，只处理已有授权媒体，不提交 Comfy。新产物放项目 `final/` 内独立版本目录，保留输入、参数、混音清单和输出哈希，再导入画布。不能用文件拼接器代替人声对齐和混音。

- 对齐完整乐句的起口、重读、停顿与句尾，允许温和的保音高时间伸缩；候选不能自然对齐时舍弃该句，保留原声。禁止用整曲统一拉伸掩盖不同句子的漂移，不用 `asetrate`、移调或滤波人为制造角色差异。
- 原曲、原曲分离人声与候选处理后统一采样率/声道，先检查分离轨的时间偏移。残余原声、串音或不匹配混响可能形成双人影子声；有问题的句子不进入采用版。
- 句首句尾在换气/低能量处做短淡化，匹配人声响度，必要时对最终整曲统一衰减防削波。淡化长度、伸缩、增益等按当前句子确定并记录；上一首歌的参数不是通用质量阈值。
- 原曲在非替换窗口继续保留；如做了全局增益、重编码或母带处理，记录变化，不能再宣称输出逐样本等同原曲。核对总时长、Hook、节拍和接缝，并提供完整混剪与原版供听审。
- 副歌可沿用原曲已有合唱/和声，或仅采用实际通过的齐唱层。相同旋律多轨叠加属于齐唱/加倍，不等于不同音高的和声；保留原曲合唱也不证明 N 位角色各有独立和声轨。需要真正独立和声时列出尚未具备的声部，不能冒充已完成。

最终混剪通过完整听审后，记录用户反馈、实际 FLAC/试听文件、哈希和采用范围。导入/确定性派生资产沿用真实采用证据，生成源 run 保留原结论，不借混剪 ACCEPT 覆盖完整候选的未知项。

## 冻结演唱者与时间轴

使用[多人音乐交接模板](../assets/group_vocals.template.md)记录最终主音轨、原曲、源 run/输出、分离轨、对齐/替换窗口、保护区间、处理参数和采用依据。将实际选中的声音来源映射到角色 ID；同一首歌里同角色保持来源一致，来源不足或某位角色尚无可辨独唱时直接注明。

逐句表使用最终主音轨毫秒位置，包含角色、来源、准确唱词、独唱/齐唱/和声状态以及歌词和起口的核实精度。保存可复查的人声素材、文件哈希及混音清单；ASR 候选词时间不得标成已核实口型时间。人数按项目填写，不写死五人。后期合成当前没有专属自动画布节点，清单是可复用的交接规范，不能声称页面会自动完成配唱。

## H3 与最终 MV

按[生产交接](production-handoff.md)把当前 Panel 的**最终采用混剪片段**实际接入 R2V `reference_audio`，核对文件、哈希、与计划 Panel 对齐的主曲源窗口和真实 `<Audio N>`，不另加前置或后置时间余量。冻结角色图与声源映射，逐句指出谁演唱、其他人何时不张口、轮唱交接或齐唱从何时开始；H3 使用 Panel 内相对时间。仅填 `song_window_ms` 不会自动裁剪音频。

单独干声只在真实音频槽位支持且有明确用途时另加，不能用未对齐干声或某份原始翻唱代替最终主音轨。混合参考音频本身不保证 H3 能识别声源归属，必须结合角色图片/标签与明确的演唱时序。多人同时张口、逐人音色及精确口型分别检查；证据不足保留未知，可按已定镜头意图使用集体表演或非近景，而不假装通过逐人近景同步。

最终后期沿用同版混剪主音轨，处理 H3 自带歌声/BGM 避免重复叠加。主音轨变化会使歌词、轮唱表、音频裁片、镜头绑定及相关同步结论失效，重新核对受影响范围；旧 MV 不能只换音轨就宣称口型已对齐。纯音频请求止于音频交付，不新增 MV 生产。
