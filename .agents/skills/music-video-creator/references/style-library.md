# MV 视觉方法

拼贴可通过材质层次、剪贴边缘、透视错位、节奏性图形与字体建立音乐感。先说明拼贴元素何时进入、如何变化和退出；固定镜数、固定画幅或全程高密度不作为要求。

## 复古拼贴 / zine / fashion performance

此路线适配 cool-music-video，主干是表演、印刷图层和版式共同作用。先选同一世界中的空间路线，例如后台通道 → 样张墙 → 摄影棚，而非随机堆场景；人物通过横穿、转身、借力、服装惯性与静点让空间发生变化，详见[导演方法](mv-direction.md)。

选择有限主色与一个必要强调色。黑、纸白、红是可用组合，不是所有歌曲的默认答案。纸张、复印、网点、套印、撕边、胶带与扫描错位按镜头选择；人物和主字保持可辨。文字按[文字导演](typography-direction.md)的 A/B/C 层分工；不要只在全局写“复古拼贴”。

| 方法 | 声音或动作触发 | 作用区域与结果 | 恢复点 |
| --- | --- | --- | --- |
| 半色调/复印毛边 | 军鼓或剪辑重音 | 纸层和主字出现印刷颗粒 | 保留清楚的主字与脸，下一节奏单位恢复 |
| 套印/扫描错位 | 短促高频或人声重音 | 字边、接缝局部偏移 | 读字窗口前归位，不让嘴眼一起错乱 |
| 撕纸/遮挡切 | 衣摆横扫或唱词落点 | 前景纸边揭开下一构图 | 接缝接住下一镜边缘后退出 |
| 非规则分栏 | 低频落点或副歌展开 | 主体、手部、材质与字块各占一栏 | 折回清楚的主构图 |
| 轮廓残影 | 连续小节奏或快速转身 | 清晰主像外留下少量轮廓 | 落点收回单一主体 |
| 字腔穿越/文字遮挡切 | 人物越过前景字块或主动作落点 | 人物从字腔负形穿过，字层掠过肩部/衣料 | 遮挡后恢复完整可读主字，保护眼睛与演唱嘴部 |
| 色块或纯文字画面 | 编曲抽空/段落转折 | 已建立的主字成为画面中心 | 读完后接下一次人声或动作 |

选用的方法必须落到具体 Shot，写触发、区域、结果、恢复。密度随音乐发展：开场建立主字与材质，中段变化，高潮由已建立的元素汇合，结尾回收。保留设计主导的镜头，让人物静点与图层运动形成反差；也保留干净呼吸段，不把所有效果叠满全片。融合其他美术时说明改变的是色彩、材料、字形还是空间；用户要求纯其他风格时不强加撕纸。

用户选择“融合进复古拼贴”时，保留纸面/印刷层与版式结构，让其他风格改变局部色彩、材料、字形、道具或光感；用户选择纯其他风格时重新建立视觉系统。人物媒介另行确定为写实、动漫或混合，不从歌曲类型推断。参考借用的是所选视觉机制，不无意复制原图人物、Logo、文字、场景道具或镜头顺序。

## 其他媒介与融合

动漫或游戏 PV 风格可用明确的角色轮廓、服装色块、场景色彩、画风媒介及动作线组织身份和速度。人物参考承担身份，场景参考承担空间，首帧承担精确构图；多参考需说明各自作用。写实、舞台、抽象及混合媒介同样按歌曲意图选择。

动态文字分为准确歌词与视觉关键词，具体依据[文字导演](typography-direction.md)。歌词贴字路线可以采用温暖、明亮或抒情设计，不必模仿 Trap 的字块冲击；低密度同样需要实际唱词、可读窗口与构图关系，不能用章节标题代替歌词。

温暖手绘方向可用清楚线稿、平涂色块和克制阴影保持角色轮廓，背景以水彩软边或局部纸张颗粒补充质感。衣角、树叶、云与水面按各自受力和距离运动，不让所有元素机械同拍摆动；主动作和歌曲情绪优先于装饰运动。

写实未来科幻方向先确定空间尺度、主光来源、材质和环境介质。反射、悬浮物、烟尘和声音服从场景设定；进出、抓握和操作保留可读路径。未来感可来自结构和尺度，霓虹、全息、磨损或阴暗只在当前视觉意图需要时采用。

把选择写回 MV 计划的视觉锚点与 Shot；歌曲时间轴、同步和表现方式由 MV 自身维护，不运行时引用故事流程的创作参考。
