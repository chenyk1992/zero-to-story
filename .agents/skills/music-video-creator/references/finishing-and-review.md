# MV 后期与成片验收

用户要求成片时，围绕采用主音轨建立覆盖采用窗口的粗剪，未就绪素材明确占位。正常速度观看并听审视觉发展、段落反差、高潮、重复、停留和结尾；结构成立后精修切点、歌词、必要的色彩匹配及音效。局部片段只检查相应范围，不强制整曲粗剪；主歌曲不自动拉伸或循环以适应视频。源视频声音按下文已核实的能力处理。

按[导演选定的事件](mv-direction.md#选择事件与乐句发展)观看实际素材，找到动作起势、完成或停住的源片位置，连同可用范围记入现有 Shot 表，再定成片入出点。计划中的“落脚卡点”、曲线或素材标签不能证明真实运动已经匹配；目标未成立时记录具体差异。演唱、舞步及多个镜内事件分别核对，不能靠统一调速证明同步。

整曲粗剪可以使用独立 preview 清单混合已有视频、静态图片与有字占位；正式 render 使用可恢复的分段缓存。具体格式、命令、进度统计及交付检查见[生产检查与结构预览](production-checks.md)，预览与技术渲染均不建立内容接受结论。

## 采用版本与后期交接

形成正式后期清单前，调用方读取当前 Canvas run 及其 review，核对 `decision=ACCEPT`、`output_path`、`output_sha256`，再核对实际文件哈希。剪辑必须使用 review 采用的真实版本；裁尾、配声等派生版已被采用时，不默认取 `outputs[0]` 或旧版节点素材。文件不存在、哈希不符、REJECT、INCONCLUSIVE 或 run 无法核实时，只暂停依赖该素材的正式采用，不能凭非空 run_id 放行。

主歌曲和独立音效也须有可追溯的实际采用依据。Canvas 生成素材沿用当前 review；用户导入歌曲/音效记录来源、选定版本、文件哈希与实际听审依据，不伪造 Canvas run。复用已有有效证据，不另建接受状态系统；所需核对结果引用到现有计划的采用版本与待核实字段。音乐时间轴的源文件、哈希和窗口须匹配所选版本，歌词听审状态也必须如实保留。

明确要求的候选粗剪可使用尚未采用素材并标注“预览/待核实”，不得据此交付正式成片。`validate_edit` 和 `render` 只验证媒体、哈希与时序等技术条件，不查询 Canvas 当前采用状态；合法的 REJECT/INCONCLUSIVE 音乐时间轴也可能技术渲染成功。调用方承担上述核对，渲染成功不升级内容结论；交付前仍须检查实际最终版本。

## 声音方案与实际能力

在现有计划中记录主歌曲、生成歌声/BGM、对白、动作声与环境声哪些保留或丢弃，需保护的成片时间窗口，以及实际来源和后期责任。按当前基础接口选择：

| 需要 | 当前可执行方式与条件 |
| --- | --- |
| 只保留主歌曲 | `native_audio_strategy=replace` 整体移除所有源视频原音，再加入主歌曲与明确列出的独立音效 |
| 保留全部原声并加主歌曲 | `mix` 整体保留源视频原音；先确认其中没有应丢弃的歌声或 BGM，实际听审叠加结果 |
| 只保留部分声音 | 使用真实独立音轨、可可靠提取的声音，或已按用途验收的派生片；`sound_effects` 可指定实际路径、哈希、源范围、成片位置和固定 `gain_db`。全局 mix/replace 不提供逐镜头原声选择，也不分离混合声源 |
| 对白或动作窗口降低音乐 | 需要已验证的额外确定性音量处理，记录窗口、实际处理文件与核对结果；当前 MV 清单没有主歌曲局部音量包络。底层整轨固定衰减不等于随对白窗口动态避让 |

例如丢弃生成歌声、保留关门声：可用 `replace` 加一条实际可用且已核对的独立关门音效。若关门声与歌声混在同一轨且无法可靠分离，这个方案尚未成立；说明缺少独立声音或可靠处理能力，不把提取整轨说成分离成功，也不静默删除必需声音。局部避让未验证时同样保留为具体缺口；其他独立工作可继续。

额外处理只写新派生文件并保留来源；若改变歌曲文件，重新绑定时间轴哈希和相关时序证据，不能套用旧版听审结论。实际听审须覆盖受保护窗口及窗口外，确认对白/动作清楚、无多余叠歌、无意外整曲衰减、截断或错位。

## 渲染与视听验收

确定性基础后期使用 `scripts/music_tools.py render --edit EDIT_JSON --output NEW_VIDEO`。`lfo.mv.edit.v1` 清单写实际 `music_timeline` 绝对路径、`width/height/fps`、按成片时间连续排列的 `segments`、`native_audio_strategy=replace|mix`、`sound_effects` 与 `text_events`。每个视频段记录已接受 Canvas `run_id`、实际文件路径和 SHA-256、源片 `source_in_ms/source_out_ms`、成片 `timeline_start_ms` 及 `transition=cut`。音效另记来源哈希、源片范围、成片位置与 `gain_db`。文字事件保留原歌时间，歌词须明确 `status=verified`；渲染时扣除采用窗口起点。渲染回执另记实际输出帧区间和 FFmpeg 源片裁切边界；帧数上限可能使输入裁切区间尾部没有进入成片，这两个值不冒充逐帧采用的源片时间戳。当前基础渲染只执行硬切、音轨处理和普通歌词/显式淡入或缩放文字；需要其他转场、人物遮挡或空间跟踪时，先核实真实工具能力并另行安排。

准确歌词以实际演唱和核对时序为准。只有逐句证据时安排逐句文字，不伪造逐字卡拉 OK。中英文及其他语言保留原文；文字留足阅读时间、避开重要表情。H3 已生成的空间歌词按实际画面检查字形、遮挡和同步，通过后直接随片段剪辑，不再重复叠同句字幕。要在已有底片上新增独立遮挡/透视字层时才需要额外合成能力，普通字幕渲染不能冒充。正面演唱和关键舞步不随意调速；切镜卡点与镜内同步分开检查。

实际演唱与用户锁定歌词不一致时，记录差异及其对采用的影响；不能为迁就候选音频改写锁定歌词，也不能用正确字幕掩盖唱错并宣称通过。获准修改歌词版本时，同步更新相关文案和时间轴。听不清的文字保持未知，只暂停依赖精确歌词的字幕或口型工作，其他不依赖该项的镜头仍可推进。

Panel 先按当前用途观看连续运动与声音，再确认身份、动作、风格、重要文字及需要的末态。硬切换场按计划判断；真实动作连续才检查相邻末态依赖。只给实际证据支持的内容 ACCEPT；妨碍用途的确认错误 REJECT；证据不足 INCONCLUSIVE。Canvas review 绑定当前实际文件和哈希。

最终交付文件完成后完整看听一次：歌曲是否完整且连续，画面与歌词/情绪关系是否成立，表演和动作是否可信，副歌重复是否有发展，切点与接缝是否自然，文字是否准确可读，结尾是否完成表达。记录影响观看的具体问题及最小修正范围；文件存在和参数数值不能代替成片观察。

交付同时核对已定画幅、成片范围与实际规格；保留全片脚本、各 Panel 完整提示词及歌词/文字方案的可访问版本，实际媒体路径对应当前采用结果。用户只要提示词时止于文本，只要代表测试时不将其标成完整 MV。

## 所选创作路线的验收

生成前检查文字图片覆盖与实际绑定，生成后再检查字形保持与时序。明确无字或独立后期字幕的镜头不强加图片参考；生成式重点句逐项有图，相同原文可以复用，不能用一张片名样式图宣称所有歌词已准备。

参考验收与视频验收分开：人物卡正面身份通过不等于侧背视角已覆盖，环境卡通过不等于每个机位/开场状态已成立，样式卡通过不等于具体歌词或空间运动已成立。生成前核对相关 Shot 的视角/状态、文字图和真实输入绑定；生成后检查实际转身身份、环境延续、文字变化与恢复。补充只针对已识别缺口，不因缺少标准三视图拒绝足够的身份素材，也不把不相关缺口扩大成整片阻塞。

用户指定 `music-video-subtitle-generator` 的精美效果或强冲击文字 MV 时，连续观看需覆盖字形/版式主次、声音触发的变化与恢复、人物/空间关系及全片高潮和回收。以选定路线在实际画面中的表现判断，不以文字数量、参考图存在或重复动画预设判定完成；已经确认的创作效果不足应记录具体差距，不能用技术通过提升为内容接受。

技术渲染通过后仍要对照创作目标检查，不用“有画面、有歌曲、有字幕”替代效果判断：

- 歌词贴字：实际唱词、入出时序和阅读窗口成立；文字在构图中有意安排，眼睛/重要表情/演唱嘴部得到保护。逐句字幕不能宣称逐字同步；片名、章节词不能冒充歌词。
- 空间与跨镜文字：运动中持续检查前后景、遮挡、透视及恢复，检查切点前后的文字方向、形状或颜色接力。只检查静态帧不足以证明跟踪和同步。
- 复古拼贴：关键镜头能看见主字、印刷层、动作层的分工，变化有声音/动作依据和恢复点；有版式主导段与呼吸段，人物表演没有吞掉图层设计。
- 表演与歌曲发展：动作有重心、接触、惯性与落点；相邻机位/空间/动作有选择依据，副歌回归形成发展；切镜卡点不自动证明镜内舞步或口型同步。

对照选定响应观察实际落点及前后发展，不要求每拍变化。精确控制按 [H3 控制边界](../../h3-prompt-writing/references/control-boundaries.md)核实；未落实的连续变焦/空间字层曲线不能登记成已执行效果，也不用音乐特征分数替代观察。

批量扩展前的代表乐句检查按[导演方法](mv-direction.md)进行。先检查方案、生成输入与实际执行路线，生产后检查该段实际效果；仅有方案不能宣称效果已验证。缺少听审/连续视频观察，或所选独立后期处理尚未落实时，将受影响结论保留为未知或预览；不以基础字幕简化版宣称原目标已完成。默认 H3 生成式效果不以额外空间合成工具为前置条件，但生成成功同样不能替代实际效果验收。

## 多人混剪主音轨

多人歌曲按[轮唱流程](multi-singer-workflow.md)保留原曲与翻唱来源、分离/对齐素材、替换窗口和保护区间。完整版混剪采用依据绑定最终文件及哈希，只有采用的乐句得到该用途的证据，完整候选未听审部分仍为未知。确认听感自然、音色可辨、歌词/旋律没有明显错误、伴奏与 Hook 仍能识别原曲，检查句间接缝与完整结尾；人数和角色归属单独核实，不能仅由 N 次生成推出 N 人成功。

MV 后期使用相同采用混剪，避免叠加 H3 自带歌声/BGM。原曲已有合唱不等于独立成员和声；实际视频按角色轮唱表核对演唱者、起口、停顿和同步，主音轨换版后重新核对受影响片段。旧成片与新歌曲时长不一致时保留已交付版本，按用户需要另行规划，不自动补长或替换。
