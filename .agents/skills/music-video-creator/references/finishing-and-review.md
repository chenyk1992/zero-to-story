# MV 后期与成片验收

歌曲到来或换版时，沿用主责按[内部复核](music-timeline.md#实际歌曲到来后的内部复核)更新的主源和声音版本，观看当前采用歌窗口及受影响段落。结合 mv_plan 检查整体风格、人物/空间/文字、音乐发展和局部拍法是否共同服务观看目标；已选的留白、重复或高能变化按其表达意图判断。

将所选风格、歌词、排字/包装与[声音互动](sound-image-interaction.md)纳入同一次视听检查：核对歌词准确与可读时间、画面主次和材料关系、声音响应及跨 Panel 的实际衔接。用真实媒体判断风格和效果，并按文字资产规则核对实际参考。

采用版技术路径按[共同后期交接](../../canvas-workspace/references/creative-handoff.md#采用版本与后期)，独立MV仍按本文件验证音乐同步与所选路线。现有MV仅加赞助落版保留本主责，只核对相关文字、时间/声音、接缝和实际新文件，不重建广告全片。

落版先辨明纯文字、Logo/图片叠加或新增片尾段：正式清单支持有限 ASS 文字、带哈希的静态图片段和定时透明图层，使用[现有后期字段](postproduction-manifest.md)。新增歌曲后片尾须显式记录 `postroll_duration_ms`，保留原歌窗口并默认补静音，不循环主歌或裁掉原结尾。preview 静态占位仍不替代正式 render；透视、跟踪或人物遮挡需另核实际工具。

用户要求成片时，围绕采用主音轨建立覆盖采用窗口的粗剪，未就绪素材明确占位。正常速度观看并听审视觉发展、段落反差、高潮、重复、停留和结尾；结构成立后精修切点、歌词、必要的色彩匹配及音效。局部片段只检查相应范围，不强制整曲粗剪；主歌曲不自动拉伸或循环以适应视频。源视频声音按下文已核实的能力处理。

按[导演选定的事件](mv-direction.md#选择事件与乐句发展)观看实际素材，找到动作起势、完成或停住的源片位置，连同可用范围记入现有 Shot 表，再定成片入出点。计划中的“落脚卡点”、曲线或素材标签不能证明真实运动已经匹配；目标未成立时记录具体差异。演唱、舞步及多个镜内事件分别核对，不能靠统一调速证明同步。

这一步用于实测与已授权后期，不反向要求多生成时间余量。沿用[生产交接的时长定义](production-handoff.md)：目标总时长为计划 Panel 合计，Canvas 与 Panel 一致；实测时长、动作或剪辑位置有差异时如实记录并核对处理范围，不自动裁切或变速凑目标。已有素材的授权选段与输入音频窗口提取仍可用。

整曲粗剪可以使用独立 preview 清单混合已有视频、静态图片与有字占位；正式 render 使用可恢复的分段缓存。具体格式、命令、进度统计及交付检查见[生产检查与结构预览](production-checks.md)，预览与技术渲染均不建立内容接受结论。

## 采用版本与后期交接

Panel 派生采用按[后期与采用状态](../../zero-to-story/references/video-qc.md#后期与采用状态)处理，已 ACCEPT 原 run 不覆盖；成片保留源并审实际最终文件。需要改绑已接受 Panel/尾帧版时报告缺口，不伪造 REJECT 或重提生成。

形成正式后期清单前，调用方读取当前 Canvas run 及其 review，核对 `decision=ACCEPT`、`output_path`、`output_sha256`，再核对实际文件哈希。剪辑必须使用 review 采用的真实版本；裁尾、配声等派生版已被采用时，不默认取 `outputs[0]` 或旧版节点素材。文件不存在、哈希不符、REJECT、INCONCLUSIVE 或 run 无法核实时，只暂停依赖该素材的正式采用，不能凭非空 run_id 放行。

主歌曲和独立音效也须有可追溯的实际采用依据。Canvas 生成素材沿用当前 review；用户导入歌曲/音效记录来源、选定版本、文件哈希与实际听审依据，不伪造 Canvas run。复用已有有效证据，不另建接受状态系统；所需核对结果引用到现有计划的采用版本与待核实字段。音乐时间轴的源文件、哈希和窗口须匹配所选版本，歌词听审状态也必须如实保留。

明确要求的候选粗剪可使用尚未采用素材并标注“预览/待核实”，不得据此交付正式成片。`validate_edit` 和 `render` 只验证媒体、哈希与时序等技术条件，不查询 Canvas 当前采用状态；合法的 REJECT/INCONCLUSIVE 音乐时间轴也可能技术渲染成功。调用方承担上述核对，渲染成功不升级内容结论；交付前仍须检查实际最终版本。

## 声音方案与实际能力

在现有计划中记录主歌曲、生成歌声/BGM、对白、动作声与环境声哪些保留或丢弃，需保护的成片时间窗口，以及实际来源和后期责任。按当前基础接口选择：

| 需要 | 当前可执行方式与条件 |
| --- | --- |
| 只保留主歌曲 | `native_audio_strategy=replace` 整体移除所有源视频原音，再加入主歌曲与明确列出的独立音效 |
| 保留全部原声并加主歌曲 | `mix` 整体保留源视频原音；先确认其中没有应丢弃的歌声或 BGM，实际听审叠加结果 |
| 只保留部分声音 | 使用真实独立音轨、可可靠提取的声音，或已按用途验收的派生片；`sound_effects` 可指定实际路径、哈希、源范围、成片位置和固定 `gain_db`。全局 mix/replace 不提供逐镜头原声选择，也不分离混合声源 |
| 对白或动作窗口降低音乐 | 在正式清单填写 `music_ducking`，成片零基窗口、相对增益及压低/恢复时间；只改变主歌曲，不压低独立对白或原声，重叠取较强值。详见[窗口约定](postproduction-manifest.md#对白窗口内压低主歌曲) |

例如丢弃生成歌声、保留关门声：可用 `replace` 加一条实际可用且已核对的独立关门音效。若关门声与歌声混在同一轨且无法可靠分离，说明缺少独立声音或可靠处理能力，不把提取整轨说成分离成功。对白窗口来自真实音轨，估计值不冒充已测时码；源歌含对白时不能靠压低整条主歌保护其中对白。

后期只写新文件并保留来源；输出包络不改变采用源歌与时间轴哈希。若另外更换歌曲文件，重新绑定哈希和时序，不能套用旧版证据。实际听审覆盖窗口内外与渐变，确认对白/动作清楚、窗口外恢复、无叠歌、截断或错位。

## 渲染与视听验收

确定性基础后期使用 `scripts/music_tools.py render --edit EDIT_JSON --output NEW_VIDEO`。`lfo.mv.edit.v1` 清单写实际 `music_timeline` 绝对路径、`width/height/fps`、按成片时间连续排列的 `segments`、`native_audio_strategy=replace|mix`、`sound_effects` 与 `text_events`。每个视频段记录实际文件路径和 SHA-256、源片 `source_in_ms/source_out_ms`、成片 `timeline_start_ms` 及 `transition=cut`；生成视频引用已接受的 Canvas `run_id`，导入/拍摄视频以 `source_note` 记录来源、选定版本和用途证据。静态图片段、定时 Logo、对白窗口音乐包络与显式歌曲后片尾按[正式后期字段](postproduction-manifest.md)填写。音效另记来源哈希、源片范围、成片位置与 `gain_db`。文字事件保留原歌时间，歌词须明确 `status=verified`；渲染时扣除采用窗口起点。渲染回执另记实际输出帧区间和 FFmpeg 源片裁切边界；帧数上限可能使输入裁切区间尾部没有进入成片，这两个值不冒充逐帧采用的源片时间戳。当前基础渲染执行硬切、静态图片段/图层、音轨处理和普通歌词/显式淡入或缩放文字；需要其他转场、人物遮挡或空间跟踪时，先核实真实工具能力并另行安排。

准确歌词以实际演唱和核对时序为准。只有逐句证据时安排逐句文字，不伪造逐字卡拉 OK。中英文及其他语言保留原文；文字留足阅读时间、避开重要表情。H3 已生成的空间歌词按实际画面检查字形、遮挡和同步，通过后直接随片段剪辑，不再重复叠同句字幕。要在已有底片上新增独立遮挡/透视字层时才需要额外合成能力，普通字幕渲染不能冒充。正面演唱和关键舞步不随意调速；切镜卡点与镜内同步分开检查。

实际演唱与用户锁定歌词不一致时，记录差异及其对采用的影响；不能为迁就候选音频改写锁定歌词，也不能用正确字幕掩盖唱错并宣称通过。获准修改歌词版本时，同步更新相关文案和时间轴。听不清的文字保持未知，只暂停依赖精确歌词的字幕或口型工作，其他不依赖该项的镜头仍可推进。

按当前用途观看 Panel 的连续运动与声音，核对身份、动作、风格、重要文字及实际依赖的末态。按共享规则对当前文件和哈希记录 ACCEPT、REJECT 或 INCONCLUSIVE。

最终交付文件完成后完整看听一次：歌曲是否完整且连续，画面与歌词/情绪关系是否成立，表演和动作是否可信，副歌重复是否有发展，切点与接缝是否自然，文字是否准确可读，结尾是否完成表达。记录影响观看的具体问题及最小修正范围；文件存在和参数数值不能代替成片观察。

交付同时核对已定画幅、成片范围与实际规格；保留全片脚本、各 Panel 完整提示词及歌词/文字方案的可访问版本，实际媒体路径对应当前采用结果。用户只要提示词时止于文本，只要代表测试时不将其标成完整 MV。

## 所选创作路线的验收

批量扩展前，按[导演方法](mv-direction.md)检查代表乐句的方案、实际输入与执行路线；生成后查看所选路线在真实片段中的效果。文字图片准备与画面效果分开核对：生成前逐项绑定生成式重点歌词的准确原文、图片版本、Panel 和槽位；同一原文可复用图片，无字镜头及明确由后期制作的字幕不要求歌词图。生成后检查字形保持、时序与可读性。

连同实际歌曲窗口观看所选路线的发展，按适用项核对：

| 路线 | 观察重点 |
| --- | --- |
| 歌词与空间文字 | 唱词及入出时序准确，阅读窗口充分；保护眼睛、重要表情和演唱嘴部。逐句证据只支持逐句字幕；片名和章节词与歌词区分。连续运动中的前后景、遮挡、透视、恢复，以及切点前后的方向、形状和颜色接续。 |
| 文字版式拼贴 | 主字、印刷层、动作层（A/B/C）的分工清楚；变化有声音或动作依据并回到可读状态；版式主导段和呼吸段服务乐句，人物表演与图层设计相互支持。 |
| 拼贴表演 | 按[实际观看重点](collage-performance-direction.md#跨段与实际观看)检查人物意图、景别、重心/眼神与图层回应；区分静态拼贴、连续表演和群体舞步。选用独立演员层时核对动态边缘、裁切/缩放及 RGB/matte 时间对应。 |
| 表演与歌曲发展 | 检查动作重心、接触、惯性与落点，相邻机位/空间/动作的发展，以及副歌重复时主次关系是保持还是变化。切镜卡点、舞步和口型分别核对。 |

长镜、停顿和重复段可以保持原样，按作品表达判断，不按变化次数评分。用户指定 `music-video-subtitle-generator` 的效果时，观察字形/版式层级、声音触发、人物/空间关系、高潮及回收。资产卡按其身份或样式用途核对；新建完整人物卡按[完整设定图模板](../assets/character_reference.template.md)检查单角色、16:9、三视图、1–2张半身变化及标志动作/道具，再检查相关镜头的身份与造型。精确控制依[H3 控制边界](../../h3-prompt-writing/references/control-boundaries.md)确认；缺少连续听看或所选后期尚未完成时，将相关结论记为待核实。

## 多人混剪主音轨

多人歌曲按[轮唱流程](multi-singer-workflow.md)保留原曲与翻唱来源、分离/对齐素材、替换窗口和保护区间。完整版混剪采用依据绑定最终文件及哈希，只有采用的乐句得到该用途的证据，完整候选未听审部分仍为未知。确认听感自然、音色可辨、歌词/旋律没有明显错误、伴奏与 Hook 仍能识别原曲，检查句间接缝与完整结尾；人数和角色归属单独核实，不能仅由 N 次生成推出 N 人成功。

MV 后期使用相同采用混剪，避免叠加 H3 自带歌声/BGM。原曲已有合唱不等于独立成员和声；实际视频按角色轮唱表核对演唱者、起口、停顿和同步，主音轨换版后重新核对受影响片段。旧成片与新歌曲时长不一致时保留已交付版本，按用户需要另行规划，不自动补长或替换。
