# 声音与画面的互动方法

供故事、MV、广告、片头及MG按需复用，成果返回各自主源。本文补声音怎样改变注意、材料感与情绪，不重建[音乐事件选择](mv-direction.md#选择事件与乐句发展)、[锁定画面配乐](music-direction.md#锁定画面配乐)或[跨Panel声音交接](../../canvas-workspace/references/creative-handoff.md#跨panel文字声音与状态)，不新增音频分析器、自动卡点或渲染能力。

## 先选关系，再考虑声音种类

从本段希望观众听见或暂时听不见什么出发。已采用歌、原片、对白和用户无音乐决定优先；不从包装风格自动分配BPM、乐器或音效数量。音乐可推动动作，也可持续铺底、与画面形成反差，或完全缺席；安静不等于需要补声。

| 声画关系 | 可以怎样创作 | 克制与高能都能保留的落点 |
| --- | --- | --- |
| 先声后形／声音引出发现 | 先听到门外摩擦、远处列车或一个有依据的音乐变化，画面稍后揭示来源或关系 | 克制版让注意先转移；高能版可让声音引出尺度跃迁。未揭示前不凭声音提前暴露必须隐藏的真相 |
| 接触与材料回答 | 手指压纸、金属落台、布料擦过字面，声音突出重量、粗糙或柔软；允许声音只在关键接触处显现 | 轻触可近而清楚，强动作可带明显惯性与衰减；声音和动作有来处，不让所有材料共用同一个whoosh |
| 视觉先行／延迟回响 | 字形或人物动作先停住，再由尾音、空间回响或后续配器使意义落定 | 延迟本身是设计时，标明谁先谁后；不把计划错拍自动修成同步，也不把未经核实的偏差美化成设计 |
| 留白与让位 | 在一句话、一次读字或一个触感动作前后减少音乐/音效，让人物或材料成为注意中心 | 可保留完整安静段，也可在高能释放前收住。保护对白、句尾和有作用的环境声，具体混音另按实际能力 |
| 节奏接力与有意不响应 | 一次乐句由人物承接，下一次由字层或材料承接；也可让重拍经过稳定画面，等待旋律或语义的转折 | 对比来自主导关系，不是每拍切镜。已有曲目不改写，重复段可以保持，也可以扩大尺度或改变主导层 |
| 声场远近与尺度 | 同一真实来源的清晰度、空间感或尾音随视点改变，近处小接触可对照远处大空间 | 近声不必响、大景不必轰鸣；具体声像、混响或分层混音须有真实工具，H3描述不是已完成的混音工程 |

比如“还亮着”这一原创示例短句可以在旋律尾音中稳定显示，让远处灯光延续等待；也可在已核实的乐句再进入时由反白字块接管构图，随后静下来。区别来自听觉关系和视觉落点，不靠加快所有表情或为每个字配一声。

## 把意图写成可以交接的事实

在当前Shot、音乐响应或声音栏中，按需要合并记录：声音依据及核对状态 → 相对或实际时点 → 谁响应、谁保持 → 读字/接触/情绪落点 → 结束或跨段继承。已有事件ID、准确原文和源版本直接引用；无变化或无声音时写清保持的关系即可，不为此建cue台账或增加必填字段。

有实际歌曲/原轨时绑定实际版本和源窗口，已核实的事件与候选时点分开；尚无音频时只写声音设计和估计窗口，不能冒充实测拍点。音乐、源视频、成片与Panel时钟的换算沿共同交接，不因声音方法新增前置时长或强行移动锁定切点。

## 生成与后期分别承担什么

分配给H3的环境、接触或音乐意图进入相应正文/声场；已经交后期的歌曲、旁白和独立音效不再让H3重复生成。要精确保留原轨或实现确定的压低/恢复，按[实际声音能力](finishing-and-review.md#声音方案与实际能力)记录真实声源、保护窗和已核实工具。生成音频参考不等于保留原轨，混合声轨不等于已有独立材料音；能力缺口只影响相关处理。

同一声音跨Panel时沿既有源窗口和当前播放位置继续，图像尾帧不携声。原轨已含目标声音时，先确认是否需要独立增强，不叠加重复声或重新触发同一次接触；有意声画错位需与事故性错位区分。方法选择不授权生成、试听或修改已采用曲目。

实际观看和听审时，看声音是否使发现、触感、停留或释放成立，是否保护所选文字与对白，前后是否无意重起或叠加。按当前用途一次判断，既不以音效数量评分，也不以候选拍点、轨道存在或写了cue证明同步；未生成时只完成方案与交接对照。
