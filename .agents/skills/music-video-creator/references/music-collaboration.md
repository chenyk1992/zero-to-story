# 音乐与 MV 的分阶段协作

采用[共享职责与最小交接](../../../../guides/ai-system-prompt.md#职责与最小交接)。主会话维护锁定歌曲、用户要求与最终责任，阶段主做只接当前版本和必要素材。纯歌词、音乐方案、局部后期以及受托的锁定画面配乐按原范围结束。

| 阶段 | 分工与交接 |
| --- | --- |
| 音乐创作与版本采用 | 主做交创作稿或当前真实候选。纯音频交付及新制 MV 主歌曲采用时，先对当前拟采用的完整歌曲或器乐做首次听审，再由主责对照歌词、主题、声部、编曲和实际用途完成现有听审。多人轮唱用最终完整混剪，角色归属由拿到声源表的主责核对。导入歌曲或继续制作可复用同一音轨和采用范围内的有效听审证据。 |
| 时间轴、分镜与结构预览 | 主做根据同版实际音轨、窗口与已核的音乐事件发展画面，交给下一阶段对应 Shot 和素材。复用已有整曲结构预览观察段落与乐句的关系；有占位时只观察能看到的结构。监督在重要交接或要求变化时核对来源、主歌版本、窗口与交付目标。 |
| Panel 生成前 | 审核者只接当前 Panel 的分镜、完整提示词、真实素材、已定模式与歌曲窗口。核对可见演唱是否接入同窗原轨、台词与槽位是否相符、文字及动作是否和本乐句冲突。具体差异交主做处理；已有[提交前检查](production-checks.md#当前-panel-的提交前检查)与授权继续适用。 |
| 完整 MV 交付 | 主做形成实际观众版，交独立审核者做首次视听。先保存原始观察，再由主责对照采用歌曲、时间轴和当前计划完成[视听验收](finishing-and-review.md#渲染与视听验收)。只替换落版等局部工作时检查改动窗口及相邻接缝；正式记录新版首次观察时另开新实例。 |

监督核对明确要求和实际证据。代理仅处理已有授权内的局部分歧，例如反复副歌是否需要换景；需要替换锁定主歌或改变交付目标时交回主会话。审核、监督和代理返回材料位置、依据、影响与未知，由主责处理修订与采用。

## 独立听审与成片观察

| 类型 | 实际给观察者的材料与问题 |
| --- | --- |
| 歌曲 song | 一份拟采用完整音轨与[歌曲中性问题](../assets/song_blind_review_prompt.txt)。重点听记住的乐句、实际唱词、可辨声部和结尾。 |
| 器乐 instrumental | 一份拟采用完整音轨与[器乐中性问题](../assets/instrumental_blind_review_prompt.txt)。观察音色、节奏、回返和收束。 |
| MV mv | 一份实际最终观众版和[MV 中性问题](../assets/mv_blind_review_prompt.txt)。保留最终字幕与音轨，观察声音和画面如何互相改变注意力。 |

各次独立观察使用干净上下文。只传上表所列的一份媒体和对应问题，不交创作稿、外部歌词、角色映射、音乐时间轴、计划、文件原名或旧结论。听过源歌或看过预览的观察者可做定向复查；最终 MV 的首次视听用新实例，不把歌曲听审当成成片观察。媒体保留作品本身的声音与文字，导出时移除制作注释、内部附轨与透露答案的元数据。没有能观察相应媒介的独立入口时，记录覆盖缺口，继续可完成的专业核对。

可复用[独立媒体观察脚本](../../zero-to-story/scripts/blind_review.py)。下列命令只生成离线准备报告。正式调用按实际外部媒体分析授权去掉 --prepare-only，并指定新报告路径；没有授权或限定离线时不发送。

~~~powershell
./.venv/Scripts/python.exe .agents/skills/zero-to-story/scripts/blind_review.py --profile song --audio "<最终候选.flac>" --output "<项目目录>/reviews/<版本>-song-prepare.json" --prepare-only
./.venv/Scripts/python.exe .agents/skills/zero-to-story/scripts/blind_review.py --profile instrumental --audio "<最终候选.flac>" --output "<项目目录>/reviews/<版本>-instrumental-prepare.json" --prepare-only
./.venv/Scripts/python.exe .agents/skills/zero-to-story/scripts/blind_review.py --profile mv --video "<最终MV.mp4>" --output "<项目目录>/reviews/<版本>-mv-prepare.json" --prepare-only
~~~

报告绑定实际记录的文件与摘要，先保存独立观察，再在现有采用记录或 MV 交付记录里引用。观察提出的唱词、声部、片中文字或同步疑点，用实际媒体和已定要求复核。切点、镜内卡点和口型各看实际证据，覆盖不足记未知；报告不直接写入 ACCEPT。媒体超过限制时，遵守既有授权另备完整观察副本，记录与原件的对应关系。分段或抽帧只用于局部判断。
