# MV 导演方法

先写一句作品主张：从歌曲开头到结尾，观众的感受或理解发生什么变化。选择能发展的视觉母题，如人物关系、物件、空间、光线或动作。歌词可由表演、叙事、隐喻或反差表达；纯表演、纯意象和器乐片都成立。

按实际乐句和情绪变化决定景别、空间、视觉密度、镜内运动与切镜频率。重拍可触发动作或画面变化，也可留在安静画面中形成对照。副歌重现时，检查视角、规模、表演或母题是否发展；有意重复同一画面时说清表达作用。开场建立听觉与视觉身份，结尾跟实际尾音及作品意图收束。

每个 Shot 写明所在歌曲时间、观众新获得的信息、主体与可见动作、起止构图、剪辑进入和退出理由。关键开场构图、跨空间或服装变化、精确卡点和独立替换需求，适合分别生成；同一空间内连续表演可组成一个 Panel。为将来选段记录可用动作区间与裁切余量。

表演根据演唱内容、呼吸、身体重心及段落情绪设计。正面演唱、舞步重音和关键动作各自标注同步要求，不能靠歌词提示词证明吻合。优先保留有观看理由的镜头，给信息和情绪留停留时间。

## 音乐怎样改变画面

把听到的具体事件写成“声音依据 → 视觉选择 → 可读落点”，同时记录时序证据。不能只填 BPM、情绪和相同长度的镜头。以下是选择方法，具体时间来自实际歌曲：

| 音乐事件 | 可选择的画面响应 | 文字与剪辑关系 |
| --- | --- | --- |
| 弱起、人声入句 | 从遮挡后进入、视线抬起、镜头靠近 | 句首出现，留出读完短句的窗口；未必切镜 |
| 底鼓或低频落点 | 落脚、转身落定、空间尺度打开 | 主字压入或构图换重心，随后稳定 |
| 军鼓、拍手 | 肩背急停、机位跳切、服装甩线 | 套印偏移或字块切入，恢复清晰主层 |
| 密集高频、快速咬字 | 细小手腕/步态变化、前景掠过 | 局部纹理短促变化，避免整句高速闪烁 |
| 留白、换气、编曲抽空 | 身体停住、空镜或版式主导 | 保留可读字或撤空画面，给下一段留反差 |
| 副歌展开、重复 Hook | 景别/空间扩大、动作弧线完成 | 主字族放大或层级展开，重复时有一次可见发展 |
| 尾音、最终重音 | 完成动作与最终构图 | 回收主字族/母题，读完后随尾音结束 |

每个段落明确谁主导：人物、场景、文字或静默留白；给另几层安排从属关系。高潮不等于所有层同时变快。叙事片段同样要说明音乐为何在此进入这一场景，避免“完整故事慢镜头 + 任意配乐”。

## 表演与空间调度

有人物表演时，按歌曲挑选路径步态、轴线转向、服装惯性、空间借力、双人换位或微表情等动作族。每镜一个主要动作链：进入路径 → 起势/重心 → 发力 → 接触或穿越 → 惯性/落点 → 镜头响应。不要用“酷炫舞动、手势卡点”替代过程。

例如人物沿门廊斜线走入，落脚后以肩带动半转，衣摆晚于身体扫过前景，镜头侧移接住停身；下一镜可以在同一世界的台阶改变机位与身体轴线。场景提供纵深、横向路径、高低关系或遮挡支点，不能只换背景墙。动作幅度服从歌曲和角色；抒情段可用呼吸与视线，不强塞舞蹈。

检查相邻镜头的动作族、运动方向、空间支点、机位高度和前后景关系是否有发展。有意重复保留音乐理由；不要全程冲镜头、伸手遮镜或匀速行走。大动作后留静点，让衣料/呼吸完成惯性；文字和版式在静点可成为主角。面向镜头表演不自动等于对嘴演唱，演唱只在确有用途与同步验证方案时安排。

## 跨镜衔接

跨镜接缝按需要写前后两端：前镜退出动作/运动方向/文字状态 → 音乐切点及原因 → 后镜进入动作/方向/文字状态；身份服装和约定光色保持一致，场景变化有音乐或表达理由。演唱特写优先在换气、停顿或可接续的位置切，若唱词中途切到另一演唱特写需有实际口型接续依据；切到不演唱的生活镜头可让主歌继续，不机械禁止所有句中切镜。调速不能自动修复唱词或多个镜内节拍的错位。生成后再依据真实出入状态选取剪辑点，计划中的匹配切不等于接缝已经成立。

## 代表乐句先验证

选择一个能代表所选路线的乐句；文字/拼贴路线应覆盖一次可读停留、一次动作或图层变化及一个镜头接缝。先完成该段 Shot、文字事件、首帧布局与执行责任。默认生成式路线先核对 H3 完整输入并在已授权生产中验证实际片段；独立后期路线才做相应局部合成试验。成立后再扩展同类镜头，不另加用户批准门。

不能听到歌曲时可准备暂定美术与构图，不把候选 BPM 当作已验证节奏；不能靠先批量生成通用慢镜头来解决音乐未知。明确授权的预览可按候选时间制作并标明局限，精确歌词、口型与镜内卡点保持待核实。
