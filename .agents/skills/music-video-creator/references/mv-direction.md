# MV 导演方法

从当前 MV 主源继承按[风格方法](../../zero-to-story/references/style-selection.md)采用的媒介、美术与整体气质，再按全曲发展组织剧情、表演、意象、文字及声画关系；整体方向未定时先结合歌曲和用户想法推荐，已有选择不重问。音乐类型、视觉风格与镜头技巧分别判断：抒情歌可以有高能段，拼贴可留白，国漫不预设同一种运镜或表演幅度。已定词曲与实际音频依据保持原范围。

歌曲到来或换版后按[内部复核](music-timeline.md#实际歌曲到来后的内部复核)更新声音依据与相关表达，导演层继续在已选方向内创作。

按需复用[反转](../../short-drama-screenwriter/references/reversal-design.md)、[喜剧拍法](../../zero-to-story/references/sitcom-direction.md)、[表演](../../zero-to-story/references/performance-direction.md)、[时间效果](../../zero-to-story/references/time-effects-direction.md)、[对称空间](../../zero-to-story/references/symmetric-storybook-style.md)、[海报/网格动效](../../visual-design-creator/references/layout-motion-handoff.md)。方法写入现有Shot/音乐响应，不补商品或影视蓝图，保持已采用歌窗口。

先写一句作品主张：从歌曲开头到结尾，观众的感受或理解发生什么变化。选择能发展的视觉母题，如人物关系、物件、空间、光线或动作。歌词可由表演、叙事、隐喻或反差表达；纯表演、纯意象和器乐片都成立。

按实际乐句和情绪变化决定景别、空间、视觉密度、镜内运动与切镜频率。重拍可触发动作或画面变化，也可留在安静画面中形成对照。母题可以改变含义，也可以通过停留、回返或稳定构图积累力量；副歌重现时，让视角、规模、表演或母题依作品意图发展，有意重复本身也可承接情绪。音乐与画面可以同向、互补、形成反差，或各自发展一段；除演唱、歌词及已定卡点等实际同步需要外，不必让每个声音事件都触发画面变化。开场建立听觉与视觉身份，结尾跟实际尾音及作品意图收束。

每个 Shot 写明所在歌曲时间、主体与可见动作，并说明它在信息、情感、表演、声画关系或母题发展中的作用；作用也可以是停留、重复或沉默，不要求每镜新增剧情信息。按需要注明起止构图与剪辑进入、退出理由。关键开场构图、跨空间或服装变化、精确卡点和独立替换需求，适合分别生成；同一空间内连续表演可组成一个 Panel。起势、停留和收束计入已定 Panel 时长，不增加时间余量后裁切。生成后记录实测可用动作区间、接缝与计划的差异；已有素材的授权选段另记真实入出点，按[生产交接](production-handoff.md)换算时间。

表演根据演唱内容、呼吸、身体重心及段落情绪设计。正面演唱、舞步重音和关键动作各自标注同步要求，不能靠歌词提示词证明吻合。优先保留有观看理由的镜头，给信息和情绪留停留时间。

## 音乐怎样改变画面

需要具体拍法时读[乐句与风格示例](route-examples.md)，从文字发展、人物/拼贴共演或意象长镜头选择当前乐句的主导关系。

先声后形、延迟回响、材料触感和重拍上的静点，可用[声音互动](sound-image-interaction.md)深化；实际主歌、生成声与后期责任分别记录。

选定的具体声音事件需要画面响应时，写明“声音依据 → 视觉选择 → 可读落点”与时序证据；不要求所有 Shot 都对应声音事件。不能只填 BPM、情绪和相同长度的镜头。以下是选择方法，具体时间来自实际歌曲：

| 音乐事件 | 可选择的画面响应 | 文字与剪辑关系 |
| --- | --- | --- |
| 弱起、人声入句 | 从遮挡后进入、视线抬起、镜头靠近 | 句首出现，留出读完短句的窗口；未必切镜 |
| 底鼓或低频落点 | 落脚、转身落定、空间尺度打开 | 主字压入或构图换重心，随后稳定 |
| 军鼓、拍手 | 肩背急停、机位跳切、服装甩线 | 套印偏移或字块切入，恢复清晰主层 |
| 密集高频、快速咬字 | 细小手腕/步态变化、前景掠过 | 局部纹理短促变化，避免整句高速闪烁 |
| 留白、换气、编曲抽空 | 身体停住、空镜或版式主导 | 保留可读字或撤空画面，给下一段留反差 |
| 副歌展开、重复 Hook | 景别/空间扩大、动作弧线完成 | 主字族放大或层级展开，重复按本曲意图保持或发展，不要求变化次数 |
| 尾音、最终重音 | 完成动作与最终构图 | 回收主字族/母题，读完后随尾音结束 |

叙事片段同样要说明音乐为何在此进入这一场景，避免“完整故事慢镜头 + 任意配乐”。

## 选择事件与乐句发展

从[实际歌曲时间轴](music-timeline.md)中选择改变乐句走向的事件，例如人声起口、低频与鼓组共同落下、和声或配器换层、停顿后的再进入。弱鼓点作品可由旋律上行、持续音和编曲增减组织镜头；密集作品只挑有作用的落点。在已有响应表记录事件 ID、声音依据、核对状态和选中理由，不为每个 beat 建视觉事件。分频、分轨或局部速度分析须使用实际可用工具，结果仍是待听审核对的候选；不能从全曲 RMS 猜底鼓或军鼓。

每段明确人物、场景、文字或静默留白谁主导，其他层怎样配合。按乐句安排蓄势、落点和释放：重要声音之前可收住动作、减少信息或暂留机位；到来时由一个动作完成或构图打开；随后留时间让情绪和文字读完。音量、事件密度与观众注意力分开判断，响而稀疏可用长镜头，低声但咬字密集可只变局部字层。高潮不要求所有层同时变快；有意略过重拍时说明哪一层承接或为何保持静点。

比较方案时可画镜内运动、切镜密度、字层变化或反差的相对发展曲线，辅助选择并标注声音证据与人工修订。选中的发展写回现有音乐响应和 Shot，按[生产交接](production-handoff.md)转换为过程描述与时间目标；逐帧控制的精度要求另按控制边界核实。

例如，弱鼓点且渐强的乐句可以先用人物停步和稳定主字建立可读状态，让镜头随着配器增加缓慢打开；在听审确认的再进入处完成一次转身或换景，随后让动作惯性和主字停留。若重复副歌需要发展，下一次可改变空间尺度或主导层，不必增加每拍硬切。

若要求“每 0.12 秒精确改变机位/字层、每次低频脉冲精准变焦”，保留精度目标，按 [H3 控制边界](../../h3-prompt-writing/references/control-boundaries.md)核对：H3 没有逐帧参数曲线接口。可另列主要落点与自然变化的候选，注明精度差异。精确切点、普通字幕或独立空间字层分别交已核实的承担方式，缺少能力就注明；不把简化候选当作原目标已满足，也不因此把全部生成式文字转为后期。

## 表演与空间调度

有人物表演时，按歌曲挑选路径步态、轴线转向、服装惯性、空间借力、双人换位或微表情等动作族。每镜通常围绕一个主要动作链来设计：进入路径 → 起势/重心 → 发力 → 接触或穿越 → 惯性/落点 → 镜头响应。把“酷炫舞动、手势卡点”等风格意图展开为可见过程，动作幅度随歌曲与角色调整。

例如人物沿门廊斜线走入，落脚后以肩带动半转，衣摆晚于身体扫过前景，镜头侧移接住停身；下一镜可以在同一世界的台阶改变机位与身体轴线。场景提供纵深、横向路径、高低关系或遮挡支点，不能只换背景墙。动作幅度服从歌曲和角色；抒情段可用呼吸与视线，不强塞舞蹈。

连看相邻镜头的动作族、运动方向、空间支点、机位高度和前后景关系，安排变化或有意重复。大动作后可留静点，让衣料/呼吸完成惯性，也可让文字和版式成为主角；冲镜、遮镜或匀速行走均按表达目的选择。面向镜头表演与对嘴演唱分别设计，演唱镜头写明同步要求。

## 跨镜衔接

跨镜接缝按需要写前后两端：前镜退出动作/运动方向/文字状态 → 音乐切点及原因 → 后镜进入动作/方向/文字状态；身份服装和约定光色保持一致，场景变化有音乐或表达理由。演唱特写优先在换气、停顿或可接续的位置切，若唱词中途切到另一演唱特写需有实际口型接续依据；切到不演唱的生活镜头可让主歌继续，不机械禁止所有句中切镜。调速不能自动修复唱词或多个镜内节拍的错位。生成后再依据真实出入状态选取剪辑点，计划中的匹配切不等于接缝已经成立。

## 代表乐句先验证

选择一个能代表本片路线的乐句，落实 Shot、所需文字事件、布局与执行责任。文字主导检查可读停留、变化和接缝；拼贴表演检查人物与设计的主次。在已授权生产中检查实际片段，再扩展同类镜头；独立后期路线使用其实际合成能力。

歌曲尚不可听时，先推进暂定美术与构图；待实际歌曲可用后，再核准 BPM、歌词、口型和镜内卡点。若已有授权的预览需使用候选时间，标明它的适用范围与待核实项。
