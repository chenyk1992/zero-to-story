# 实际歌曲时间轴

## 先锁交付规格与音乐窗口

沿用 MV 主计划的歌曲范围、平台、画幅与目标时长；规格依据按[共享规则](../../../../guides/ai-system-prompt.md#制作规格与判断依据)记录，不把模板的 15 秒或资料板比例当作成片规格。歌曲范围属于内容选择，按下段的用户指定或已有导演授权处理。成片画幅约束首帧、构图、文字安全区和输出；输出尺寸与帧率须可执行，不把后期缩放称为原生生成规格。

歌曲长于目标片长时，按用户时间戳或已授权导演判断选定有完整乐句的窗口，记录起止及选择依据；未授权自行选取且尚无范围时先确认，不默认截取开头。歌曲短于目标片长时记录差额，不能擅自拉伸、循环或补写；完整歌曲请求以实际采用版本为依据，精确时长请求保留其约束并解决差额。超过所选能力单次上限时按真实上限拆 Panel，不把原 Skill 的 15 秒视为所有模式的固定能力。多个试验窗口仅在用户需要变体时安排，不自动扩大生成数量。

## 实际分析与证据

时间轴绑定采用音频的路径、SHA-256、真实时长、采样率与选用窗口。Music 3 的 `max_duration` 只规定上限。所有事件时间使用原歌毫秒位置；成片位置减去窗口起点，并按输出帧率落到可实现的帧边界。

正式使用前由调用方按[采用版本核对](finishing-and-review.md#采用版本与后期交接)确认当前实际采用文件，源哈希须与其一致；用户导入歌曲使用真实选曲与听审证据。`inspect/analyze/validate` 的技术成功不验证 Canvas 采用状态；时间轴允许记录 REJECT/INCONCLUSIVE 以保留事实，不能据此把候选时间轴当作正式采用。歌曲换版后重新核对相关时序，不沿用旧版已核对标记。

听完整首或采用窗口，标出实际段落起止、人声进入与结束、歌词逐句位置、显著重拍、停顿、能量与情绪转折。节拍分析只提供候选，半速/倍速歧义和弱鼓点保留未知。逐字时间需要足够听审证据；不能按字数平摊。合唱重叠可分层记录，拖音按实际演唱处理。器乐时间轴没有歌词项目。

使用 Skill 的 `scripts/music_tools.py`：`inspect --audio SONG --start-ms START --end-ms END --output TIMELINE` 读取实际元信息；`analyze` 使用相同参数补候选；`validate --timeline TIMELINE --output CHECKED` 核对修订后的时序及源媒体。输出路径必须是新文件，工具不会覆盖素材。项目解释器可以执行 inspect/validate；analyze 需要显式选择已装 librosa 的 Python 环境，例如本机已验证的 Comfy Python，不自动安装依赖。每条段落或歌词事件使用原歌 `start_ms/end_ms`、原文或段落名及 `status=candidate|verified|unknown`；歌词可加 `layer` 区分合唱。每个 beat 使用原歌 `time_ms` 与核对状态。手工修订后再次验证媒体哈希和窗口范围；旧音频版本的已核对时间不能挪用到新版本。

镜头表使用歌曲时间段、最终成片 Shot、生成 Panel 三个不同单位。同一已定 Panel 可包含多个短 Shot；已有较长素材可按授权选段，但新生成不为短 Shot 另留时间余量再裁切，时长与音频窗口按[生产交接](production-handoff.md)核对。乐句和观众注意力比机械逐拍切镜更重要。

在创作计划另记实际 groove（平直/摇摆/切分等）、人声咬字/拖音/换气、鼓与低频的主次、编曲增减和主观能量发展，并绑定原歌位置与听审依据。将值得响应的事件编号，供动作、镜头和文字共同引用；不把每个候选 beat 都当切点。上述创作注释不擅自扩充时间轴 JSON schema。无法听审时保持候选或未知，先做不依赖精确时序的美术准备。

## 实际歌曲到来后的内部复核

从歌词/音乐创作稿转到实际歌曲，或已用歌曲换版时，主责用已有的实际采用、听审与时间轴证据核对原视觉推荐依据：歌曲的语义、人声质感、groove、编曲增减、留白与能量发展，是否仍支持所选媒介、美术与观看目标。复用有效证据，不为此增加试听生成、独立报告或用户确认；不是每个Panel重新检查一次。已有实际歌曲的新MV直接以这些事实推荐，不先按歌词想象一版声音。

原方向相容就直接继承。需要调整时，优先在已选风格内改变镜头停留、动作/字层主次、运动幅度或声音让位，保留锁定歌词、曲目和已采用美术；低能量可以有鲜明视觉身份，高能段也可以用稳定画面承接。尚未采用的视觉候选可以在原授权范围内修订，但不能把暂定依据自动写成实测或用户确认，更不能以内部复核为名替换用户已选风格。真实冲突涉及锁定项且现有依据无法协调时，沿共享规则只处理具体取舍，不重开整片风格审批；未知时序只影响依赖它的部分。

将结论合并到现有mv_plan的“整体风格采用与依据”和音乐响应/Shot：引用实际音频版本、原推荐依据仍成立的部分、局部调整或未解决冲突。采用音频是否可用、视觉方向是否沿用、镜内同步是否已验证分别说明，不新增状态枚举。再按实际时间轴更新受影响的Shot/歌词窗口、参考音频、完整H3草稿、Canvas当前投影、后期与验收重点；保留未变内容与历史快照。已定当前Panel交给H3/Canvas时直接继承这些事实，不再次索要风格批准。
