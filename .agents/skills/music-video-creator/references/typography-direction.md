# 文字导演：歌词、版式与空间

文字驱动 MV 从分镜阶段开始。先读实际歌词和人声时序，再决定文字与人物、场景如何共演；最终加几张片名或底部字幕不构成空间歌词方案。用[文字方案模板](../assets/typography_plan.template.md)保存全片系统和必要事件，纯无字项目无需建立。

## 效果基准与全片发展

用户指定 `music-video-subtitle-generator` 或要求精美、高冲击的文字 MV 时，以文字参与整幅画面的设计效果为基准。把“精美”“炸裂”写成当前作品可观察的选择，不以增加字幕数量、闪烁频率或特效种类替代设计：

- 字形与版式：按音乐和语言选择字形骨架、字重、字距、尺度与材质；歌词和重点词有清楚主次，同一视觉身份在全曲中发展。具体尺度按阅读时间与构图决定，不套英语模板的固定比例。
- 音乐冲击：挑选主要唱词、鼓点、拖音或停顿，写出触发 → 局部变化/动作落点 → 清晰恢复；冲击段与可读静点形成反差，不要求每拍变化。
- 人物与空间：逐镜决定文字、人物和摄影机的关系。可用前后景、遮挡、字腔穿越、墙面贴附或纯版式构图；左右分栏只是一个选择，不能为方便贴字长期限制人物路径与机位。
- 全片发展：开场建立文字身份，中段变化，高潮强化，结尾回收；重复副歌通过尺度、层次、机位、动作或跨镜字势产生发展。平面海报、抽象图形与实体空间均可成立，不强制所有字都立体化。

固定布局或重复动效可以服务已定表达，须说明它与音乐段落及观看目标的关系；不能仅凭逐句叠字或重复预设证明文字主视觉、空间互动已成立。具体实现按下文[执行责任](#先确定实现责任)交接；静态参考只支持构图与字形判断，动态效果须有实际片段证据。简化导致选定效果缺失时，写明差异并保留为候选，直到相关要求有实际证据或用户明确调整目标。

## 文本归属与系统

区分三类内容：准确歌词来自实际核对的演唱原文；视觉关键词来自已定歌词、片名或主题提炼，标明它不是逐字歌词；装饰碎片只能取已定字形，不填随机乱码。歌词保留原语言，不能为包装自动翻译中文。只核对到句级就按句级做，不能把均分时间写成逐字同步。

建立主字族、至多一个必要辅字族、字重/字宽/字距、颜色、材质与画幅安全区域。中文重点检查实际字体字形覆盖、复杂字笔画、横排/纵排读序；英文凝缩字的参数不能机械套到汉字。字体参考只说明字形/版式/材质，人物和场景参考单独记录。

生成式文字用可观察的字形骨架与真实图片传递，不要求 H3 安装某款字体；只有确定性文字图片或后期排字才核实实际字体文件和字符覆盖。歌词贴字与演唱同镜时，显示的歌词须对应当时演唱的原文；主题关键词可按已定创意另用，但不能标成逐字跟唱或冒充同一句歌词。

## 可选择的字体与版式方法

以下保留原模板的具体设计手段，按音乐和语言选择，不要求全部使用：

| 字形路线 | 可观察特征 | 用途与限制 |
| --- | --- | --- |
| 极粗凝缩无衬线 | 窄字宽、紧字距、平直切角、矩形字腔、厚重字块；英文可用全大写 | Hero 主字与压屏词，横压或纵拉后仍保留准确骨架 |
| 粗报刊衬线/板状衬线 | 明显衬线、粗细对比、报纸或旧海报的字面 | 编辑/报刊方向，跨纸缝或画框时先完整可读 |
| 窄体中性无衬线/等宽/手写辅字 | 选择一种辅助语气；手写保留清楚笔画和轻微基线变化 | 短歌词、边注或强调，不能堆随机小字、数字或伪 UI |

Hero 可占据较大甚至越界的画幅，动作字层使用较小尺度响应动作，歌词可沿边缘或人物轮廓排列；具体尺度由阅读时间、字数和面部保护决定。版式可选负空间孤字、纵排、横向压缩、非规则分栏、跨接缝连接、字腔挖空或前后景穿插。改变尺度/排版要服务乐句发展，不用缩放同一条字幕代替全部设计。

复古拼贴可用油墨、复印纸、半色调和硬阴影表现字面；温暖生活感等其他路线重新选择材质，不照搬厚重印刷或金属立体字。字腔穿越时写人物从哪里进入、谁遮挡谁、怎样恢复完整读字；镜像或裁切只作明确的短暂变化，准确歌词的主要阅读状态保持正常读序。

每次主文字事件写清：

- 原歌时间与核对状态、对应 Shot、准确原文、歌词/关键词/装饰类别。
- 声音触发：唱词、鼓点、拖音、停顿或段落变化；一个主要语义焦点。
- 尺度、位置与深度：前景字块、中景人物前后、背景贴附或纯版式；需要时标明透视和遮挡次序。
- 动作过程：进入 → 清晰阅读 → 声音/动作触发变化 → 遮挡或穿越 → 恢复/退场。不是每个事件都必须变形，但必须有可读窗口。
- 人物眼睛、重要表情与演唱嘴部的保护区域；动作移动后也须检查，不能只检查首帧。
- 出镜方式及下一镜如何承接同一方向、形状、颜色或字族；独立新事件也可用停顿清空。

歌词拖音时让字稳定或缓慢展开；快速歌词可分短句、让主唱词与少量关键词交替主导，不能用大量同时闪字掩盖时序缺失。副歌回归可放大同一字族和构图规则，结尾回收已经建立的视觉身份。

## 拼贴文字图层

采用 cool-music-video 路线时，在关键文字镜头设计可辨认的层次；按功能取舍，不能只把同一个字幕复制三遍：

| 层 | 职责 | 典型处理 |
| --- | --- | --- |
| A：Hero base | 稳定、可读的语义锚点 | 厚重主字、负空间孤字、海报底字 |
| B：Print plate | 建立印刷与材料关系 | 同词套印、纸面网点、跨接缝字面；服务 A 的识别 |
| C：Action / foreground | 音乐或动作触发的前景变化 | 字块扫入、撕纸边、局部压缩，随后让 A 恢复完整 |
| D：Occlusion / recovery（按需） | 组织人物穿插与可读恢复 | 肩部在字前、布料扫过字块、遮罩撤回 |

层级是创作事实，不是当前后期接口的字段。逐镜记录哪些层存在、谁在前后及哪个时刻完整可读。拼贴路线保留版式主导的停顿与高潮，不能让所有镜头退化为同一条字幕加人物走动。

## 先确定实现责任

两份原 Skill 的动态文字、拼贴、人物与文字遮挡，主要作为逐镜提示词交 H3 一同生成。项目沿用这条实现路线：先把完整效果写进生成输入，再检查实际产物。不能因为基础字幕器没有空间效果，就把原有生成任务改写成未实现的后期需求。H3 能接收这些创作要求不等于每次能准确实现，字形、动作、时序仍须实际验收。

| 目标 | 默认执行责任 | 交付边界 |
| --- | --- | --- |
| 空间歌词、定制版式、印刷字层、撕纸 | H3 生成：交准确文字、A/B/C 层关系、材质、进入/可读/变形/恢复的 Panel 内时间 | 检查实际可读原文及发展过程，不将错误生成文字当作合格素材 |
| 人物与文字前后穿插、透视关系 | H3 生成：交前后景、人物路径、遮挡顺序与表情保护区域 | 生成画面包含这种空间关系时无需另建跟踪插件；实际遮挡与稳定性仍须观看验证 |
| 跨镜文字动能 | H3 分别生成前镜退出与后镜进入；后期在主音轨上选择匹配切点 | 核对实际运动方向、字形与切点；切片不能修复已经烘焙进画面的错字 |
| 普通字幕、可关闭的字幕或明确要求独立可编辑文字 | 后期，准备干净底片、字体和已核对时间 | 现有 ASS 基础链路提供普通歌词及淡入/缩放；不替代已选择的空间歌词路线 |
| 要在已生成底片上新增/精修独立空间字层 | 另行实现确定性合成，按目标准备字形、遮罩、透视/跟踪数据 | 这才需要额外合成能力；不能把它设为所有生成式 MV 的前置依赖 |

生成式文字事件交接时必须有明确承担者：准确原文、层级与运动写入 H3 完整提示词，不能只留在导演计划中；按[生产交接](production-handoff.md)转换时间和参考，不照搬原 Skill 的提示词外壳。基础 `text_events` 只存另行后期叠加的事件，不重复覆盖 H3 已生成且通过验收的同一段歌词，也不擅自加入空间字段。

每个选定上屏事件先落实准确原文的图片参考，按[文字资产规则](visual-assets.md)区分全片样式卡与具体事件图。I2V 首帧体现第 0 秒应有的状态；需要稍后才出现、首帧中未包含的新词时，不能只写进入过程就认为图片依据已传递，应选择带该词事件图的普通 R2V、拆分有字首帧镜头或明确的独立后期方案。既不提前显示所有歌词，也不虚构 I2V 的额外图片槽。

若 H3 实际产物错字、遮挡错误或同步失败，按影响范围记录问题并沿共享规则处理修订；不能悄悄删掉文字，也不能用普通字幕掩盖已生成错误。确需后期修复时再核实修复方法及其依赖。方法迁移、输入交接可执行与实际成片通过验收分别记录，不能相互冒充。
