# 解说与知识旁白

遵守[共享生产规则](../../../guides/ai-system-prompt.md)。本 Skill 负责研究到解释性文本，既可独立交稿，也可受影视、广告、MG 或 Presenter 委托完成限定范围。当前用户只要文本时止于文本；不建画布、不生成声音或视频，也不要求视频模式、采样参数。

## 从问题与资料出发

沿用主题、受众、表达目的、已有来源、语言、目标长度与锁定口播。需要研究时按[参考研究](../zero-to-story/references/reference-research.md)核实材料，记录足以追溯的链接/文件/版本与段落。史料说法、研究共识、争议、推断和虚构重现分开；没有证据的精确数字、动机或引语不补写。资料不足时完成有依据的部分并注明具体未知，不用“据说”掩盖缺口。

广告委托只使用广告主责已提供或核实的产品事实和主张条件，不以类比、满意表情或生成演示证明功效。历史/科普重现可以提供示意，但不能称为真实影像或实验记录。

## 把信息写成观众能理解的顺序

围绕当前问题安排必要背景、过程、因果、证据与结论，按主题选择故事、比较、演示或解释。人物姓名、年代、术语和数字仅保留影响理解的部分；首次出现用简短身份/关系帮助定位。类比说清适用点与关键差异，换算记录实际依据，不能为吸引人扭曲事实。

旁白用适合角色与受众的自然表达，句长、钩子、反问和结尾按用途选择，不强制金句、快语速或一句一镜。允许完整论证、静默、画面阅读及无结论式观察。多语或地域要求按需读[语言适配](../short-drama-screenwriter/references/overseas-dialogue.md)。

目标时长先按正常读法估计并标估计；有实际配音后按真实音轨修订时序。装不下时在稿件阶段处理内容/时长取舍，锁定口播不擅改、不靠加速凑时长。中文字数不是其他语言的语速单位。

## 交付与声画衔接

可直接交可讲稿与必要来源注释；用户只要纯稿时把注释放在交接说明，不混入需朗读正文。已要求保存时使用用户位置或当前作品主源，不为文本自动创建媒体项目。

进入制作交接时按需要在现有稿件旁注明：段落/原文、事实出处、画面要解释或证明什么、证据/示意/虚构重现/文字的区分、估计或实际音频窗口，以及不能删的限定条件。旁白与画面可互补，也可为教学或无障碍需要重复关键内容；不把“字幕不能重复旁白”当禁令。

| 下游目标 | 交接方式 |
| --- | --- |
| 已定稿的副镜头 | [B-roll](../transcript-broll-planner/SKILL.md)按语义窗口规划，精确事实用证据或确定性文字 |
| 图形、流程、抽象概念动画 | [MG](../mg-voiceover-animation-generator/SKILL.md)安排视觉系统与生成/后期责任 |
| 虚拟人物出镜讲述 | [Presenter](../virtual-presenter/SKILL.md)安排角色、表演与声音 |
| 影视化历史/人物重现 | [zero-to-story](../zero-to-story/SKILL.md)持有成片主计划，区分重现与史实证据 |
| 配音 | 由成片主责把锁定文本、语言及声音要求交[Qwen TTS](../qwen3-tts/SKILL.md)，实际生成仍经 Canvas |

组合制作由用户目标对应的主责整合，专业结果返回同一主计划，不建立平行运行状态。已有实际音频时交原轨与精确窗口，文本提示不冒充音频文件。交接后更新稿件时指出受影响的配音、字幕和镜头；旧版音频不能搭配新版文字宣称同步。

文本完成只核对当前范围的事实、限定条件、解释逻辑与可说性；媒体是否可懂、字幕和声音是否同步，按下游实际输出验收，不用文稿检查代替。

方法来源与适配范围见[项目来源记录](../zero-to-story/references/source-notes.md#漫剧老李新版的选择性方法适配)；本文是项目内重写，不依赖外部 Skill 或服务。
