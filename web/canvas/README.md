# 轻量节点画布

这是 Codex 对话旁的本地视频创作画布前端。它只负责编辑节点图、保存创作配置和提交已确认的生成请求；Comfy、mmx、imagegen 等调用由同源后端与对应 Skill 处理。

## 本地运行

在本目录执行：

```powershell
npm install
npm run dev
```

默认开发地址为 `http://127.0.0.1:4178/`。前端请求同源 `/api`；开发代理或宿主应用需要把这些接口转发到画布服务。若 API 位于其他地址，可通过 `VITE_API_BASE` 设置，例如：

```powershell
$env:VITE_API_BASE = 'http://127.0.0.1:8000/api'
npm run dev
```

生产构建使用 `npm run build`，验证使用 `npm test`。

## 使用方式

- 顶部可切换“节点画布”和“镜头总览”。总览按镜头编号浏览图片、视频和分镜板，支持搜索、预览、编辑和定位原节点；切换视图不改变连线或提交生成。
- 左栏“素材”按类别查找内容，“大纲”可定位分区和所有组件。搜索无结果时可一键重置筛选。
- 左侧组件可以点击加入画布，也可以拖入画布；节点右侧的输出端口连接到目标节点的对应输入端口。
- 卡片优先展示编号、标题、实际媒体和创作摘要。预览随图片或视频的实际宽高比调整，卡片和输入区随内容增高，较长文字可在卡内滚动。预览标明素材来源，新任务失败或草稿修改时仍保留原有成品。
- 选择工具用于移动组件，抓手工具用于平移画布；也可按住空格拖动。`V` / `H` 切换工具，`F` 查看全部，`Shift+F` 定位选中，`0` 恢复 100%，`/` 查找，`?` 查看快捷键。输入文字时不会触发这些快捷键。
- 选中节点后，直接在卡片上编辑名称、完整提示词、文档正文和创作说明。文字修改会防抖保存，中文组词结束后提交完整文本；点击“完成”或画布空白处返回浏览，不再打开右侧编辑栏。
- 素材卡直接提供上传或替换入口，“路径导入”按需展开；修改路径时保留已有素材，导入成功后才替换。当前素材或成品只在卡片上方展示一次。
- 图片、视频和音频卡的参数位于“生成设置”，故事来源、关联信息和导入设置位于“更多信息”，默认收起。任务记录可展开查看当次固定输入，运行进度、失败和待处理审查仍直接显示。确认执行始终是独立操作，编辑文字不会提交生成。
- 生视频节点默认使用 Comfy。切换方式只改变节点配置，执行时才由服务端选择对应 Skill；不支持的像素预算等字段会保留并提示清空。
- 已确认的任务会固定本次快照。生成期间仍可以编辑下一版配置，最近一次成功成品会保留预览；点击预览可以打开带播放控制的大窗口。
- 版本冲突会保留当前草稿并禁止执行，避免用旧版本覆盖或提交旧值。
