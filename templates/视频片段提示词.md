# MiniMax H3 Panel 视频提示词模板（v0.9.0 双档版）

> 一张 2×3 分镜板对应一条 H3 Clip。故事板负责六镜设计和连续性账本；本模板只保留 H3 生成成片真正需要的信息。权威规则见 `.agents/skills/zero-to-story/references/h3-prompts.md`，运镜词汇见 `references/creative-assets.md` 末尾《运镜词汇与摄影动作词典》。

## 选档决策

按 [h3-prompts.md 决策表](.agents/skills/zero-to-story/references/h3-prompts.md#两档长度决策) 选档：

**任一满足选成片档：**

- 6 镜中 ≥ 3 镜含精确对白落点（>5 字台词）
- 6 镜中 ≥ 2 镜需要跨 shot 台词（J-cut / L-cut）
- 涉及至少 1 个有具体动作语义的运镜（`truck left`、`dolly in`、`crane up` 等词汇表词）
- 多模态参考 ≥ 4 个文件（图 + 视频 + 音频合计）
- 涉及 TTS 多语种场景
- 复杂声音设计（多层音效、节奏卡点）

**否则用紧凑档**（默认）。

## 紧凑档模板（300–900 字符）

```text
[时长、画幅、成片媒介、场景、光线与气质]。
【参考素材说明】
@图片 1 = [角色 A 角色卡：身份/发型/服装/关键道具不变]；
@图片 2 = [角色 B 角色卡：身份/发型/服装/关键道具不变]；
@图片 3 = [Panel N 黑白分镜：仅参考构图/空间/动作链/节奏，不采用线稿画风]。

【核心创意】
[主体] 在 [地点] 做 [事件]；[题材/风格]。
[P002 起：承接上一段最小可见末态——主体位置/朝向/关键道具/仍在变化的动作。]

【画面过程说明（压缩为一段）】
[按分镜从左上到右下，用单一因果叙述写完六格核心动作和结尾状态；一句运镜与节奏总括。]

【声音与禁项】
[对白（如有）]；环境声 [列出]；动作声 [列出]；
非叙事性音乐：N/A，不要可读文字。[只列当前段最可能失败的 3–6 项]。
```

### 紧凑档使用规则

- 把三段公式压成 1 段自然段，但**段内顺序仍按 3 段公式**
- 6 镜动作链用单一因果叙述串起来，不写"shot 1... shot 2..."
- 运镜只写一句话总括（"从动作特写急推到中近景"），不展开成 shot 级别词汇
- 声音只列总类（"环境声、动作声"），不展开具体音效
- 默认无 BGM；末句固定写 `非叙事性音乐：N/A`

## 成片档模板（1.5–3KB）

```text
【参考素材说明】
@图片 1 = [角色 A 角色卡：身份、发型、体型、服装、关键道具保持不变]
@图片 2 = [角色 B 角色卡：身份、发型、服装、关键道具保持不变]
@图片 3 = [Panel N 黑白分镜：仅参考构图、空间关系、动作链与节奏，不采用线稿画风]
[如有末帧、视频参考、音频参考，顺延编号；每张图/视频/音频都写明"是 XX 参考"]
[模式说明：当前为多模态参考 / 图生视频（首/尾帧或首尾帧） / 纯文生]

【核心创意】
[主体] 在 [地点]，做 [事件]；[题材/风格，如：3D 渲染都市悬疑、电影感、克制超自然]。
[画幅]、[光线]、[整体气质]。[运镜风格总述：开场 wide → medium close-up → extreme close-up + 慢动作；切镜以 cut 为主，结尾叠化]。
[P002 起：承接上一段最小可见末态：主体位置/朝向/关键道具/仍在变化的动作。]

【画面过程说明】
S1（0–1.7s）— [景别]，[运镜词汇]：[主体位置/朝向/空间关系]，[具体动作]。[台词（如有）]。[声音：环境声/动作声/音效]。
S2（1.7–3.3s）— [景别]，[运镜词汇]：[...]。
S3（3.3–5.0s）— [景别]，[运镜词汇]：[...]。
S4（5.0–6.7s）— [景别]，[运镜词汇]：[...]。
S5（6.7–8.3s）— [景别]，[运镜词汇]：[...]。
S6（8.3–10s）— [景别]，[运镜词汇]：[末态锁定：下一段依赖时写清可见末态]。

【声音与禁项】
对白：[列出，含角色名 + 完整台词；跨 shot 台词写明"接着上镜继续"或"画外音起"]。
环境声：[列出]。
动作声：[列出]。
非叙事性音乐：N/A，不要可读文字，不要 [当前段最可能失败 3-6 项负面约束]。
```

### 成片档使用规则

- 三段分明、自然段分隔（用【】标头）
- 每个 shot 5 要素（景别/运镜/动作/台词/声音）尽量齐全
- 时间戳是按 24 FPS 切分的近似分段（10s/6 镜 ≈ 1.67s/镜），不是毫秒级精确
- 运镜从 [运镜词汇表](.agents/skills/zero-to-story/references/creative-assets.md#运镜词汇与摄影动作词典) 选词，不用"手持微晃""跟拍"等泛词
- 跨 shot 台词：在镜头 S_n 末尾写"接着上镜继续"或在 S_n+1 开头写"承接上镜画外音"
- 台词字数对齐 shot 时长：每 shot 内台词字数 ≤ shot 秒数 × 4（中文）

## 运镜词汇速查（详见 references/creative-assets.md 末尾）

| 词汇 | 含义 | 典型场景 |
|---|---|---|
| `固定` | 摄影机不动 | 静态人物对话、关键帧 |
| `handheld shake` | 手持微晃 | 纪实、紧迫、跟拍 |
| `dolly in/out` | 推/拉 | 逼近主体或拉远 |
| `push-in` / `pull-out` | 跟推/跟拉 | 跟运动中同步推近 |
| `truck left/right` | 水平平移 | 侧向跟主体、扫视 |
| `pan left/right` | 水平摇 | 揭示空间 |
| `tilt up/down` | 俯仰 | 揭示高度 |
| `pedestal up/down` | 整体升降 | 改变视平线 |
| `zoom in/out` | 变焦 | 廉价感慎用 |
| `crane up/down` | 摇臂 | 大范围升降 |
| `环绕` | 围绕主体旋转 | **必须写明** `truck left + pan right` 或反之 |

## 三种生成模式速选

| 模式 | 何时选 | 关键写法 |
|---|---|---|
| 多模态参考 | 上传人物图+动作视频+场景图+音乐组合 | 每个素材写 `@X = YY 参考`；混合 ≤ 12 文件 |
| 图生视频（首/尾帧） | 只传 1 张图作首/尾 | 明确写"首帧参考"或"尾帧参考" |
| 图生视频（首尾帧） | 传 2 张图 | 写清首帧+尾帧；H3 不自动加切镜只补过渡 |
| 纯文生 | 不依赖参考 | 用"大全景 + 中景 + 特写"分层写；主体外观、场景细节、动作都要写清 |

## 完档前检查

- [ ] 已按决策表选好档位（紧凑档 ≤ 900 字符；成片档 1.5–3KB）
- [ ] 图片编号与 LFO 固定槽位一致
- [ ] 分镜板用途明确为构图、空间、动作链与节奏参考，不继承黑白线稿
- [ ] 六格关键动作完整、顺序正确，没有新增剧情
- [ ] P002 起与上一段可见末态连贯
- [ ] 紧凑档：1 段自然段、内部仍按 3 段公式顺序
- [ ] 成片档：3 段分明，【参考素材说明】【核心创意】【画面过程说明】结构清晰
- [ ] 运镜从词汇表选词，无"手持微晃""跟拍"等泛词
- [ ] 跨 shot 台词明确写明"接着上镜继续"或"画外音起"
- [ ] 末句固定 `非叙事性音乐：N/A`
- [ ] 提示词总字数 ≤ 7000 字符
