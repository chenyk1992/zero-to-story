### 阶段说明

**起势期（1-3 集）**
- 节奏：中速启动，快速建立人物和矛盾
- 核心：兄弟同时牺牲 / 暗恋曝光 / 错题集告白
- 情绪：1 → 3

**攀升期（4-6 集）**
- 节奏：波浪式递进，反派登场
- 核心：学霸张浩打压 / 模考危机 / 林小溪妈妈病情
- 情绪：3 → 4

**风暴期（7-9 集）**
- 节奏：密集冲突，抉择
- 核心：陈星河告别 / 100 天承诺 / 最后模考
- 情绪：4 → 4.5

**决胜期（10 集）**
- 节奏：全面加速，大结局 + 彩蛋
- 核心：高考日 / 志愿揭晓 / 100 天后婚礼梗
- 情绪：4.5 → 5（峰值）
